## 原创试片

`school_injection.txt` 对已存在的策略标识符只声明学校字段的条件加数。试片依赖引擎保留默认值、活动策略、其他机构及候选比较。

候选条件是国家 ROOT 为 AI，精确现行公校法且有实际学校，识字率在 `[0, 0.5)`，至少一处有人口的并入州，本国净官僚大于零、未违约且当前净收入为正。学校与法件读点分别见原版 `movement_values.txt:92–98` 和 `01_education_system.txt:367`。识字率的国家消费者在 `01_admin_strategies.txt:79–89`，州人口可见于 `00_default_strategy.txt:6312`。预算读点采用 3.4.0 已使用的 `bureaucracy`、`in_default` 和 `net_total_income`。这些余额条件只约束试验增量。学校这一档的实际边际 BUR、原版上限和将来财政支出须另读。只有缺口缓解带来的直接识字增长可独立于通用教育收益时，+0.25 的候选理由才成立。此分值是待校准的试验幅度。

| 纯原版 | 10，活动策略分数另加。 |
| `neutral` | 所有条件组合均为 10。和原版比较可查初值或兄弟项被覆盖。 |
| `diagnostic` | 条件全成立时 10010，否则 10。极端分值仅用来查消费者是否能改变实际选择。 |

合成手填结果与 ZIP 的真实 PDX AST 独立核对。财务违约且行政充足、财政宽裕且行政不足、净官僚恰好为零、识字率恰好 0.5、空人口州、仅未并入州、玩家及缺失 ROOT 都只得到零新增值。正净官僚再小也可满足软偏好测试，实际原版资格仍需独立通过。学校字段未证明分相位可写。若原版在降档方向也读取它，候选同样可能影响维持学校，须分别验收。

## 冻结及本机复现

从工作树根目录用 CPython 3.15.2 的仓库解释器运行。若复用其他工作树的虚拟环境，需将 `PYTHONPATH` 指向当前工作树的 `src`。生成工具只读取明确指定的安装根及其六个身份来源，要求原版默认策略的字节和学校形状都匹配。在独立的新目录落盘三个 ZIP 和关联清单。每包只有自有元数据和单个注入文件，ZIP 配置单独用于本地诊断。

~~~powershell
python -B -X utf8 -m tools.probes.d13_school_investment.build --installation '<当前 Victoria 3 安装根>' --output-dir 'tools/out/d13-school-investment'
python -B -X utf8 -m pytest -o addopts= -p no:cacheprovider -n 2 -q tools/probes/d13_school_investment/test_school_investment.py
~~~

## 最小实机判读

1. 运行同一构建、同一玩法 DLC 和模式。为纯原版、三个试片、3.4.0 分别准备单独的本地 playset 与用户目录。每个试片 ZIP 解压到独立的 Mod 目录。仅启用当次组，记录启动日志、实际启用、游戏校验和和 ZIP 摘要。先验加载、日志、同包保存与重载。以同一父存档在暂停时分叉，读档后确保目标国仍由 AI 管理机构，观察玩家保留在同一个其他国家。若起点跨包读档会改变决策条件，该档只作定位，改用各组相同条件的新局并登记不同种子。
2. 用梅克伦堡旧窗口校验同一机构的目标和兑现。优先从 NET 30 或 POR 31 找实际可竞争的公校和其他机构，TAS 可补学校与殖民的竞争线索。选择前核本国实际法、学校当前档、目标空置、当期上限及另一机构可达档，记录活动策略、国家层评分的已知读点和同窗零动作。核当下 GDP 的周口径、有效机构计数、当前总机构 BUR、本档边际 BUR、当前实际官僚产用余额、违约状态、当期净收入和并入州人口。界面取样可通过同档的暂停副本切国，只读完成后回到原 AI 分支。
3. 先单测原版 GDP 规则。固定机构法、等级、候选和单位成本，在原版标注的升档上限两侧及临界附近取不同周 GDP 样本，行政余额均充足。然后固定处于该上限以内的机会，比较实际官僚余额充足、为零、不足，并另记余额虽为正却小于边际档开支的情形。用行政产出造成自然对照时，同时核 GDP、其他支出和合法选项仍可比。只有同一调度评价的实际拒绝理由或在有界窗口内可复现的条件反转，才能核实独立官僚门。存档缓存仅定位时窗，短窗无目标仍登记未知。另取达到原版下档条件、有两个已投资机构可降的样本，回读学校分数是否参与相反方向。
4. 先对比原版和中性组的学校、兄弟机构与其它默认字段的实际读点和选择。再走中性与高增量配对，要求同一含学校和另一机构的可行窗口，观察首个学校目标、另一机构目标或维持。只有一项变化的重复配对可为采纳提供证据。若没有分值接口，只观察到目标翻转时保留默认初值、兄弟项和确切运算顺序待证。若出现字段拒绝、覆盖兄弟、初值漂移或重复叠加，停止采用当前写法。高增量不能替 +0.25 作成效凭据。做 +0.25 的相同条件重复配对，并与正式 3.4.0 的产品基准对照。
5. 固定学校档位，分别覆盖当前无学校、学校已到上限、现行教会及私校、寺子屋、财政违约、行政不足、已有升级目标、玩家接管及任何可证的玩家委托。原版玩家组检查仍可操作且容量拒绝一致。记录目标国公私施工与投资池路径、委托状态、实际决策者和适用资格。两类主体的自然选择和存档接管需分别回读。若评估同时由委托管理调用，结合玩家 `is_ai = no` 负控确认增量为零。
6. 先从日档或同一日内时点取得首次 `target`、原投资档和进度，再到周结算回查 BUR 入账。继续跟到实际升档或撤回、并入州与未并入州的教育可及性及实际识字变化。默认从 0 进度走完一级约需 358 天，按每个样本的实际进程调整结束日期。实际资格变化、纸张、行政工资及学校覆盖分别登记。U 另用固定包、多局和可比窗口记录学校目标、兑现速度、识字、职业资格、机关成本和被推迟的其他机构，并计算配对差及不确定性。
