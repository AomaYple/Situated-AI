## 原创判断与冻结载荷

比较普通生产项目继续投入和延后投入。B 需要由 AI 控制且与 ROOT 同一国家，有正信用，债务比例严格在 0 与 0.4 之间，本国固定净收入为负、总净收入为正。满足时给现有农业卡贡献 `−0.10`，意思是短期好看的总收支无法单独支撑追加产出投资。其余条件取增量零。该试验值在现行 ±0.25 合成限内。政策价值仍取决于项目等待代价、到期承诺和真实预算门。固定与总净收入目前只构成当期分歧信号，不能证明其净差是一次性到账、发生在哪个账期、支出是否已经计入或原版是否已经处理。任何这些口径影响选择的地方，等候本国同窗证据。无正信用、缺观察、两种收入同号、债务比例等边、不同国家和玩家控制均纳入反例。原版根据自己的资格与调度裁决实际执行。 [开发原则](../../../docs/principles/Mod开发原则.md) · [合成上限](../../../mod/decisions/actions.toml)

## 实机配对和停止点

1. 只读快照来自 `%USERPROFILE%/.codex/evidence/situated-ai/3.4.0/fixed/sa-police-loop/replay-vanilla/checkpoints/`。起点 `1836.12.1.v3` SHA-256 `69558fbb278d8635c7176fe91cd5ee3cf99292dbf11e10c664a20b2b2281d18d`。样本实际标签 MNL、国家 399、AI 行 394、州 828、项目 `building_fishing_wharf`、队列资金身份国家 399。同一玩家国家为法国 5，MNL 活动策略为农业扩张、保守议程和附属维持自治。起点项目剩余 196.40675、速度 5.35078、档案本金／信用约 0.378814。原版记录 `1837.1.1.v3` SHA-256 `ac9b1fa6637b87312d72ae72f37b6264b4e5a1d45533a2425bfe4821218263c3`，同项目余 185.69864、未写速度，国家写出 `construction_paused=yes`，档案比率约 0.418151。档案中的周收支缓存由 −3020.09460 到 +213.64713。这两档提供窗口，不能确定 B 的触发条件或原版第一次比较。
2. 从相同存档副本用纯原版和 A 分别跑到首个可读的公共建造预算机会，并记录指定渔场的首个进度变化或停止、用途、政府付款、队列来源及原版资格。读当时实际参与的策略、农业卡的既有评价及供给等兄弟属性，并比较其他两张活动卡。A 在字段、兄弟属性或项目选择上与原版出现无法解释的差异时停止解释 B。
3. 先在单独的观察分支从暂停帧运行 `effect c:MNL = { sitai_d01_observe_budget = yes }`，回查游戏退出后的调试日志。该观察只印证当前国家作用域的触发器，策略实际调用另取证。若 A 与纯原版等同而 B 的同窗财政读点未同时成立，可用校准组从同一副本定位原版对字段的响应。校准值若进入组合后仍未区分案件，缩小到可辨识的近门入队和实际付款；暂停、恢复、入队各单独标注。通常先看两个周结算，仍未见机会则按日推进至 1837.1.1。随后这个月档可作已达到上限的负对照。
4. B 需要同一个真实机会的 A 与 B，读决策前的有效条件、分量变化、首次原版选择及一至两次周结算的累计施工产出、净付款、信用和政府侧支出。出现一次性与持续来源的对照时，核对到期和未来支付、市场供需、施工可用能力和项目前值，并记相关来源独立变化。加入两个负控窗口，分别为已达 0.4 和有私人排队但无本国公共候选。能构造关键工程、舰船和玩家接管窗口时，按独立比较复查同国状态和作用是否溢出。原决策的执行资格与有价值项目被延缓的代价均需登记。
5. 每组另外留 Mod 摘要、实际挂载、游戏校验和、起点与相邻存档摘要、调度时点、字段实值和观察渠道。没有字段实值时，干净日志加同档分支的首个行为分歧只能证明对应情境的样本差异。两个周结算约 15–30 分钟人工采样，完整月窗另计。两个应用生命周期之间确认上个进程退出。各组独立装载，排程与涉及 AI 策略的其他探针分开。
