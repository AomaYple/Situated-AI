## §0 这一页回答什么、不回答什么

**回答**：9 份档案的 `why` 里「原版 **N 处 / N 条 / N 张 / 共 N**」这类**正计数断言**，逐条现读是多少、与原话是否相符、范围与计数规则写没写清。

**不回答**：

* 否定式断言（「原版没有…」「搜不到…」）—— 那批由 `t102` 的判据页与 `t104` 的修复轮处理，本卡不重做（`nonGoals`）。

import re, sys, collections; sys.path.insert(0, "tools")
from pdx import config
def dist(token, rel, norm=False):
    key = re.compile(r"^\s*([A-Za-z_][A-Za-z0-9_]*)\s*=\s*(.*?)\s*$")
    out = collections.Counter()
    for path in sorted((config.GAME / rel).rglob("*.txt")):
        for line in path.read_text(encoding="utf-8-sig", errors="replace").splitlines():
            m = key.match(line.split("#", 1)[0])
            if m and m.group(1) == token:
                v = m.group(2)
                out["%g" % float(v) if norm and v.replace(".", "").replace("-", "").isdigit() else v] += 1
    return sum(out.values()), out.most_common(12)
print(dist("country_law_enactment_success_add", "common", norm=True))
print(dist("country_aristocrats_pol_str_mult", "common/static_modifiers"))
