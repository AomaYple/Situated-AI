# `en/` —— 英文界面（`-language=l_english`）的模板

与 `../zh/` **同名同结构**，只是文字换成英文（"Situations (difficulty)" / "History-friendly" /
"Even-handed" / "Ruthless" / "Russia" …）。口径 §4.2 要求**正例 + 负对照成对**：
中文会话里中文模板命中**且英文模板不命中**，英文会话反之 —— 所以两套必须分开收、分开存。

⚠️ **本目录现在为空**：英文会话要单独起一局（`--lang l_english`），首跑同样先 `--recon`。
