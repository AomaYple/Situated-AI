# A2 阶段静态证据

本目录持久保存当前架构阶段收据所引用的原始产物及引用迁移副本；它不是生产 Mod 内容，不进入标准发布包。
入口为[架构阶段收据](../../../docs/design/exec/架构阶段收据.json)及[阶段结果](../../../docs/design/exec/架构重设计-结果.md)。

- `raw/` 保留实际命令、测试、审计和交付产物的原始内容；文件名按原始内容 SHA-256 寻址。
- JSON 使用确定性 gzip 封装，解压后保留原始字节；进程 stdout/stderr 使用 `.bin` 保存原始编码和换行，不进行文本规范化。
- Steam 公开页面的原始 HTML 保留抓取字节，包括网页自身的空白；Git 按原样证据保存，不对其作文本规范化。
- ZIP、wheel 和校验文件保留原始文件名，父目录为内容 SHA-256；发布文件名也是交付身份的一部分。
- `derived/` 仅保存将临时路径迁移到本目录后产生的 JSON；原始报告仍保留在 `raw/`，不能用迁移副本冒充原始输出。

每个收据引用均包含路径和实际存储内容的 SHA-256。使用贡献流程中的 `situated_closeout.py` 严格核对；
原始内容、引用迁移和静态验收不证明长期游戏行为、平衡或实际游戏性能。不得手改证据内容来消除失败。
