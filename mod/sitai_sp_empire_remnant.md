| goal | `je_sitai_sp_empire_remnant_window_goal` | 第一行 = **当前目标**。写「把这个国家重新拼起来」而不是点名某条法律：改哪条法由 AI 与原版牌池决定（§0「让 AI 自己推导」），而这正是 01a §K 给西班牙推出的最优解原文「**保住残存帝国 + 内部整合**」（docs/design/01a-依据与参考.md:279）里那半句「内部整合」。这一行与 `[pressure.effects]` 里减教会的那一条是同一个因果的两端。 |
| pressure | `je_sitai_sp_empire_remnant_window_pressure` | 第二行 = **最大压力与阻力**。压力项与 `[pressure.effects]` 的四条字段一一对应（合法性 / 教会 / 军队 / 借债），并且**按本档案的判据把两类东西分开写**：前三条是**内战**的（王位之争、卖教产、军队坐大），最后一条是**帝国残骸**的（没有帝国收入只能借贵钱）—— 这一行是玩家唯一能读到这条区分的地方，所以两句都要在。阻力项与 `complete = { legitimacy >= 75 }` 是同一条判据的两种说法 —— 数值改了这行也要改（P9：一处改、三处同步）。 |
| last_change | `je_sitai_sp_empire_remnant_window_last_change` | 第三行 = **上次改主意的原因**（G3 里最容易被跳过、却最关键的一行）：没有它，玩家只能看到「它在改革」，看不到「**为什么是现在**」。与既有六份的区别正在这里：ru/tr 的起点是「外部打进来」，au 是「内部裂开」，cn 是「被人撬开门」，eg 是「钱不是自己的了」，pe 是「被两边夹着」—— 本档案的起点是「**帝国已经没了，本土还在为谁来当国王打仗**」，玩家从这一行读得出因果链的起点。 |

> 为什么拆成三个键而不是揉进 `_reason`：G3 判的是**试玩者能复述**「当前目标 + 主因」，揉在一起就分不清是哪一行没写清楚。缺行当场可见。
