## 面板三行（P11 / G3）

| 行 | 本地化键 | 为什么是这一行 |
|---|---|---|
| goal | `je_sitai_pe_great_game_window_goal` | 第一行 = **当前目标**。写「推过去」而不是点名某条法律：改哪条法由 AI 与原版牌池决定，本档案不替它选（§0「让 AI 自己推导」）。用「**有限**现代化」这个词是有判据的：`01a` §K 给波斯推出的最优解原文就是「在两大国之间求存 + 有限现代化」（docs/design/01a-依据与参考.md:293）—— 不是全盘维新，所以这一行不能写成「完成现代化」。这一行与 `[pressure.effects]` 里减教士的那一条是同一个因果的两端。 |
| pressure | `je_sitai_pe_great_game_window_pressure` | 第二行 = **最大压力与阻力**。压力项与 `[pressure.effects]` 的三条字段一一对应（合法性 / 利率 / 教士），并且**按本档案的判据把两种东西分开了**：合法性是「夹击的直接后果」，高息外债是「求存必须付出的代价」—— 这一行是玩家唯一能读到这条区分的地方，所以两句都要在。阻力项与 `complete = { legitimacy >= 75 }` 是同一条判据的两种说法 —— 数值改了这行也要改（P9：一处改、三处同步）。 |
| last_change | `je_sitai_pe_great_game_window_last_change` | 第三行 = **上次改主意的原因**（G3 里最容易被跳过、却最关键的一行）：没有它，玩家只能看到「它在改革」，看不到「**为什么是现在**」。本档案的这一行与 ru/tr 有一处刻意的差别：写「**这场漫长的**夹击」而不是「这一仗」—— 「没有那个可以指出来的时刻」正是本处境与战败、与列强干涉的分界（见 `[memory].why`），玩家应当从这一行读得出来。 |

> 为什么拆成三个键而不是揉进 `_reason`：G3 判的是**试玩者能复述**「当前目标 + 主因」，揉在一起就分不清是哪一行没写清楚。缺行当场可见。
