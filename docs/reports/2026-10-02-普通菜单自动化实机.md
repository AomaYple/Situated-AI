# 普通主菜单自动化实机报告

日期：2026-10-02  
平台：Windows 本机实测  
游戏：Victoria 3 1.14.5  
界面：简体中文，默认 1920×1080 窗口布局

## 目的

验证没有 `-scripted_tests` 时，自动化是否能从普通主菜单完成：

新游戏 → 开始游戏 → 观察 → 速度 5 → 空格解除暂停 → 切回后台。

这条路径用于制作 mod 时的实机冒烟测试；官方 `-scripted_tests` 流程仍由游戏负责开局、存读档和套件判定，`game_auto` 只负责补齐必须的人机交互和后台推进验证。

## 实际命令

在仓库根目录执行：

```cmd
.venv\Scripts\python.exe -m pdx.game_auto run --no-scripted-tests --lobby-timeout 300
```

运行前通过 `python -m pdx.game_auto check` 确认没有其它 Victoria 3 进程。运行结束后通过 `game_auto.kill_game()` 清理本次游戏进程；最终进程数为 0。

## 三次尝试

1. 第一次运行成功启动游戏，但在 180 秒后超时。日志显示 CLI 传入的 `--lobby-timeout 300` 被内部硬编码的 180 秒覆盖；修复为把调用方的 `lobby_timeout` 原样传入 `start_session`。
2. 第二次运行识别并点击了普通主菜单的「新游戏」，进入「目标」设置页，但旧流程只等待「观察」按钮，没有处理设置页的「开始游戏」；补充第二个模板和状态步骤。
3. 第三次运行完整通过，形成下列证据链：
   - 识别并点击「新游戏」；
   - 识别并点击「开始游戏」；
   - 在国家/观察者界面识别并点击「观察」；
   - 速度模板定位成功，尝试 2 次后达到约 3.555 天/秒，`speed_ok=True`；
   - 按空格开始推进；
   - 恢复前台并完成截图验证，然后最小化窗口；
   - 运行返回码为 0，后台验证通过。

## 当前结论

Windows 简体中文界面的普通菜单路径已经实机通过，自动化现在支持两条入口：

- 带 `-scripted_tests`：等待官方套件进入国家界面，再点击「观察」；
- 不带 `-scripted_tests`：按「新游戏 → 开始游戏 → 观察」回落路径进入观察者局。

这份报告只证明 Windows、Victoria 3 1.14.5、简体中文界面的短时闭环。macOS/Linux 的真实 Victoria 3 GUI 没有实机证据；英文 UI、长期无人值守数小时、完整游戏年限压力测试也仍未验证，不能从本次成功外推。
