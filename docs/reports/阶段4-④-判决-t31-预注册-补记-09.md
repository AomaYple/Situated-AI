## 1. 目标与停止规则

### 1.1 目标

- **目标 = 让判决「可判」**（`U(n) ≤ 0.5`），**不是**保证「达标」。三支互斥（预注册 §2⑤）：`U ≤ 0.5` 且 `|Δ̂|+U ≤ 0.5` = 可判·达标；`U ≤ 0.5` 且 `|Δ̂|+U > 0.5` = 可判·超预算；`U > 0.5` = 未判决。
- 依据现读数（n=15：`Δ̂ = +0.162178`、`s_d = 0.865498`）：`U(15) = 0.479297 ≤ 0.5`（已可判·超预算）。要落**达标**支，需要 `U(n) ≤ 0.5 − |Δ̂| = 0.337822`；按同一 `s_d` 与同一 `t_{0.975,n−1}` 精确解 ⇒ **n = 28**（`U(27) = 0.34237 > 0.337822`，`U(28) = 0.33561 ≤ 0.337822`）。
- 因此本轮 = `--repeat 13`（13 对 / 26 局），把总对数从 15 提到 **28**。**跑的动机是可判性，不是方向** —— 延伸后可能是三支中的任何一支，报告照实写。

### 1.2 停止规则（钉死）

1. **到 n = 28 就停**，按冻结公式出**一个**判决（达标 / 超预算 / 仍不可判），**不许再自动加对**。若 `U(28) > 0.5`，报「未判决」+ 新的最小 n + 还差多少机器时间，**停在 28**，是否继续由队长裁决（那将是**新的预注册**，不是本件的自动延伸）。
2. **不做中间读数决定（no peeking）**：跑动期间不因中间结果停手、加对、换对、改判据。只允许因下列情形中断：① 闸不过 / 机器锁被破；② 失败签名（见 1.3）；③ 队长指令。
3. **判据侧零改动**：如果本轮结束需要报「仍不可判」，就报「仍不可判」——不许为了让结果可判而调阈值、换估计量或挑样本（预注册 §2⑥ 原文）。
4. 判决必须**逐对可核**：13 对的原始 CSV、逐对记账、逐臂归档、仪器修订分栏全部落盘后才出判决。

### 3.1 证据（跑前已算，见 §7 证据件；输入 = 30 份臂 CSV）

- 两处修订的差别是**记账 / 隔离 / 公告路径**（B114：`_announce`、`_quarantine_logs(*, stamp, announce)`、`_as_str_list`、`_report_scan`、`stress_control_verdict` 与 `run_once` 的调用点），**不在被测量路径、也不在聚合路径**（补记 07 逐行论证 + 补记 08 §3）。⇒ 该改动对两臂**对称**，不会只作用到某一臂。
- **段间台阶只出现在 vanilla 臂**（Welch，A+B = slots 1–11 vs C = slots 12–15）：

| --- | --- | --- | --- | --- | --- |
| `delta_ai`（判决量配对差，ms/帧） | +0.390242 | −0.465000 | −0.855242 | 0.371789 | −2.300 |

- **同一修订内部本来就有单臂漂移**：inv1（slots 1–4，42149 B）→ inv2（5–11，42149 B）时 `ours_frame` 从 29.6853 涨到 30.4099（+0.72 ms），而 `vanilla_frame` 只从 28.9907 到 29.1178（+0.13 ms）；段内 `delta_ai` 从 +0.188333（`s_d = 0.856675`）到 +0.505619（`s_d = 0.916817`）。⇒ **单臂漂移在单一修订下已经存在**，不是新修订带来的新现象。

### 3.2 我的建议：(a)

三条理由：

1. **对称性论证 + 经验证据都指向「台阶不是修订造成的」**（§3.1 前两条）：改动的路径在测量之外，且观察到的台阶是单臂的；同一修订内部已有同类单臂漂移。
2. **(b) 花 ≈5.7 h 换不到更稳的判决**：inv3 段那 3.1 ms/帧的**单臂**漂移比整条 0.5 ms 预算大 6 倍（判决量级 0.35–0.9 ms 也只是漂移的 1/4–1/9）⇒ 噪声主因是「段 × 臂」的绝对水平漂移，重跑 15 对只是**换一个段**，噪声结构不变；同时多出「旧 15 对 @42,149 作历史 + 新 28 对 @42,895」两套分栏，反而增加解释面。

**采纳 (a) 的对冲要求（写进判决措辞，见 §4.3）**：新 13 对跑完后，用 §7 的同一套诊断脚本（输入扩到 28 对）重算段间/臂间漂移，把「新段是否再次出现单臂台阶」写成报告里的**描述性证据**；若再现，判决措辞必须显式带模型风险限定。

## 4. 方差缩减：预先声明的副量（不进判决）

### 4.1 不变的主口径

主判决**只**用冻结口径：`Δ_i = M_AI(W_i)^ours − M_AI(W_i)^vanilla`（同一 `--repeat` 序号）、`s_d`（ddof = 1）、`U(n) = t_{0.975, n−1}·s_d/√n`、阈值 0.5 ms/帧、§5 五条作废规则。副量**不进判决、不换估计量、不改判据**。

### 4.2 预声明两条副量（只作用于新 13 对）

- **副量-1「噪声分解」（控制变量）**：控制变量 `X_i` = 该对 **vanilla 臂自身的 `M_AI(W)` 绝对量**（ms/帧）。报告：`ρ(X_i, Δ_i)`、`β = Σ(Δ_i−Δ̄)(X_i−X̄) / Σ(X_i−X̄)²`、`s_d_resid = s_d·√(1 − ρ²)`，以及「若按 `s_d_resid` 反算需要多少对」的**建议性**数字（明确标注「建议，不是判决」）。
- **副量-2「相对效应」**：`r_i = M_AI(W_i)^ours / M_AI(W_i)^vanilla`，报告均值及其与 1 的偏离区间（描述性，量纲为比值）。
- **判读规则（预先钉死）**：`|ρ| < 0.30` ⇒ 副量-1 记为「**无信息**」，只登记不解读；副量-2 恒为描述性。**跑完不许追加/替换副量**。
- **范围**：只算新 13 对（slots 16–28）；**不回头重算旧 15 对**。旧 15 对的同类数字只作**本文件落盘前已存在**的参照（下表），不构成对新数据的分析。
