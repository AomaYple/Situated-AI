## §6 滚动/滚轮的真相（最小实验，一处一处量）

同一会话、游戏**暂停**、同一次光标停靠纪律，两帧之间算「区域灰度平均绝对差」（0~255，越小越像）：

| 做的动作 | 量哪块 | mean\|Δ\| |
|---|---|---|
| **什么都不做**，只等 1.2 s | 地图区 (200,700)-(1200,1000) | **0.719**（噪声底） |
| 滚轮 ×3 打地图中央 (700,850) | 地图区 | **12.374** ⇒ **滚轮真的到了引擎** |
| 滚轮 ×5 打「修正」小框 (350,950) | 修正框 (115,890)-(600,1015) | **0.681** ≈ 噪声 |
| 拖「修正」小框右缘 (600,1012)→(600,888) | 修正框 | **0.681** ≈ 噪声 |
| 拖「修正」小框内部 (350,1005)→(350,895) | 修正框 | **0.0**（逐像素相同） |

- 帧：`t33-ctl-00-idle-a.png`（3,093,724 B / `53bb8423a902d37c…`）、
  `t33-ctl-01-idle-b.png`（3,092,956 B / `3acbc6000014d363…`）、
  `t33-ctl-02-map-wheel.png`（3,099,230 B / `8aabf1b027159c33…`）、
  合图 `t33-scroll-compare.png`（1,123,415 B / `e2ddf07a3d463ada…`）。
- **结论**：上一局「注入滚轮 no-op、拖滚动条也没滚出更多行」**不是设备问题**（同一会话里滚轮打地图
  有 12.374 的变化，比噪声底高 17 倍），也**不是坐标问题**（框内部与右缘都试过）——
  **那个小框本身只显示前 2 行、没有可滚动的多余内容**（框里也看不到轨道/滑块）。
  ⇒ 面②的「没看到」曾经是**归因 ②**，而**正解是换面板**（§3 的修正页签）。

## §7 合法性读数那格：为什么判不出 −20/−15，以及下一次怎么判

现读链（全部有帧或日志出处）：

| 时刻 | 合法性 | 出处 |
|---|---|---|
| 投降前（1837.5.11 前后） | **100** | `t33-05-left-column.png`（655,504 B / `e58ee548c4b25ed0…`）左栏「合法性：100」 |
| 投降后首月脉冲 `2月12, 1839` | **74** | `debug.log` 的 `ZZPROBE T5;F;LEGV;74` |
| `4月13, 1839`（并面板现读） | **73** | `ZZPROBE T5;F;LEGV;73` + 国家面板左栏「合法性：73」 |

差值 **−26 / −27**，而我们两条修正的合法性项合计是 **−35**
（基线 `country_legitimacy_base_add = -20` + 叠加档 `-15`）。所以**这一次仍然判不出来**，原因是三个叠加：

1. 和约**强制执行了「俄罗斯发生政权更迭」**（帧 `t33-13-after-yes.png`；修正页签里另有一行
   「被迫进行政权更迭 4年」）—— 强制改政体本身会重设合法性、新政府还有自己的合法性目标与月度变化；
2. 面板只给**净数**与**聚合项**（「修正条目」是聚合值，不按来源拆），没有逐条 delta；
3. 投降确认落在游戏日 **2.1**，而月度脉冲在 **12 日** —— 中间 11 天里别的效果也在同窗生效。

**给 t8/t15 的最小条件（下一局照这个做就能判出来）**：

1. 用一个**不强制政权更迭**的战争目标（割地 / 赔款 / 羞辱 / 开放市场之类），把政权更迭这一项从
   合法性变化里摘掉；
2. **投降前同一颗脉冲**记基线（直接读月度行 `LEGV;`，别用 UI 现读 —— 避免跨月）；
3. 投降后**第一个**月度脉冲就读 `LEGV;`，差值就是「基线 −20 + 叠加档 −15 = **−35**」（默认档
   `uniform` 时没有难度叠加档）；
4. 同时在「国家详情 → 修正」页签落一帧确认**两条修正都挂上**——这样即使数值被别的效果污染，
   「修正可见 / 修正生效」这条判据也不受牵连。
