## 2. 判据与判决（冻结，跑完照此落结论）

阈值 = **0.5 ms/帧**（口径页 §5 P3）。

* ① `Δ̂ = mean(Δ_i)`，`Δ_i = M_AI(W_i)^{ours} − M_AI(W_i)^{vanilla}`（**同一 `--repeat` 序号**的两局相减）
* ② `s_d` = 配对差的**样本标准差（ddof = 1）**
* ③ `U(n) = t_{0.975, n−1} · s_d / √n`；`t` 分位用**正则化不完全 Beta + 二分反演**算（与标准 t 表 df=1…22 交叉验证偏差 ≤0.002）
* ④ **n = 11**（冻结）。边界证据（缺一不可）：**`U(11) = 0.4834 ≤ 0.5` ✓ ／ `U(10) = 0.5148 > 0.5` ✗**（按 `s_d = 0.7196`；本例 `s_d` 由 t29 用 pilot 同一批 3 对估计，见 §4 的偏差风险）
* ⑤ 三路判决（**互斥，必须给一个**）：
  1. **可判 · 达标**：`U(11) ≤ 0.5` 且 `|Δ̂| + U(11) ≤ 0.5`
  2. **可判 · 超预算**：`U(11) ≤ 0.5` 且 `|Δ̂| + U(11) > 0.5`
  3. **未判决**：`U(11) > 0.5` ⇒ **只许**报 `Δ̂ ± U(11)`，并给出按判据算出的**最小 n**（从 n = 3 起逐个试，取第一个 `U(n) ≤ 0.5` 的 n）与「还差多少、要多少机器时间」
* ⑥ **本批的实际 `s_d` 只用于报数**，**不许**据此在跑完后改 n 或改阈值；若实际 `s_d` 变大导致 `U(11) > 0.5` ⇒ **如实报「未判决」**（**不许**为凑可判加对、挑样本、换估计量或改判据）。
* ⑦ 副量（只记、不进判决）：整帧 `M(W)`、`RecalculateModifierNodes`、`UpdateAI` 单任务、`TickDaily` / `OnActions`（背景）。**两条线并存不混算**。

## 5. 作废规则（冻结，一字不改；逐对记账）

对照 `docs/design/exec/并行测试内存基线.md:892-904` §10，落地为**五条**：某一对的**两局之间**出现下列任一 ⇒ **该对作废并重跑**（理由写进采样器日志与结果报告）：

1. 出现**别人的** `owner-*.flag`（本卡自己的 `owner-t31.flag` **不算**）；
2. `victoria3` 进程数 > 0 且**不是**本 runner 自己的那一个；
3. 出现**外部** ≥200 MB 的 python（非本 runner 自身进程）；
4. `<用户目录>\content_load.json` 在 runner 自己的备份/还原窗口**之外**被改写（sha256 变化）；
5. 采样器出现异常墙钟（单次 tick 间隔 > 90 s，或日志断档 > 5 分钟）。

* 另记（不判作废，只披露）：采样器自身开销（30 s 一次 `Get-Process` + 每 2 分钟一次 CIM 命令行查询）是常驻小负载，**不当作「无」**。
* 作废对**不进** `Δ̂` / `s_d`；结果报告列出「作废了哪几对、因为什么、重跑结果」。
* **阈值与判据不因作废而放宽**；作废导致有效对不足 11 ⇒ 补跑到 11 对为止（补跑的对同样编号与记账）。

## 8. 每臂原始引擎日志按臂归档（B114；因 t9 缺口而设）

**要防的事**：`t6` pilot 的 8 个臂原始引擎日志只剩最后一遍 —— 日志按大小**轮转**，上一局的尾巴留在 `debug.1.log`… 里，不归档就等于证据蒸发。

* **机制**：runner 每局开局前调 `perf_compare._quarantine_logs()`（`perf_compare.py:163`、`:422` 调用）⇒ `game_auto.quarantine_logs()` 把 `<用户目录>\logs\*.log`（`game_auto.py:1678` 的 `USER_LOGS_DIR`）挪进 `%TEMP%\v3_quarantine_logs\`，**同名换名不覆盖**（`archive_stamp()` + `unused_path()`，`game_auto.py:1685` / `:1694`）⇒ 每一代都留在那里、带 UTC 时间戳。
* **动作**：本卡跑动期间常驻一个**归档看门狗**（≈15 s 一轮），把 `%TEMP%\v3_quarantine_logs\` 里**本批新出现**的每一代**复制**到 `tools/out/mem/t31-logs/session-<k>-<label>-<index>/`（`k` 按时间戳排序；`<label>-<index>` 用该代**对应的那一局**的 CSV 落盘时刻归属），并写 `MANIFEST.txt`（逐文件 `名字 / 字节 / sha256`）。
* **归档失败即出声**：某一局的目录为空、或 `MANIFEST` 缺项、或 ≥3 代对不上局 ⇒ **立刻**在台账与结果报告里写「臂 X 的第 k 局原始日志缺失」，**不许**在跑完后补一个「大概是这样」的说法。
* 跑完后**结果报告必须给归档路径 + 逐文件 sha256**（这是本卡的 acceptance ④）。
