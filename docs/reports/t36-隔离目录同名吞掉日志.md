## §2 机制：卡面写的口径不对，实测是这个

卡面（t31 的观察 + B114 的推论）写的是「同名冲突抛 `shutil.Error`，被 `except (PermissionError, OSError): continue` 吞掉」。**这个机制不成立**：
`_quarantine_logs()` 传给 `shutil.move` 的是**完整文件名**（`target / path.name`），走不到「目标是目录」那条分支。真正的两条静默路径是：

| 场景 | `shutil.move` 的实际行为 | 结果 | 输出 |
|---|---|---|---|
| 隔离目录里**已有同名文件** | `os.rename` 在 Windows 上抛 `FileExistsError` ⇒ 回退 `copy2` + `unlink` | **上一代被静默覆盖** | 0 行 |
| 隔离目录里**已有同名目录** | 按"目标目录"语义把文件挪进 `target\<name>\<name>` | **证据被埋深一层** | 0 行 |

第一条正是 t31 实测「`%TEMP%\v3_quarantine_perflogs` 里 60 个文件全是同一局、8 局只剩最后一局」的成因：
pilot 每局都往同一个隔离目录挪同名的 `debug.log`，于是**每挪一次就抹掉上一局**。
