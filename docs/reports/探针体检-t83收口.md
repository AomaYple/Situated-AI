### 2.1 方法学旁注（今天第二次踩，写给下一位）

**`mypy <文件参数>` 与仓库配置的全量跑不是一回事**，读数不可互换：

* 传文件参数时，若参数里**没有** `src/pdx/*.py`，mypy 会去解析**装好的 `pdx` 包**（无 `py.typed`）
  ⇒ 每个 `from pdx import …` 都报 `[import-untyped]`。实测：
  `.venv\Scripts\python.exe -m mypy tests/test_verify.py tests/test_cli_more.py tests/test_stress_probe.py`
  = **`Found 4 errors in 3 files (checked 3 source files)`、exit 1** —— **4 条全是 `Skipping analyzing "pdx"`**，
  没有一条是 t24/t73 那些历史上的真红；同时 mypy 打印
  `pyproject.toml: note: unused section(s): module = ['pydirectinput', …]`（那些 per-module 覆盖没匹配上）。
* 把本地包一起给 mypy（让 `pdx` 从源码解析）后，同一组文件立刻干净：
  `.venv\Scripts\python.exe -m mypy src/pdx/preflight.py tests/test_verify.py tests/test_cli_more.py tests/test_stress_probe.py`
  = **`Success: no issues found in 4 source files`、exit 0**。
* 结论：**门禁只认不带文件参数的那条**（与 t24 合约同口径）；带文件参数的跑法可以用来"单查某个文件"，
  但要认清它换了模块解析基准。
