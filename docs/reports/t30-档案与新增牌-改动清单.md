## §6 复算与校验

```powershell
# ① 改动面清单（77 文件 / 870,105 B）
Get-ChildItem 'mod' -Recurse -File | Measure-Object -Property Length -Sum

# ② 逐文件 字节 + sha256（附录 A/B/C 的表就是这么生成的）
Get-ChildItem 'mod' -Recurse -File | ForEach-Object {
  "{0}`t{1}`t{2}" -f $_.FullName.Substring($repo.Length+1), $_.Length, (Get-FileHash $_.FullName -Algorithm SHA256).Hash.ToLower()
}

# ③ 九份数据源的小节结构
Get-ChildItem 'mod\data' -Filter *.toml | ForEach-Object { Select-String -LiteralPath $_.FullName -Pattern '^\[[^^]' }

# ④ 九份本地化键名
Get-ChildItem 'mod\localization' -Recurse -Filter *.yml | ForEach-Object { Select-String -LiteralPath $_.FullName -Pattern '^ ([a-zA-Z_0-9]+):' }
```

**丢失 / 被动过的判法**：重算上表后，**字节数**或 **sha256** 或 **文件集合**任一不等即为「丢了或被动过」。
注意 `tools/out/**`（帧与 `evidence/`）**不入库**（gitignore）—— 附录 C 给的是**本机现读**值；
`tools/out/mem/**` 是 in-flight 台账，**不进清单**（这一点与 captain 给的收口口径一致）。
