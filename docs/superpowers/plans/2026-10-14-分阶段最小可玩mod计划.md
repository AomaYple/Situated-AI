**工具链**：仓库 .venv Python、pathlib/hashlib/json/ast、环境已有的 markdown-it-py、现有 pytest-xdist、pdx CLI、Git。文档写盘显式 UTF-8/LF；不为本次计划任务引入新依赖或新阶段状态机。

**依据**：[产品主计划 2.0](../../design/exec/mod重设计-实施计划.md)、[处境决策设计](../../design/03-处境决策设计.md)、[工程原则](../../principles/工程原则.md)和 [Mod 开发原则](../../principles/Mod开发原则.md)。

## 全局约束

- 正确性第一、开发速度第二、内存第三；游戏运行速度和内存分别实测。
- 受控文本 UTF-8 无 BOM、LF；原始证据、第三方和二进制按字节契约保留。
- Python 工具支持 Windows、macOS、Linux；未实测 GUI 不写成通过。
- 不手改生成物、原件或黄金指纹，不通过修改成功判据或错误白名单放行。
- 每个产品阶段必须有实际新增能力和可正常游玩的包；工具准备和空基线不单独算阶段完成。
- 中文提交、短期 codex 分支和 PR 按 CONTRIBUTING 执行；本计划重审不自动触发公开发布。
- 质量门、状态、实验与成本分别由主计划、工作清单、结果页和效率附件维护。
