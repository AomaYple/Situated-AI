#### 4.1.1 `game/common/script_values/script_values.md` — 4,007 B / 143 行 / 混合

- **作用域**：脚本值可用在**几乎任何接受数字的脚本位置**（部分场景也接受 true/false）。
- 分两大变体：**静态值（Static values）** 与 **公式（Formulas）**。
- 静态值：`name_of_scripted_value = value`（原文例 `minor_stress_gain = 10`），引用时直接写名字，如 `add_stress = minor_stress_gain`。
- 公式用花括号声明，**可使用当前作用域的一切**；每次求值都要重算，**复杂公式性能开销大**；**公式不适用于 true/false 值**。
- 数学运算：`add`、`subtract`、`multiply`、`divide`、`modulo`（原文提醒不要除以 0、不要对 0 取模）、`value`（直接设为该值）。
- 裁剪/取整：`max`、`min`、`round = yes`（四舍五入）、`ceiling = yes`（向上）、`floor = yes`（向下）、`round_to = 5`（就近取到指定数，**勿取到 0**）。
- 条件分支：`if = { limit = { } ... }`（**可在 if 内再嵌 if**）、`else_if = { }`（可连续多个）、`else = { }`。
- 随机范围：`fixed_range = { min max }` 取随机定点数（如 1.242）；`integer_range = { min max }` 取整数。
- **执行顺序按书写顺序**。原文算例：`add=5 → multiply=4 → max=10 → add=5` 结果为 **15**（因 `max=10` 在最后一次 `add` 之前生效）。
- **内联（Inlining）**：公式可写在任何脚本值可用的地方，甚至可写在数学操作符内部；只用一次就不必命名、不必放进 scriptvalues 目录。
- **链式（Chaining）**：可用作用域链引用命名公式，如 `mother.example_age`。
- **范围（Ranges）**：`add_gold = { 1 5 }` 或 `{ named_value another_named_value }`；**范围内不能内联公式**，需要时改用 `integer_range` / `fixed_range`。
- **列表（Lists）**：`every_child = { add = 1 }`、`ordered_child = { order_by = age max = 3 add = age }`；所有列表（含脚本定义的）都可用。
- **作用域切换**：`father = { any_child = { add = 1 } }` —— 加「你父亲有多少孩子」那么多金。
- **模板**（完整语法）：
  ```
  name_of_scripted_value = value
  name_of_scripted_value = {
      add = / subtract = / multiply = / divide = / modulo = number|scripted value|scope.something
      value = ...
      max = ...   min = ...
      round = yes   ceiling = yes   floor = yes
      round_to = 5
      if = { limit = { some conditions } add = 5 ... }
      else_if = { limit = { ... } operations... }
      else = { operations... }
      fixed_range = { min = ...  max = ... }
      integer_range = { min = ...  max = ... }
  }
  ```
- **AI mod 要点**：AI 分值、权重、接受度几乎全部用脚本值表达（`ai_weight`、`accept_score`、`propose_score` 等）；`if/else_if` 是写条件分值的主力。

- **⚠️ 关键陷阱**：`effect` 块与 on_action 触发的事件是**并发执行而非先于**；效果形成独立链条，**在此处改的值不能可靠地在同时触发的事件中读到**；此处设置的 scope 或局部变量**不会传递**给它触发的任何事件。
- `fallback = another_on_action`：若无任何事件/on_action 运行则改调 fallback；**原文警告不要造成无限 fallback 循环，否则游戏可能无法推进时间**。

  ```
  some_vanilla_on_action = { on_actions = { some_modded_on_action } }
  some_modded_on_action = { effect = { some_fun_modding_effect = yes } }
  ```
- **模板**（完整语法）：
  ```
  on_action_name = {
      trigger = { trigger_conditions = yes }
      weight_multiplier = { base = 1  modifier = { add = 1  trigger_conditions = yes } }
      events = { event_id.1  delay = { days = 365 }  event_id.2  delay = { months = { 6 12 } }  event_id.3 }
      random_events = { chance_to_happen = 25
                        chance_of_no_event = { value = 0  if = { limit = { ... } add = 10 } }
                        100 = event_id.1   200 = event_id.2   100 = 0 }
      first_valid = { event_id.1  event_id.2  fallback_event_without_trigger }
      on_actions = { on_action_1  on_action_2  on_action_3 }
      random_on_actions = { 100 = on_action_1  200 = on_action_2  100 = 0 }
      first_valid_on_action = { on_action_1  on_action_2 }
      effect = { effects = yes }
      fallback = another_on_action
  }
  ```
- **AI mod 要点**：这是**给 AI 挂载额外逻辑最便宜的方式**——不覆盖原版文件即可追加效果；但务必记住 `effect` 与事件并发、scope 不传递这两条。
