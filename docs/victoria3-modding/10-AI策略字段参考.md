## 0. 最关键的一条：字段叠加语义不统一

官方注释明确了每个字段在**多个策略同时生效**时的合并方式，共三种：

| 语义 | 数量 | 含义 |
|---|---|---|
| **相加 additive** | **36** | 各策略的值**累加** |
| **覆盖 override** | **10** | 后加载的策略**替换**先前值 |
| **相乘 multiplicative** | **2** | 各策略的值**连乘**（其中 `building_group_weights` 用的是另一种措辞，见下） |
| 未标注 | 其余 12 | 原文未说明，需实测 |

> ⚠️ **这意味着「多加一个策略」通常会让效果累加，而不是取代。** 新增自定义策略前必须确认目标字段的语义，否则会无意中放大行为。
>
> 口径说明：标准措辞是 `will function multiplicatively`（1 个字段）；
> `building_group_weights` 写的是 `will result in several multiplications`，
> 语义同为连乘但措辞不同，因此计入「相乘」共 2 个。

### `fleet_compositions`

**叠加语义**：未标注

> A fleet composition describes a role a fleet can take (e.g. main_battle_fleet, raid_fleet): what kind of ships it should be made of and what missions it should pursue. The AI will try to match each of the country's existing fleets to the role they best fit. All numeric fields accept script values, so weights can be tuned from country scope. ship_group_weights: Per ship group desire for this role. Across all available roles, weights are summed per group, and each role's share becomes its target ratio of the country's total ships in that group. Existing fleets are scored against every role's target ratios and assigned to the role they fit best, so these weights drive both "how should the country's ships be split across roles" and "which fleet plays which role". mission_type_weights: Multiplier applied when a fleet in this role picks which mission to pursue. 1.0 is neutral, higher biases the fleet toward that mission, 0.0 disables it for this role. IMPORTANT: if the block is present, any mission type not listed is treated as 0, so the list gates which missions this role will take. Omit the whole block to leave every mission neutral. min_ships_wanted: Soft floor on fleet size used during role-fit scoring. Fleets smaller than this take a penalty when matched to this role; it does not disqualify them and is not a hard cap. potential: Country-scoped trigger. If it fails the role is dropped entirely, so no fleet will be assigned to it. replace_key: Optional key of another composition that this one should replace when both are collected from the country's active strategies. Use it in a country-specific strategy to override a default role (e.g. a custom raid_fleet with replace_key = raid_fleet swaps out the one defined here). Without a replace_key the composition is added alongside the existing set.
