# 工程提速复核（2026-10-11）

本轮按用户最新范围只优化工程；Mod 行为、数据源、生产开关与实机任务暂缓。沿用[速度优化计划](../design/exec/速度优化计划-正确性优先.md)的 O11/O13，不重做工程底座，不删减现有测试，不改变黄金指纹、覆盖率下限或默认并行预算。

## 改动与等价边界

1. `pdx.snapshot.compare` 对两侧完全相同的字符串列表直接跳过，不再复制列表、构造 `Counter` 或调用 `SequenceMatcher`。不同列表继续走原比较器，普通域保留多重集合语义，有序域保留重排与重复项；精简/完整口径不匹配仍先拒绝。
2. 域与名称的键并集使用字典键视图，保留排序输出，减少临时集合。
3. 黄金回归的七项只读检查共享模块级真实写盘产物；输出路径补丁仅在生成期间生效，返回前恢复。确定性测试继续在自己的临时目录独立写两次。整文件真实写盘从九次变为三次，八项原测试及其断言全部保留。
4. 全量分析测试删除与 `conftest.py` 同义的三份 session fixture，统一复用已有定义；真实消费者只读，合成测试使用自己的对象。完整快照形状类在结束时释放类属性。
5. 快照确定性测试保留两次独立构建，使用 `JSONEncoder.iterencode` 与 `zip_longest` 逐块比较完整规范 JSON；输出块或结束位置有差异就失败，原有首个结构差异诊断保留，避免同时持有两份完整字符串。

使用已有 Python 标准库和 pytest 能力，没有新增依赖或持久缓存。复核时环境为 Windows、Python 3.14.7、pytest 9.1.1、pytest-xdist 3.8.0。查阅日期为 2026-10-11，fixture 生命周期依据 [pytest 官方文档源码](https://github.com/pytest-dev/pytest/blob/main/doc/en/how-to/fixtures.rst#fixture-scopes)；官方文档 HTML 入口返回 403，改用同一项目的官方源文档核对模块作用域与清理约定。流式编码核对了 [Python 官方 JSON 文档](https://docs.python.org/3/library/json.html#json.JSONEncoder.iterencode)，该入口成功返回 200。

## 完整验收与失败保留

首轮完整回归为 2929 passed、1 failed、10 skipped、1551 subtests passed，pytest 622.79 秒。失败是 `tests/test_repo_numbers.py::test_README里的用例数与实际收集一致`：新增三个测试后根 README 已同步，但 `tools/README.md` 漏改为 2940 条，现有统计门禁正确拒绝。全部 618 件冻结文件在运行前后内容 SHA 相同，分支覆盖率 88.9199%，11 个核心模块下限全部通过；这些读数不将失败回归改写为通过。

首轮原件在本轮输出目录的 `coverage.json`、`full-junit.xml`、`full-memory-index.json`，外部采样在 `tools/out/mem/20261011-engineering-auto.*`。当次默认预算选择三个 worker，墙钟 624.3 秒，RSS 峰值 3044.5 MiB、private 峰值 5075.3 MiB；没有超时、watchdog 中止或采样错误。查明并修正工具手册的统计后，相关文档测试及完整回归重新执行，使用新的产物目录与 tag，不覆盖失败记录。

修正后的 `final/` 回归为 2930 passed、10 skipped、1551 subtests passed，pytest 599.11 秒；分支覆盖率 88.9199%，11 个核心下限通过，冻结文件未变化。但单 worker OS 高水位 1579.4 MiB 超过原有 1536 MiB 上限，故整体资源验收未通过；整套 RSS 3028.6 MiB、private 5192.4 MiB、包装墙钟 600.6 秒不改变这一判决。

随后 `diagnostic/` 使用现有 `mem_baseline --inproc` 做完整归因，同样 2940 条用例与 1551 个子测试，跳过身份和原因不变。资源门禁通过，RSS 3156.8 MiB、最高 worker 1391.4 MiB、包装墙钟 599.3 秒；该轮最高已记录峰值出现在快照确定性比较。执行顺序与 worker 分配影响峰值，不能据另一次通过改写 `final/` 的超预算记录，也不能据此认定首次峰值的全部根因。
