## 采用的结构

当前设计统一七个因素模块：财政存续、外部安全与承诺、市场依赖、政治约束与身份偏好、经济与行政能力、外交目标与战争负担、宗主国与属国关系。执行链为真实状态 → 允许信息与事实 → 七类因素 → 统一可行性与字段仲裁 → 原版接口适配 → 原版 AI 执行 → 解释和结果。

保持先完整实现、再集中验证的开发顺序：

- **F0**：C0 目标/接口映射，C1 既有四模块补齐，C2 经济行政，C3 外交目标/战争负担，C4 宗属关系，C5 仲裁/解释/生命周期/交付，C6 实际全语言文本，C7 批次冻结。
- **F1**：集中接口、生命周期、玩家/存档、语言和行为验证；单模块归因后安排共享输出与高风险组合，不穷举 128 局实机。
- **F2**：适用 M4 的长期、真实后期、压力、速度/CPU/内存、兼容与恢复，以及正式交付。

V0.1–V0.7 对应七模块的累积可玩验收，V1.0 对应完整组合。每个可玩包完成自己的 M1–M4、玩家与交付出口；F0 仍是实验候选。范围在 1.0 封闭，后续新增行为须另行批准；不建立常驻 Python AI、通用长期规划器或底层 C++ 接管，不通过免费资源、强制行动和全局削弱伪造收益。
