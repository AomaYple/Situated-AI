## 历史审计

[archive/](archive/) 保存已完成的工程收口和重构前审计；其他日期文件保留当时的输入和判断。审计中的“完成”只对该报告的范围和时点成立，不能覆盖后续结果。

## 使用规则

- 读审计时同时记录游戏版本、工具版本、输入指纹、命令和是否有实机；
- 发现当前状态变化时，新建日期化审计或追加结果页，不改写旧审计的原始事实；
- 原始日志、截图、存档和恢复副本不放入本目录，位置和 manifest 见 tools/out/；
- 审计通过不等于 Mod 行为或 AI 质量通过。
