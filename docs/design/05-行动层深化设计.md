# Situated AI 行动层深化设计

> 设计版本：31.3（2026-10-31）。状态：**设计合同已落盘，D0–D14 尚未执行**。本轮扩展覆盖面和因果深度，并修正执行依赖；最小步骤以[31.3 主计划](exec/mod重设计-实施计划.md)为唯一来源。
> 本文建立在 3.0.1 的生产架构上；它描述下一轮深化的目标和验收边界，不把设计目标当作当前能力。
> 当前静态基线、包、标签和用户长期验收边界见[当前工作清单](当前工作清单.md)和[3.0.1 交付结果](exec/3.0.1-交付结果.md)。

## 1. 目标

在保留现有 Python 生成器、DecisionIR、PDX lowering、原版消费者适配和有限国家状态的前提下，把当前“7 张完整跨域行动卡 + 大量 rule_action 规则实例”深化为统一的三层行动模型：

```text
战略行动卡 strategy_card（可选目标关联与有限惯性）
        ⇢
领域行动卡 domain_card（工具必须归属领域）
        ↓
具体工具行动 tool_action
        ↓
原版 AI 消费者 consumer
```

最终要求每一条合法生产写入都能说明：它服务哪个领域目标、使用哪些可观察事实、承担什么成本、与哪些行动互补或替代、在什么时机退出，以及如何回退到原版行为。

这不是新增一套常驻 AI，也不是把所有字段压成一个总分。三层行动只在生成期组织语义，在游戏运行期仍按原版消费者作用域进行有限求值。

## 2. 三层模型

### 2.1 战略行动卡

战略卡表达国家在一段有限时期内的总体方向。当前 7 张显式卡迁移为战略层：

- `fiscal_recovery`：财政恢复
- `wartime_defense`：战时防御
- `political_reform`：政治改革
- `industrial_foundation`：产业基础
- `education_and_research`：教育与研究
- `diplomatic_restraint`：外交克制
- `diplomatic_opening`：外交主动

战略卡最多形成一条主路线记忆；它不能直接写原版字段，也不能禁止其它领域继续评估。

### 2.2 领域行动卡

领域卡把战略方向拆成可解释的领域目标。最低覆盖 19 个现有行动族：

```text
fiscal administrative industry resources market research education
political population social identity diplomacy subjects army war navy
overseas geography temporal
```

每个领域卡必须声明一个真实目标、至少一个事实输入、一个收益方向、成本/承诺的适用性说明、一个原版消费者集合和一个退出/回退策略。领域卡可以并行存在；同一国家的教育需求和安全需求不互相抹除。

领域卡示例：

```text
industry.input_relief
  事实：关键投入价格、供应缺口、行政能力、财政状态
  目标：降低工业投入瓶颈
  工具行动：工具、煤炭、钢铁、运输等具体消费者权重
  关系：运输与工业互补，海外承诺与国内建设竞争
  退出：瓶颈消失、违约、战争抢占或事实未知
```

### 2.3 具体工具行动

工具行动是一个具体原版消费者上的一个可追溯写入。它可以来自当前 `rule_action`，但不再是没有父级语义的孤立规则。

每个工具行动必须关联领域归属；战略关联用于解释、收益和有限惯性，不是所有行动的运行前置：

```text
domain_id → tool_action_id → consumer_id → PDX AST 写入
strategy_id → domain_id（可选目标关联，不构成全局资格开关）
```

工具行动保留原版字段、资格、成本、随机、终结零分和执行尾部；行动层只提供有界倾向，不免费创造资源、不强制玩家、不替换整个 AI。

## 3. 统一行动合同

`ActionCard` 和迁移后的 `ActionInstance` 统一满足以下字段合同：

| 类别 | 必须内容 |
|---|---|
| 身份 | 稳定 ID、层级、父级 ID、领域、源文件和定义路径 |
| 事实 | 事实 ID、来源、作用域、类型、单位、新鲜度和未知策略 |
| 目标 | 领域目标、改善方向、时间尺度和退出目标 |
| 可行性 | 原版硬资格、Mod 安全边界、局部软证据和未知回退 |
| 经济性 | 收益档、实际承诺/机会成本、政治或外交成本、强度上限 |
| 关系 | 互补、替代、冲突、使能、作用域、深度和失效条件 |
| 时间 | 求值时机、进入、保持、退出、TTL、冷却、抢占和存档默认 |
| 适配 | 原版消费者、字段、操作、原版尾部和单一 owner |
| 证据 | 正例、反例、成本变化、未知回退、玩家回退和 source→IR→PDX 映射 |

缺少任一适用字段的工具行动只能是 `pending`，不能通过改名或库存统计计入完成。

## 4. 规则实例迁移边界

当前 1,401 个 `rule_action` 是迁移输入，不直接被宣传为完整行动卡。D2 阶段为每个实例建立唯一绑定：

```text
rule_action
  → tool_action
  → domain_card
  → strategy_card（适用时）；无战略关联必须有 neutral_local 的局部目标理由
```

纯迁移阶段保留原有稳定 ID 和游戏语义/载荷字节；source fingerprint、锁与 manifest 根据新源机械重算。进入 D5–D10 有意深化时，记录具体行为差异及正反见证；迁移完成后，`rule_action` 只能作为兼容别名或审计标签，不能存在没有父级、没有目标、没有消费者或只存在于报告中的孤立实例。

## 5. 多领域同时评估

领域卡并行评估，消费者局部选择。一个国家可以同时得到：

```text
经济：投入瓶颈缓解
教育：识字率改善
军事：军需和防御
外交：降低冒险
政治：延后高风险改革
```

但每个消费者最多选择一个主工具行动和一个受控互补；跨消费者结果不能伪装成一个实际的全局预算锁。路线记忆只保留有限惯性，不关闭其它领域。

## 6. 分层门槛

所有领域都使用三档而不是全满足门槛：

- **基础档**：原版资格和该领域的直接问题已知即可产生低强度候选。
- **稳健档**：增加本领域能力与成本证据，提高强度或允许互补。
- **扩张档**：只检查该行动实际需要的财政、行政、政治或投射承诺；这些承诺可承担时才提高相应昂贵扩张强度，不为每种行动统一要求所有能力。

缺少高档条件只能降低强度或选择低成本替代，不能把无关领域全部关闭。未知不是否定；核心事实未知时局部回退原版，辅助事实未知时只使用已证实低档。

## 7. 关系和反馈边界

跨域反馈只允许有限、可解释的链：

```text
教育 → 研究 → 工业 → 市场 → 财政 → 军事/外交
```

关系图必须满足：

- 使能图无环；
- 关系最大展开两级；
- 同一事实在同一消费者内只计一次；
- 每条关系有作用域、条件、失效和未知策略；
- 不进行国家×州×商品的运行期笛卡尔扫描；
- 不把“选中工具行动”当作“行动已经成功”。

## 8. 完成合同

深化完成必须同时满足：

```text
19 个领域均有领域合同或明确 engine_unexposed 证据
AND 所有合法生产写入都有唯一 domain/tool/consumer 追溯链及明确战略关联或 neutral_local 理由
AND 所有适用工具行动都有事实、目标、成本、消费者和生命周期
AND 规则行动不再孤立或只进报告
AND 每个声明因素有反事实或不干扰证据
AND 基础档不依赖无关全局条件
AND 未知、玩家和原版尾部均回退正确
AND 独立 PDX 求值、失败注入、完整静态回归和资源门通过
```

这份合同仍然不证明国家长期路线、数值平衡、游戏内后期性能或 Workshop 体验；这些由用户在标准包上验收。

## 9. 广度按真实决策面展开，不按卡数封顶

19 个领域是分类，不是 19 张卡的上限。7 张战略卡是迁移种子，不是后续战略数量目标；1,401 条旧规则和 377 个消费者只描述 3.0.1 基线，不能作为新增范围的上限。

范围登记以锁定原版独立发现的 `文件 × 定义 × 字段 × actor × target × 操作` 为单位。默认、活跃行政、外交和宗属策略中的同名字段分别登记；不能只扫描本 Mod 已经修改的文件证明“全覆盖”。建筑、三树科技、法律组、制度、商品、条约、战争目标和州目标还要按具体原版目标展开。

每个面同时登记 `observable` 和 `controllable`：能读取不等于能直接控制，日志/存档可读不等于游戏脚本可读，原版键存在不等于当前消费者作用域合法。直接、间接、仅观察、引擎未暴露四种结论分别列出来源和限制；未接线的合法接口保持 pending。

本轮新增或细化的最低审查面包括：

- 经济：融资与偿付、维护与新增投资、投资/所有制、税收能力、公共与私人建设边界、价格和利润差别、生产方式与劳动力替代、资源耗尽/开采资格、粮食与现金作物、产业链与市场接入。
- 知识与社会：三树研究的机会成本、学校/大学/研究的不同瓶颈、资格与识字率差别、就业与机械化、移民与住房/运输承载（只有合法读数时）、医疗/福利/劳工/治安的分离、政治联盟和现状替代。
- 对外与安全：贸易多元化、经济依赖、投资/条约/集团相关接口审计、盟友可靠性可见边界、宗主与属国双向承诺、军事供应与规模、现役与动员、有限战争目标、和平/战败恢复、护航/投射/殖民的区别。
- 目标与时间：actor/target/owner 的切换、边际目标价值与治理成本、身份与政治支持、路线迟滞和安全抢占、冲击消退、结果重评、旧存档、禁用、玩家接管和确定性恢复。

以上是审查需求，不能在底本审计前宣传为已支持。没有接口的具体面保留原版；必须检查合法替代，不能创造国家/州/商品全扫描或常驻采集服务来填补接口空缺。

## 10. 深度按每个工具行动的决策剖面验收

每个具体工具行动必须具有下列剖面，不能只给族模板填一次：

| 剖面 | 必须回答的问题 | 明确边界 |
|---|---|---|
| 输入 | 哪个 getter、参数、actor/target、单位、时点和证据质量？ | 真实 0/false 与 unknown、stale、unsupported 分开；无法表达的运行期缺测先在构建期拒绝 |
| 问题 | 当前缺的是需求、能力、供应还是政治可行性？ | 同一代理量不能冒充多个独立瓶颈；相关事实去重 |
| 目标 | 改善谁、改善哪个方向、短期还是结构目标？ | 不把国力、识字率、货币、军力直接相加；目标不创造资格 |
| 备选 | 直接修复、能力建设、合法替代、延期/原版分别何时可用？ | 中性和原版是合法结果；不得为展示“AI 有行动”而强选候选 |
| 成本 | 新增维护、一次承诺、机会成本、政治外交风险如何局部作用？ | 零直接成本需证据；倾向机会成本不冒充跨消费者真实资源预留 |
| 收益 | 哪些已证实条件改变收益/强度，何时饱和或反向？ | 单因素反事实必须能改变声明的输出，不能从静态评分推断实际 GDP 收益 |
| 联动 | 互补、替代、冲突、使能各依赖何种已完成条件？ | 被选中不等于已建成；一次证据只计一次；运行求值最多展开两级 |
| 时间 | 即时求值还是有限状态，退出、到期、抢占后怎样恢复？ | 无状态行为逐项说明；有状态行为缺清理或旧存档默认即拒收 |
| 输出 | 哪个消费者的哪个逻辑决策分区由谁写入？ | 唯一工具 owner 允许互斥 AST 分支；不能把每个语法分支当成独立行动重复计数 |
| 证明 | 手写预期、参考器、独立 PDX AST 和原版尾部是否一致？ | 比较选择、替代、方向、幅度、状态和回退；文本标记不能代替语义 |

每个剖面的适用性必须逐实例记录。不能为了“深”给无实际成本的工具捏造收费，也不能为了“广”给无时间状态的建筑权重添加持久变量。

## 11. 联动为有界局部评估，不是全局排他计划

同一国家允许多个领域同时评估。战略主路线只影响与其明确关联的收益、承诺和保持强度；`neutral_local` 工具在没有主战略、其它战略活跃、低识字率、局部行政欠缺和正常低债融资时仍按自身资格评估。

基础、稳健、扩张是强度档，不是必须依次解锁的全局阶段。扩张只检查本行动实际依赖的财政、行政、政治或投射能力；不能把所有能力都放进所有行动的 AND 门。遇到危机只压低真正不可承担的新承诺，保留相关修复、必要防御和不依赖该约束的研究。

关系存在三种不同边界：

1. 生成期层级树只表达归属，必须无环；domain 不需要通过某张当前活跃战略才能存在。
2. 同次求值中的有向使能依赖必须无环；对称替代/互补/冲突按有界配对处理，不误判为循环。
3. 现实中的经济与政治反馈可以跨时点反复出现，但只能在实际结果可观察后重新评估。长链由多个相邻局部关系组成，单次求值仍最多两跳，不能宣称预测整条因果链的最终收益。

跨域最低联合场景由主计划的关系步骤逐条列出；每条必须同时有正例、断链、成本增加、未知、不干扰和结果未实现六类证据。把所有相关因素塞进 `requires_all`，或者只给每张卡永久加 priority，都不算联动。

## 12. 数值、兼容与完成边界

每个消费者单独冻结原版尺度、中性值、正负方向、可达区间、插入位置和资格/终结零分。沿用既有保护范围；加法不能把终结 0 抬为可选，乘法不能把负分反向变为奖励，成本增加必须在非同分场景降低强度或改变替代。

变化幅度按“直接需求、机会、成本、风险、惯性”的局部证据确定，不设全局激进开关。阈值必须测试阈值前、等于阈值、阈值后；超出输入合法范围拒绝，不能夹成健康值。完全未知回原版，部分辅助未知只退到证据充足的低档。

迁移 D0–D4 比较的是生产 PDX 语义和标准包游戏载荷；新增层级文件会合法改变 source fingerprint、metadata、generation-lock 和 manifest，不能要求这些源指纹也与 3.0.1 逐字节相同。所有指纹须重算，不能伪造原值。D5–D10 的有意行为深化必须逐面保存差异和新预期。

工程完成必须覆盖实际发现的全部合法接入面；不可见字段公开列出且不算功能完成率。性能优化维持测试身份、断言、失败语义、覆盖与资源门；固定输入和并行度的同口径测量才可声称提速。最终结论限于静态生产实现、工程与标准包合同，不能宣称全知最优或长期效果已获证明。
