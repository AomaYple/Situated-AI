## 历史依据

[01 · 大方向](01-大方向.md)与 [01a · 依据与参考](01a-依据与参考.md)保留旧路线、实验依据和引用锚点。当前设计已调整实现手段；旧文档中的规则、预算和完成表述按当时范围解释，不能覆盖当前设计或执行纲领。

`exec/` 保留有独立复核价值的旧阶段结果、实验口径和实机读数。已被取代的交接、团队台账与重复收尾页已从当前目录移除，原件通过 Git 历史恢复，范围见 [过时内容清理记录](../audits/2026-10-10-stale-cleanup.md)。需要纠正历史结论时追加独立记录并链接原件。
