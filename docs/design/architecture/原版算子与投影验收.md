# 原版算子与投影验收

每个适配器以“在锁定底本的这个位置，对哪些国家、候选和相位，允许哪一种有界干预”为输出。一个物理字段可接受多个领域的贡献。统一合成者须能解释它们同时存在或分别撤回时的实际判断；原版状态、事件效果、通知与下次观察各自有所有者。[主计划的原版投影与运行生命周期](../架构主计划.md#原版投影与运行生命周期)

## 以原版机制族选择适配器

| 形态与代表原件 | 决策、约束与写入 | 要击穿的错误 |
|---|---|---|
| 排序或加权，学校、动员与条约 | 定位同组候选、默认值、组合秩序、零基数、截断、阈值、否决、抽样及后续独立阶段。只有合成者校准过的单位和范围才能映射为加、乘或枚举调整。 | A 超过 B 却挤出更好的 C。提案初筛概率增加但最终零基数或批准门阻断，预测不得宣称成交。 |
| 报价与条款包 | 起草者、条款输入、对方主动受理、批准分别登记。包内条款有共同约束、上下限和双边角色，整组改变后重新检验可行性。 | 对单项的有利评价在整包存在反向支付、互斥或接受上限时无效。 |
| 制度、法律与授权 | 国家选择制度、政策或委托开关时核对法定主体。法律修改后检查资本所有权、可用资金、私人投资机会等相关约束。委托执行和国家下一次重新决定各有原版入口。 | 用国家国库直接支配私资，或把市场反应和原版自动投资评估当第二次国家选择。 |
| 空间、权限与通道 | 用原版节点、连通、实际控制权、各类通行许可、费用、替代路线和运输时段分别定义可通行、成本、受益者与外交后果。证据分别来自海峡定义、相关对象和实际可用的权限及支付机制。 | 甲能通行即推断乙也能通行，或把收取费用与关闭通道混为一个世界状态。不同伙伴共享瓶颈导致原路线不可维持。 |
| 持续状态与多阶段机制 | 如条约冻结、同盟、法律施行及屯垦进程，按实际原版状态划分进入、维持、暂止、恢复、终止及另开机会；只接入能定位到国家选择的边。 | 原版中间状态可能被撤回、延迟或自动推进。可观察到中间状态便提前支取最终收益会改变方向。 |
| 新选项、整组或整套替换 | 登记使用的官方接口、加载次序、原组全部操作、新增候选实际权限、玩家可选择路径及残留依赖。替换外部表现需回读有效定义。 | 覆盖后同名内容遮蔽其他原版功能，玩家可见但不能完成，或把正式游玩绑定到开发调试命令。 |

同一方面可有多个独立消费者，同一消费者可由多个方面供给。表中“制度”“空间”等分类按本次所需的原版操作确定，可以组合使用。只在共享的绑定、基准和运算顺序相同处复用适配器。来源发生漂移须回查它实际支持的读点、守卫、算子和尾部。[原版策略结构](../../../research/situated/1.15.2/default-strategy-structure.json) · [随附资料与路径](../../../research/official-docs-1.15.2.manifest.json)

## 多字段、合成与撤回

物理写点键包含有效文件路径、定义、完整字段路径与出现号、加载优先级及底本。角色与相位属于守卫。两个语义条目即使分别服务不同国家或相位，也不能各自覆盖同一个实际字段。登记一个合成者和它消费的所有贡献，定位其原版 AST、其他活动策略、有效语句顺序及原版剩余路径。对合法可重合的输入区间，确定贡献是可相加的独立残差、互斥分支、替代估计，还是依赖其他贡献的共同后果；不能由领域注册先后来决定原版运算顺序。

一项财政收入预测由港口可达 P、已批准通行权 T 和合法可知的单位费用 F 共同支持，收入贡献 G 仅在三者都有效时出现。同期政治支持变化 H 有单独、独立且仍有效的证据。若 T 到期，撤 G，重估受影响的组合与其下游，H 的证据、算子和许可范围仍独立时保留 H。若 H 的获知也来自同一通行通知，则它属于受影响集合。身份切换、缓存过期和 DLC 更新均用实际依赖表定位。撤回最后的新增贡献时从正式产物还原原版表达并复核其余原版项；联合估值有非线性时，撤一项后重新求值余组，不能对上次总分直接减旧值。

即使字段不同也可能共同影响同一候选。举例把结算概率看作初筛与条件接受的乘积，`0.4×0.5=0.20`，两者同时改为 `0.6×0.75=0.45`。边际分别 +0.10，合计总增量 +0.25，交互 +0.05。若两处都引用同一已登记收益，不得据此重复放大。核对四种字段开关及真实概率质量从哪些替代候选中转移；受不同国权限保护的两个字段仍须各自证明受理角色与其真实操作。原版字段产生的局部差值、选择概率差和国家终点差分别写入相应收据。

## 条约从条款到实际债务

以安装下 `game/common/treaty_articles/treaty_articles.md`、`04_take_on_debt.txt`、`05_transfer_money.txt`、`20_law_commitment.txt` 为可重查原件。随附文档第 130–131 行给出强制条款的两个生效回调，第 249–267 行规定重谈和一次性条款，第 345–384 行描述不履约与周/月检查，第 435–496 行附近说明批准、维持及提案门，第 575–623 行附近区分接受算子和调用作用域。各条款的具体开关和效果以实际定义为准。[官方随附资料指纹](../../../research/official-docs-1.15.2.manifest.json) · [条款定义及原件定位](../../../research/situated/1.15.2/treaty-opportunities.json)

|---|---|---|

原版消息可能送达多个观察者，估值字段也会多次被引擎查询。登记原版操作、物理结果、面向每个国家的披露和再次求值四种不同事件。用原版可证身份区分既有条款和重谈中新条款，效果只由引擎执行。重复送达同一次承债的通知不重复记账。同日的周、月检查若是不同原版事件则各自保留。若真实存读后无法取得可靠实例键，就从原版当前状态重新读取有据事实，撤回依赖事件计数的贡献。对重入的回调只作该相位允许的工作，不在禁止修改条约集合的退出回调中创建或删除条约。可观察状态的恢复与已经永久发生的支出分开验收。

## 从独立参考到真实回读

1. 为一个真实候选冻结基础 AST、调用身份、已知时点、原版其他候选与最终否决。构造正例、换国家／主体、换方向、零／未知、阈值下／等／上、无资格、批准失败、重复与延迟事件、同版存读。小参考机不调用生产规则评分函数。
2. 从正式生成和包读取最终**有效**字段、完整父结构、其他策略的遮蔽和原版尾部。将参考输入逐一代入合法输出条件。对单处移除、依赖组移除、两处同时生效、原件缺失及互斥／叠加冲突，分别对比基线。用故意交换 ROOT、误作整组乘法、删去存在性保护、双记债务等反例确认验证能捕捉相应错误。
3. 固定游戏构建、Mod 包哈希、玩法组合、模式、观察国及事件窗，逐项取 R。证据分别指向原版提供机会、该相位实际求值、是否采纳、原版何时支付／改变状态、谁实际获知、下一机会是否利用。能够回读本地生成的表达式即可验证 M 的对应命题，R 中观察不到的阶段保留待证。
4. 从同一包进行 U 的单国和全体部署对照。记录相近候选的合理随机、相反利益、阶段未发生、持续退步与适用范围。原版提供但未采用也计在原版机会分母里。局部算子正确仍需经其他国家回应、国内分配与实际时间跨度检验。[跨国反事实与跨期求解](跨国反事实与跨期求解.md) · [工程交付基线](../exec/工程基线-1.0.md)
