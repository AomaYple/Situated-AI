# 跨国反事实与跨期求解

主计划的条件策略能比较在当前候选之后逐步到达的机会。要将同一判断交给所有 AI 国家，还需回答两个问题。各国同时作出选择后原来的比较是否依然成立？当财政收益和国内群体、他国或远期的得失不同向时，谁以何种口径衡量？这里的数值都是可精确重演的模型夹具。真实参数按原版机会重新取得。[主计划的条件策略与反事实估值](../架构主计划.md#条件策略与反事实估值)

## 政治财政与分配

沿同一条轨迹维护两组有联系的记录。第一组登记谁拥有、能调度或须偿还什么，含财政现金流、债务存量、产能、交付期限、在途与可用量。第二组登记各州、阶层、利益集团、企业所有者及对外伙伴分别收付或承担什么，以及由此如何影响本国实际目标。原始数量尽量沿原版单位保存。把数量映射到末端效用时才引用该国政体、目标、时段和经验证的交换尺度。两张账通过唯一交易和期间连接。

举例设一项已可实行的国内税收在某周给国家财政增加 10 单位货币，同周本国纳税者支出 10。模型假定该处境下公共资金的边际效用为 0.8、私方消费的边际效用为 0.6，每项均以效用／货币计，则分配引起的本国净效用为 `10×0.8−10×0.6=2`。不另记“国家收入增加 10”的同一收益。若同等收入来自境外，另列承担方和可证的贸易、外交及支付后果，再按决策国评估。若增税还使政府延续概率从 0.6 降至 0.4、该政体对延续的独立价值为 15，其他后果均保持，则总差变为 `2−0.2×15=−1`。与稳定损失独立的延续价值在此能翻转决策。若有关政治损失已经计入财政边际效用，应移出已计成分或合并估值。缺乏公共与私方交换尺度时，只能给出各自分量和在许可尺度集合上的偏序／区间。

每个资源账户登记权属、物理单位、地区与有效期。私人可投资资本不能直接填国库，名义已批拨款不能同时充当前线现货。对于转移商品、借贷和国内资产回购，在来源与去向账间核对数量及损耗，另记价格变化给第三方带来的分配；对本国净估值作淘汰和替代的差额分析。失去一个选择后所释放或占用的资源只结算一次。当价格还会改变另一项动作的可得性时，显式比较可行的延续集。共同驱动和共同约束须先登记，再选择按路径估值、增加联合作用或仅保留有据的局部影响。

## 逐国部署的四种反事实

固定起点、外生冲击的生成机制、构建、模式、玩法组合和物理观察窗。选定国家 C，对每条轨迹均按 C 的收益函数记录 `Yij(C)`；下标 i 指 C 执行原版（0）或拟部署策略（1），j 指其他适用 AI 国家执行原版（0）或同一拟部署策略（1）。各国实际输出依自身处境，玩家与独立主体在四组内均按其原有权限行动。需要诊断四种构成时，可先离线施加明确限定的策略，在 R/U 中只能签署实际能控制和确认的比较。

| 其他 AI 的策略 | C 按原版 | C 按拟部署策略 |
|---|---|---|
| 原版 | Y00 给出纯原版对照 | Y10 给出本国单独调整及原版各方回应 |
| 拟部署 | Y01 显示其他国家改动传回原版 C 的间接影响 | Y11 显示完整部署时其他国家再回应后的 C 的处境 |

四格均重新运行世界，以同一外生情景配对。市场结算、外交选择、机会出现、生灭和拒绝可以因先前行动而分叉。比较 `Y10−Y00` 为原版环境下的本国改动，`Y01−Y00` 为他国部署的外溢，`Y11−Y01` 为拟部署环境下的本国边际，`Y11−Y00` 为全体部署的总变化。两项本国边际之差 `Y11−Y01−Y10+Y00` 衡量相互作用。设四格依次 `Y00=10, Y10=14, Y01=8, Y11=7`，单国获益 4，全体部署时本国边际为 −1，总变化 −3，交互 −5。由此可查多数国家同时寻求相同进口时的稀缺、拥堵与替代路线。各国各自重算，甲损失不能用乙的获益抵销后声称甲受益；整体采用的条件按 MP-47，对退步国家记录幅度和持续性。[成效采用条件](../../principles/Mod开发原则.md)

同时决定的两国只按各自当时的合法历史提交决策。引擎若逐一调用但两者之间没有合法披露，顺序交换时相同可见史应给出相同策略分布。若原版在两次决策间确实发送了可知通知，则后一国可以利用该信号，前一国只按可预期的回应分布比较。随机对照固定外生生成条件，保留同一世界中的内生反应；引擎无法精确重放时登记可配对范围、离散分叉和不确定性。玩家回应的异质性可分层、设有据区间或按实测场景报告。没有信息权或跨局依赖时不把玩家的私有目标编码进预测。

## 时间、冲击与非平稳回应

事实到达按日历与原版相位推进。以实际占用区间计算预算，以真实结算时点处理支付与解除，以随后合法得知的观察更新预测。月末派发多少次相同估值回调不会延长物理时域或叠加价值。期间 `[t0,t1)`、`[t1,t2)` 可以相加，跨越两段的截尾观测须按有据上下界处理。转向已经开工的项目时，把不可收回的投入视为两路线共有的当前状态，未来取消支出、违约成本、可回收产能与替代工期另算。停止依据对结果的预测与选择，不以某次预测已经变差就撤销原版已发生的付款。

把伙伴和竞争者的回应建模为随信息、政策、资源、制度与部署配置变化的条件核。观察到的历史频率绑定其样本选择、暴露、制度和时间段。对同一组候选先比较原版环境与完整部署环境，再报告罕见冲击、战争爆发、新市场成员、伙伴换届或拒绝后的重新校准。研究训练／校准／独立评价分国和分时保留，含未选中的机会及未知结果。超出训练支撑时扩大区间，保留可证局部比较。用未来回应回填先前的本国历史、或只看胜者和成交者，都会把原先不可知的内容引入决策。

反馈回路还须在不同时滞检验稳定性。例如两个国家对共同市场缺口的调整形成归一化偏差 `d`。若合计反馈系数为 1.2，按当期信息即时纠偏得到 `d(t+1)=−0.2 d(t)`，偏差衰减；若行动时只能看到上期偏差，则 `d(t+1)=d(t)−1.2 d(t−1)`，其复根模为 `√1.2≈1.095`。相同局部响应在错拍时可扩大震荡。为相应原版机会分别比较迟报、重新定价、取消成本、适用的状态阈值和按已观察实现量更新的版本。紧急短缺且信息即时可见的国家可能受益于及时行动，统一冷却不能由该夹具推出。

## 有界搜索与降级

先在现实机会和共享终点上建立带信息集的有限图。小图穷举合法策略，作为分支限界、变量消元或抽样的独立参考。全图昂贵时依照建模证据分解。市场价格、债务、共同条约及同一港口运力可能将相距很远的国家连在一起。以联合边界变量分隔子图，边界必须带资源承诺、共享外生因子、策略制度和可知历史；未证明条件独立的边保留联合表示。消元复杂度随最大联合边界的取值组合增长，记录该规模、最大内存、时间窗、实际展开、被截断的候选及编译后分支数。可变宽度应由同口径的最难机会和整局预算约束。

具体剪枝从允许的模型集合取得双边界。设把完整方案逐次替换成局部方案，每次替换在**该步所有可能的其余配置**下改变根行动价值的绝对值至多 `e_k`，则逐步差值望远镜求和得总误差至多 `Σe_k`。共同市场冲击使误差依赖邻国组合时，只在已覆盖的组合内使用该界。A、B 两根各有误差 0.4、0.7，算得差为 +0.9，则真实差范围至少要容纳 `[−0.2,2.0]`，该方向尚不能授权。若能直接证明配对差的更小误差，可以用其收紧。无界损失或未封闭的时间尾部保留未知，不能将其删为零。

对合并状态，逐步检查可行候选和合法信息等价，再为每期即时效用最大误差 `ε` 与转移分布总变差 `δ` 给上界。若下期价值跨度至多 `S`，一步值误差至多 `ε+γδS`，更长时域加上折现的后续近似误差；总变差采用半个 L1 距离，`γ` 为本期至下一期折现。概率相差 0.1 且下期取值 0 到 100 的转移可使期望差达到 10。保留相同均价却遗漏极端缺口或罕见亡国损失的两个状态，须拆开或扩大界。评估概率区间时保持同一隐藏模型的跨期一致性，处理非矩形集合的方法见[求解与宽度控制](../架构主计划.md#求解与宽度控制)。

当预算不足时，依次考虑可证明的等价合并、有界截尾、只输出有余量的偏序和单处原版残差。每级均校验合法观察、候选组合、归因和最终算子响应。基准简式与精确小图逐格相同且成本较低时可直接特化简式。若仍有可改变结论的未知则回退该贡献。对关乎生存的小概率路线保留有据概率范围和损失上界，既测保守路线获胜，也测低风险高收益足以改选的反例。

## 全体国家的效果验收

先登记固定场景、国家利益终点、最小有意义变化、可接受损失、观察期、模式、DLC 和分组边界，再投放对照。按初始国家及后续出现的国家分别定义目标人口、存续期间、机会暴露和换手。国家灭亡进入相应的损失终点，灭亡前未等到机会属于真实世界路径；新生国在实际存在且符合控制条件后才进入。某国只在一种部署中成立时，单列出现概率及分支所能观测的结果，不能将另一分支随意补成零或拿同标签他国替代。基线可匹配国家的全期结局、各自实际出现机会上的描述性结果及不共同存在国家的差异分别报告，避免只数幸存者、实际采用者或易取证的大国。随机化与不确定性按独立对局／对局组，国内机会之间、同局不同国家均可能相关。

部署本身可改变机会是否出现。欲估计全体部署的国家总效应，部署前固定可比风险集，比较同一物理时窗内各国完整结局，保留机会消失后的实际路线。欲识别某个机会的局部因果效应，可在相同国家、候选、原版相位和可知状态下固定该次机会，成对改变受评判断并保留后续响应。无法这样重放时，明确目标群体、共同支撑、可比性的识别假设和不确定界限。只按两组部署后实际获邀或实际采用的样本计算的差值，登记为条件描述。

设两类机会各有一例，原版都出现，结果分别为 10、0。全体部署后只有第一类出现，结果为 9。两组各自出现机会的均值从 5 升到 9，描述差为 +4；在其他状态相同且能重放的第一类机会中，实际配对差是 9−10=−1。要得到部署对全部国家的总效应，还需记录第二类机会消失后该国在同一观察期的真实结局。若该结局为 x 且两例等权，总差是 (9+x)/2−5；x 未知时只报告由其有据范围给出的界限。

分别检查机制正确、选择时信息与国家利益一致、以及多局实际净效益。记录最差处境和持续退步，分层报告适用国家数及未识别的国家效应。不能区分四格中的某个分量时，仅签署实际可比的总差或条件差。新制度、其他部署、未来更新、不同控制方式的外推均要经新证据验证。[E、M、R、U 的签署与证据口径](../exec/工程基线-1.0.md)
