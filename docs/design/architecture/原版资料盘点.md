在仓库根目录可用以下代码复核安装文档、词法信号、原版定义、策略卡和消费者摘要，使用仓库 Python 执行。`V3_ROOT` 与安装核验命令使用相同值。

```python
from collections import Counter
from hashlib import sha256
from pathlib import Path
import json
import os
import re

from pdx.model import Block
from pdx.parser import parse_bytes
from pdx.situated.vanilla_inventory import discover
from pdx.version_contracts import verify_installation_identity

root = Path(os.environ["V3_ROOT"])
verify_installation_identity(root)
game = root / "game"
common = game / "common"
manifest = json.loads(
    Path("research/official-docs-1.15.2.manifest.json").read_text(encoding="utf-8")
)["文档"]
documents = {path.relative_to(root).as_posix() for path in root.rglob("*.md")}
assert documents == set(manifest), (documents - set(manifest), set(manifest) - documents)
assert all(
    sha256((root / path).read_bytes()).hexdigest() == item["sha256"]
    for path, item in manifest.items()
)
print("官方 Markdown", len(documents))
print("common 一级目录", len([path for path in common.iterdir() if path.is_dir()]))

pattern = re.compile(
    r"^\s*(ai_[a-z_0-9]+|ai|who_can_use|scoring_override|should_auto_expand|"
    r"would_sponsor|will_form_power_bloc|will_incorporate_state)\s*=",
    re.I | re.M,
)
spellings = Counter()
matched_files = 0
matched_categories = set()
for tree in (common, game / "events"):
    for path in tree.rglob("*.txt"):
        found = pattern.findall(path.read_text(encoding="utf-8-sig"))
        if found:
            matched_files += 1
            spellings.update(key.lower() for key in found)
            group = path.relative_to(tree).parts[0] if tree == common else "events"
            matched_categories.add(group)
print("词法信号", matched_files, spellings.total(), len(spellings), len(matched_categories))

block_name = re.compile(r"^\ufeff?([\w.]+)\s*=\s*\{", re.M)
definition_trees = (
    "common/decisions",
    "common/diplomatic_actions",
    "common/treaty_articles",
    "events",
    "common/journal_entries",
    "common/scripted_buttons",
    "common/war_goal_types",
    "common/map_interaction_types",
)
for tree in definition_trees:
    names = set()
    for path in (game / tree).rglob("*.txt"):
        names.update(block_name.findall(path.read_text(encoding="utf-8-sig")))
    if tree == "events":
        print("events 行首候选", len(names))
        names = {name for name in names if "." in name}
    print(tree, len(names))

strategy_files = sorted((common / "ai_strategies").glob("*.txt"))
strategy_cards = 0
strategy_fields = Counter()
for path in strategy_files:
    parsed = parse_bytes(path.read_bytes(), path=path.name)
    assert not parsed.errors, parsed.errors
    for card in parsed.top_assignments:
        if isinstance(card.value, Block):
            strategy_cards += 1
            strategy_fields.update(field.key for field in card.value.assignments())
print(
    "原版策略", len(strategy_files), strategy_cards, len(strategy_fields), strategy_fields.total()
)

inventory = discover(game=game)
print(
    "消费者文件",
    len(inventory.scanned_directories),
    inventory.parsed_files,
    len(inventory.source_hashes),
)
print(
    "声明与引用",
    inventory.discovered_count,
    inventory.capability_counts,
    len(inventory.unknown_scopes),
    len(inventory.references),
)
```

## 逐域复查的证据边界

每次回查以安装及玩法身份、方面 ID、原件相对路径、原字节摘要、定义和字段、出现号、候选的双方方向、触发时相及处置记录为最小单元。由上至下列原版定义、条件和调用，再由下至上核对法律资格、候选生成、哪国能读、谁真正选择以及后果由谁承担。已知名称无消费者、消费者实际候选未知、动态作用域未证、原版自动处理或仅有玩家按钮均可依证据登记。更新分母时同时记录新增的原版机制、合并的重复定位和待解除的缺口。[资料与机会](资料与机会.md) · [来源证据](../../../research/situated/README.md)

源文件、AST 和本页统计提供 `static_check` 或已有冻结 `snapshot`。参考模型、合法观察合同与生成投影的一致性由独立对照建立。固定构建、包及玩法组合下的引擎采纳、角色隔离、存读与长期体验分别由对应范围的 `runtime` 或用户验收建立。本轮游戏内证据未知。[投影与验收](原版算子与投影验收.md) · [证据口径](../exec/工程基线-1.0.md#证据口径)
