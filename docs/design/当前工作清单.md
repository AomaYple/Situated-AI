## 本轮实现

- 条件充分且国家有能力时，提高财政、建筑、教育、贸易、外交、军备、科技和制度消费者的倾向增量。
- 将高合法性、低债务、正结余、行政能力和和平状态组合为严格 `strong_capacity` 高档；同一字段只取一个优先级结果，
  不叠加多个奖励。
- 对高债务、破产临近、投入品短缺、失业、储备不足、市场可达性下降、战争失败恢复和政治危机增加有界纠偏，
  但保留原版资格、成本、随机性、谈判、执行和失败处理。
- 将新读取器 `weeks_until_bankruptcy` 登记为有界数值输入；原版不可见状态保持 `unknown`/`unsupported`。
- 更新生成器版本契约为 1.1.0，重新生成 59 个生产文件；受控文本仍 UTF-8 无 BOM、LF，游戏交付边界才添加 BOM。

## 本轮收口顺序

1. 运行 `modgen --check`、`modguard --offline`、`decision-audit`（生产与离线）。已完成。
2. 运行编码、卫生、lint、格式、类型、baseline、deadcode 和必要的完整回归；记录实际 worker、跳过项、墙钟和 RSS。已完成。
3. 生成并校验 `dist/situated-ai-1.1.0.zip`，核对 manifest、11 种语言、BOM/LF、路径、重复项、探针边界和 SHA-256。已完成。
4. 写入 [1.1.0 结果收据](exec/1.1.0-条件化激进平衡-结果.md)，明确静态检查与用户长期实机边界；不自动替换用户目录中的历史包。已完成。
