## 当前生产机制

原版机会 → 精确对象与真实观测 → 具体行动 → 同因分档取强、独立收益/成本联合 → 消费者末端一次限幅 → 原版比较与执行。
Python只用于开发、编译、检查和打包，游戏中运行有限PDX。核心未知局部回退，辅助未知退出相关增量；正常借款、低识字或行政短板不作为全域禁令。

- 科技按锁定原版科技、建筑、PMG、PM、商品及直接效果派生研究选项。135个具体科技消费者、578项贡献；准备采用档检查真实投入和被替代产出。研究高分不代表建筑、PM或军队已经采用，也不把未来费用当研究即时账单。
- 法律按具体候选的边际效果、实际当前法、真实政治运动、政治阻力和行政转换损失评估。六完整法律族37候选的新派生与既有医疗、教育、行政和社会改革共同进入生产；不从借款推断税收制度收益。
- 大学以实际知识需求形成基础选项，完成academia及真实纸投入准备只影响额外档；违约成本独立参与。铁路以本州基础设施缺口触发基础修复，不要求已有铁路PM；具体PM的投入准备和每种材料成本分别参与。
- 建筑与公司按实际配方识别成本。不同材料独立累计，同一材料短缺/高价分档取强，收益共同参与，最后才限幅；未知PM不把所有已知成本变成健康。
- 社保响应真实生活/粮食压力，政治不稳不再冒充福利需求。医疗、教育、福利和劳动法律保留真实制度、投资、退出损失及独立负担。
- 外交/宗属/军备策略使用实际目标与承诺，付费动员按真实编队owner与候选材料分别权衡；外交支持由同一个连续程序提供参考、生产和IR。
- 没有证明的殖民比例、殖民区域正加分及粗步骑比例材料作者已撤销，恢复完整原版。保留原版只关闭兼容责任，不代表这些面新增业务已经深化。
- 全国排他路线、预算、TTL、切换冷却和旧仲裁模型已退役。国家协调只在消费者求值时读取当前事实；教育、政治、工业和安全需求可以同时存在。真实战败记忆和独立财政迟滞保留，取消旧政治路线迟滞是有意语义变更。
- 原版资格、成本、随机、政治支持、否决和终结零分必须保留；不赠资源、不强制行动、不按国家名写死路线、不改变玩家路径。
