**F0 当前候选实现已完成；F1 已完成一次缺陷修复和短期复验，完整 F1/F2 及整个 Mod 尚未完成。** 当前为 `2.0.0.dev2 / experimental`，使用标准 `integrated` 变体。战略协调、测试设施和同盟修复三批均已合入，交付事实见[dev2 收据](exec/完整候选-结果.md#2026-10-19-dev2-交付收据)。`dev0/dev1`、旧七模块 `full`、原始失败及累计停止保留各自身份与证据。

- 信息声明、适配声明、类型化读取、共享约束、相对比较、实际 PM 配方、唯一字段作者与安全插入位置均进入生产生成链；没有 Python 常驻服务或新增世界扫描。
- 原始全量目录与候选连接分开：目录完整登记发现项，候选按精确来源/路径连接实际合同，祖先命中不代表整个子树。数量和指纹在结果页维护。
- 规则覆盖政治、财政行政、产业科技、市场军需、外交宗属、战争、地理及身份；可读公共信号联合影响原版权重，最终资格、成本及执行继续原版。
- 原版税率枚举、战斗规则及明确保留字段不算 Mod 新实现；精确企业利润/补贴、直接 PM 切换及贸易路线规划等限制在结果页明列。
- 11 种本体语言已有结构生成；语言实际显示/语义、玩家、保存恢复、行为质量和游戏运行性能未验收。旧实机不追认为新候选证据。
