## 当前事实

**F0 源码、标准实验候选与离线出口已完成；整个 Mod 尚未完成。** 本轮遵照用户要求，阶段性 Git 交付后停在 F1 前，未部署或启动游戏。`integrated` 是已冻结的 2.0.0.dev0 全域实验候选；`full` 保留旧七模块身份，两者不可互换。实际检查、冻结指纹、保留项与未新增能力见结果页。

- 信息声明、适配声明、类型化读取、共享约束、相对比较、实际 PM 配方、唯一字段作者与安全插入位置均进入生产生成链；没有 Python 常驻服务或新增世界扫描。
- 原始全量目录与候选连接分开：目录完整登记发现项，候选按精确来源/路径连接实际合同，祖先命中不代表整个子树。数量和指纹在结果页维护。
- 规则覆盖政治、财政行政、产业科技、市场军需、外交宗属、战争、地理及身份；可读公共信号联合影响原版权重，最终资格、成本及执行继续原版。
- 原版税率枚举、战斗规则及明确保留字段不算 Mod 新实现；精确企业利润/补贴、直接 PM 切换及贸易路线规划等限制在结果页明列。
- 11 种本体语言已有结构生成；语言实际显示/语义、玩家、保存恢复、行为质量和游戏运行性能未验收。旧实机不追认为新候选证据。

## F1 接续准备

使用标准 `integrated` 候选，先核对冻结指纹和旧实验账本，再按主计划判断正式样本或独立安全诊断。加载失败归类并修因，不能因普通资源问题停止所有独立工作；也不能借新包清空旧失败窗口。优先验证高风险 scope、法律/建筑/海军消费者及原版尾项，再验证联合规则是否实际改善行动。

运行期每次只允许一个游戏进程，复用 `pdx.game_run` 的互斥、部署、归档与逐字节恢复。没有消费者数值 getter 时验证实际行为，不能拿策略持有或评分变化替代行为质量。已删除定时任务不重建。
