## 当前生产变化

- 显式行动由独立收益、需求金额、成本、关系与因果分组组成消费者联合程序；同字段共同计算后一次限幅。成本可反转净支持，元数据优先级不再冒充效用。
- 旧规则经精确 IR/绑定进入有界消费者程序；同因果来源同方向取最强已知档，正负贡献联合。未声明独立来源的旧条件保持同一包络，不能声称已完成全部旧业务因果拆分。
- 联动只认实际世界条件，不以候选卡可用或获高分代替行动完成；新增程序不添加世界扫描、运行时 Python 或持久资源预留。
- 工业与教育对经济/政府支出平衡使用相反方向；行政成本使用真实行政余额；合法性和识字衍生条件保留原始数值范围。
- 独立 PDX 数值 AST 解释器核对实际生成表达式；玩家、关闭、资格、原版尾部和未知输入继续分别验收。
- 数值字面量保留源十进制精度；公开默认策略参考接口按实际字段作者合并，不再漏掉显式消费者；编译边界对照冻结的完整 reader 签名，拒绝同名事实偷换参数、路径或数值范围。
- 首批业务迁移后生产为11张显式卡及1,499条规则变体（消费者数量由当前生产合同核对）；这些数量不是原版覆盖率或完成比例。
