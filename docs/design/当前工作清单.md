# 当前工作清单

本页是截至 2026-10-10 的状态摘要，不替代 [backlog](backlog.md)。它只保留仍有触发条件、重开条件或发布影响的事项；历史编号、原始讨论和已结案条目继续保存在 backlog。新实测追加到结果页时同步本页，实验参数与完整证据只在结果页维护。

## 读取顺序

1. 先读 [工程基线 1.0](exec/工程基线-1.0.md)和 [Mod 开发原则](../principles/Mod开发原则.md)；
2. 按 [最终执行纲领 1.0](exec/mod重设计-实施计划.md)选择最早仍可执行的阶段；
3. 读取相关 [M1–M5 结果页](exec/README.md)；
4. 需要历史编号、失败样本或原始引用时，再查 [backlog](backlog.md)、[审计](../audits/README.md)和 [报告](../reports/README.md)。

## 允许继续推进的工作

- 修复或扩展工程门禁、文档链接、生成一致性、快照和恢复契约；
- 为 M3 寻找合法、可计数、可复核的新机会或受支持接口，并先写预注册；
- 在获得冻结候选和真实后期输入后执行 M4 资源预算；
- 对政治、市场等扩展继续做默认关闭的接口侦察和负例复核；
- 游戏版本变化时更新输入指纹、范围快照和受影响阶段，不沿用旧实机结论。

## 明确停止条件

- 缺少机会分母、资格窗口、合法存档、完整挂载或零错误门禁时，结论为无法判定；
- 评分、策略切换、脚本强制机会、加载成功、CI 或离线快照不能单独宣布 AI 质量；
- 没有真实后期输入时不把早期长跑写成后期性能；
- 没有支持的 GUI/运行期证据时，不把跨平台代码或无头测试写成平台实机通过；
- 不通过扩大修正、免费资源、暴力削弱、固定国家脚本或无限延长窗口制造成功。
