## 当前事实

**F0 完整实验候选已实现，F1 正在修复实机缺陷；完整 F1/F2 和整个 Mod 尚未完成。** 当前标准候选为 `2.0.0.dev4 / experimental / integrated`。dev3 及此前候选保留；dev4 不含研究、解释、资源或原版修复探针。

- 共享信号、跨领域意图、类型化读取、相对比较和唯一字段作者进入生产生成链，最终资格、成本及行动仍由原版决定；无 Python 常驻服务和新增世界遍历。
- 完整目录记录发现范围，候选按精确来源/字段连接合同。公开脚本不能读取或可靠影响的能力继续列为限制，不冒充全局最优规划。
- 实机发现原舰队内联权重触发 `Invalid mission type 'multiply'`，旧 dev1/dev2 的短诊断存在漏判。统一检测和历史只读复核已补；旧报告及账本不回写。
- 原常量隔离、具名值引用隔离均到菜单交接且目标错误消失。dev4 保留整个动态规则并生成独立值文件；加载接受不证明动态求值或护航行为。
- 日志采集已修复制截断的等长漏字节，真实轮转回放与修复实机归档逐字节一致；主菜单点击无响应仍待定位。
- 前台回退的 `AttachThreadInput` 已按 pywin32 `BOOLAPI` 成功返回 `None` 修复；7 项边界回归通过，真实诊断记录 5 次成对连接/解除并进入国家选择页，但观察者输入前主动结束，不能写成自动化或行为通过。
- 179 科技键与原字节指纹绑定；研究探针的 GUI `IsResearching` 在启动 hook 下实测触发 `GameStateAccess` 断言，已移除该读取并以 `unknown/null` 保留缺口。修复后诊断局完成 55.88 游戏日、两国 179 项观测帧和恢复，断言/脚本/VFS 门禁为零；getter 和完整 AI 候选分母仍未验证，行为保持 `not_evaluated`。
- 11 语言 × 8 键已作模型语义审校；母语质量、真实显示/布局、玩家/保存/禁用/卸载和长期性能仍未验收。
- 当前树第四轮完整验收已通过：4,492 项收集，4,472 passed、20 分类跳过，3 workers/loadscope，89.4620% 分支覆盖率，进程树 RSS 峰 2,956.4 MiB，单 worker 高水位峰 1,305.0 MiB；这只关闭工程质量门，不提升 F1/F2 行为结论。上一轮 4,491 项读数保留在结果页。
