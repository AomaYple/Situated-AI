M0–M5 是质量门；V0.1–V1.0 是逐步交付的可玩版本。每个版本只增加一个模块，必须保留上一版可玩包，并完成新模块的 M1–M4、可玩性烟测、继承模块回归和 Python 交付包检查。

## 明确停止条件

- 缺少对应验证问题所需的机会证据、资格窗口、合法存档、完整挂载或零错误门禁时，不放行正式实验；M3-A 的指定响应机会与 M3-B 的发起候选分母分别核验，实际失败与无法判定分别留档；
- 评分、策略切换、脚本强制机会、加载成功、CI 或离线快照不能单独宣布 AI 质量；
- 没有真实后期输入时不把早期长跑写成后期性能；
- 没有支持的 GUI/运行期证据时，不把跨平台代码或无头测试写成平台实机通过；
- 不通过扩大修正、免费资源、暴力削弱、固定国家脚本或无限延长窗口制造成功。
