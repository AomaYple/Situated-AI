# Situated AI 架构子计划

当前子计划：**A4 1.15 迁移与全域分层联动**（目标版本变量：`TARGET_VERSION=1.15.0`）；状态：已制定，待执行。旧 A3 原始字节见 [A3 归档](archive/A3-manifest.json)。
本页列出战略方向，不把目标列表当作已实现能力；逐项合同与验收边界见[架构深化计划](架构深化计划.md)，其中[范围与验收闭环](架构深化计划.md#范围与验收闭环)是唯一闭环规范。B/R/U是稳定ID的初始集合，不是固定完成分母；每个方向执行时必须以1.15.0独立原版证据建立最小义务，并把新发现追加到台账。旧A3状态只作归档参考。

## 统一执行规则

每个最小工作项都必须回答：具体原版消费者和对象是什么、需要什么事实、哪些是资格、哪些是独立收益、哪些是成本/替代/退出、未知怎么处理、生产writer在哪里、独立参考和PDX见证在哪里。
字段、单位、作用域、时机和性能成本缺一即保持未完成。基础行动只需满足原版必要资格；辅助事实用来分档，不得构造“所有条件都满足才能开始”的全局门槛。

每项分开登记接口状态、产品义务状态和处置决定，按[范围与验收闭环](架构深化计划.md#范围与验收闭环)计算最终结论；不能混用三者。该合同统一定义发现来源、状态组合、A3逐项接收、哈希与依赖失效以及阶段检查，本文不另设第二份状态机。尚未调查、缺适配器或实现成本高不能成为保留/不支持依据。

所有方向还必须遵守“对立且统一”原则：正向收益不能脱离真实成本、约束、风险、机会成本、替代或恢复，原版已计成本不重复扣除；多个领域可以同时提出需求，只在同一对象/消费者/字段发生真实冲突时仲裁。州、国家、市场、战略区域及可观察国际关系的事实不可串用；发起者、目标国、宗主、附属和第三方的角色分别取证，事实对称时允许相同结果。每项可实现义务都登记适用的正反、边界和状态变化见证，不适用有具体依据；未知按资格、成本或辅助信息分别局部处理。

领域之间通过命名端口交互。端口只能消费已经发生或可重读的事实；不能读另一个领域的内部变量、不能在同一轮递归、不能把同一因果复制到多个奖励。每个方向既要登记可实现缺口，也要登记原版已处理、非AI、无合法接口或纯展示的边界。

## B01 财政、行政与国家承受力

收支、债务、利息、偿付、官僚、税制、公共支出、军备承诺和危机恢复分别建模。它们可以同时影响多个行动，但只有在实际消费者中表达相应机会成本；正常借款、低识字或行政短板不能成为所有建设的共同禁令。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B01.1 收支与融资 | 收支、债务/信用、利息、当前偿付与危机分别判断；收入不足和投资需要可同时存在 | 对相关支出和投资表达分档融资成本；正常借款不等同违约，不封死全部建设 |
| B01.2 征税与行政 | 同州可达征税缺口、整合状态、全国官僚及实际行政投入分开 | 行政建筑、合法制度配置等分别响应；有地方征税需要不必同时有全国官僚缺口 |
| B01.3 税制与财政结构 | 已生效税法、可观察税基、政治资格、消费负担与财政需要 | 经合法法律/策略消费者协调财政与社会成本；不凭贫穷强制转法，不凭高收入忽视税负 |
| B01.4 公共支出与承诺 | 可观察的制度、军备和建设负担，维护与新增承诺的区别 | 相关原版预算/策略字段表达机会成本；不将影子偏好声称为已分配真实预算 |
| B01.5 危机与恢复 | 偿付、实际冲击、恢复状态与真实可观察时间 | 危机提高相关新增承诺的机会成本或降低其倾向，保留有效恢复行动；恢复后退出，不形成永久紧缩锁 |
| B01.6 承诺的边际负担 | 当前维护、新承诺与恢复投入分别核对 | 在具体消费者比较新增成本，不假装全国预算已分配 |

## B02 生产、建设、资源、能源与公司

农业基础供给、工业链、建设投入、州级运输、能源、生产方式、公司部门和投资结构分别处理。新版铜矿和建筑AI字段优先纳入调查；新地标/特殊建筑必须与普遍产业建筑区分。短缺带来“先补一部分”的增量，不要求整条链完整后才开始。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B02.1 农业与基础生计 | 粮食/基础品、就业与自给人口、资源和土地约束的可读状态 | 相关农业和基础供给建设；不以低工资推断无限利润，不等所有现代化条件达标才补基础供给 |
| B02.2 工业链与建设能力 | 上下游投入、工具/材料、当前建设成本、真实生产配方 | 各合法工业与建设消费者分开评估；短缺成本保留，不能把整条产业链全部建好作为起步条件 |
| B02.3 生产方式与资质 | 当前及候选 PM、已研究技术、劳动/资质、投入与就业代价 | 比较当前与候选的实际效果差、配套变化和替代代价；候选技术不等于已研究，旧 PM 不假装使用新投入 |
| B02.4 基础设施与能源 | 州级运输、接入、投入和实际能源适用对象 | 铁路、港口、能源等合法建设响应瓶颈与维护成本；市场总余量不等于本州可用 |
| B02.5 公司、服务与投资结构 | 可观察公司部门、经营结构、服务供给和公共/私人投资边界 | 在真实公司/产业消费者内表达条件偏好；不越权控制私人队列，不把公司存在当自动盈利 |
| B02.6 新版铜与建筑AI入口 | 铜—采掘—加工—PM—科技链、22类建筑ai_value与政府建设资格 | 逐建筑验证实际字段及州/国家上下文；地标不计通用产业，不与旧评分重复奖励 |

## B03 市场、贸易、供给韧性与价格

商品、市场、同州可达性、进口依赖、来源集中、运输、关税、封锁和恢复分开处理。高价、短缺、依赖和安全不重复奖励；没有真实路线或消费者时回退原版。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B03.1 供需与价格 | 商品、市场、同州可达性、实际短缺与价格信号 | 在相关生产/贸易消费者中分别响应；高价格不重复充当独立需求、盈利和安全三份奖励 |
| B03.2 贸易机会与成本 | 可读取路线、进口/出口条件、运输、关税和法律 | 合法贸易/外交贸易消费者评估机会与负担；没有路线评分接口时不伪造直接选路线能力 |
| B03.3 依赖与韧性 | 实际进口依赖、来源集中度或其可证实代理、替代来源、封锁风险 | 供应替代、国内能力、贸易与外交组合；不把不可读来源分布假定已知，不要求全部国产化 |
| B03.4 冲击与重配 | 战争、市场脱离、供应中断及恢复的可观察变化 | 恢复性调整、替代方案和退出；同一短缺经多路径到达时不重复放大 |
| B03.5 市场分区与运输重配 | 新版市场/运输/季节成本、实际封锁暴露与可达输入 | 目标市场和州替换不串源；成本、依赖与短缺分别保留，未知不假装路线存在 |

## B04 科技、教育、资质与知识扩散

教育法律、实际制度、识字、大学、研究承受力、候选科技、生产应用和资质需求分开判断。具体科技按前置、当前产业、投入和政治可行性比较，不用统一倍率替代阶段差异。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B04.1 教育基础 | 已生效法律、实际学校制度、识字和教育能力 | 教育/制度/相关法律消费者分别反映真实缺口；准备好教育法律不代表制度已建成 |
| B04.2 研究能力与承受力 | 大学、合法可读创新能力、当前投入、财政与资质 | 相关建设及研究配置分档；研究能力不足增加改善需要，不封死基础工业 |
| B04.3 具体科技选择 | 候选技术及前置、当前产业、政治改革和安全需要 | 按真实解锁效果和当前已有能力比较边际用途、长期价值与成本；不把所有科技套同一倍率，不越过技术前置 |
| B04.4 知识应用与阶段差异 | 已研究技术、当前 PM、可达投入、成熟产业与新兴机会 | 研究—生产应用—资质需求的真实反馈；不把倾向提高当作科技已完成或生产已升级 |
| B04.5 科技到行动的边际价值 | 具体解锁、当前/候选配方、大学政府建设与制度投入 | 科技未完成不兑现新产能；研究、教育建设和应用可分步改善，不共用全满足门 |

## B05 政治、法律、制度、运动与治理

利益集团、运动、政府合法性、法律前置、制度维护、选举、决议、事件和新版巩固/对抗策略分别进入合法消费者。候选法评分不提前兑现制度；稳定、改革和镇压/让步形成有代价的组合。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B05.1 支持、阻力与可行性 | 实际法律、政府/利益集团与可读政治支持、原版转法资格 | 对具体候选法的收益与阻力分别评估；有改革需要不等于有执行资格，也不预设统一意识形态 |
| B05.2 改革路径与顺序 | 法律前置、当前制度、资源与可观察改革窗口 | 比较现法与候选法的真实收益及失去的保护，对可执行局部步骤给出渐进/危机差异；不要求一次满足全部远期改革条件 |
| B05.3 制度投资与维护 | 已实施制度、官僚成本、社会受益与可读执行能力 | 具体制度/相关策略和行政消费者协调；通过法律不直接假装完成制度投入 |
| B05.4 稳定与合法性 | 动荡、政府合法性、政治冲击及其真实暴露范围 | 合法稳定/改革消费者中的权衡；不把异议等同于应无条件镇压或无条件让步 |
| B05.5 选举、运动与国家特有机会 | 可读取政党/运动、选举、决议、日志或事件的 AI 入口 | 分清可读、可影响与纯展示内容；玩家可见“决议卡”不等于 Mod 最小行动卡，不注入无意义事件链 |
| B05.6 巩固、对抗与革命窗口 | 新版两议程、运动/利益集团、制度投资与真实改革条件 | 活跃策略覆盖路径逐项证明；尊重原资格和DLC，不把通用改革倍率套所有制度 |

## B06 人口、劳工、生活、健康、迁移与整合

就业、资质、工资、生活需求、健康/卫生、人口变化、迁移容量、服务、文化、宗教和歧视按州/国家作用域区分。吸引倾向不等于迁移执行，社会整合不等于无条件改革。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B06.1 就业与劳动力 | 同州劳工、资质、工资、可读失业/自给状态 | 相关建设和生产方式权衡岗位、效率与升级代价；不把全国劳力当各州都能使用 |
| B06.2 生活水平与基本需求 | 实际生活/基础品压力、社会结构和财政成本 | 生活供给、社会制度与法律的相关消费者联动；不赠送生活水平，不重复统计贫困代理 |
| B06.3 健康、人口再生产与公共服务 | 合法可读的卫生、人口变化、制度及服务压力 | 对应制度、服务建设或法律倾向；不可读病情和未来人口不编造精确预测 |
| B06.4 迁移、城市化与吸纳 | 目标州容量、实际迁移条件、就业、住房/服务的可读信息 | 在可影响的建设、法律或策略端协同吸纳；不承诺直接选择人口目的地 |
| B06.5 文化、宗教与歧视 | 实际接受/歧视、法律和动荡、政治支持 | 社会整合与政治可行性共同参与；不以文化或国名写固定路线，不凭改革偏好认定已获社会支持 |
| B06.6 人口结构与承载反馈 | 新版pop_type_percent_country、承载、歧视与真实地方吸纳 | 人口比例的单位与作用域逐项核对；全国代理不得替代本州劳工、健康或就业 |

## B07 陆军、装备、动员、军工与战后恢复

安全压力、真实军力、装备解锁、军工供给、动员、战争负担、战败和恢复分层。敌方未知保持未知；战争不自动触发顶格动员，军需成本与财政/劳工机会成本同时存在。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B07.1 安全需要与军力结构 | 合法可读的自身/目标威胁、实际军力和现有负担 | 相关军备/策略消费者表达防御和扩张差异；不能假装知道敌方秘密意图或完整战场态势 |
| B07.2 装备与军工 | 已解锁装备、当前编制、实际军事商品和生产配方 | 比较现有装备与合法候选的实际能力及新增投入，装备、军工、PM 联动；换装需要与真实供应成本共同存在 |
| B07.3 动员与战争负担 | 可观察战争、动员选项、财政/劳工/商品成本 | 具体动员选项按需要与代价评估；战争不是全选高档动员的充分条件 |
| B07.4 战后重建与战备 | 原版战败事实、实际损失或可证实代理、恢复状态 | 先恢复能力再承接相关新风险；不把一次战败变成永久禁战或强制改革 |
| B07.5 战争压力与可持续承诺 | enemy_pressure的真实调用、装备供应、融资与当前承诺 | 威胁只计一次同因贡献，财政与劳工成本独立保留；未知敌情不生成精确概率 |

## B08 海军、海运、港口与海外投射

舰队分类（含新版潜艇面）、基地、港口、运输、贸易保护、封锁、海外目标和投射能力分别核对。沿海身份不等于无条件造舰；海军、国内替代和外交缓和可以竞争。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B08.1 舰队能力与代价 | 已有海军、技术、舰船/军需、财政和可用基地 | 合法舰队/海军建设和装备倾向；不凭沿海身份无条件造舰 |
| B08.2 运输与贸易保护 | 真实海运、港口、运输需求和战争暴露 | 贸易、港口与海军倾向有限协调；运输瓶颈不等于只能扩军 |
| B08.3 海外承诺与可达性 | 海外对象、地理可达、已有利益/承诺和投射能力 | 外交、海外目标及支持行动评估实际能力；不绕过原版航程、利益与资格 |
| B08.4 封锁冲击与替代 | 已观察中断、供应替代、恢复路径 | 国内替代、外交缓解与海军方案可竞争；不把猜测封锁当作已发生事实 |
| B08.5 潜艇、封锁与海上替代 | 潜艇分类/舰队输入、blockaded_gdp_share、港口和季节运输 | 逐精确消费者证明海军/港口/进口替代/缓和的条件收益；无接口的调度保留原版 |

## B09 外交、条约、市场合作与国际关系

双边关系、力量、利益、承诺、条约、市场/集团、声誉、竞争和危机缓和按目标对象独立判断。宗主/附属视角分离；盟友存在不等于参战承诺已完成。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B09.1 双边利益与威胁 | 本国/目标国真实关系、力量与已观察利益 | 具体外交目标、态度或可写策略偏好；不同对象交换后结论随真实身份改变 |
| B09.2 条约与承诺 | 合法候选条约、已有义务、目标需要与可负担性 | 精确条约消费者协调收益和新增承诺成本；已有同盟不假装必然参战 |
| B09.3 市场合作与国际组织 | 已有市场关系、集团/合作的可读状态、资格和影响力 | 相关合作消费者与产业贸易联动；无接口时保留原版，不声称控制集团成员决策 |
| B09.4 声誉、竞争与危机缓和 | 可读恶名、外交压力、竞争对象和恢复条件 | 对扩张/合作/缓和的相关倾向表达权衡；声誉不作为所有外交行为共用禁令 |
| B09.5 新条约与目的化可达 | 新条约、人物互动、relations调用及不同外交目的 | 提案、接受、维持和解除分开；发起者/目标/付费方互换见证，原拒绝与执行保持 |

## B10 战争目标、地区目标、升级与和平

新版 `state_target/country_target`、可达性用途、战争目标价值、升级风险、持续战争、和平和多线恢复分开建模。一个目标字段不能代表所有外交行动；不可观察的参战概率不伪造精确值。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B10.1 目标价值与可执行性 | 候选对象、实际资格、地理/战略/经济利益和代价 | 具体目标/外交博弈消费者比较目的；不因战争需要强制制造目标资格 |
| B10.2 承诺与升级风险 | 已有战争、联盟/承诺、力量及可读外部威胁 | 新冲突、支援与相关条约的边际负担；不假装精确预知各国参战概率 |
| B10.3 持续战争与和平选择 | 可读战争状态、成本、既有目标和精确和平评估入口 | 合法和平/让步倾向与恢复方案；接口未暴露时不以脚本名猜测控制力，不强制签和平 |
| B10.4 多线压力与恢复 | 多线负担、财政/装备/供应压力及冲击退出 | 军事、外交和经济恢复共同参与；同一战争成本不在单一消费者内重复累计 |
| B10.5 新版对象与战争持续性 | state_target/country_target/invalid、征服/胁迫/宗属可达和僵局/投降 | 无效目标、目的错配和对象替换不能沿用旧权限；暴露defines不冒充可写执行器 |

## B11 殖民、地理、资源、边疆与地区发展

殖民资格、地区目标、资源机会、相邻/可达、整合、行政、运输和当地代价分别处理。资源吸引只是一项机会，维护和国际代价必须仍参与；替代的贸易、宗属和合作不能被单一路线锁死。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B11.1 殖民需要与政治条件 | 原版殖民资格、法律/制度、实际能力和国内约束 | 合法殖民/法律/策略消费者分层；不把原版必要资格当作不合理门槛移除 |
| B11.2 地点与资源机会 | 实际可读资源、相邻/可达、气候/地形或相关修正 | 精确州/殖民目标与资源建设评估；不凭洲名或国家标签决定恒定优先级 |
| B11.3 整合、维护与当地代价 | 真实控制状态、整合、运输、行政和社会压力 | 殖民、行政、港口和当地发展协调；殖民目标价值不覆盖维护与冲突成本 |
| B11.4 替代扩张与退出 | 市场合作、宗属、贸易与殖民的可观察替代收益 | 在各自合法消费者内调整倾向；不假装中央执行器统一选中并锁定海外路线 |
| B11.5 资源、维护与替代组合 | 新版铜及其它可见资源、地方资格、运输与国际维护 | 具体地点、技术和合法对象独立取证；单项真实机会可起步，不强制殖民优于贸易 |

## B12 主权、宗属、身份与国家特有机制

依赖、自主、宗主/附属收益、市场互惠、地位、承认、独立和关系重组按真实身份和合法消费者判断。新版人物互动、哥萨克及国别机制只有在可泛化、可证据化且不把国名写死时才进入通用内核；纯叙事保留原版。

| 稳定方向 | 独立调查与分层目标 | 最小验收与反例边界 |
|---|---|---|
| B12.1 依赖与自主能力 | 实际宗属关系、市场/财政/军事依赖、可读自主空间 | 合法宗属与自主相关消费者权衡自身利益；不把独立等同于任何处境下的最优解 |
| B12.2 宗主与附属收益成本 | 双边真实义务、市场互惠、控制收益和承诺负担 | 分别核对宗主/附属视角和目标身份；不共用颠倒的作用域与数值方向 |
| B12.3 地位、承认与身份限制 | 实际地位及原版认可/资格条件 | 可读信息进入合法外交、发展与改革行动；不赠送承认、不越过原版身份资格 |
| B12.4 独立、整合与关系重组 | 合法候选关系、真实能力/支持/风险和退出条件 | 仅在有证据的消费者内评估；不使用已退役的实验宗属开关或仅为凑覆盖启用不安全扩展 |
| B12.5 新版身份与专属制度 | 哥萨克、革命阵营、人物/国家身份机制、主权和宗属关系 | 逐接口区分通用条件、原版专属资格和纯叙事；保留原国别内容，不编造通用控制权 |

## R01–R12 联动族

| 联动族 | 重点路径与负责领域 | 必须区分的权衡与反例 |
|---|---|---|
| R01 | 财政—行政—有效收入—公共能力（B01、B05） | 地方征税与全国官僚分开；行政扩建有投入和维护成本，偏好增加不算收入已提高 |
| R02 | 教育—资质—研究—生产应用（B02、B04、B06） | 基础建设先可行，已具条件再给高档；研究、识字和 PM 升级不能互相假装已完成 |
| R03 | 基础供给—就业收入—财政—工业机会（B01、B02、B06） | 生存供给与高附加值投资分别评估，工资/就业代理不重复计益 |
| R04 | 投入—能源运输—生产升级—贸易替代（B02、B03、B08） | 同州可达与市场总量分开，瓶颈带来改善需求和真实成本，不能形成全链全满足锁 |
| R05 | 社会压力—政治可行性—法律—实际制度（B01、B05、B06） | 改革需要和政治阻力并存；仅已生效法律/制度影响后续事实，候选评分不提前兑现 |
| R06 | 人口流动—地方就业—资质服务—社会整合（B02、B04、B06） | 人口与目标州作用域一致；吸引倾向不算真实迁入，不越权控制迁移执行器 |
| R07 | 安全压力—军备—工业供给—融资（B01、B02、B07） | 同一威胁分档，不重复奖励；战时也保留军需和财政成本，不自动顶格扩军 |
| R08 | 海运依赖—贸易韧性—舰队/港口—外交缓和（B03、B08、B09） | 海军、国内替代和合作可并存竞争，真实海权不足不等于必须军事扩张 |
| R09 | 外交承诺—升级风险—战争负担—和平恢复（B01、B07、B09、B10） | 无法观察的参战概率保持未知；不从条约评分推断盟友已承诺执行 |
| R10 | 海外机会—殖民能力—当地维护—国际代价（B08、B09、B11） | 资源吸引与投射/治理成本共同参与，目标切换后端口映射不串国串州 |
| R11 | 宗属依赖—市场收益—安全承诺—自主选择（B03、B09、B12） | 宗主与附属利益分别核对；独立与合作都有处境化收益成本，不预设身份终点 |
| R12 | 战败/供应危机—恢复能力—改革窗口—新承诺（B01、B04、B05、B07、B10） | 危机是可观察冲击，恢复后退出；一次战败不等于获得转法或下一场战争资格 |

每条链都必须逐边确认：端口身份、来源事实、单位方向、作用域、时效、同因ID、共享成本、替代、断边和退出。R族不是全量两两配对分母；盘点中新发现的有效依赖必须增加稳定ID，不能静默丢弃。

## U01–U10 对立统一横切机制

这些机制横跨 B01–B12 和 R01–R12；它们不是新的领域功能，而是所有领域实现必须共同满足的设计与验收维度。

| 横切机制 | 统一要求 | 最小验收边界 |
|---|---|---|
| U01 多目标张力 | 需求、能力、收益、约束、风险、承诺、替代和恢复分开记录 | 每个适用消费者的独立收益与真实代价并存或有不适用依据，原版成本不重复扣除 |
| U02 机会成本 | 建设、军备、改革、外交、殖民和福利都保留可观察的资源/政治/安全代价 | 单因素改变只改变对应代价或收益，不凭空改变资格或行动完成 |
| U03 替代与组合 | 同一国家可以并存多个行动；受阻行动可由合法替代竞争 | 每个适用替代有阻断、替代和恢复序列；没有全国中央队列或虚构预算 |
| U04 多尺度 | 州、国家、市场、战略区域及可观察国际关系使用声明作用域 | 对象/作用域替换不串源，聚合有合法映射，不强制相同事实产生不同结果 |
| U05 角色不对称 | 适用角色的收益/成本方向分别取证 | 角色互换重新求值，不能复用相反证据；事实对称时允许相同结果 |
| U06 阶段与反馈 | 可并存的领域状态随真实事实变化，不是全国排他路线 | 每个适用状态序列有进入、变化、退出及阻尼/其不适用依据和替代路径 |
| U07 不确定性 | 不可见信息保持未知，部分可见信息使用声明档位 | 未知不变成零/健康/无风险；核心未知局部回退原版 |
| U08 路径与惯性 | 已发生承诺影响后续，但不永久锁死行动或伪造完成 | 承诺、冷却、方向反转和到期均可退出；不生成无界状态 |
| U09 内生特征 | 国家风格由处境、制度、资源、关系和历史反馈形成 | 同一国家输入变化会改变倾向；无国名硬编码路线 |
| U10 解释与复杂度 | 每条张力边追溯到字段、消费者和证据，运行期成本受控 | 能生成因果解释、正反边界和资源测量；不以说明文件代替生产接线 |

U01–U10逐项映射到全部生产义务、联动边与生命周期，不能靠全局样例关闭矩阵；精确合同由[横切验收](架构深化计划.md#u01u10-对立统一横切验收)维护。U系列完成不代表领域自动完成，每个B方向与R联动仍须分别通过生产接线和独立见证。

## 新版优先调查族

- **AI策略与地区目标**：巩固/对抗策略、州/国家目标、目的专用可达性和目标替换。
- **生产与资源**：铜及新增生产方式、建筑 `ai_value`、政府建设资格、公司和特殊建筑。
- **战争与海运**：封锁GDP、敌方压力、僵局/投降、潜艇、季节运输成本和港口。
- **政治与社会**：新版法律、制度投资、人物互动、哥萨克、人口/健康/教育新入口。
- **事件、按钮、条约**：新增事件/JE/按钮/条约文章的AI入口、完整父结构和玩家路径保护。

这五族是A4-1的调查优先级，不代表它们已经获准写入生产。

## 方向完成边界

完成一个方向需要该方向全部发现与新增义务的逐项终态证明；生产纵切及独立见证覆盖所有适用等价类，不能用一条样例代签整域。只有原版已满足目标或精确不可实现等边界才可按合同处置，纯保留方向不强造无用writer，尚待确认仍阻止关闭。跨域联动完成不等于任何一侧领域完成；所有R族及新增有效边、领域和时间义务收口后才进入整Mod复核。

## 小计划拆分与推进方式

以上保留A3的52个细分方向，新增12个新版/纵深方向，形成64个调查方向；另有U01–U10十项横切机制。它们是范围起点，不是64项功能或完成率分母。
每个方向依据1.15.0原版拆成具体消费者义务；A3的96项历史义务须逐项关联到A4处置，17项旧签实现也不自动通过新版验收。方向、联动和横切机制只有全部相关义务进入终态后才能关闭，不能以一个纵切、静态报告或脚本加载成功代签整域。
新增入口或依赖继续追加稳定ID；不得删除难项、把待调查写成不支持或用批量保留冲完成率。

一个小计划完成一个可独立审查的生产纵切：明确源和目标 → 证实必要资格/事实与未知 → 类型化端口及独立收益成本 → 精确IR/writer → 独立参考/PDX正反见证 → 定向检查和收据 → 中文提交。
同源/同消费者家族可批量取证和复核，使用一次不可变解析结果；缓存必须绑定完整输入身份。先用一个真实纵切证明公共机制，再按家族推广；不为每个方向重造一套引擎。

领域、联动、时间和数值随纵切共同交付；A4-3/4/5分别检查覆盖面、逐边关系和生命周期，避免先写遍所有领域再补接线。测试按变更域集中运行，冻结最终候选后才做一次完整回归；失败保留并只重跑受影响检查，候选改变使最终验收失效。

小计划按深化合同的六步闭环收口；同一底本的共享事实和保护证据只维护一份，引用完整身份。阶段集中检查覆盖与失败状态，不重复运行未受影响的完整回归，也不因阶段提交重写历史收据。
