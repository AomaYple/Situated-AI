## 执行与验收方式

每个 `Bxx.n` 是一个可继续拆分的战略方向；执行 A3-0 时依据锁定原版，把其中独立决策缺口逐一登记成 C3 最小工作项。
表中的观测是调查范围，必须先证明实际可读；“影响”仅经精确合法消费者提供有界倾向，不代表直接执行。
无 AI 消费者、不可读或不具决策价值的条目须提供逐项依据，只闭合盘点责任；待确认项和已知可实现缺口不能这样关闭。
原版已有完整判断可核对并保留，不能把它计作新增功能；可实现且有实质价值的缺口不能仅凭一条样例宣布整个方向完成。

各方向都需完成：事实/作用域与成本 → 领域分层 → 最小行动及独立贡献 → 适用跨域端口 → 实际 writer → 独立参考/PDX见证。
具体字段、数值、文件拆分和子项数量依据证据决定，目标与验收不因此含糊；范围变动按 C1 记录差异，不能缩范围冲完成率。
每个完成的小工作项定向验收并中文提交。共用基础合同统一维护，不为每个领域复制一套规则引擎。

## B01 财政、行政与国家承受力

| 方向 | 需要区分的事实和机制 | 目标影响面与反例边界 |
|---|---|---|
| B01.1 收支与融资 | 收支、债务/信用、利息、当前偿付与危机分别判断；收入不足和投资需要可同时存在 | 对相关支出和投资表达分档融资成本；正常借款不等同违约，不封死全部建设 |
| B01.2 征税与行政 | 同州可达征税缺口、整合状态、全国官僚及实际行政投入分开 | 行政建筑、合法制度配置等分别响应；有地方征税需要不必同时有全国官僚缺口 |
| B01.3 税制与财政结构 | 已生效税法、可观察税基、政治资格、消费负担与财政需要 | 经合法法律/策略消费者协调财政与社会成本；不凭贫穷强制转法，不凭高收入忽视税负 |
| B01.4 公共支出与承诺 | 可观察的制度、军备和建设负担，维护与新增承诺的区别 | 相关原版预算/策略字段表达机会成本；不将影子偏好声称为已分配真实预算 |
| B01.5 危机与恢复 | 偿付、财政迟滞、冲击、恢复状态与真实可观察时间 | 危机降低相关新增成本并保留有效恢复路径；恢复后退出，不形成永久紧缩锁 |

## 领域外入口和新发现

A3-0 同时盘点上述分组之外的原版 AI 入口，例如可读的政令、决议、日志、事件 AI 选择及新版本机制；
有实际价值且能兼容接入的缺口增加稳定方向 ID，与既有义务一起验收。
纯叙事、玩家操作、未暴露执行器和引擎内部调度不为追求“全覆盖”而伪造控制。
没有领域归属的接口必须有去向，不静默丢弃；此入口不是将已发现的合法缺口无限延期的清单。

## R01–R12 重点联动子计划

以下是必须盘点并闭合的链路目标；不是在当前同一次求值内递归执行整条因果链。
每条链消费各节点已发生的真实状态，分别映射相关行动与消费者；按 C6 提供逐边、断边和组合见证。
中间环节没有可读状态或合法影响端时记录具体边界，不能跳过缺口却宣称整条链已实现。
适用的计划内联动义务必须全部生产接线；这些链也不替代盘点中新发现的其他有效联动。
联动全集从已确认的领域输出、消费需要和共享因果独立调查，分类、ID 和证据按 C1 冻结；未选入重点链的实际依赖不能遗漏。

| 链 | 重点路径与负责领域 | 必须区分的权衡与反例 |
|---|---|---|
| R01 | 财政—行政—有效收入—公共能力（B01、B05） | 地方征税与全国官僚分开；行政扩建有投入和维护成本，偏好增加不算收入已提高 |
| R02 | 教育—资质—研究—生产应用（B02、B04、B06） | 基础建设先可行，已具条件再给高档；研究、识字和 PM 升级不能互相假装已完成 |
| R03 | 基础供给—就业收入—财政—工业机会（B01、B02、B06） | 生存供给与高附加值投资分别评估，工资/就业代理不重复计益 |
| R04 | 投入—能源运输—生产升级—贸易替代（B02、B03、B08） | 同州可达与市场总量分开，瓶颈带来改善需求和真实成本，不能形成全链全满足锁 |
| R05 | 社会压力—政治可行性—法律—实际制度（B01、B05、B06） | 改革需要和政治阻力并存；仅已生效法律/制度影响后续事实，候选评分不提前兑现 |
| R06 | 人口流动—地方就业—资质服务—社会整合（B02、B04、B06） | 人口与目标州作用域一致；吸引倾向不算真实迁入，不越权控制迁移执行器 |
