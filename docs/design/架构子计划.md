# Situated AI 架构子计划

状态：**仅目标，未启动**。本页只维护领域目标与目标级边界，不写算法、阈值、代码、适配实现或实施步骤。
未来先完成[架构主计划](架构主计划.md)，接口合同见[1.15架构设计](1.15架构设计.md)，当前事实见[工作清单](当前工作清单.md)。
25个领域是可修订的规划分类，不是完整能力分母，不证明1.15支持相应控制权，更不继承旧版完成率。

## 共同目标与边界

每域最终均应能说明：具体对象、真实可观察需求与能力、收益/成本、相反目标、跨域关系、时空边界和原版实际消费者。
每域目标都必须绑定适用的国家 actor、可观察利益来源和观测时点；相对最优只在同一原版消费者的候选集合内表达。
独立依据、逐层处境派生与条件联动三类路径可以并存，按行动需要组合，最终汇入统一行动评价与消费者出口；
不以穿越全部层、层数增加或每层加分衡量深化。职责分层与可降低网络的详细合同只在[1.15架构设计](1.15架构设计.md)维护。
因果目标是区分共享证据与真实效应：同事实的不同收益和成本可共存，同效应的别名与重复路径不叠加；
联动只补充有依据的交互部分或显式替代已有项。必需未知成本与相关收益保持完整性，深化不无故抹去已知独立项，也不重复原版已计成本。
时序与尺度目标是区分当前候选、已发生承诺及新的真实观测，并在地方、国家、市场和双边对象以及短期、长期之间保持身份和边界；
局部压力不无依据升级为全国禁令，跨时点反馈不冒充同轮已实现结果。
广度以独立原版发现项逐项处置，深度以国家处境/利益→事实到行动到消费者内比较的完整解释链衡量；能力未知、不支持、原版保留和未实现分别公开。
输入不足时局部回原版；不赠送资源、不强制执行、不改变玩家路径、不以全国唯一发展路线替代具体权衡。
这些是目标级成功标准；后续被选中的领域才单独制定实施计划和验收场景。

## D01 财政、税收与债务

目标：同时识别经常收入、偿付压力、税负承受与危机恢复需要；短期现金改善不掩盖长期承诺与社会代价。

## D02 行政、征税与国家能力

目标：区分地方征税缺口、中央行政承受与制度能力；改善具体瓶颈，避免负行政成为所有发展的全国禁令。

## D03 建设能力与投资节奏

目标：平衡新增建设、既有队列、真实财政和资源承受；保留恢复与基础发展机会，避免无成本扩张或长期停滞。

## D04 农业、粮食与基础资源

目标：识别具体地区资源条件、基本需求和供应脆弱性；兼顾就业、资源约束与市场变化，不预设统一产业路线。

## D05 制造业与产业结构

目标：评估具体产业机会、投入约束、就业与结构风险；区分需求增长和不可持续过剩，保留国家发展差异。

## D06 能源、运输与基础设施

目标：识别地方运输、电力及基础设施瓶颈与准备度；避免同一缺口重复奖励，协调新产能与可持续运行条件。

## D07 生产方式与技术采用

目标：权衡具体生产方式的投入、劳动力、资格、产出与转换风险；技术存在不等于立即采用最优。

## D08 所有权、资本、公司与投资关系

目标：兼顾产权变化、投资能力、公司条件、国有化成本与外资依赖；区分可观察收益和不可保证的未来资本流动。

## D09 国内市场与商品平衡

目标：识别具体商品、市场与地方供需矛盾及替代空间；区分价格信号、供给安全和生活需求，不把一次信号扩大为全市场政策。

## D10 国际贸易与供应韧性

目标：兼顾可获得供给、运输条件、依赖暴露和贸易收益；候选贸易改善不冒充已经实现的进口或供给。

## D11 人口、就业、劳动力与资格

目标：区分人口结构、可观察的出生与死亡变化、失业、缺工、资格不足及劳动结构变化；使具体发展机会与实际人力相联系，避免重复计算同一人口约束。

## D12 迁移与人口流动

目标：兼顾迁入吸引、迁出压力、就业、生活条件和制度边界；不把迁移意向视为确定人口增量。

## D13 教育、人力资本与社会流动

目标：区分基础教育、资格形成、高等教育与长期流动目标；保留低识字国家的发展需要，同时面对真实财政与制度成本。

## D14 研究、扩散与科技选择

目标：区分自主研究、传播机会、采用准备和现实需求；不预设统一科技顺序，不把未观察的未来回报当确定收益。

## D15 国内政治、政府与权力

目标：兼顾合法性、已知政治支持、政府稳定与利益分布；尊重现行制度和候选差异，不按国名或统一意识形态选择路线。

## D16 法律改革、运动与制度转换

目标：权衡具体法律相对现状的收益、支持、阻力与转型风险；既不以阻力自动否决所有改革，也不假定改革必然成功。

## D17 生活水平、公共健康与社会保障

目标：识别群体脆弱性、基本消费、健康和保障需求；兼顾持续负担与长期发展，不以单一平均数遮盖真实分化。

## D18 稳定、动荡与内部安全

目标：区分已发生动荡、可观察压力、镇压成本与恢复需求；稳定手段和民生改善各有代价，不能依靠无依据全国惩罚制造秩序。

## D19 文化、宗教、公民身份与整合

目标：面对具体身份群体、制度待遇、融合和政治社会后果；避免统一同化路线，尊重可观察信息与玩家边界。国家形成、统一与分离的身份和政治目标归本域，具体领土机会与外部冲突归D25/D24，均以能力核实为前提。

## D20 外交、条约与国际秩序

目标：评估具体双边对象、条约承诺、相互利益、威胁与信誉代价；集团等内容以能力证实为前提，不假定对方必然接受。

## D21 宗主、附属与自治关系

目标：同时表达安全、市场、资本依赖与自治诉求；明确两端对象和不对称利益，不把宗主收益当作附属国收益。

## D22 陆军、备战、动员与装备

目标：协调可观察威胁、兵力准备、供给、人力与持续负担；安全需要与可负担约束并存，和平或战时均不无成本扩军。

## D23 海军、海运与海外投射

目标：区分海上安全、运输暴露、具体舰队角色、补给和海外能力；尊重编成、任务与船舶消费者的不同语义。

## D24 外交博弈、战争、和平与恢复

目标：权衡具体冲突的目标、盟友、风险、消耗、退出与战后恢复；不把行动意图当胜利，不以战时需求屏蔽偿付与民生。

## D25 殖民、海外与领土机会

目标：评估具体空间机会、合法资格、投射与行政承受、竞争和长期承诺；扩张与恢复并存，不预设全球扩张路线。

## 跨域联动目标

以下关系同样仅目标，未启动；不是已经存在的运行期联动。

| 关系 | 目标 |
|---|---|
| 资源—生产—市场—贸易 | 区分实际供给、潜在机会和依赖风险，使同一商品缺口不在多域重复计分 |
| 建设—财政—行政—制度 | 同时面对新增能力与真实承诺，保留基础恢复空间，不虚构全国统一资源预留 |
| 人口—教育—生产方式—产业 | 连接资格、就业、技术采用与发展需要，区分短期瓶颈和长期收益 |
| 民生—身份—迁移—稳定 | 同时表达群体差异、制度代价、流动和稳定目标，避免平均值掩盖脆弱性 |
| 政治支持—改革—国家能力—社会结果 | 区分改革意图、通过可能和已实现变化，保留支持与阻力的相反作用 |
| 贸易依赖—外交—海军—海外 | 面对具体伙伴、航线暴露和投射承受，使安全与经济利益共同可解释 |
| 宗属—市场—资本—安全—自治 | 保留双边不对称目标，区分短期保护与长期依赖，不把一端利益冒充共同利益 |
| 战争—军需—财政—人口—恢复 | 同时面对威胁、消耗、持续负担、和平机会与战后修复，避免战争覆盖所有发展目标 |

地理、对象尺度、时间、DLC条件和不确定性是所有目标的共同维度，不另算业务领域以夸大覆盖。
真实世界的反馈必须通过已发生事实；目标关系不声称拥有引擎未提供的联合优化或执行权限。

## 横切产品目标与归属

以下目标横贯各域，不新增业务领域，也不代表已完成；架构必需合同先由主计划建立，后续增强仍只登记目标。

| 目标 | 架构阶段必需边界 | 后续增强目标 |
|---|---|---|
| 本地化与展示一致性 | 沿用Mod开发原则的全部支持语言、自有键集合、占位符、命名与编码约束；领域扩展和版本迁移不能使既有交付合同失效 | 随领域深化完善真实新增内容的译文与说明；未完成译文如实标记，不把键齐全等同于翻译质量通过 |
| 配置与模块可用性 | 明确核心与领域开关的适用对象、依赖和组合边界，关闭、不可用及移除时局部回原版；配置不得改变玩家路径或绕过原版资格 | 依据实际需要改善配置说明与可理解性；不预设新增设置界面，也不因配置项数量宣称领域覆盖 |
| 可解释性与反馈 | 原因、对象、参与贡献、未知与退出能够追溯到事实、声明、消费者和生成证据；构建期解释与游戏内可观察能力分别声明 | 利用用户提供的版本、包身份、存档和日志辅助定位偏差；按已证实能力改善说明，不强制新增游戏UI、探针或长期观测任务 |
| 兼容与演进 | 原版版本、DLC、玩家、存档、卸载及第三方边界由主架构统一维护，领域目标不得另行承诺未经验证的兼容性 | 后续逐项研究具体兼容需求并保留证据，不以加载顺序、无持久变量或静态通过替代实际支持结论 |

## 后续领域深化的目标级出口

- 广度：从1.15独立原版分母核对遗漏，解释保留原版、待研究与证实不支持的边界。
- 深度：每个已深化机会均有实际对象、观察、需求/能力、收益成本、关系与时序及原版消费者的对应。
- 联动：独立、逐层与条件联动路径均可解释并统一收敛；共享证据不抹去不同效应，重复效应不叠加，必需成本与收益不被拆散。
- 时空：地方与全国、同市场与双边对象、短期与长期保持明确边界；候选评价、实际执行和新观测分别说明。
- 可用性：未知、关闭、玩家、DLC缺失和原版特殊语义有可信边界；新增领域不要求核心加入政策特例。
- 行为质量：长期平衡、游戏内性能和体验保留给用户实机验收，不由静态证据代签。
