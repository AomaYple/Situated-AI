# Situated AI A4 深化合同与验收边界

A4的公共合同把1.15.0迁移、极致分层、全域广度、跨域联动和可交付性绑定在同一证据链上。它是战略合同，不冻结文件数量、阈值或具体执行顺序；实现时可按原版证据调整，但必须保留差异与原因。

## C1 版本与范围冻结

锁定安装根、EXE、可取得的游戏/Clausewitz修订、Jomini输入、源文件身份、研究材料和包源；未暴露的修订保持未知，不伪造版本身份。旧1.14.5快照只用于比较。范围表分开记录“接口状态”和“产品义务状态”；缺字段、源漂移、删除/新增、DLC差异和作用域变化都必须有稳定ID。

**出口：**1.15.0精简/必要完整快照、生产锁、AI surface索引、来源清单和差异报告均可复算；任何混合输入硬失败。

## C2 证据图与类型化端口

节点至少包含来源、实体、作用域、单位、方向、有效时机、未知策略、求值成本、生产消费者和因果ID。端口只能输出声明过的类型；跨域依赖不得通过复制代码或内部导入隐藏。

**出口：**每个端口有正例、否例、未知、边界、对象替换和版本反例；未知不会静默变成零/健康/没有需求。

## C3 最小行动合同

最小行动固定为“具体原版消费者 × 具体对象 × 一次倾向评估”。行动可以分为保底、机会、风险、恢复和替代档；每档独立记录收益、成本、资格和退出。行动卡、规则行动、IR实例和PDX writer共用追踪ID。

**出口：**每个生产writer都有独立证据、原版消费者、对象作用域、正/负贡献、未知回退、关闭行为和执行尾部保护；没有只写名称的空卡。

## C4 分层无全满足门槛

必要资格只由原版必要条件决定；辅助事实作为分档、加成、成本或替代，不组成全局AND门。每个基础行动都要有“只有一项短板改变”的反事实见证；短板改善时增量可逐级提高，缺少远期配套不阻止合理起步。

**出口：**对有依据的最低可行、改善、成熟和危机/恢复档逐项验证；不适用的档位记录理由，不凭空造成本或门槛。基础行动至少一个正例证明局部起步，至少一个反例证明不越过原版资格。

## C5 联动与因果预算

关系有类型：互补、约束、替代、冲击、恢复。在同一消费者评估内，共享因果使用同一ID去重；不同消费者仍分别承担真实成本，不能把去重当成已分配资源。独立收益/成本可叠加；同消费者末端一次限幅。关系图必须定向分层，同一求值内不得递归；跨轮循环只通过真实原版状态变化。

**出口：**每条关系逐边通过正例、断边、同因去重、对象替换、未知退出、冲突和组合见证；关系消失后无残留奖励。

## C6 国家画像与多目标仲裁

画像只作有限解释层，不生成万能总分。需求、能力、机会、风险、承诺和恢复分别保留单位与来源；只有在同一消费者的合法字段上做有解释的联合。多个领域需求可并存；真实冲突由原版消费者和局部权衡解决。

**出口：**同一国家可同时拥有建设、教育、安全、外交和恢复行动实例；互不相关行动不会因一条全国路线被排除。

## C7 时间与持久边界

事实时钟每次重读；承诺时钟只覆盖合法期限；恢复时钟以真实冲击为起点并可退出。只有不能从原版重读、且有独立决策价值和生命周期的状态才持久化。

**出口：**输入变化、期限到期、恢复完成、关闭/未知均有静态生命周期见证；持久状态还须核对原版存储/重载合同、过期与迁移语义。静态重载模型不称为实际游戏存读档实测；不生成无界变量、常驻服务或虚假行动完成状态。

## C8 兼容、性能与内存

优先原版消费者与求值时机；禁止不必要的整文件覆盖、无界世界扫描、重复reader、冗余持久状态和无证据缓存。引擎加载规则要求输出完整父结构或同源文件时，记录原因并逐项保护非目标内容，不以此获得整文件写入权。生成和检查可批量化，但必须保持输出、异常、回退、覆盖率和资源门语义。

**出口：**生产源码/生成物/锁/包身份一致；同口径测量报告解析时间、生成时间、测试墙钟、worker、峰值RSS和产物大小；任何提速都附语义等价证据。游戏内性能仍标为用户验收。

## C9 原版保护与发布

原版资格、成本、政治支持、随机、拒绝、终结零分、玩家路径、事件/JE父结构、同名兄弟、语言头和占位符都要保护。生产包不含Python、探针、日志、缓存、历史证据或研究源码。

**出口：**全部语言、生成、审计、完整回归、包manifest/SHA、工坊正文、部署和恢复步骤一致；只发布 `vMAJOR.MINOR.PATCH` 正式版本。

## C10 复核与未知清单

在A4-7，对所有未改动消费者、所有生产writer、所有目录和文档做整Mod复核。`native_exact`、`derived_typed`、`boundary_unknown`分开统计；接口未知但已有精确不支持依据的项保持边界，尚未调查确认或已知可实现的产品缺口阻止A4完成，不得转嫁给用户长期验证。

**出口：**逐项清单与结果收据可以回答“已实现什么、保留什么、未知什么、为什么”；清理不删除原始证据，删除/移动前有调用方与生成入口核对。

## C11 数值语义与可解释性

每个消费者分别记录原版尺度、符号、单位、阈值来源、收益/成本来源、同因组、正常/危机响应、饱和及恢复退出。阈值假设与原版硬资格区分；不让统一倍率掩盖候选差异，不要求所有领域都用同样档位。

**出口：**生产参考与真实PDX对单因素、独立收益成本组合、同因重复、临界边界、对象互换和恢复序列给出一致结果；解释链指向具体源、端口、writer和最终字段，不用报告存在或分数变化证明行为质量。

## U01–U10 对立统一横切验收

U系列将“对立且统一”作为所有领域和联动共同承担的验收维度。U系列不能关闭任何 B 方向或 R 联动；它要求每个生产纵切都在同一套张力、多尺度、反馈和不确定性规则下实现。

| 编号 | 合同 | 最小出口 |
|---|---|---|
| U01 | 多目标张力 | 一个具体消费者同时保留至少一项独立收益和一项独立成本/约束/风险，并能追溯末端仲裁 |
| U02 | 机会成本 | 建设、军备、改革、外交、殖民或福利的单项变化只改变其有证据的代价/收益，不伪造资格或完成状态 |
| U03 | 替代与组合 | 同一国家可同时存在多个领域行动；至少一个行动受阻后由合法替代竞争，并保留真实成本 |
| U04 | 多尺度 | 州、国家、市场/战略区域、国际系统的对象和事实不串用；对象/作用域替换有反例 |
| U05 | 角色不对称 | 发起者、目标、宗主、附属和第三方角色互换后重新取证，方向和成本不能沿用相反证据 |
| U06 | 阶段与反馈 | 正常、危机、恢复至少有进入、阻尼、退出和替代序列；阶段转换依赖已发生事实 |
| U07 | 不确定性 | 不可见信息保持未知；未知只退出对应增量或回退原版，不静默变成零/健康/无风险 |
| U08 | 路径与有限惯性 | 承诺、冷却、方向反转和到期都可退出；状态有界、可重载语义有依据，不虚构行动完成 |
| U09 | 内生特征 | 同一国家在输入、制度或关系变化后倾向可变；没有国名硬编码路线作为生产依据 |
| U10 | 解释与复杂度 | 每条正/反张力边可追溯到字段、消费者、证据和资源测量；解释文件不能替代生产接线 |

U系列的统一正例是“多个领域需求并存且真实冲突在具体消费者处解决”；统一反例是“所有领域先满足一个总门槛才允许行动”。任何 U系列失败都阻止当前纵切关闭，不能用长期游戏验证或静态文档存在代替。

## 失败处理

版本漂移、源缺失、父结构改变、字段方向不明、对象作用域不明、证据哈希过期、资源超预算或测试失败均硬失败当前小计划。
可以继续做不依赖失败的调查和文档，但不能混合来源、放宽锁、复制旧快照或把部分通过写成阶段完成。
