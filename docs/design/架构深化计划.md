# Situated AI A4 深化合同与验收边界

当前状态：**执行中，阶段未完成**；本轮启动与前置核对见[A4实施结果](exec/A4实施-结果.md)，逐项事实见[当前工作清单](当前工作清单.md)。

A4的公共合同把1.15.0迁移、极致分层、全域广度、跨域联动和可交付性绑定在同一证据链上。它是战略合同，不冻结文件数量、阈值或具体执行顺序；实现时可按原版证据调整，但必须保留差异与原因。

本文中的“1.15.0”是本次调查锁定的当前目标版本，记作`TARGET_VERSION`。A4-0和A4-7必须重新读取安装身份；若目标版本已变化，先登记版本差异并把所有受影响引用、台账行、见证、锁和计划标题迁移到新版本，禁止把旧版本继续称为最新版或在一个候选内混合版本。

## 范围与验收闭环

B01–B12 的64个细分方向、R01–R12 的12个联动族和U01–U10是设计地图与初始种子范围，不是固定的完成分母。A4-0建立发现台账和校验器，A4-1完成锁定版本的独立全量盘点；执行中发现的新入口、消费者、对象、角色、尺度、DLC面和有效依赖必须追加稳定ID，已发现但没有合法写口的内容也必须逐项处置。不能通过缩小地图、删除难项、用一条样例或把待调查内容改名为“不支持”来关闭范围。

发现集合至少来自：

- 1.15.0结构快照、AI surface、information-catalog及其版本差异；
- 生产适配器、当前Mod writer、事件/决议/按钮/策略/地区目标/脚本值及其父结构；
- 无DLC和适用DLC的原版消费者、脚本字段、可观察对象、角色和作用域；
- A3归档的96项历史义务，以及A4执行期间通过调查新增的发现。

盘点必须记录已扫描目录、源身份、解析失败、未识别结构和重复项，不能从现有适配器白名单倒推全集；快照、调用/引用索引与生成writer清单交叉核对，未识别项不能静默丢弃。还须从共享事实、资源/政治约束、角色、空间和时间变化中调查新联动，不只移植原版已有的显式依赖。动态国家、州和未来局势不逐实例穷举，而是按具体消费者、对象类型、角色、适用条件及数值边界建立有限等价类；每类有代表见证和合并依据，不同语义不能为节省用例强行合并。原版输入全量盘点与游戏内按需读取分开：每种相关信息都有用途或不用理由，不为凑收集数量增加无用世界扫描。

A4机器可读台账的最小字段为：

```text
id, goal_ids, kind, domain, relation, source_version, source_paths,
input_hashes, object, scope, role, consumer, disposition,
interface_status, obligation_status, disposition_reason,
evidence_level, fact_ids, port_ids, causal_ids, qualification,
unit, direction, timing, benefit, cost, opportunity_cost, risk,
alternative, unknown_policy, saturation, persistence, exit,
applicability, case_ids, production_paths, witness_paths,
evidence_hashes, dependency_ids, predecessor_ids, failure_reason
```

`interface_status` 描述原版边界：`discovered`、`verified`、`changed`、`boundary_unknown`、`native_handled`、`unsupported`。
`obligation_status` 描述产品义务：`pending`、`in_progress`、`implemented`、`verified`、`retained`、`blocked`。
两者不能互相代替；接口已知不等于产品已接线，原版已处理也不等于Mod新增实现。`disposition` 声明 `implement`、`retain_native` 或 `unsupported`；行的最终结论由校验器按下表计算，不另设可手填的“已完成”开关。

| 行结论 | 必要状态组合 | 必须核实的证据 |
|---|---|---|
| `verified` | `disposition=implement`，两种状态均为`verified` | 当前底本、生产接线、独立见证和全部适用用例相符 |
| `retained` | `disposition=retain_native`，接口为`verified`或`native_handled`，义务为`retained` | 原版已满足该目标或该项无需新增调整，完整父结构/引用闭包与关闭路径受保护，没有被掩盖的新增义务 |
| `unsupported` | `disposition=unsupported`，接口为`unsupported`，义务为`retained` | 精确证明无合法读写口、非AI消费者、纯展示或与产品目标无关的原始发现，未声称新增能力 |

`boundary_unknown`、`pending`、`in_progress`、`implemented`、`blocked`、缺失行、无效状态组合、过期哈希、未闭合依赖和失败见证均不产生终态，并阻止对应阶段收口及A4-7。接口状态只能按来源与调用证据核实；`implemented→verified`必须重新执行独立验收。输入、生产源、见证或依赖变化使受影响项和传递依赖退回待重验，不能继续沿用旧签名。

闭环必须能机械复核：

```text
发现 ID 集合 = 已处置 ID 集合；遗漏、孤儿和重复 ID 为零
每一行的计算结论 ∈ {verified, retained, unsupported}
所有需新增/改进的可实现产品义务的计算结论 = verified
所有 writer → 对象 → 事实/端口 → 原版消费者 → witness 可追溯
所有 G/B/R/U/DLC/关闭路径与 A3 义务有完整映射，无孤立目标
```

原始发现、产品义务、关系边和U适用单元使用不同`kind`和稳定ID；处置覆盖原始发现，验收覆盖由发现与目标派生的全部义务。一个发现产生多项义务或多项发现共同支撑一个消费者时，用显式映射解释拆分/合并，不能合并后丢失旧ID、适用条件或见证。未应用字段用带理由的不适用记录，不能填虚假零值。

保留或不支持需要具体原版来源、理由和独立复核；“尚未调查、实现成本高、缺样例、目前没写适配器、DLC未安装”都不是结论。“无接口”只关闭精确边界，相关领域其它合法入口、可证实的间接影响和产品义务仍须继续。不能自行将目标内难项划出范围；不可读输入仍按C2的未知策略测试，不能把“未确认接口为零”解释为运行期永远没有未知。

A3的96项及检查点候选差异必须逐项关联到A4，迁移决定为 `migrate`、`reverify`、`retain`、`replace` 或 `withdraw`；该决定不等于验收状态。替代记录前后ID与功能等价/有意变化，撤回必须证明过时、重复或违反当前目标，并继续保留仍有效的目标义务；旧的17项已签实现不能自动成为A4的 `verified`，原始字节不改写。

A4-0交付校验器反例：删掉一条发现、重复或悬空ID、无证据保留/不支持、未接线writer、过期哈希、失败测试、未闭合依赖、遗漏适用DLC或关闭路径均必须拒绝。按阶段校验依赖和该阶段出口，未来阶段的待办可以保留；A4-7的全计划检查不允许任何目标缺口。报告分别显示发现/处置、产品实现、保留/边界、见证和交付状态，不用文档数、测试数或一个合并百分比代替。

每个小计划的战略目标在开工时转为以下可审查任务；主计划不预设未经1.15取证的字段、函数或阈值。

| 步骤 | 最小交付与验收边界 |
|---|---|
| 1 定义 | 选稳定ID、消费者、对象、角色及依赖，列出生产/测试文件归属和通过条件；没有实际消费者则继续调查，不能建空卡 |
| 2 取证 | 核实来源、必要资格、作用域、单位、方向、时机、DLC、未知和成本，绑定输入哈希及独立预期 |
| 3 设计 | 定义事实/端口、独立收益成本、同因组、替代和生命周期；逐项登记U及状态用例适用性，不适用须有理由 |
| 4 实施 | 完整接入生产源→语义IR→PDX writer→活跃消费者及本地化，不能止于离线模型或默认策略 |
| 5 验收 | 独立原版参考与实际生成PDX比较；正/反、未知、阈值两侧、对象/适用角色替换、关闭及生命周期用例通过；普通处境不能总被限幅压成同一值 |
| 6 收口 | 写入源码/见证哈希、命令、选择集和失败记录，校验本项及依赖、清理缓存、更新台账与收据并中文提交；阶段完成另查该阶段全部出口 |

参考预期不能调用同一个生产评分函数来证明自身正确；PDX见证核对真实AST和原版尾部，不能只核对字段名、字符串、hook或包存在。数值保留对正常、危机、恢复及替代的处境差异；不要求某个自定增量保证真实行动必定发生。

## C1 版本与范围冻结

锁定安装根、EXE、可取得的游戏/Clausewitz修订、Jomini输入、源文件身份、研究材料和包源；未暴露的修订保持未知，不伪造版本身份。旧1.14.5快照只用于比较。范围表分开记录“接口状态”和“产品义务状态”；缺字段、源漂移、删除/新增、DLC差异和作用域变化都必须有稳定ID。

**出口：**A4-0复查当前安装身份，A4-1交付精简/必要完整快照、信息/消费者/调用索引、来源清单和差异处置；现有reader、writer、父结构与加载路径重证后，通过正式生成流程产出新版生产锁及迁移候选，不仅替换旧哈希。A4-7再核对安装身份与最终候选；版本改变按受影响依赖重验并同步目标版本，任何混合输入硬失败。

## C2 证据图与类型化端口

节点至少包含来源、实体、作用域、单位、方向、有效时机、未知策略、求值成本、生产消费者和因果ID。端口只能输出声明过的类型；跨域依赖不得通过复制代码或内部导入隐藏。

**出口：**每个端口有正例、否例、未知、边界、对象替换和版本反例，非法类型/单位/角色映射被拒绝；跨尺度聚合具有合法遍历、对象映射与有界成本。核心资格未知不扩张资格；成本未知走已声明保守分支或回退，辅助未知只退出对应项，均不能静默变成零/健康/没有需求。

## C3 最小行动合同

最小行动固定为“具体原版消费者 × 具体对象 × 一次倾向评估”。行动可以分为保底、机会、风险、恢复和替代档；每档独立记录收益、成本、资格和退出。行动卡、规则行动、IR实例与PDX writer保持稳定映射；多个行动贡献同一字段时经同一作者联合，不能为每张卡生成互相覆盖的writer。

候选方案可以依据已证实的解锁、配方、法律效果和当前投入形成条件化边际收益或长期选项价值，但必须与当前已发生事实分开；不把候选研究、提案、建设或法律通过倾向当作已经得到的产能、盟友支持或制度收益。预期依赖未知时只保留有来源的部分及替代路径，不伪造未来概率。

**出口：**每个生产writer都有独立证据、原版消费者、对象作用域、收益与代价或其不适用依据、未知回退、关闭行为和执行尾部保护；已有原版成本不能为凑正负数重复扣除。关闭时生成差异在原版消费者处等价回退，必要资格、终结零分、拒绝和执行不被绕过；没有只写名称的空卡。

## C4 分层无全满足门槛

必要资格只由原版必要条件决定；辅助事实作为分档、加成、成本或替代，不组成全局AND门。每个基础行动都要有“只有一项短板改变”的反事实见证，证实单项已知需要可触发有意义的局部评估；不要求最终总分必为正或原版必执行。改善按该消费者声明的响应曲线改变收益或代价，不要求所有因素无条件单调提高；缺少远期配套不阻止合理起步。

**出口：**对有依据的最低可行、改善、成熟和危机/恢复档逐项验证；不适用的档位记录理由，不凭空造成本或门槛。基础行动至少一个正例证明局部起步，至少一个反例证明不越过原版资格。

## C5 联动与因果预算

关系有类型：互补、约束、替代、冲击、恢复。同因取强仅合并同对象、同消费者、同单位且同语义方向的替代档位；不能吞掉同因但独立的收益与代价，原版已计成本不重复惩罚。不同消费者仍分别承担真实成本，不能把去重当成已分配资源。独立收益/成本在字段语义允许时联合，末端一次限幅。关系图必须定向分层，同一求值内不得递归；跨轮循环只通过真实原版状态变化。

**出口：**每条关系逐边通过正例、断边、同因去重、对象替换、未知退出、冲突和组合见证；分叉后汇合、共享收益与独立成本、多条边同时生效及任一边退出不放大或吞掉其它项。按端口依赖扫描有效边，跨两个以上领域的适用链须有端到端见证；不做无依据的全领域两两连线，关系消失后无残留奖励。

## C6 国家画像与多目标仲裁

画像只作有限解释层，不生成万能总分。需求、能力、机会、风险、承诺和恢复分别保留单位与来源；只有在同一消费者的合法字段上做有解释的联合。多个领域需求可并存；真实冲突由原版消费者和局部权衡解决。

**出口：**同一国家可同时拥有建设、教育、安全、外交和恢复行动实例；互不相关行动不会因一条全国路线被排除。

## C7 时间与持久边界

事实时钟每次重读；承诺时钟只覆盖合法期限；恢复时钟以真实冲击为起点并可退出。只有不能从原版重读、且有独立决策价值和生命周期的状态才持久化。

**出口：**输入变化、期限到期、恢复完成、关闭/未知及必要方向反转均有静态生命周期见证；优先复用已存在的原版事实与时效，不能为展示惯性强加持久变量或全国排他阶段。新增持久状态还须核对原版存储/重载合同、过期与迁移语义；静态重载模型不称为实际游戏存读档实测。不生成无界变量、常驻服务或虚假行动完成状态。

## C8 兼容、性能与内存

优先原版消费者与求值时机；禁止不必要的整文件覆盖、无界世界扫描、重复reader、冗余持久状态和无证据缓存。引擎加载规则要求输出完整父结构或同源文件时，记录原因并逐项保护非目标内容，不以此获得整文件写入权。生成和检查可批量化，但必须保持输出、异常、回退、覆盖率和资源门语义。

**出口：**首个纵切就冻结可复算的脚本求值预算，包括遍历对象规模、嵌套深度、重复读取、分支/产物体积和持久写入上界；超限须先优化或有证据修订预算，不能删除功能放行。生产源码/生成物/锁/包身份一致，同口径测量解析、生成、测试墙钟、worker、进程树峰值RSS和产物大小；任何提速都附语义等价及失败语义证据，完整回归沿用覆盖与资源门。游戏内性能仍标为用户验收。

## C9 原版保护与发布

原版资格、成本、政治支持、随机、拒绝、终结零分、玩家路径、事件/JE父结构、同名兄弟、语言头和占位符都要保护。逐字段查明默认策略、活跃策略和DLC变体的覆盖路径；不从默认策略存在推断所有策略生效。生产包不含Python、探针、日志、缓存、历史证据或研究源码。

**出口：**全部游戏语言的键、占位符、路径、编码及自有译文审阅完成；默认/活跃策略、无DLC/相关DLC、启用/关闭和玩家路径逐项保护。A4-7核对生成、审计、完整回归、标准包manifest/SHA及面向用户的全语言工坊正文；A4-8另核对授权的实际Git/CI/合并、tag/Release和固定包部署身份及恢复收据。只发布 `vMAJOR.MINOR.PATCH` 正式版本。

## C10 全量复核、未知清单与关闭证明

在A4-7，重新运行独立盘点并对照台账、全部生产writer、未改动原版保护、引用闭包、所有目录、文档、本地化和固定包，不只复读前一阶段的清单。`native_exact`、`derived_typed`、`boundary_unknown`分开统计；已证实无法读取/写入的边界可以按本页状态组合关闭，仍然不授予写入权。尚未确认接口或已知可实现的产品缺口阻止完成，不能转嫁给用户长期验证。

**出口：**重新发现集合与处置集合的差异为空，全部G/B/R/U义务及适用配置都有计算终态，保留/不支持有独立证据，所有writer到实际PDX/包无漏项。完整回归、编码、类型、lint/format、生成及审计、标准包合同和最后卫生门全部通过；源码或依赖变化使受影响验收失效。原始证据不改写，删除/移动前核对调用方、动态注册、生成入口和链接；完成的计划归档、过时逻辑与可再生缓存清理，并更新导航。

## C11 数值语义与可解释性

每个消费者分别记录原版尺度、符号、单位、阈值来源、收益/成本来源、同因组、正常/危机响应、饱和及恢复退出。原始数量经有依据的映射才成为该消费者尺度上的有界偏好，不把GDP、人口比例、政治支持等不同单位直接相加。加法、乘法、权重和概率分别保留中性值、运算次序与原版零分语义；语义方向不由数值正负猜测。阈值假设与原版硬资格区分；不让统一倍率掩盖候选差异，不要求所有领域都用同样档位。

**出口：**独立参考预期、生产求值与真实PDX对单因素、独立收益成本组合、同因重复、临界边界、对象互换和恢复序列一致；无效数、错误中性值及破坏原版零分的组合被拒绝。普通处境、资源紧张、危机、恢复和替代可体现声明的方向与敏感度，避免常态全部饱和；解释链指向具体源、端口、writer和最终字段，不用报告存在或分数变化证明行为质量。

## U01–U10 对立统一横切验收

U系列将“对立且统一”作为所有领域和联动共同承担的验收维度。U系列不能关闭任何 B 方向或 R 联动；它要求每个生产纵切都在同一套张力、多尺度、反馈和不确定性规则下实现。

| 编号 | 合同 | 最小出口 |
|---|---|---|
| U01 | 多目标张力 | 每个适用消费者同时保留独立收益与真实成本/约束/风险或不适用依据，能追溯末端仲裁；原版已计成本不重复扣除 |
| U02 | 机会成本 | 建设、军备、改革、外交、殖民或福利的单项变化只改变其有证据的代价/收益，不伪造资格或完成状态 |
| U03 | 替代与组合 | 同一国家可同时存在多个领域行动；每个适用替代有阻断/替代/恢复序列，仍保留真实成本，不虚构已分配预算 |
| U04 | 多尺度 | 州、国家、市场、战略区域及可观察国际关系的对象和事实不串用，聚合有合法映射；对象/作用域替换有反例 |
| U05 | 角色不对称 | 适用角色互换后按各自事实重算，不能沿用相反证据；事实对称时允许结果相同，不强制制造差异 |
| U06 | 阶段与反馈 | 每个适用状态序列有进入、变化、阻尼/其不适用依据及退出，依赖真实事实；不同领域状态并存，不生成全国排他阶段 |
| U07 | 不确定性 | 不可见信息保持未知；未知只退出对应增量或回退原版，不静默变成零/健康/无风险 |
| U08 | 路径与有限惯性 | 承诺、冷却、方向反转和到期都可退出；状态有界、可重载语义有依据，不虚构行动完成 |
| U09 | 内生特征 | 同一国家在输入、制度或关系变化后倾向可变；没有国名硬编码路线作为生产依据 |
| U10 | 解释与复杂度 | 每条正/反张力边可追溯到字段、消费者、证据和资源测量；解释文件不能替代生产接线 |

U系列逐项映射到所有生产义务、联动边和生命周期；每个单元标明适用或精确不适用依据，不能用全局一个示例关闭整张矩阵。统一正例是“多个领域需求并存且真实冲突在具体消费者处解决”，统一反例是“所有领域先满足一个总门槛才允许行动”。任何适用U失败都阻止当前纵切关闭，不能用长期游戏验证或静态文档存在代替。

## 失败处理

版本漂移、源缺失、父结构改变、字段方向不明、对象作用域不明、证据哈希过期、资源超预算或测试失败均硬失败当前小计划。
可以继续做不依赖失败的调查和文档，但不能混合来源、放宽锁、复制旧快照或把部分通过写成阶段完成。
