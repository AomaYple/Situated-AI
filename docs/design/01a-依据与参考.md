## A. 输入清单：内部因素 + 外部因素

> **国策 = f(内部因素 · 外部因素)**，**玩家是外部因素的一部分**。

| 类别 | 输入 | 变化速度 |
|---|---|---|
| 内部 | 禀赋：地理、人口、资源、产业存量、制度遗产、财政能力 | 几乎不变 |
| 内部 | 摩擦：利益集团、法律、政治运动、财政 → 决定**能不能做 + 什么时候能做** | 中～慢 |
| 外部 | 位置：邻国强度、可结盟对象、出海口/海峡、殖民地网络 | 很慢 |
| 外部 | 威胁结构：谁在扩军、谁刚战败、谁正被围殴、**玩家在做什么** | 快 |
| 外部 | 市场结构：世界市场、关税与条约、谁买它的货 | 中 |

**目标函数两层记账**：利益项（存续、财政、合法性、军力、市场依赖）决定"能不能做"；
身份项（历史使命、意识形态、威望诉求）决定"想不想做"。

**三条纪律**：① 身份项是一等公民（否则收敛成"理性扩张机器"、大国寡头化）；
② 身份项必须能被现实惩罚（重大失败要让执念衰减或转向）；③ 锚定可观测的失败模式。

## C. 实现四件套与增强清单

**四件套（实现手段，不是目标）**

1. **处境账本**：把 A 节输入量化成**离散档**，事件驱动更新；
2. **处境档案库**：每个档案 = 触发门槛 + 三槽偏好 + 一段可读解释文本（少而准）；
3. **策略配平**：把三槽偏好落成**我们自己新增策略**的权重与门槛（纯追加）；
4. **三行解释**：当前目标 / 最大外部压力与最大内部阻力 / 最近一次改主意的原因。

**为原版补的五项能力**

| # | 补的能力 | 原版为什么缺 | 加法怎么补 |
|---|---|---|---|
| 1 | 处境感知 | 权重静态，不因"我刚输掉一场大战"改路线 | 处境账本（量化档写进世界状态） |
| 2 | 记忆 | 没有跨事件累积 | 账本累积量：战败、失地、被封锁、改革失败留痕 |
| 3 | 时机（耐受度） | 只有机械重掷 | 执念 / 耐受度双参数（进权重与门槛） |
| 4 | 解释层 | 只看得到策略图标，看不到"为什么" | 三行面板 |
| 5 | 对玩家的战略级重推 | 对玩家只有数值级反应 | 玩家动作改变输入 ⇒ 所有国家重算 |

**执念与耐受度**：普鲁士统一执念与耐受度都高；奥斯曼存续耐受度极高（可割地、可借外力）；
荷兰商业中立耐受度低（被封锁就转向依附）。**耐受度就是"时机感"的参数化。**

## D. 手段阶梯（从最兼容到最侵入；决定"用什么方式实现一条需求"）

| 级 | 手段 | 占槽 | 能表达 | 代价 |
|---|---|---|---|---|
| **A** | 修正 / 变量 / JE / 法律（**真实改变世界状态**，叠加生效） | 否 | "让这个国家真的进入改革窗口/战时状态" | 几乎为零，且可解释 |
| **B** | **喂输入**：让原版自己的权重公式算出不同概率 | 否 | 原版已有牌之间"该轮到谁" | 零占位；只能表达概率移动 |
| **C** | **递接替牌**（我们自己新增的策略，占 1 槽） | 是 | 原版池**没有**的整条路线 | 占位期原版那张牌不生效；稀释；维护成本 |
| **D** | 国家专属牌（原版先例：`montenegro_admin`） | 是 | 单一国家的独特处境 | 维护成本最高，只给极少数国家 |
| **E** | 改原版权重 / 关原版子系统 | — | — | **禁用（R3）/ 封存（R4）** |

**决策规则**：**能用 A 表达的绝不占槽；只有"整条路线都要换"时才递 C。**
判断顺序：原版池里有这张牌吗？有 → B；没有 → 先问"能不能用 A 让原版自己产生等价行为"；不能 → C。

**⚠️ 阶段 2 实测修正（2026-09-20，见 `exec/阶段2-结果.md`）**：**B 级单独用几乎无效** ——
AI 策略是**十年尺度**才重抽一次（政治槽实测 ≈1%/国家·月；`NAI` 的周通道期望 ≈9.6 年才攒够
一次重抽），所以"喂输入改变概率"在战役里推不动任何东西。**B 必须配节奏杠杆**：
用独立小文件覆盖 `NAI` 的 `CHANGE_STRATEGY_THRESHOLD` / `CHANGE_STRATEGY_INCREASE_WEEKLY_CHANCE`
（实测生效：三个槽位的重抽率从 1.05%/0.07%/3.26% 拉到 33.8%/56.6%/51.5% 每月每国）。
C 级的价格也量化了：等效竞争权重 **政治 ≈33 / 外交 ≈107 / 行政 ≈690**。

**关键认识**：A 级被严重低估。我们想要的多半不是"AI 换一条路线"，而是"**世界真的变了**"——
战败后贵族失势、合法性下降、财政崩溃都可以真实发生；一旦真实发生，**原版自己的公式就会转向改革**。

**⚠️ 阶段 3 实测补丁（2026-09-20，见 `exec/阶段3-结果.md`）**：**A 级"改了世界"不等于"原版就转向"** ——
原版那张"改革派"牌（`ai_strategy_progressive_agenda`）的权重**只读它自己的输入**
（`ig:ig_intelligentsia ?= { is_powerful = yes }` / `ig:ig_industrialists ?= { is_powerful = yes }`
各 +10，03_political_strategies.txt:528-544）。阶段 3 只压了贵族与合法性，于是 AI 重抽后落到
"保守/兜底"而不是改革路线。**推论：把"处境"喂进原版时，要顺着原版那张牌真正读的字段喂**
（IG 政治力量 `interest_group_ig_*_pol_str_mult` 就是这类字段），而不是只喂我们觉得该疼的地方。
这也给了 A 级一个**新的用法**：`add_modifier` 直接改原版读的量，仍然不占槽（F5）。

**粒度纪律（细读、粗动）**：观测可以细（多因子），参与决策的数要粗（量化成 3–5 档），
行动只需少数杠杆。四条：① 判据驱动（挂不上差分的维度不进账本）；② 量化档位；
③ 瞬时量便宜、累积量贵（累积维度必须少）；④ 代理必须标注为近似。
第一版账本 8–12 个因子（其中 3–5 个进决策），扩张期 20–30 个。

## E. 引擎现实（1.14.3 实测）

### E.1 可挂载面

| 事实 | 证据 |
|---|---|
| 1.14 就是官方的「AI update」 | DD#185《AI Update & War Support Rework》、DD#186《AI Update Open Beta Start》；本机 1.14.3 |
| **槽位靠 `type =` 声明** | `administrative \| political \| diplomatic`，计数对上 **7 / 9 / 18** → **新增策略标好 `type` 即可入池** |
| 策略权重**是脚本块** | `03_political_strategies.txt:117`：`weight = { value = 20  if = { limit = {…} add = 10 }  if = {… multiply = 0.25 } }` |
| 权重能读**任意状态** | 同文件用了 `has_journal_entry = je_metternich`、`ruler = { has_variable = house_orleans }`、`is_princely_state` |
| 策略有 `possible` 门 | 可禁止某路线（"欠债期间不许殖民冒险"） |
| 一个策略块 ≈ **40 个一级字段** | 经济：`building_group_weights` / `goods_stances` / `subsidies` / `desired_tax_level` / `institution_scores`；政治：`pro_interest_groups` / `anti_interest_groups` / `pro_movements` / `anti_movements` / `change_law_chance` / `max_progressiveness` / `revolution_aversion`；外交：`aggression` / `recklessness` / `diplomatic_play_boldness` / `diplomatic_play_neutrality` / `wargoal_weights` / `treaty_category_scores` / `secret_goal_scores` / `strategic_region_scores` / `undesirable_infamy_level` … |
| 默认层：`ai_strategy_default` | `00_default_strategy.txt`（199 KB）：**所有国家始终加载**；官方注释：*"can be either added to or overridden by data from its other strategies"* → **我们的牌只写差异字段** |
| 权重基准值分布 | 33 个权重块：`0 / 5 / 7.5 / 10 / 20 / 25 / 50 / 100 / 250 / 10000`，**中位数 10**；`10000` 是"几乎必选"档 |
| 原版自己就在做粗糙版 | 保守策略权重直接读 `has_journal_entry = je_metternich`（"挂着梅特涅体系 JE 就 +20"）—— 「身份 → 意图」的手工版 |
| 逐目标通道 | 策略里的 `secret_goal_scores` / `secret_goal_weights` / `wargoal_weights` / `strategic_region_scores` / `treaty_category_scores` / `subject_value` → **粒度是"国家 × 目标国"**，不额外占槽 |
| 全局参数面 | `common/defines/00_ai.txt` **144 KB / 1311 行**，含 `NAI` 块与 34 个 `AI_*` 顶层条目 |

### E.2 硬约束

| 约束 | 后果 |
|---|---|
| **「何时重新考虑」在引擎手里** | `change_points` / `add_ai_strategy` / `set_ai_strategy` 全树 **0 命中** → **不能命令 AI 改主意**，只能改变它**下次掷骰时的分布** |
| **推理在 C++ 里** | 建筑选址、军事调动、市场与贸易选择改不动；数据层只能改变它们**读到的值** |
| **裸同名键先到先得** | 本仓库实测 `Duplicated key … will not be created from file: …` → 后写的同键**不生效** |
| **子目录不被枚举** | 候选文件必须**平铺**在 `common/<库>/` 下 |
| **本地化不支持 YAML 块标量** | `|` / `>` 报 `Missing quoted string value`，游戏内显示原始键名 |
| **槽位数量固定为 3** | DD#59 明说"三个策略"；数据只有 3 个 `type` 值 → 无法加第 4 槽（**待实测确认**，见 backlog） |

### E.3 与原版的关系：骑上去，不推倒（读 → 让 → 改 → 补）

1. **读**：把原版当前策略／欲望当作"这个国家的自我认知"，我们的推导**以它为起点修正**；
2. **让**：我们没意见的地方**默认不干预**（默认行为贴近原版，玩家才能感知"哪里变了"）；
3. **改**：只改我们自己的策略权重与门槛，以及它读到的世界状态；
4. **补**：原版完全没有的四样 —— 处境账本、身份项、可解释层、对玩家动作的战略级重推。

> **原版决定它「是谁」（先验），我们决定它「此刻该做什么」（似然）。**

## F. 性能最佳实践（硬要求）

**前提**：脚本跑在**主线程**、多人**锁步**、不能线程化、不能做可能发散的缓存。

**八条实践**：① 量化世界，别做连续曲线；② 把计算摊到时间上（事件驱动 + 月度衰减 + 季度分片错峰）；
③ 冷却期防抖；④ 平滑退化，不要悬崖；⑤ 接受迭代上限；⑥ 数据打包（按位存标志，防溢出）；
⑦ **代码生成**（"元层才是架构，生成的脚本是它的编译产物"）；⑧ 可观测性优先于聪明。

**预算**：我们的开销 ≤ **引擎自身 AI 开销的 5%** 量级；平均 **每月每国 ≤2ms、单帧 ≤0.5ms**；
账本分级（列强 / 玩家邻国 / 使命型策略持有者 = 完整账本，其余惰性初始化）。
测量工具：游戏自带 `logs/gametimer_*.tsv`。

**三条红线**：① 任何「每月遍历所有国家」的脚本 = 设计缺陷；② UI 每帧求值的字段里绝不放表达式链
（实测：JE `current_value` 引用未创建变量 → 8 分钟刷 **1772 条**报错）；③ `weight` 块里不写 `every_*` / `any_*`。

**怎么算"达成"**：平均（gametimer 对照）+ **最坏情况**（压力场景：列强大战 + 连锁破产 + 革命潮 + 玩家大动作）。

**原版的代价模型（抄什么、不抄什么）**：原版在 `weight` 块里**不做全球遍历**，循环只出现在
一次性钩子与窄作用域（`any_country_strategic_region`）；199 KB 的默认策略是**按需读**。
但"处境账本 + 跨事件记忆累积"**没有先例可抄**，频率与规模必须自己定、自己测。
→ 四条规则：**结构像原版 · 频率自己负责 · 热路径只读预存值 · 最坏情况实测。**

## G. 兼容性最佳实践（硬要求）

**兼容性目标只有一个：官方原版。** 其它 mod 不在兼容目标内（不为它们让路、不改设计、不写兼容测试）。

**纯追加（R0）**：不碰原版文件、不重定义原版键、不关原版子系统 → 买到**与官方兼容** + **卸载即回原版**。

| 级 | 手段 | 放行条件 |
|---|---|---|
| R0 | 纯追加（新策略 / 触发器 / JE / game rule / 修正） | 默认，永远优先 |
| R1 | 自有 defines 文件覆盖**特定**键 | 有实测证据 + 文档记录理由（注意：**全局**生效） |
| R2 | 数据功能前缀（`INJECT:` / `REPLACE:`）改**某个**原版键 | 需先验证该目录支持前缀；只改一个键 |
| R3 | 整文件替换 | **禁用** |
| R4 | 用 `NAI = { … }` 关掉原版子系统 | **封存**：仅 H1 不成立且经逐案批准 |

> 事实：官方在 `defines/00_ai.txt:1` 的 `NAI = { … }` 里明文提供关闭开关
> （`GOVERNMENT_MONEY_SPENDING_ENABLED`、`TAX_LEVEL_CHANGES_ENABLED`、
> `PRODUCTION_BUILDING_CONSTRUCTION_ENABLED`、`AUTONOMOUS_INVESTMENT_CONSTRUCTION_ENABLED` 等）。
> "替换"不是被禁止，而是**粒度不匹配**：defines 是全局旋钮，策略是逐国旋钮。

**命名与命名空间**：策略键 `ai_strategy_sitai_<name>`；变量 `sitai_<name>`；loc `sitai_*`；
文件 `sitai_*.txt`（不占任何原版路径）；图标先**只读引用原版**；新增值**必须带 description**（官方注释要求）。

**三层检查**：① 与官方（键/路径不相交 + 引用完整性）；② 与存档（装→卸往返净度）；
③ 与版本（版本指纹 + 生成器输入清单）。

**版本升级演练**（官方每次更新的固定动作）：记录指纹 → 跑五道闸门（重点：引用完整性）→
跑一次常规开局让 golden 回到实跑口径 → 若官方改了字段则重新生成并比对 diff → 结论写进变更记录。

**五道自动闸门**：① 键/路径不相交；② 引用完整性；③ 稀释预算（默认条件下原版策略仍占多数，
只有处境命中时才显著压过）；④ 往返净度；⑤ 生成可复现 + `why` 非空。

## H. 可维护性六条

| # | 纪律 | 机械化手段 |
|---|---|---|

## I. 能力天花板与 wishlist

| 放弃的能力 | 后果 | 缓解 |
|---|---|---|
| 改原版策略 `weight` | 不能直接削弱某条原版路线 | 新增竞争者（稀释）+ 改世界输入 |
| 改 `ai_strategy_default` 基线 | 只能在我们策略**生效期间**覆盖它 | 把"基线偏离"做成我们策略的一部分 |
| 关原版子系统（R4 封存） | 子系统真坏时只能在旁边加一层或放弃 | 记入"要修的具体失败模式"清单，逐案评估 |
| 改 C++ 决策 | 建筑选址、军事调动、市场选择改不动 | 只承诺"改变它决定时看到的值" |

> **射程 = 动机 + 它读到的世界，不是引擎的推理过程。**

**给官方的 wishlist**：AI **重掷时机**（`change_points`）的脚本可见性／可触发 ——
它是唯一能让本设计质变的接口（"时机感"从"等它重掷"变成"在正确时刻促成重掷"）。

**四条代价**：不可预测 → 三行解释层 + 前兆；寡头化收敛 → 身份项 + 摩擦；
脚本性能 → 预算与红线；玩家被压死 → 难度分档。
