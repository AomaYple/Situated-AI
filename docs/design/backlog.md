# backlog · 悬而未决的问题（不是否决，是排队）

> **用法**：任何"发现了但挡不住当前阶段"的问题，30 秒落一条，不展开讨论。
> 每条格式：**问题 → 我的推荐值 → 何时才需要（触发条件）**。
> 触发条件到了才把它拉进执行文档；否则一直躺在这里。
