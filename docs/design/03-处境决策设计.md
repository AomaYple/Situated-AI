# 处境决策设计

> 设计基准：2026-10-26，当前生产候选 1.2.0。以下分别标明已实现模型和深化目标；执行顺序只在[权威计划](exec/mod重设计-实施计划.md)维护。

## 目标和运行边界

**Situated AI 让每个国家基于自身处境和可观测信息，在 Victoria 3 原版机制内持续做出符合自身约束与利益的相对最优决策。**

“相对最优”是在国家可观察事实、能力、政治阻力、财政成本、外部威胁和原版规则内的情境选择。结构相似的国家可以选择相似路线，同一国家在条件改变后可以转向；不使用国家名称强制重演历史，不保证全局最优或某个固定结果。

Python 负责发现、来源登记、规则校验、生成、解释、打包和工程检查。游戏运行期只加载标准 PDX 脚本和本地化，没有 Python 常驻进程。Mod 在同一路径覆盖部分原版文件，通过原版消费者修改有限倾向，保留周围的资格、费用、随机性、协商、执行、失败和终止逻辑。兼容基线是锁定原版；其他 Mod 同路径覆盖不在兼容承诺内。

## 已实现的决策模型

```text
锁定原版、快照与接口证据
    → information_catalog + vanilla_index + decision_interfaces
    → TOML 中的 reader、predicate、signal、intent、rule 和 adapter
    → 生成期展开共享 AND 条件、校验字段优先级和唯一作者
    → 运行期读取该消费者可见的事实、选取首个匹配规则
    → 对原版字段施加一次有界增量，保留原版尾部
```

当前“国家画像”是对有限条件组合的命名和解释，不是引擎内全知状态向量，也没有跨所有行动联合求解的优化器。意图图复用生成期条件，不能把源文件复用误认为运行时必然只求值一次。后续深化首先扩展可靠输入、共享组合和合法消费者；只有反例表明表达能力不足时才扩展 schema。

“生存、经济、安全、长期发展、政治可行性、风险”是设计时的评估维度，各字段有自己的优先级合同。不存在一套适用于所有字段的固定总排序或任意相加的万能分数。紧急防御未必必须等待财政改善，政治消费者也不机械复用建筑阈值。

## 信息合同与覆盖处置

| 合同部分 | 必须回答的问题 |
|---|---|
| 来源和版本 | 哪份锁定原版文件、哪行、哪个指纹支持该结论？ |
| 访问 | 属于哪个作用域、actor/target 方向是什么、是否真的存在合法 getter？ |
| 数值语义 | 类型、单位、范围、零值、缺失变量和接口不可用分别是什么意思？ |
| 时机和成本 | 何时由原版消费者求值、条件展开多大、是否需要有限状态？ |
| 用途 | 改变哪个合法字段，谁是唯一作者，原版资格和尾部是否保留？ |
| 反例和解释 | 什么情况下不应生效，未知时如何回退，如何追溯到生成合同？ |

`discovered`、`runtime_readable`、`derived`、`consumer_mapped`、`behavior_verified`、`unsupported` 表示不同能力事实，不是必须依次升级的阶梯。静态定义可以直接用于生成期判断，不必先成为运行期 reader；运行期事实不一定需要派生；同名匹配不能证明可读或可消费。`behavior_verified` 需要用户实际游戏证据，不能由目录或静态门禁自动赋予。

能力状态之外，还要记录候选处置：接入、保留原版、没有可靠 reader、没有合法 consumer、重复补偿、成本过高或仅解释。全面发现不意味着全面运行；没有独立价值的重复事实不进入每次 AI 求值。

## 深化目标覆盖面

下表是需要逐项审计的设计空间，表示希望深化的输入和消费面，不是当前全部功能已经完成的清单。

| 信息面 | 需要综合的约束与机会 | 允许扩展的消费方向及边界 |
|---|---|---|
| 财政/行政 | 现金流、债务、破产窗口、行政容量、承诺负担 | 建设、制度、军备和外交权重；不直接发放资源或接管税率枚举 |
| 生产/科技/基础设施 | 投入成本、就业、能力、科技、运输瓶颈 | 已映射建筑、制度、研发和策略字段；不把权重接口冒充直接生产方式控制 |
| 市场/贸易 | 价格、储备、可达性、依赖、运输和风险 | 商品立场、贸易与对外经济机会成本；不承诺完整金融市场模拟 |
| 社会/政治/人口 | 集团力量、政府、合法性、激进度、识字率和生活水平 | 法律、政府和制度候选；保留意识形态、资格、协商和失败 |
| 外交/宗属 | 关系、条约方向、联盟、宗属结构、博弈和威胁 | 合作、支持、宗属和外交目标权重；不创造承诺或强制参战 |
| 军事/战争 | 军力、军需、补给、战争负担和安全压力 | 军费、军备和合法战略消费者；不接管前线战术 |
| 地理/殖民/身份 | 邻接、港口、远程投射、资源、殖民机会和身份结构 | 州价值及相关策略权重；保留地图特殊值与组建/并入资格 |
| 时间/冲击 | 可靠失败记忆、当前危机、有限迟滞和机会窗口 | 已证实读取器和受控状态；不根据当前状态虚构历史结果 |

## 跨域组合与机会成本

每个消费者先检查 AI 路径、作用域、已知输入和原版可达性，再比较声明的互斥规则。事实既可以支持一项选择，也可以降低另一项选择的吸引力；成本、危机和安全风险允许产生负向调整，不要求所有倍率都大于等于一。

组合采用“需求/机会 + 承受能力 + 政治/执行约束 + 成本/风险”的字段合同。例如高需求不自动等于应该扩建，还要核对投入成本、市场可达性、就业与财政；对外经济机会也要考虑依赖、运输和防御负担。同一短缺若已经被原版建筑逻辑和 Mod 商品立场吸收，不能在多个层面盲目重复奖励。

同一生产字段只有一个作者，首个匹配决定增量，强档应是普通档的严格子集。已知、为假、缺失、接口不支持分别处理；高优先级未知输入不能被低优先级猜测绕开。生产求值和离线解释复用同一合同，测试还需用独立参考求值核对生成脚本、作用域和边界。

税率枚举、政策/意识形态身份、资格、固定防御、补贴/建筑组权重、地图特殊值及原版策略选择默认保留原版。要改变处置，须先证明合法访问、可达消费位置、独立收益和无重复补偿；不能因为它们属于“方方面面”就机械新增作者。

## 当前 1.2.0 的数值与记忆

当前采用条件化的强响应：高合法性、低债务、正结余、行政能力和和平条件满足时，部分发展消费者可以进入更强档；危机、成本和安全条件不足时保留较低档或回退原版。同一字段不叠乘多个档位，倍率不是实际行动概率。原版零目标和资格拒绝不能被增量唤醒。

财政风险已经使用进入 26 周、退出 52 周、TTL 62 天、按月续期的迟滞。原版 `recently_lost_war` 是 1825 天内原版记录的战争目标受害方失败记忆；当前恢复规则有和平、未违约、收入和能力条件。它不表示所有战败，也不直接证明改革发生。

外交羞辱、革命结果、改革结果、资源中断历史目前没有可靠读取器，保持 `unsupported`。这些是候选研究面，不能写成现有冲击机制。当前价格或关系可以重算，但并非所有规则都已有平滑或冷却。

新增持久状态必须证明来源、范围、进入/退出、刷新、TTL、续期、存档默认和禁用后的停止续期/清理路径，并测试过期与未知值。没有实际必要时复用原版状态和刷新时机；不保存无界事件历史。卸载不能撤销已经发生的国家行动或世界变化。

## 结构差异与历史合理性

设计期望是：人口多、财政弱、保守集团强的国家，更重视可负担的行政和能力积累；只有可靠冲击、政治空间和执行能力共同满足时，相关改革候选才可能更有吸引力。港口和海运条件较好、陆上扩张成本较高的国家，可能更偏向贸易、经济合作、海军和适合其能力的殖民路线。

这些是结构推导的设计例子，不是对俄罗斯、荷兰或任何国家的脚本承诺。战争失败与改革、海运与金融选择之间必须存在实际消费者连接；未连接的因果链保持设计目标，不能凭示例宣布已实现。长期结果还受原版随机性、政治和其他国家行动影响。

## 计算成本、交付和证据

运行期复用原版消费者和刷新时机，不新增全世界扫描、常驻服务或无界缓存。候选数、谓词数和依赖深度保持受控；生成期的共享信号不自动减少展开后的运行成本，优化要审计实际生成脚本。等价性先于速度，速度先于内存；Python 墙钟、分配峰值、RSS 与游戏内性能分别报告。

`v3 decision-audit` 默认复用生产构建 metadata，`--offline` 从入库源和锁定底本构建相同领域合同；快照、候选覆盖和 `modguard --offline` 核对各自边界。`distribution.py` 将生成脚本、本地化、metadata 和 manifest 组成标准包，游戏文本只在交付边界添加 BOM。

工程检查证明来源、字段、作用域、回退、脚本结构和包契约；用户日志只证明日志实际记录的事实。它们不能自动证明引擎所有运行分支无错、历史合理行为、平衡、后期性能、语言体验或工坊结果。新阶段实施和完成状态以权威计划、当前工作清单与结果收据为准。
