# 处境决策设计

> 设计基准：2026-10-30。已发布基线为 Situated AI `1.4.0`，分层联动目标为 `1.5.0`，尚未发布。
> 当前阶段与出口只在[分层联动实施计划](exec/mod重设计-实施计划.md)维护；事实见[当前工作清单](当前工作清单.md)，
> 工程证据见[分层联动执行结果](exec/分层联动-执行结果.md)。本页定义架构与边界，不代替阶段或行为验收。

## 目标和运行边界

**Situated AI 让每个国家基于自身处境和可观测信息，在 Victoria 3 原版机制内持续做出符合自身约束与利益的相对最优决策。**

“相对最优”是在国家可观察事实、当前能力、政治阻力、财政成本、外部威胁和原版规则内的情境选择。
结构相似的国家可以选择相似路线，同一国家在条件改变后可以转向；不使用国家名称强制重演历史，不保证全局最优或固定结果。

Python 负责发现、来源登记、能力分类、规则校验、生成、解释、打包和工程检查。游戏运行期只加载标准 PDX 脚本和本地化，
没有 Python 常驻进程。Mod 只在原版消费者中修改有界倾向，原版实际成本、资格、前置、政治支持、随机、谈判、拒绝、
终结零分、执行、失败和终止逻辑保持原有职责；玩家决策路径不变，不赠送资源，不增加全世界扫描。

## 分层联动架构

```text
锁定原版可观察事实：来源、作用域、单位、范围、未知策略
    → 四层承受能力：recovery / foundation / stable / expansion
    → 八类领域需求：fiscal / administrative / political / education
                    industry / security / reconstruction / overseas
    → 六条路线的有限记忆、局部资格、瓶颈优先与机会成本
    → 同一原版消费者优先级链中的单项有界调整
    → 原版实际成本、资格、前置、政治支持、随机、终结零分与执行
    → 下次合法求值时重新读取事实
```

承受能力回答“当前能承担多大承诺”，需求回答“什么瓶颈值得优先处理”。两者分开计算，不把财政、政治、行政、产业、
教育和军事的所有正向条件串成一条全局发展门槛，也不把不同单位相加成万能分数。

### 事实与证据

每个事实必须明确锁定原版来源、版本和指纹，reader 的作用域与 actor/target 方向，类型、单位、范围、缺失和未知语义，
合法求值时机、性能成本、具体消费者、唯一作者和原版尾部。无法可靠读取的引擎内部状态不能假定为已知。

能力分类使用 `discovered`、`runtime_readable`、`derived`、`consumer_mapped` 和 `behavior_verified`；它们不是自动升级的
流水线。无可靠读取或合法消费者的能力应明确处置为 `retained_vanilla`、`explanation_only`、`discovered_only` 或 `unsupported`，
不能把研究索引数量当作生产接线或行为验证数量。

### 四层承受能力

| 层级 | 含义和约束 |
|---|---|
| 恢复 `recovery` | 严重偿付问题先修复能力，限制新增昂贵、长期承诺；恢复研究和低成本合作仍按自身资格评估。 |
| 基础 `foundation` | 允许基础发展和补瓶颈，不要求所有高档正向条件同时成立。 |
| 稳健 `stable` | 财政与行政承受能力支持更稳健的投入；不等于统一意识形态，法律仍依据政治可行性。 |
| 扩张 `expansion` | 只有已证实的更强承受能力才提高高成本和长期扩张倾向；具体行动继续核对原版局部资格。 |

四层是本次求值的互斥选择，不是国家固定等级。低识字率、行政欠缺、小国规模和正常低债借款不构成所有发展的全局禁令。
战时安全需求不自动创造可负担军费；新增承诺仍受财政约束。战败重建优先于扩张，不能把近期失败变成扩大征服的奖励。

### 八类领域需求

| 需求 | 解释 |
|---|---|
| 财政 `fiscal` | 区分正常融资与偿付压力，优先修复持续赤字或高债务。 |
| 行政 `administrative` | 行政欠缺引导补能力；行政余量不成为所有研究和发展的前置。 |
| 政治 `political` | 政治危机改变改革机会成本；政治支持和改革条件由具体法律消费者保留。 |
| 教育 `education` | 教育缺口与支付、行政能力分开评估，学校、大学和研究分别受各自消费者约束。 |
| 产业 `industry` | 产业路线、生产瓶颈和重建需求影响生产能力优先级，不把既有工业路线当作工业化的唯一资格。 |
| 安全 `security` | 战争下关注生存、军需与防御；昂贵的新增长期承诺须可负担。 |
| 战后 `reconstruction` | 只采用原版近期战败等正面证据，不伪造未暴露的战争历史。 |
| 海外 `overseas` | 海外需求依赖可观测投射能力与路线，强度另受财政、行政和层级约束。 |

`mod/decisions/country_state.toml` 是协调事实与条件的唯一生产来源，`pdx.country_coordination` 提供参考求值和触发器编译。
四层、八类需求及其已知守卫在原版消费者时机按需求值，不新增持久变量。核心事实未知时回退原版；高档辅助事实缺失时，
只允许使用已证实的低档，不伪造高档能力或“国家健康”的结论。
产业、重建、海外的原始需求保留三值；消费者另读取“已证实需求”布尔信号。无正面证据只表示尚未证明需求，
不表示隐藏事实为假，也不挡住其它已证实能力；核心财政、政治、行政等未知仍遵守保守回退。

## 领域广度、深度与消费者

九个粗域 `political`、`fiscal`、`economy`、`market`、`diplomacy`、`subjects`、`military`、`geography`、`identity`
只作为合同开关，不表示域内深度相同。细分域以 `pdx.decision_report.TAXONOMY` 为唯一分类来源；每域都须能查到真实事实、
协调信号、原版消费者、优先级和未知回退，或明确保留原版/仅发现。下表说明各面的职责，不代替生产接线报告或声称同等深度。

| 细分域 | 决策职责与原版边界 |
|---|---|
| 政治与法律 `politics` | 政府、合法性、利益集团和政治阻力进入法律、改革与谈判权重；保留政治支持和法律资格。 |
| 人口与劳动力 `population` | 人口、阶层与劳动力条件用于学校、建筑和迁移相关消费者；不创造劳动力或人口。 |
| 社会、健康与福利 `social` | 生活水平、识字率和社会压力进入制度、法律与稳定判断；不保证改革成功。 |
| 财政与债务 `fiscal` | 收支、债务与违约区分融资和危机，影响建设、支出和财政相关倾向；不修改实际资金。 |
| 行政与国家能力 `administrative` | 行政与基础设施瓶颈连接制度、建设和研究；不免费提供官僚力。 |
| 产业与生产方式 `industry` | 生产事实和本地条件连接建筑、建设与生产研究；无合法生产方式消费者时保留原版。 |
| 农业与资源 `agriculture_resources` | 农业劳力、商品和资源投入连接具体建筑与路线，保留本地建设资格。 |
| 市场、商品与贸易 `market_trade` | 商品供需、价格、隔离与运输进入商品姿态和贸易/经济合作权重；不冒充完整金融模拟。 |
| 科技研究 `technology` | 已有科技与瓶颈影响候选研究权重；保留研究前置和原版研究执行。 |
| 教育与知识 `education` | 教育缺口连接学校、大学和教育相关候选；研究倾向不等于免费研究速度。 |
| 外交与条约 `diplomacy` | 关系、停战、联盟和外部承诺连接条约及外交权重；不强制签约、参战或选边。 |
| 宗主与属国 `subjects` | 宗属关系、自由度和对象资格连接自治、服从及宗属价值；保留原版关系规则。 |
| 陆军与动员 `military` | 军力、动员和军需进入军队目标、编成与征召；不直接创建军队或接管前线微观战术。 |
| 战争与战后恢复 `war` | 战争、供给和近期战败联动战争目标、军需和重建，重建优先扩张。 |
| 海军与海上投射 `navy` | 海军、舰船投入和港口能力连接舰队、舰种与海上投射倾向；不免费创建舰队。 |
| 殖民与海外 `colonial` | 既有路线、投射和海外条件影响殖民兴趣与姿态，保留可达性、目标资格和实际成本。 |
| 地理与目标州 `geography` | 目标州、孤立、家园和可达性连接州价值与目标倾向；不假定隐藏引擎状态。 |
| 身份、文化与路线 `identity` | 文化、家园和宗属条件影响目标价值及路线；不按国家名称写死历史。 |
| 时间、冲击与惯性 `time_shock` | 原版近期战败与既有路线生命周期影响恢复和稳定；不维护无界事件历史。 |

## 路线、预算和有限记忆

原有六条路线为财政整固、内部稳定、防御安全、产业发展、教育追赶和商业海洋。它们是通用的有限倾向，
按既有月度刷新及重大冲击 hook 更新，保留进入/保持/退出、紧急抢占、迟滞、唯一活动路线、TTL 100 日和切换冷却 62 日。
路线记忆与按需计算的层级/需求职责分开，不因分层新增持久变量。

影子预算表达资格档位和跨领域机会成本，不分配真实资源。建设、军备、制度、研究和海外承诺在各自局部条件下协调，
同字段优先级链第一匹配胜出，选择单项有界调整，不累乘多项发展奖励。新增记忆必须另行证明生命周期、性能、存档默认、
未知回退和禁用停止路径，不能保存无界历史或无消费者的解释状态。

## 原版适配与覆盖边界

`information.toml`、`adapters.toml`、共享意图和路线条件只连接已经核实的原版消费者。原版保留实际成本、资格、
前置、政治支持、随机性、谈判、拒绝、限幅、终结零分和执行。未暴露的前线微观战术、秘密外交意图与隐藏引擎状态保留原版。

活跃原版策略定义的同名字段可能覆盖默认策略。静态脚本能展示哪些字段在何处定义、哪些规则已接入，但不能擅自认定
引擎如何合并或覆盖这些字段，也不能据此声称默认策略调整在所有活跃策略中均生效。关闭、玩家、不可用和未知场景均须
保持各自回退合同；没有接线的面不能计作新增能力。

## 计算成本、交付和证据

运行期不新增全世界扫描、常驻服务或无界缓存。候选数、谓词数、状态变量数和依赖深度保持受控；生成期共享信号不自动证明
运行期只求值一次。速度优化须先证明正确性、等价性、覆盖率和失败语义不变，并使用同口径时间与内存测量。

工程检查证明来源、字段、作用域、回退、脚本结构和包合同；模拟证明参考求值与生成物在覆盖范围内一致；用户日志只证明
实际记录的事实。它们都不能自动证明引擎运行期覆盖语义、历史合理行为、长期平衡、后期性能、语言体验或 Workshop 结果。
这些结论仍需用户在固定标准包上验收。
