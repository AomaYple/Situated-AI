# 处境决策设计

> 设计基准：2026-10-28，当前生产候选为 Situated AI 1.4.0。
> 终极方案 4.0 的顺序和出口只在[实施计划](exec/mod重设计-实施计划.md)维护；本页描述目标架构、运行边界和实现处置。

## 目标和运行边界

**Situated AI 让每个国家基于可观测事实、国家能力、政治约束、外部环境、历史冲击和机会成本，
在 Victoria 3 原版机制内持续协调生存、政治、经济、外交、军事、科技、人口和长期发展目标，
做出当前可执行的相对最优决策。**

“相对最优”是在国家可观察事实、当前能力、政治阻力、财政成本、外部威胁和原版规则内的情境选择。
结构相似的国家可以选择相似路线，同一国家在条件改变后可以转向；不使用国家名称强制重演历史，不保证全局最优或固定结果。

Python 负责发现、来源登记、能力分类、规则校验、生成、解释、打包和工程检查。游戏运行期只加载标准 PDX 脚本和本地化，
没有 Python 常驻进程。Mod 通过原版消费者修改有限倾向，保留原版资格、费用、随机性、协商、执行、失败和终止逻辑。

## 终极方案 4.0 的七层架构

```text
原版可观察事实
    → 事实与证据层
    → 有限国家状态层
    → 政治/财政/经济/市场/外交/军事/科技/人口/地理领域评估
    → 目标、预算、机会成本、路线惯性与冷却协调层
    → 原版 AI 决策消费者中的有界倾向调整
    → 原版资格、成本、概率、谈判、失败和行动执行
```

### 事实与证据层

每个事实必须回答：

| 合同部分 | 必须回答的问题 |
|---|---|
| 来源和版本 | 哪份锁定原版文件和指纹支持该结论？ |
| 访问 | 作用域、actor/target 方向和读取路径是什么？ |
| 数值语义 | 类型、单位、范围、零值、缺失值和未知值分别是什么？ |
| 时机和成本 | 何时求值，是否需要刷新或持久状态，成本如何控制？ |
| 用途 | 改变哪个合法字段，谁是唯一作者，原版尾部是否保留？ |
| 反例和回退 | 哪些情况下不生效，未知时如何回到原版？ |

能力状态使用：

```text
discovered → runtime_readable → derived → consumer_mapped → behavior_verified
```

它们不是必须依次升级的流水线。没有可靠路径的能力必须处置为 `retained_vanilla`、`explanation_only` 或 `unsupported`。

### 有限国家状态层

终极方案需要国家画像，但国家画像不是全知向量，也不是保存整个世界。目标是保留少量、稳定、可解释并具有独立决策价值的维度：

- 财政承受力；
- 行政能力；
- 政治稳定和改革空间；
- 社会发展和人口压力；
- 生产与产业能力；
- 市场与贸易能力；
- 外交安全和依赖；
- 军事准备和战争负担；
- 科技与教育阶段；
- 海外投射和殖民机会；
- 地理、身份和宗属结构；
- 当前危机、冲击和有限历史记忆。

普通事实优先在原版消费者求值时读取；只有存在明确生命周期、性能和存档收益时才创建 Mod 自有变量。

### 领域评估层

各领域独立解释自己的事实和单位，不把识字率、军力、债务、外交关系等不同量纲机械相加成万能分数。
评估输出是有边界的需求、能力、风险、机会和冲突信号，供协调层使用。

### 协调层

协调层处理以下冲突：

1. 生存与破产；
2. 财政和行政承受力；
3. 内部政治稳定；
4. 外部安全；
5. 改革可行性；
6. 产业与市场发展；
7. 教育和科技追赶；
8. 外交影响；
9. 贸易、殖民和海外投射；
10. 长期结构性目标。

协调层可以使用有界的财政、行政和安全影子预算，以及有限路线惯性、进入/退出阈值和冷却。
它只产生倾向，不直接创建资源、资格、军队、舰队、条约、建筑或外交承诺。

### 原版适配层

原版继续负责资格、成本、概率、谈判、拒绝、执行、零目标和终止。Mod 通过合法消费者提供有限调整：

- AI strategy 数值；
- 建设、制度和法律启动权重；
- 商品供给、贸易和经济外交倾向；
- 军队、海军、军备和战争目标倾向；
- 科技、教育、殖民和宗属相关权重；
- 其他已经通过字段、作用域和行为边界核实的消费者。

没有合法消费者的生产方式、动态税率、前线微观战术、秘密外交意图和隐藏引擎状态保持原版。

## 信息覆盖与处置

信息发现范围尽量覆盖：

政治、人口、社会、财政、行政、生产、建筑、市场、贸易、科技、外交、宗属、军事、战争、殖民、地理、身份和时间冲击。

但“全量发现”不等于“全量运行”。接入生产必须同时满足：

- reader 合法且作用域已核实；
- 单位和未知语义明确；
- 有独立价值；
- 存在合法 consumer；
- 性能成本可控；
- 有安全回退和反例。

发现数量、原版索引数量和 consumer reader 数量必须与 Mod 自定义 reader、Mod 自定义规则和行为验证数量分开统计。

## 领域设计

### 财政、行政与经济

财政和行政优先处理生存、建设承受力、制度成本、产业升级、战争经济和战后恢复。高需求不自动等于扩建，
还要核对投入品、市场、就业、行政和债务。生产方式、税率、补贴只有在合法消费者存在时才接入。

### 政治、改革与人口

政治评估使用利益集团、政府、合法性、激进度、生活水平、识字率、人口结构和社会压力。改革倾向表示可行性和权重，
不代表改革已经成功；革命和改革结果只有存在可靠读取器时才进入后续状态。

### 市场、贸易与外交

市场和贸易评估商品压力、价格、储备、运输、隔离、依赖、条约港和外部风险。外交评估关系、联盟、防御承诺、威胁、
外交博弈和宗属结构。不强制签约、参战或选边，不把贸易权重冒充完整金融模拟。

### 军事、战争、海军与地理

军事评估军力、军费、军需、补给、战争负担、战争目标、海军投射、港口、海外成本和战后恢复。
没有合法前线消费者时不接管微观战术，通过军备、战争目标、外交支持和战略权重表达判断。

### 科技、教育、身份与殖民

科技与教育评估研究机会成本、技术阶段、识字率和产业升级。身份、地理和殖民评估港口、本土文化、战略位置、
海外投射和殖民机会。路线由处境条件产生，不由国家名称写死。

## 路线、预算和有限记忆

当前生产使用六类动态路线：财政整固、内部稳定、防御安全、产业发展、教育追赶和商业海洋；它们是通用路线，不按国家名称写死历史。
路线是由事实和状态推导出的有限倾向，不是国家专属脚本。路线在月度刷新或明确重大冲击 hook 时重算，使用迟滞和冷却，
限制同时处于最高强度的路线数量。

影子预算只表达承受能力，不改变真实资源：扩军会压缩部分建设或殖民空间，教育追赶需要人口与财政行政能力，
海外投射需要港口海军和收入，政治危机会压低高承诺改革和扩张。

历史记忆优先使用原版状态。新增变量必须有进入、退出、TTL、刷新、存档默认、未知回退、禁用停止路径和测试，
禁止无界事件历史、国家专属性格和不能连接消费者的解释状态。

## 当前 1.4.0 与终极方案 4.0 的差异

当前 1.4.0 已具备：

- 12 个有限国家状态维度和 18 个 Mod 自定义信息 reader；
- 六条带优先级、预算、TTL 和冷却的动态路线；
- 建设、制度、军备、科技、教育、贸易、外交和殖民相关的原版消费者适配；
- 多因素条件和字段级唯一作者；
- 有限财政风险状态、进入/退出迟滞和 TTL；
- 原版消费者适配、未知回退、标准包和工程门禁。

终极方案 4.0 的静态工程出口已经完成，但这不等于所有引擎运行期事实都可读取，也不等于行为质量、平衡或长期性能已经通过。已有画像维度大部分是事实分组，并非每一项都进入持久路线；影子预算是互斥路线的资格档位，不是实际资源分配。无法合法读取或没有可控消费者的事实继续保留原版、标为未知或仅作解释。完整证据和限制见[当前执行结果](exec/终极方案4.0-执行结果.md)。

阶段顺序、命令和证据见[终极方案 4.0 实施计划](exec/mod重设计-实施计划.md)及[执行结果](exec/终极方案4.0-执行结果.md)。

## 计算成本、交付和证据

运行期不新增全世界扫描、常驻服务或无界缓存。候选数、谓词数、状态变量数和依赖深度保持受控；生成期共享信号不自动证明运行期只求值一次。
速度优化必须先证明正确性、等价性、覆盖率和失败语义不变。

工程检查证明来源、字段、作用域、回退、脚本结构和包契约；模拟证明参考求值与生成物一致；用户日志只证明日志实际记录的事实。
它们都不能自动证明历史合理行为、长期平衡、后期性能、语言体验或 Workshop 结果。
