# 行动覆盖与验收

> 范围版本：30.0（2026-10-31）；全部条目为待实施要求，不是当前能力声明。本文是[目标设计](03-处境决策设计.md)的范围合同；执行顺序与状态只在[主计划](exec/mod重设计-实施计划.md)和[工作清单](当前工作清单.md)维护。

## 1. 覆盖分母与行动粒度

以下 19 子域是最低审计范围。K0 必须遍历锁定原版的脚本消费者、事实接口、策略定义、建筑、科技、法律、外交、条约、宗属、军备、地理和制度目录；发现的额外决策面只能加入范围，不能因表中没写就不做。
原版内部没有合法脚本入口的行为仍保留原版；无法分析、没有做、解析失败和不理解作用域属于 pending/blocked，不能冒充 engine_unexposed。

下列 ID 是**必审行动族**，不是预先计数的生产卡。K0 为每族列出完整目标集合；K4–K9 按具体消费者、商品、技术、法律和目标实例化卡。每族的全部合法绑定均完成后才可验收。
实例 ID 采用 `domain.family.target.consumer`，禁止省略目标后把模板算作全部实现。每族至少有正例、反例、局部未知、成本、替代、适用时的时间用例；每个实例至少有选中见证和原版回退见证。

表中的字段是当前源和锁定底本审计的起点，不是新增接口已验证的声明。所有候选在生成前仍须核对真实底本、作用域和终结尾部。找不到直接消费者时，审查合法间接路径并标注间接程度，不能发明字段。

### 1.1 广度与深度的五轴覆盖

“极致广度”不是把域名列得很长；“极致深度”也不是把同一权重复制很多次。每个 `surface_id × action_id × consumer_id` 必须沿以下五轴登记覆盖，任一适用轴缺失都不能标为 implemented：

| 轴 | 必须穷举的内容 | 最低证据 |
|---|---|---|
| 面发现轴 | 原版目录、定义、字段、作用域、hook、策略遮蔽和 Mod 旧写入 | `SurfaceInventory`、source hash、解析失败清单 |
| 事实处境轴 | 原始 getter、派生信号、能力/压力/机会/承诺、目标和新鲜度 | 类型化 `EvidenceSpec`/`SignalSpec`、正反事实 |
| 行动消费者轴 | 具体行动实例、原版消费者、字段方向/单位/尾部、唯一 owner | `ActionSpec`、`ConsumerSpec`、source map |
| 联动时间轴 | 成本、互补、替代、冲突、使能、进入/保持/退出、TTL/冷却、未知回退 | `RelationSpec`/`TemporalSpec`、真/假/未知和突变 |
| 生产交付轴 | IR、PDX AST、生成包、语言、确定性、资源和恢复 | `DecisionIR`、AST 见证、manifest、预算和收据 |

K0 必须为每个发现面建立五轴占位行；K5 以前可以是 pending，但不能没有行。K13 必须证明不存在“已发现但没有轴记录”的孤立面，也不能用某一轴的高覆盖抵销另一轴缺失。

## 2. 逐域行动族

### DOM01 政治与法律

- 行动族：`politics.reform_start`、`politics.legitimacy_repair`、`politics.revolution_avoidance`、`politics.government_composition`、`politics.law_transition`、`politics.interest_group_accommodation`。
- 事实：合法性、IG 势力/支持/在政府状态、激进派、叛乱、现行法律、人口结构和财政；不把某个 IG 的名字当成支持所有改革的证据。
- 消费者：`00_default_strategy` 的 change_law_chance、min_law_chance_to_pass、interest_group_government_weight、revolution_aversion；全部已有 laws 的 `*.ai_enact_weight_modifier`。
- 联动：学校/土地/税制/军制等改革分别关联能力收益、支持与动乱风险；低可行性优先替代或等待，不统一自由化，也不压制非政治发展。
- 必验：同样经济条件，政治支持或叛乱变化能改变法律候选；不能因需要稳定反而鼓励会引发内战的改革。

### DOM02 人口与劳动力

- 行动族：`population.absorb_unemployment`、`population.release_peasant_labor`、`population.qualification_support`、`population.migration_response`、`population.workforce_participation`。
- 事实：人口、失业、农民/职业比例、识字率、文化和州市场条件；无法读取资格需求则不得伪造精确缺工数。
- 消费者：建筑 `*.ai_value`；迁移、妇女权利、儿童权利、土地和奴隶制度法律消费者；学校相关倾向。
- 联动：岗位需求与教育、机械化与失业、迁移与基础设施、妇女/儿童政策与政治成本相互约束。
- 必验：失业不自动触发所有建筑扩张；缺劳动力与失业不能同方向机械加权。小国不因人口阈值被全部排除。

### DOM03 社会、健康与福利

- 行动族：`social.health_capacity`、`social.welfare_relief`、`social.workplace_safety`、`social.policing`、`social.internal_stability`、`social.civil_rights`。
- 事实：生活水平、激进派、失业、现行法律、IG 支持、行政和财政；健康等无法直读的指标保留未知。
- 消费者：institution_scores 的 health_system、social_security、workplace_safety、police、home_affairs；对应医疗、福利、劳工、治安、言论和内部安全法律。
- 联动：财政与制度维护、行政扩容与制度扩张、民生与稳定、劳工政策与支持；不把所有民生问题归为治安问题。
- 必验：需求提高与承受力降低产生不同作用，不能债务一高就全关闭，也不能需求一高就无视长期维护成本。

### DOM04 财政与债务

- 行动族：`fiscal.default_recovery`、`fiscal.debt_risk_control`、`fiscal.construction_sizing`、`fiscal.revenue_structure`、`fiscal.spending_mix`、`fiscal.ownership_commitment`。
- 事实：违约、债务比、储备、收入、净收支、借款、距破产时间；分清存量、流量与比例。
- 消费者：wanted_construction_output、economic_vs_government_spending_balance、nationalization_desire、税制法律、外交风险相关字段。
- 联动：正常融资与破产风险、投资回报代理与债务服务、军费/制度/海外承诺；不能直接改税率或扣资源而宣称倾向。
- 必验：正常低债借款保留基础建设；违约压制新增昂贵承诺但修复路径可达；债务缓解不得提高危机档位。

### DOM05 行政与国家能力

- 行动族：`administrative.bureaucracy_repair`、`administrative.tax_capacity`、`administrative.institution_capacity`、`administrative.organizational_research`、`administrative.governance_transition`。
- 事实：行政、基础设施、财政、现行官僚/税制、识字率和相关科技；未暴露的税损不伪造为确定数。
- 消费者：官僚/税制法律、central_archives、centralization、tech_bureaucracy 等真实科技、制度评分；政府行政建筑如无合法 AI 权重须明确证明并审查替代。
- 联动：补行政后才提高昂贵制度档位，但不把行政欠缺变成所有经济/研究的否决。
- 必验：行政赤字时至少一条合法修复候选可达；反例为没有资源或前置时不能硬建。

### DOM06 产业与生产方式

- 行动族：`industry.input_bottleneck`、`industry.output_shortage`、`industry.tools_foundation`、`industry.energy_transition`、`industry.transport_bottleneck`、`industry.productivity_upgrade`、`industry.investment_expansion`、`industry.production_method_alternative`。
- 事实：逐商品投入/产出、州和市场价格、供需、市场接入、运输、就业、科技及已启用生产方式；不把商品价格等同于工厂利润。
- 消费者：全部现有工业建筑 ai_value、铁路 ai_value、production 科技 ai_weight、行政策略 weight；PM 选择接口单独核对，不能借读取 PM 就声称直接控制 PM。
- 联动：工具—铁—煤—钢—发动机—铁路、电力—新工艺；兼顾上游瓶颈、投入涨价、就业和新增承诺。
- 必验：只有工具短缺也有低依赖修复；下游高需求但关键投入不可得时偏向补瓶颈；技术或能源条件改善能改变具体候选。

### DOM07 农业与资源

- 行动族：`resources.food_security`、`resources.construction_inputs`、`resources.industrial_inputs`、`resources.energy_supply`、`resources.cash_crop_opportunity`、`resources.land_transition`、`resources.import_substitution`。
- 事实：粮食、木材、铁、煤、硫、铅、油、橡胶及其他可观察商品、农民比例、科技、市场与土地法律；资源禀赋只能来自合法读数。
- 消费者：全部农业、矿业、种植园和杂项资源建筑 ai_value，土地法律、农业/采矿科技。
- 联动：粮食与民生、资源与工业、现金作物与外贸风险、机械化与劳动力；不可因为标签“资源国”写死发展方向。
- 必验：粮荒与出口机会冲突有理由；无某资源的州不能凭短缺创造资源；进口替代与本地效率相比较。

### DOM08 市场、商品与贸易

- 行动族：`market.shortage_relief`、`market.surplus_outlet`、`market.trade_cooperation`、`market.market_access`、`market.supply_diversification`、`market.external_dependency`。
- 事实：商品差额和价格、市场接入、市场隔离、关系与条约、经济依赖；没有库存/路线历史就不声称预测断供。
- 消费者：goods_stances 的底本可用路径、treaty_category_scores.trade/economy、贸易法律、建筑和目标州相关倾向。
- 联动：本地增产、合法贸易、生产方式替代；外部依赖与外交风险，海上供应与海军保护。
- 必验：闭关或战争使贸易路径不可行时存在合法本地替代；只能调整贸易姿态时不得写成直接创建每条路线。

### DOM09 科技研究

- 行动族：`research.production_bottleneck`、`research.agricultural_productivity`、`research.energy_transport`、`research.administration_finance`、`research.education_society`、`research.health_labor`、`research.army`、`research.navy`。
- 事实：已研究科技、产业/军需瓶颈、识字率、现行法律、财政、战争和海上需求；前置、研究资格继续原版。
- 消费者：生产、军事、社会三树的全部已接入 `*.ai_weight`，并遍历底本其余合法候选，不以现有 136 字段为覆盖上限。
- 联动：研究改变下游可行性，但不能将选中研究当成研究完成；危机下保留低直接成本研究候选。
- 必验：同识字率不同瓶颈产生不同科技倾向；任何财政状态都不绕过前置；技术完成后的下游见证用真实已完成事实。

### DOM10 教育与知识

- 行动族：`education.literacy_foundation`、`education.school_institution`、`education.university_capacity`、`education.academic_research`、`education.qualification_pipeline`、`education.childhood_transition`。
- 事实：识字率、人口/职业、现有学校法律、财政、行政、IG、知识相关科技。
- 消费者：institution_schools、building_university.ai_value、academia/empiricism/dialectics 等 ai_weight、学校/儿童法律。
- 联动：学校、大学、科研各有不同成本与受益时限；行政和财政约束局部调整，不能互相要求“先全部完成”。
- 必验：低识字率本身产生需求，大学投入不能只因同一识字事实重复获奖；低行政国家仍有合法教育/研究路径。

### DOM11 外交与条约

- 行动族：`diplomacy.restraint`、`diplomacy.cooperative_opening`、`diplomacy.security_assurance`、`diplomacy.economic_bargaining`、`diplomacy.infamy_management`、`diplomacy.wargoal_selection`。
- 事实：战争、关系、联盟/条约、休战、恶名、经济依赖、目标州、宗属和可观察军力；不推断隐藏外交意图。
- 消费者：recklessness、diplomatic_play_neutrality、negotiation_chance、treaty_category_scores、恶名阈值、secret_goal_scores、wargoal_scores。
- 联动：保障与军备替代、贸易与关系成本、扩张与恶名/财政、战争目标与战后负担；actor/target/支持方方向独立核查。
- 必验：相同机会下战争/高承诺可降低冒险；防守与进攻不能把同一条约方向算反；休战与拒绝保留。

### DOM12 宗主与属国

- 行动族：`subjects.autonomy_maintenance`、`subjects.self_strengthening`、`subjects.overlord_compliance`、`subjects.integration_choice`、`subjects.external_protection`、`subjects.independence_opportunity`。
- 事实：宗属关系、独立倾向、关系、相对 GDP/军力、战争、条约和财政；不得假定宗主知道属国全部内部状态。
- 消费者：三个 subject 外交策略 weight、subject_value、become_subject_value、wargoal_scores 的自治/独立/附庸/转移等合法路径。
- 联动：自主与保护、宗主承诺与财政、实力建设与政治可行性；不让所有属国永久忠诚或一律独立。
- 必验：同一关系不同实力/外部保护产生不同倾向；独立不能越过资格或保证成功。

### DOM13 陆军与动员

- 行动族：`army.force_sizing`、`army.composition`、`army.mobilization_commitment`、`army.modernization`、`army.military_supply`、`army.defensive_capacity`。
- 事实：军队规模、战争、财政、军需供需、已有军事科技、军制；不可观察的前线算法仍原版。
- 消费者：wanted_army_size、combat_unit_group_weights、conscript_battalion_ratio、军制法律、军工建筑与科技。
- 联动：军力—军需—财政—技术—动员；提升军力不能不顾弹药瓶颈，新增长期军费与临时防御分开。
- 必验：战争不无条件最大扩军；补供应与扩军具有替代/互补反例；不直接操控将军与战斗。

### DOM14 战争与战后恢复

- 行动族：`war.crisis_defense`、`war.supply_repair`、`war.commitment_restraint`、`war.limited_objectives`、`war.postwar_reconstruction`、`war.demobilization_transition`。
- 事实：在战、recently_lost_war 等真实变量、财政、军需、市场和目标信息；不发明战争疲劳或损失历史。
- 消费者：wargoal_maneuvers_fraction、wargoal_scores、建设/军工/交通/军力等已有消费者；无法调整复员时明确保留原版。
- 联动：战败后恢复优先于昂贵海外扩张，防御紧急性不阻断民生/科研；收益和承诺不可等同。
- 必验：战败且和平和仍在战争区分；过期战败不永久惩罚；无历史证据时不触发战败专属路径。

### DOM15 海军与海上投射

- 行动族：`navy.force_sizing`、`navy.fleet_composition`、`navy.supply_protection`、`navy.marines`、`navy.shipbuilding`、`navy.naval_research`。
- 事实：海军规模、海上/海外路线、蒸汽船和军需、战争、财政与科技；不凭地理常识创造航线可见性。
- 消费者：wanted_navy_size、ship_construction_output_multiplier、ai_ship_category_weights、舰队 protect_supply、wanted_marines/补给船和 ship_design 字段。
- 联动：贸易/海外需求—护航—造船—海军科技—维护承诺；不能把所有国家推为海军强国。
- 必验：内陆/无海上机会和海上贸易结构有区别；高承诺抑制扩张但保护既有供应可达。

### DOM16 殖民与海外

- 行动族：`overseas.colonial_interest`、`overseas.governance_capacity`、`overseas.treaty_port`、`overseas.resource_access`、`overseas.commitment_restraint`、`overseas.consolidation`。
- 事实：海军、原版扩张策略、宗属、行政、财政、市场资源、条约港/地理；治理风险只使用可读代理。
- 消费者：colonial_interest_ratio、institution_colonial_affairs、stance_colonize_region、treaty_port_value、殖民法律和合法战争目标。
- 联动：海军、财政、治理、资源机会；殖民与本土能力建设冲突可解释，不靠固定国家路线。
- 必验：低能力先巩固/补能力；有海军但没有机会不自动殖民；有资源机会但无投射能力不越界扩张。

### DOM17 地理与目标州

- 行动族：`geography.market_connection`、`geography.resource_target`、`geography.strategic_access`、`geography.homeland_interest`、`geography.target_commitment`。
- 事实：目标州 owner、市场隔离、条约港、资源与文化故土、州人口/文化比例、与 ROOT 关系。
- 消费者：state_value、stance_conquer_region、合法目标战争分数；目标作用域逐项检查，不按州名写死价值。
- 联动：市场接入、资源、身份、恶名和治理成本；不能只看资源就无限提高征服倾向。
- 必验：换目标州能改变结果而 actor 不变；未知 owner/文化不能被误判为敌对或“无本土价值”。

### DOM18 身份与文化

- 行动族：`identity.political_feasibility`、`identity.citizenship_transition`、`identity.religious_settlement`、`identity.labor_access`、`identity.homeland_cost`、`identity.social_inclusion`。
- 事实：文化构成、故土、热情、IG、现行公民/宗教/种姓/奴隶/迁移法律、激进派；不直接改变 POP 文化。
- 消费者：对应法律 ai_enact_weight_modifier、state_value、迁移和相关政治倾向；直接文化操控无接口即原版保留。
- 联动：权利变化、政治支持、劳动力、民生、稳定和外交成本；不统一预设所有文化政策的最优意识形态。
- 必验：同样文化构成不同政治条件可有不同合法候选；缺文化事实不能自动提高排斥或接纳倾向。

### DOM19 时间、冲击与惯性

- 行动族：`temporal.crisis_preemption`、`temporal.route_hold`、`temporal.route_exit`、`temporal.recovery_transition`、`temporal.commitment_reassessment`、`temporal.expiry_fallback`。
- 事实：现有路线/到期/冷却、违约、战争、战败、市场和政治事实；新 shock 只用核实的钩子或消费者求值。
- 消费者：六路线相关触发器/效果与所有使用姿态的卡；无单独权重时作为生命周期策略归属对应生产卡，不重复统计为额外行为。
- 联动：安全条件实时检查，月度结构姿态保持；危机可抢占，解除后按明确保持/退出规则恢复。
- 必验：进入前、到期前、到期点、冷却点、未知、玩家接管、禁用、旧存档缺变量、持续危机与危机解除全覆盖。

## 3. 必验跨域场景

每例以参数夹具构造，不按 RUS/GBR/NED 国家标签分支。国家名称仅用于说明。
断言须检查实际生产卡、IR 和生成后 PDX AST；只检查 helper 返回值不算通过。

## 4. 深度与逐项见证合同

每条生产卡的验收行包含：`action_id, family_id, consumer_id, facts, signals, goals, relations, rank_terms, effect, temporal, source_map, positive_cases, negative_cases, unknown_cases, cost_cases, boundary_cases`。
同一参数化用例可覆盖多张卡，但每张卡都要有具体实例输入和生成 AST 位置；没有产物差异或选择差异的注释不算见证。

每个可变判断字段必须有反事实见证：只改变该事实/关系/成本/时间，符合设计的主/替代/强度/回退发生变化。
有意不影响某行动的因素要有不干扰测试。不能让每项输入都必须改变每个结果，也不能把配置字段全部变成无生产影响的说明文字。

对宣称单调的项分别验证：压力缓解不加强危机；成本上升不增加新增昂贵承诺；信息减少不加强未获证支持；能力提高不无理由降低对应可行档。
阈值、上/下界、中性、负值、终结零分和零成本行动均测。没有数学单调性的冲突目标只要求声明预期，不强加错误的全局单调性。

时间只对有记忆价值的卡适用；不适用必须说明即时求值机制。关系不适用必须列出替代审查和理由；不能每张卡统一标 N/A。
生产可达见证和参数化测试不得通过给所有事实塞“健康默认值”获得；至少 SC02–SC04 保持其余非必要信息未知。

### 4.1 单张行动卡的最小验收包

一张卡只有在以下最小证据包全部存在时，才能把对应 `CoverageRow.status` 设为 `implemented`。这套要求对每个 `action_id × consumer_id` 实例分别执行；不能用行动族模板、同一文件中的另一张卡或同一消费者的总报告代替。

| 必需件 | 最低边界 | 拒收示例 |
|---|---|---|
| 唯一身份 | `domain.family.target.consumer`、source 定义、actor/target 作用域和原版字段均唯一 | 只有 `family_id`、省略目标或把多个消费者合并 |
| 生产接线 | source → `ActionSpec` → `DecisionIR` → PDX AST → 实际生成文件的可重算路径 | 只在 TOML、报告、Python 参考器或测试 fixture 中出现 |
| 正例 | 一个可观察事实组合使该卡被选中，输出字段、方向和幅度均可核对 | 只断言卡存在、权重非零或字符串出现 |
| 回退 | 缺核心事实、无候选或不满足软条件时，原版资格/尾部和回退结果可核对 | 回退仍偷偷写入增量或被报告默认值掩盖 |
| 负例 | 错 actor/target、玩家、禁用、硬资格失败或错误作用域至少一个明确拒绝 | 所有失败都归为“无数据”而不区分原因 |
| 未知 | 辅助事实未知与核心事实未知分别有局部回退结果 | 未知统一变成0、false、健康或全局关闭 |
| 动态反事实 | 只改变该卡声明的事实、关系、成本或时间，选择/替代/强度/回退至少一项按合同变化 | 字段只写进解释或 coverage，不改变生产 AST |
| 成本与关系 | 成本档、互补/替代/冲突/使能（适用时）有单独真/假/未知证据 | 永久 priority 偏移、只在同分时参与或只写文字联动 |
| 生命周期 | 进入、保持、退出、TTL/冷却/清理按卡的适用性有证据；即时卡明确无状态理由 | 只有进入条件，没有退出；或所有卡统一标 N/A |
| 解释与范围 | reason code、evidence ID、source map 和版本/范围哈希一致 | 自由文本解释、不可重算路径或过期 scope hash |

同一参数化用例可以为多张卡提供部分证据，但收据必须逐卡列出实际 `action_id`、生成 AST 路径和断言；共享测试不能把缺失的卡隐式算作通过。任一必需件缺失时，该卡保持 `pending` 或 `blocked`，所属行动族和子域也不能关闭。

## 5. 完成计数与禁止的替代证明

报告分别统计已发现面、合法可接入面、已实现面、引擎未暴露、待实现、阻塞；19 子域均必须展示这些分母。
已有 377 消费者库存、1,401 条规则、7 张卡是迁移起点，不是下一轮完成阈值，也不是新卡数量。

以下任一情况即不满足本方案：

- 行动数量很多但只绑定四个总策略字段，实际具体消费者仍走旧旁路。
- 旧规则包装成卡，却没有目标、状态、成本和适用的关系见证。
- 只有 Python 模型能选择替代，游戏 PDX 永远按固定顺序输出。
- 表中每域只接一个容易字段，其余可接入面不分类或被删出分母。
- 用缺实机反馈、缺美术资源或用户长期验证解释功能未实现。
- 依据已有测试全绿、包生成、文档勾选或新 tag 证明机制完整。

最终只能在 pending=0、blocked=0、无未分类项，且合法接入面全部具有生产见证时宣布工程实现完成。engine_unexposed 不计入功能完成率，必须公开列示。计划30.0另要求所有适用阶段收据为 `verified`，并且每张卡的最小验收包均可重算；只完成行动族统计或域级汇总不能关闭实例。
