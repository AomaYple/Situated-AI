# D25 殖民、海外与领土机会

AI 国家在实际有权处分或申请的州上比较土地、位置、人口、生存与长期治理成本。D20、D21、D24 提供外交、宗属和战目标路径，D02、D09、D19 提供行政、市场与人口归属。新领土可改善贸易安全，也会争夺行政和航线资源，安全和财政恶化会反向改变海外路线。

## D25.colonization

殖民机会与竞争

- **机会与基准**　有资格的国家比较原版州建立殖民地、维持增长与推迟。基准含现有殖民事业和被挤出的另一处机会。州分割、竞争者和可观察的地方国家分别绑定。
- **信息和接口证据**　`establish_colony` 可在原版地图接口定位。候选基础评分、已有增长殖民地和地区存在性的权重是全局参数，`institution_colonial_affairs` 是独立机构设置。确认逐国州机会和获知竞争、补给与增长的权限。见 `game/common/map_interaction_types/map_interaction_types.txt:80`、`game/common/defines/00_ai.txt:1213`、`game/common/institutions/00_institutions.txt:1`。
- **跨域取舍与结果反馈**　有可达通道及现有支点时可降低新增成本，供给不足、多个殖民并行时可能宜等待。按实际殖民开始、增长、地方反应及州主变化更新，长期开支同 D02。
- **反例和验证**　同一州候选对照本国已有支点、邻区有支点及完全没有，断开航线或令另一个国家率先取得资格。只变本国没看到的增长计划时，当前计算保持等价。

## D25.claims

领土宣称、条约港与沿海争端

- **机会与基准**　国家比较具体领土宣称、取消宣称、取得或让渡条约港的原版动作，与现有宣称和通行安排作对照。正式战目标、条约条款及单方殖民宣称分别绑定。
- **信息和接口证据**　`treaty_port_value` 是原版经济或地缘评价先例，条约港条款另有州资格、维持和生效效果。`da_stake_colonial_claim` 有 `propose_score` 且不需接受。见 `game/common/ai_strategies/00_default_strategy.txt:3189`、`game/common/treaty_articles/14_treaty_port.txt`、`game/common/diplomatic_actions/56_stake_colonial_claim.txt:177`。
- **跨域取舍与结果反馈**　港口通行价值可能高于完整州成本，额外宣称也可能提高争端和伙伴损失。在可观察的实际州主、所见市场路径及第三方回应发生后，更新 D10、D20、D24。只作出宣称时保留主权基准。
- **反例和验证**　对照宣称已生效而州未取得、只有条约港、具有条约通行但无领土，以及州主易手。只出现一种原版候选时对照该字段，以同一权属事件作归因。

## D25.territory_value

具体州价值、位置与长期负担

- **机会与基准**　各有权国家在取得、处置或保持具体州时评价本国净得失。原版只给单州时对照该候选的原版估值或合法现状。争议中候选对象、法律持有人和当前控制者分别记录。
- **信息和接口证据**　`state_value` 定位原版国家策略，州转让的条款 `inherent_accept_score` 读取 `scope:article.input_state.ai_state_value:root` 的可比较候选。输入州、估值国及本国可见资源或群体应逐项验明。见 `game/common/ai_strategies/00_default_strategy.txt:1773`、`game/common/treaty_articles/06_transfer_state.txt:192`、`game/common/treaty_articles/06_transfer_state.txt:276`。
- **跨域取舍与结果反馈**　有矿产而无接入的州可能弱于资源少但联通的州。多期收益取决于并入、劳力和供应，额外军费只算本国可证明成本。实际取得、履行和管辖变化逐次更新。
- **反例和验证**　同一州对照买方、卖方和战目标受益者，变更具备航路、有无行政余量及不同折损。只变期间之外的未来资源，也没有合法估计依据时，当前评分保持。

## D25.administration

占领、州主交接与殖民建置

- **机会与基准**　D25 负责州占领、州主与领土交接的状态，以及实际完成并入的州观察。实际处分国以现有管辖为基准，只在原版有资格时评价殖民行政建置。普通现有州的启动、维持和合法取消并入由 D02.incorporation 统一评价和投影。占领国的军事或外交行动按自身原版资格由 D24 等实际机会承接。[现有州并入](D02.md#d02incorporation)
- **信息和接口证据**　地图 `incorporate_state` 定位 D02 的行动。州 `on_state_owner_change`、`on_state_incorporation` 和 `on_colony_created` 定位 D25 的不同结果。殖民行政建置另有 `je_colonial_administration_button_senegal` 和独立的 `ai_chance`，实际逐国候选、观测及原版执行待证。见 `game/common/map_interaction_types/map_interaction_types.txt:51`、`game/common/on_actions/00_code_on_actions.txt:4145`、`game/common/on_actions/00_code_on_actions.txt:4150`、`game/common/on_actions/00_code_on_actions.txt:4253`、`game/common/scripted_buttons/00_colonial_administration_buttons.txt:40`。
- **跨域取舍与结果反馈**　领土接管可提高安全或取得本地资源，也会增加实际治理负担。D02 用本国行政成本和等待期评价普通并入。D25 在实际确认完成后共享新的州状态，供 D02 核对税基和行政承诺，供 D18、D19 核对秩序与群体覆盖。
- **反例和验证**　对照暂时占领、已交接但未启动并入、并入中、在途取消或换主及实际完成。按原版结果和各国获知时点更新权限、税与服务基准，换主时撤回旧主已失效的观察。验证 D02 独立处理普通并入候选，D25 的一次完成观察只反馈一次。

## D25.release

释放、分割、新建与转让

- **机会与基准**　处分国、受让国、被释放国家以及对其有义务的第三方分别绑定原版机会。主动释放、战争解放、转让州和释放为附属采用不同基准。
- **信息和接口证据**　`country_creation/00_releasable_countries.txt` 多种定义带 `ai_will_do = { always = no }` 的原版门，逐一证明能否合法改投。`transfer_state` 条款一次性生效，另有 `release_as_subject` 战目标。见 `game/common/country_creation/00_releasable_countries.txt`、`game/common/treaty_articles/06_transfer_state.txt:71`、`game/common/war_goal_types/38_release_as_subject.txt`。
- **跨域取舍与结果反馈**　释放可减并入和防御负担，可能失去税、外交杠杆和关键通道。只在新国家真正形成、州主和承诺更新后重新比较，其国家操控权按现时验证。
- **反例和验证**　同一州对象对照提案失败、释放独立及释放为附属，候选从国家列表消失时不提前生成。战和条款共同触发时只登记州的一次实际处分。

## D25.capital_relocation

国家首都迁移

- **机会与基准**　国家在合法候选州比较迁都与保留，绑定实际州主、当前首都与原版冷却。市场首府有 D09 的独立机会，借用的市场影响须在实际变更时验证。
- **信息和接口证据**　原版地图 `move_capital` 和 `move_market_capital` 是独立界面入口，前者的 `MOVE_CAPITAL_COOLDOWN_YEARS` 可定位。逐国 AI 写点、可用读数与具体州资格待证。见 `game/common/map_interaction_types/map_interaction_types.txt:58`、`game/common/map_interaction_types/map_interaction_types.txt:65`、`game/common/defines/00_defines.txt:21`。
- **跨域取舍与结果反馈**　某候选州可降低丧失首都的风险或改变地方行政影响，同时让保护现有港口和供应更困难。实际迁都后再向 D02、D23、D24 更新，物流或市场变化按其自身事件。
- **反例和验证**　将同一目标州设置为已失去控制、在冷却中及合法可迁三种情况。分别只变市场首府和只变国家首都，核对其各自后果。

## D25.expeditions

海外探险决议与阶段性后果

- **机会与基准**　用国家当前资源与合法后续机会比较发动原版探险和维持现状，再按原版角色处理确实收到的事件选项。探险与建殖民地分开。
- **信息和接口证据**　`central_africa_expedition` 用殖民科技、探险占用状态、东非利益、奎宁和军官数量等原版门，有 `ai_chance`，选择后玩家触发事件而 AI 调用模拟器。只有切实可证明的本国决议与事件机会能消费改进，阶段成功或失败由原版。见 `game/common/decisions/central_africa_expedition_decision.txt`、`game/events/expedition_events/central_africa_expedition_events.txt`。
- **跨域取舍与结果反馈**　探险可以带来威望或条件收益，却占用预算并可能失败。D01 计持续开支，D20 计实际关系后果。只有新机会确实出现后才计殖民或市场价值。
- **反例和验证**　对照和平与战中、国库不足与充足、缺地区利益及他国先完成。对 AI 模拟与玩家事件分别回读，结果失败或提前停止时撤回依赖成功的后继贡献。

## D25.cossack_hosts

哥萨克军团建置、保留与解散

- **机会与基准**　有原版资格的国家按其州现行状态评价建立、保留或解散。保持国家 ROOT 与具体目标州，不把边疆所有州视作候选。
- **信息和接口证据**　`cossack_host_scores` 给国家 ROOT 与 `scope:target_state`。两类状态分别由建立与解散字段记分，原版将当前状态乘惯性值，零分排除候选。原例检查地区、分割、殖民、群体份额、法案与近期移除。见 `game/common/ai_strategies/00_default_strategy.txt:10767`、`game/common/map_interaction_types/map_interaction_types.txt:87`。
- **跨域取舍与结果反馈**　边疆扩张时的军事或殖民收益应和可证治理、人口政策代价比较。当州已并入或改法，维持的价值随实际附带义务改变。D18、D19、D22 在知晓机构和影响后计实际结果。
- **反例和验证**　同一个州在未建立、已建立和近期移除后分别验证。对建立或解散出现精确零分、所属国换手、原版限制性法律更替保留原版门和惯性，玩家选择单独测试。

## 跨期对照与实施出口

设获取新州会发生确定的 3 点外政代价。若实际取得后，只有下一轮具备行政和交通条件才得到 12 的净收益，否则一般治理与补给负担为 6。在已知条件下后续合格概率 0.7 时，期望为 3.6，降低到 0.4 时期望为负 1.8。这里把当前取得视为已经确定的对照，只改变后继机会和费用。若目前只在草拟条款，要再计批准、有效和实际处分的原版分支。

首选一州纵切回放殖民或条款取得、接管、并入与位置价值，用一次实际州主和时期交接压测归因。另以确有独立国家机会的海外探险和哥萨克州政策核对原版资格、玩家路径、原版自动结果与合成语义，保留未知的逐国接口。
