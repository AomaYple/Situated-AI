### B.0 一条命令跑完（复制即用）

```powershell
$u="$env:USERPROFILE\Documents\Paradox Interactive\Victoria 3"
"游戏进程：$((@(Get-Process victoria3 -ErrorAction SilentlyContinue)).Count)  ← 必须 0"
"我们的 mod 目录："; Get-ChildItem "$u\mod" -Directory | ForEach-Object { $_.Name }

Get-ChildItem 'C:\Program Files (x86)\Steam\steamapps\common\Victoria 3\game\tools\scripted_tests' -File | ForEach-Object { $_.Name }

"我的截图："; Get-ChildItem "$env:TEMP" -Filter 'v3-*.png' -ErrorAction SilentlyContinue | ForEach-Object { $_.Name }
"归档目录数：$((Get-ChildItem "$u\v3probe-logs-archive" -Directory -ErrorAction SilentlyContinue).Count)"
```

判定：游戏进程 0、套件列表**不含** `sitai_*.txt`、仓库垃圾为空、`%TEMP%` 截图已删、
归档已按"每局一个代表目录"整理（其余移入 `_obsolete\`）。

### B.1 明细表

| 项 | 命令 / 判定 |
|---|---|
| 游戏进程 | `Get-Process victoria3` → **必须 0 个** |
| 后台任务 | `job_list` → **不得有 running**；空转的 watcher/监控一律 kill |
| 子代理 | `list_agents` → 不得有 running |
| 临时产物 | `%TEMP%` 下自己的截图/脚本删掉；仓库内不得有 `.dmp/.tmp/.bak/.orig/.rej` |
| **游戏安装目录** | 不得残留我们写入的文件（例：`game\tools\scripted_tests\` 只应有原版 5 个：germany / ip3 / italy / springtime / test） |
| 实验归档 | `…\v3probe-logs-archive\` 清点，写进结果文档（哪一局、多少月、结论） |
| 依赖锁 | 新增/变更依赖 → `requirements.lock` + `pyproject.toml` 的 `why` 同步 |
| 文档数字 | README / tools README 的用例数、测试文件数、覆盖率、模块数由 `test_repo_numbers` 与 `v3 cov` 对账（**改 README，不改测试**） |
| 生成物 | `v3 modgen --check`、`v3 ai-surface --check`、`v3 tables` 一致 |
| 自动化开局 | 结论见 `exec/自动化范式.md`：官方 `-scripted_tests` + **一次「观察」点击 + 解除暂停**（点击前必须**强激活前台窗口**，否则点击会发给抢焦点的其它程序）；引擎侧判定读 `Documents\tests.txt` 与 `binaries\*_GameTests_testoutput.xml` |
| 观察者局的判据 | 观察者模式**没有玩家国家** → 探针的 `PLAYER` 行不会出现；自检改用 `ROLE;RUS` 是否每月在写（= 时间在推进），并确认 `SHOCK` 比例符合该角色预期 |

## C. 门禁：全绿（缺一不可）

### C.0 交付物先过"机器判据"（血的教训）

**不许用 grep/肉眼"看到关键字"就算交付物合格**——实测发生过：某交付的 `.py` 是
**UTF-8 带 BOM + 双重编码（有损）**，`grep` 照样能匹配到 ASCII 标识符，但 `ast.parse` 直接
`SyntaxError`、`import` 全废。所以每个新增/改动的 Python 交付物必须先过：

```powershell
.venv\Scripts\python.exe -c "import ast,pathlib,sys; [ast.parse(p.read_text(encoding='utf-8')) for p in map(pathlib.Path, sys.argv[1:])]" <文件...>
.venv\Scripts\python.exe -c "import importlib; importlib.import_module('pdx.game_auto')"
# 编码：仓库 .py 一律 UTF-8 **不带 BOM**、LF
```

判定：`ast.parse` / `import` 通过 + 无 BOM + ruff/format/mypy 绿，才算"文件存在且可用"。

```powershell
.venv\Scripts\python.exe -m ruff check .
.venv\Scripts\python.exe -m ruff format --check .
.venv\Scripts\python.exe -m mypy
.venv\Scripts\python.exe -m pytest -q -n 4
.venv\Scripts\v3.exe verify            # 不带 --fast：全树扫描
.venv\Scripts\v3.exe tables
.venv\Scripts\v3.exe ai-surface --check
.venv\Scripts\v3.exe cov               # 整体 ≥86% + 各模块下限（FLOORS 只升不降）
.venv\Scripts\v3.exe modguard          # 五道闸门（阶段 3 起）
```
