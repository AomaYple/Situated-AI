# 发布自动化结果

日期：2026-11-04。范围：标准 Mod 包的本地部署、既有 Steam 工坊条目内容上传与全部语言正文同步。
Mod 生产版本仍为 3.2.0；本轮不修改机制、数值、游戏本地化或公开版本。

## 已实现

- `v3 publish` 统一编排，默认只读预检和逐项预览；`--execute` 后串行写入，可单选 local、workshop、descriptions。
- `distribution.validate_package` 对固定 ZIP 做生产源校验；同一次运行保存 ZIP、展开内容及逐文件哈希，
  本地部署与工坊内容使用同一来源，上传前后再核对内容树。
- `deployment` 限定 `mod/Situated AI` 身份，拒绝链接/重解析点，检查游戏与启动器，
  同卷暂存和核对后替换；旧目录备份位于 Mod 扫描目录之外，异常时恢复，原播放集及存档保持原字节。
- `publishing_contract` 核对 11 语分母、Steam 官方语言映射、BBCode、UTF-8 长度与路径；
  `docs/publishing/workshop.toml` 唯一维护条目和正文映射，正文仍是长期稳定的玩家介绍。
- Windows x64 原生适配使用本机游戏 DLL 的 SteamUGC016 / SteamUser021 / SteamUtils010，
  只更新现有条目，每次提交前核对账号所有者和 App ID。主工具通过 JSON 隔离一次性 Steam 子进程，
  不保存密码、不依赖网页操作、不留下常驻轮询。
- 内容更新核验 Steam 异步提交结果；逐语言正文独立提交并禁用缓存读回比较，相同正文跳过。
  排他锁和原子 JSON 收据保留完整、部分失败及提交后不确定状态；失败不会自动重发内容。
- 发布指南统一维护用法、平台范围、备份恢复和失败处理；任务入口、贡献指南、README 和当前清单同步导航。
