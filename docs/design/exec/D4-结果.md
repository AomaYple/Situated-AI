# D4：逐目标覆盖与领域责任链

状态：`in_progress`。证据类别：`static_check`。本收据只记录本轮真实落地的局部实现和未关闭边界；不把文件存在、测试数量或静态通过解释为全阶段完成。

## 已落地

- `domain_coverage.py` 生成 19 个细分领域的逐目标责任行；当前规则、显式卡与 writer 数量统一见[工作清单](../当前工作清单.md)，历史基线 1,401 个身份另行冻结；每个 target 带 source、definition、consumer、actor、target、owner、unknown policy、cost contract 和 vanilla fallback。
- `domain_actions.toml` 的 14 条联合链、领域实例计数和行动族分类均由当前规则目录重算，计数不再手写冒充生产覆盖。
- `tests/test_situated_domain_coverage.py`、`tests/test_situated_families.py` 和 `tests/test_situated_inventory.py` 覆盖目标身份、计数、联合链断链和重复 owner 拒错。

## 未关闭

- 领域 target 目前证明的是生产责任和静态接线，尚未为每个目标补齐 D6-D8 要求的六类行为见证；状态继续为 pending。
- 原版独立发现中的能力 pending 面尚未全部转为具体生产责任；最新计数与作用域证据见[D0 结果](D0-结果.md)。

本页机器收据是当前源码的未完成身份快照，仅更新输入和依赖哈希，不继承历史测试的通过结论；阶段与原子单元仍须各自验收。
