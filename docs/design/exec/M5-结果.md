# M5 · 政治与市场扩展

> 2026-10-05 实验快照：实现已生成并通过相关离线测试；`mod/decisions/extensions.toml` 两个开关默认false。已有实机属于隔离侦察，正式候选提升与启用需各自通过 M1–M4；后续按最终执行纲领处理，不宣布质量验收。

## 政治改革节奏

只追加默认策略 `change_law_chance` 的贡献，原版自行选择法律。脚本基值为1，但当前实测未核对最终聚合、限幅、更新和候选筛选，不能把它直接写成每次更新1%的实际启动概率。高合法性、和平、无叛乱且政府含工业家或知识分子时追加1；战争、叛乱或极低合法性时追加−0.5。IG身份是机会代理，不能保证他们支持任意法律。

不改IG力量、不改法律或成功率，不调用开始立法效果。直接读取真实条件，无新增持久状态。阈值与权重是待校准参数。

只读仪器从全量原版法律键自动生成目标识别，分别观测started/pass/fail/ended，月度读取合法性、战争、叛乱、任意立法和条件。原版 `enacting_any_law` 纠正了旧探针对不存在通用接口的判断。未找到已核对的最终chance getter；`COMPUTED_DEFAULT_DELTA`只是与规则同源的default贡献重算。没有当前立法不能直接充当存在可行法律的机会。

## 市场依赖与外交支持

`economic_dependence`为0到5的方向性标度，包含外国资产、市场份额/商品和交易关系，不是百分比或单一贸易额。评估国对被支持方的依赖减去对另一方的依赖，再乘5，支持贡献限定在−25到25。交换两侧时符号相反，依赖相等时为0。

使用原版提供的root、country与enemy_country作用域，不遍历全世界，不改经济、不绕过参与资格、不强制加入。每个新增支持项有双语理由。它表达经济关系破裂的代价，不能称为控制市场加入/退出。实际支持偏好margin会减掉另一侧支持或中立中的较大者，所以一个支持贡献变化不总等于相同的margin差分。

两局 `mod_errors=[]`、挂载齐、`cleanup_errors=[]`，但这些不能把原始失败报告改成通过。

因此该局仍未证明启动通道改变了行为；没有可行法律候选的直接读数，不能把99无启动解释成接口无效。
`COMPUTED_DEFAULT_DELTA`继续是保守规则重算，实际99贡献由候选源快照和 `analysis.experiment` 标识。
实验开关维持false；这是一项已执行但未获正向行为结论的实验，不能宣称政治扩展质量验收完成。

## 强依赖与整数精度的当前有效配对

两臂使用相同的原版中文缺键补全仪器，十类错误及收尾均通过，原始证据为
`behavior/market-control/PRU-FRA/input-none/20261005-001420` 与
`behavior/market/PRU-FRA/input-none/20261005-001930`。同一完整自然检查点、相同仪器、相同声明参数，
只有候选市场支持贡献不同。两局分别推进103.32和102.32天。

SAX有37个共同有效资格采样点，BAV有3个；均不是独立机会，两国各只观察一场受控博弈。
例如SAX依赖为2.943/0.050，重算支持贡献14.465，双方margin差分+14/−28；
BAV依赖2.922/0.050，贡献14.36，margin差分同为+14/−28。其余有效点方向与一至两倍margin范围一致，
无模型外记录。SAX两臂均未加入，BAV两臂均加入，因此本实验仍没有实际加入行为差分。

实机Getter即使请求 `|3` 仍输出整数分数，依赖读数保留三位小数。比较器改用保守截断误差界：
两臂整数差分小于2个分值、依赖输入经两倍margin传播最多 `4×|权重|×0.001`，默认合计2.02。
理论效果必须超过总界，实际两个有符号差分都必须大于2，才能计为可分辨效果。
精确引擎舍入方式未证明；弱效应、零差分、反方向和过大差分继续拒绝，不能靠放宽误差制造通过。
本局证明两国强依赖下市场支持评分带宽，`quality_improvement_proven=false`，扩展开关仍false。
