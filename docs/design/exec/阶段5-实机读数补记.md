### 1.1 为什么「窗口开过」是本次最有价值的一条

**它把两条从没在引擎里验证过的结构性判据，从「原版有先例」升级成「本机实测生效」**：

* `country_has_primary_culture = cu:south_german`
* `is_in_geographic_region = geographic_region_german_confederation`

这两条只写在 `je_sitai_bv_alignment_window` 的 `is_shown_when_inactive` 里。写错任何一个
字母、或者这两个触发器的作用域不对，**窗口就永远不开，而且完全静默**（JE 条件为假就是
不出现，引擎一个字都不报）。这正是 `自动化范式.md` 反复强调的那类失败 ——
本批次之前它是"原版有先例"的**推断**，现在是**读数**。

### 1.2 行为层：动了，但动的不是目标那条法

本档案的整个前提是「选边的代价 → 原版自己的权重公式转向土地改革」。
实测读数是**分裂的**：

* **动了**：进步牌挂上了（`progressive_agenda`），而且引擎日志里出现了**正在推的候选法**
  —— `law_landed_voting`（投票权那一组）。这是四批档案里**第一次**读到"AI 真的在推法"。
* **没动到点上**：目标法 `law_tenant_farmers` 到 1841.7 仍是现行法律，引擎侧的
  `law_changed` 判据因此 **判失败**。

也就是说，**"窗口开了、牌换了、法也推了，但推的不是我们要它推的那条"**。
这与批次 1–3 记的结论（"窗口开了、改革派抬头了，AI 依然不动手改法"，B53–B60）
**不是同一句话**，比那一句更细一层：**"不动手"要改成"动的手不是那条"**。

⚠️ **不许把这条读成"档案成功"**：G-EXIT-5.3 要的是「危机期上升」，
本档案真正的判据是**目标法换没换**，而它**没换**。剩下的归因问题
（是递牌通道、是法律承诺、还是 `is_powerful` 没翻过线）仍是 B53–B60 那一族，未解。

### 1.3 一处异常：`TARGET` 自臂行**没有落进日志**（已修成不依赖它）

`阶段5-批次3-结果.md` §四.2 把「`ZZPROBE AB;TARGET;<档案 id>` 自臂行还没在实跑里被看见过」
列为待复核项。**这次复核的结论是：它没落**。

* 日志里 `ROLE` 行 **56** 条、`SHOCK` 行 **56** 条，但 `TARGET` 行 **0** 条；
* 分析器据此把「法律换过没有」报成 **不判**（白白丢掉一条本可以判的读数）；
* `SELFARM` 行实测在 `zz_probe_ab_effects.txt:49` 与 `:58` —— 说明**自臂路径本身跑了**
  （月份 13 与 37 都对），只是那一刻没写 TARGET。

**修法不是"再把它写一次"，而是让分析器不依赖它**（`stage3_rerun._subject_archive`）：
`ROLE;<TAG>;<本地化国名>` 里**第一格就是 tag**，而档案 ↔ 国家是数据源里的事实
（`[archive].country`）—— 比"某一条只在某一刻写的日志"稳得多（P9）。
现在两条路并存：有 `TARGET` 用它，没有就按 tag 反查；一个国家对上多份档案时**不猜**（返回空）。
按新口径重跑分析（`--analyze-only`，不重开游戏）后那一栏就出数了：
`本档案盯的法 = law_tenant_farmers`、`那条法已不是现行法律 = False`。

### 1.4 一处没查清的（记 backlog **B84**）

同一个探针里，**`on_actions` 文件的行号与重新生成的结果逐行对上**（引擎报 25 / 39 / 50 / 60 /

不能当证据用（`on_actions` 的可以）。**记 B84，不展开。**
