* 两份档案的数值（`-35` / `-0.30` / `0.35` / `0.5` / 门槛 `75` / `days 3650` / `weight 100`）

  唯一独立取档的是 `au_revolution` 的激进派系数 `0.25`（依据是原版档位本身
  `00_ip4_04_modifiers.txt:177`），但它对奥地利的效果大小**没有实测**。

  第 4 步的 A/B 会话**已为 `au_revolution` 跑了一局**（见 §二·补）；`cn_intervention` 的 A/B 会话、
  以及所有档案的 **G4（试玩者）** 仍未做 ⇒ G-EXIT-5.4 记为"尚无读数"，**不许读成已达成**。

## 四、抽象改进与随之更正的两处事实（G-EXIT-5.5 要求写明）

1. **生成器里写死的"战败"措辞被参数化**（`modgen.py`：产物注释头 / 压力修正注释 / `Memory` 文档串）。
   原来它往**每份**产物注释里写"战败求存 / 战胜方也记成战败 / 战败压力"，
   于是革命潮与列强干涉的产物注释是**错的** —— 而"只生成不手写"之下人改不了产物，
   只能改生成器。现在注释由**档案自己的 `title`** 说话。**这属于抽象改进，不是特例分支。**
2. **`country_loan_interest_rate_add` 的一句断言是错的**：`ru_defeat` / `tr_defeat` 都写
   「原版**只出现过一次**」。实测（1.14.3，`common/`）**12 处**：全局基准
   `00_code_static_modifiers.txt:12 = 0.2`、法律侧 `00_amendments_enactment_04.txt:644/1138/1174/1222/1266
   = 0.02/0.02/0.03/0.01/0.05`、科技侧 `30_society.txt:209/599/1226/1473/1647 = -0.02`、
   字段定义 `00_modifier_types.txt:662`。「**国家静态修正**那一侧没有档位阶梯」仍成立。
   **两份档案的 `why` 都已改成实测事实**（记 backlog B72）。教训：`v3 citations` 只能查
   "引用指得到"，**查不出"计数断言"** —— 要真防住还得再有一条计数检查，未做。
