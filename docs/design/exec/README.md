## 当前状态

F0–F18 已完成工程基线，当前维护候选为 Situated AI 1.2.0。U0 已冻结基线、场景矩阵和行为指标；
U1–U8 已由历史收据完成工程映射，U9–U10 保留工程与游戏验收边界，U11–U12 已交付观察器、候选包、
Workshop 文案和维护入口，U13 已把多因素协同规则接入生产源并生成 1.2.0 候选。

每个 U 阶段都必须沿用上一完整包并生成一个可安装、可运行的标准包。工程检查、日志观察和存档
摘要不能单独证明 AI 行为质量；用户长期游戏证据按工程交付基线分类记录。观察器和 Workshop 文案已经是当前
工程能力，但平台上传、游戏行为、平衡和体验仍不自动通过。
