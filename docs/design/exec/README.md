# 执行文档索引

这里仅保留当前交付所需的少量权威入口。已完成的 F、T、U 和早期版本执行页已从工作树移除，原始内容仍可从 Git 历史按标签或提交追溯；它们不再作为当前计划、当前状态或发布依据。

## 当前入口

1. [Situated AI 终极方案 4.0 实施计划](mod重设计-实施计划.md)：唯一当前产品计划，记录 E0–E15 阶段、出口和验收边界。
2. [终极方案 4.0 执行结果](终极方案4.0-执行结果.md)：当前生产改动和静态证据收据。
3. [工程交付基线](工程基线-1.0.md)：生成、编码、包结构、证据分类和恢复合同。
4. [版本交付索引](版本交付-结果.md)：不可移动标签、标准包哈希和 GitHub Release 状态。
5. [当前工作清单](../当前工作清单.md)：当前事实、限制和下一动作。

当前工程交付为 `Situated AI 1.3.0`；E0–E15 的静态工程出口已在最新执行收据中记录。历史收据只用于追溯。

## 维护规则

- 计划目标不等于已实现能力；只有生产源、生成物、检查结果和收据相互对应时，才能标记静态出口完成。
- 结果页只记录可核查证据，并明确区分 `static_check`、`snapshot`、`simulation`、`runtime` 和 `inference`。
- 历史执行页留在 Git 历史，不复制到当前工作树，不进入标准 Mod 包，也不参与当前 CLI 默认路径。
- 版本标签不可移动或覆盖；标准包只能从对应标签的源和生成器重建。

命令、验证、文档维护和 Git 流程统一见根目录 [CONTRIBUTING.md](../../../CONTRIBUTING.md)。
