## 当前状态读取顺序

接手任务时依次读取：

1. 工程基线-1.0.md；
2. mod重设计-实施计划.md；
3. 本轮相关的 M1–M5 结果页；
4. [当前工作清单](../当前工作清单.md)，需要历史编号细节时读取 [backlog](../backlog.md)；
5. 需要复核历史事实时再读 audits/ 和 reports/。

`收口清单.md`、`自动化范式.md` 和 `编码口径审计.md` 保留为历史执行参考；当前通用命令、跨平台入口和验证矩阵以 [CONTRIBUTING.md](../../../CONTRIBUTING.md) 与 [工程基线](工程基线-1.0.md) 为准。历史清单中的 PowerShell 命令只表示当时的现场记录，不是跨平台要求。2026-10-10 按用户决定删除根级变更说明及其 release 专用命令；历史报告中的旧命令保留为当时记录，旧文件内容可从 Git 历史恢复，当前入口不再依赖它们。

结果页追加新证据，不改写历史实验的原始结论。当前状态中的数字必须来自生成器、测试输出或有日期的实机记录，并写明口径。
