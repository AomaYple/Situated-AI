## 当前状态读取顺序

接手任务时依次读取：

1. 工程基线-1.0.md；
2. mod重设计-实施计划.md；
3. 本轮相关的 M1–M5 结果页；
4. [当前工作清单](../当前工作清单.md)，需要历史编号细节时读取 [backlog](../backlog.md)；
5. 需要复核历史事实时再读 audits/ 和 reports/。

当前通用命令、跨平台入口和验证矩阵以 [CONTRIBUTING.md](../../../CONTRIBUTING.md) 与 [工程基线](工程基线-1.0.md) 为准。[自动化范式](自动化范式.md)提供实测参考；历史报告中的旧命令只表示当时记录。

结果页追加新证据，不改写历史实验的原始结论。当前状态中的数字必须来自生成器、测试输出或有日期的实机记录，并写明口径。
