# exec · 阶段 3 结果：最小闭环「战败求存」

> 一页执行文档在 `阶段3-最小闭环.md`；原始数据清点与新判据在 `阶段3-归档清点.md`；
> 自动化跑局方式在 `自动化范式.md`。本文件只写**结论、证据与偏差**。

## 一、这一阶段在问什么

**H2（可证伪）**：一个真实发生的冲击（战败）能不能让**同一个国家**在**行为层**产生可测差分 ——
不只是策略卡换个名字。执行文档写死了：**只有策略层动 = 意图层是薄壳 = H2 不成立**。

## 二、跑了什么（4 组有效局）

| 局 | 设置 | 观测 | 读数 |
|---|---|---|---|
| A 基线 | 无冲击 | 40 个月 | 改革窗口**从未开**、法律全程 `law_serfdom`；合法性 16/16 月 >80 |
| B-1 | 冲击 -20（合法性） | 15 个月 | `SHOCK 100%`，窗口**未开**——压不到原判据 `≤50` |
| B-2 | 冲击 -35 / 贵族 -0.30 / 利率 +0.35 | 61 个月 | 仍**未开窗**；合法性只在 70–80 徘徊且**会自愈**（证明该档位够不到原版 50 线） |
| B-3 | 开窗判据改为 `legitimacy <= 75`（按 A/B 实测水位校准） | 24+ 个月 | **窗口连续开启**（`JE;active`）；策略牌由 `reactionary_agenda` 重抽到 `conservative_agenda`；**法律一条未换** |

## 三、结论：三层分明

1. **世界层：动了** —— A 级修正（变量 + 静态修正）确实改变真实世界状态，合法性被压下一档；
2. **策略层：动了** —— 温和节奏（≈2.6 年重抽）+ 压力使 AI 重抽，牌从反动议程转到保守议程；
3. **行为层（实质）：没动** —— 窗口开着、压力在场，农奴制依然一条未改。

**机制诊断**：原版"改革派"那张牌的权重取决于**它读到的输入**（工业家/知识界是否强势、
统治者意识形态），而本阶段的冲击只压了贵族与合法性，**没有把改革侧的输入抬起来** →
AI 重抽后落到"保守/兜底"，而不是改革路线。**瓶颈不在窗口，在"AI 的策略选择"这一环。**

## 五、偏差与口径提醒（如实记录）

1. **本阶段的冲击是"实验用直接修正"**（`add_modifier` 直接给三个数值），**不是正式版设计**。
   正式版应由**真实触发**（输掉战争 / 割地赔款）+ **因果链**（战时消耗→激进派→合法性自然下滑、
   赔款→真实财政动作）导出。已进 `backlog`（与"谁算战败"的挂载点合并考虑）。
2. **开窗判据 `≤75` 是按实测分位校准的实验值**；正式档案必须按**设定**重新论证，不能拿"能分开 A/B"当理由。
3. **观察者局没有玩家国家** → 探针的 `PLAYER` 行不出现，自检须改用 `ROLE;RUS` 是否每月在写。
4. 官方 harness 会把 `error.log` 的错误条数当失败判据，而本机那 85 条是**原版噪音** →
   判定只数"我们命名空间内的错误"。

## 六、下一轮（判据已预注册，见 `阶段3-归档清点.md` 第四节）

臂阶梯（`RUN;A` → `RUN;B` → `RUN;B2`：追加改革侧输入）已由 `ab_probe` **实现**，
但**尚未跑过一局**。两条限制分别记在下面，不要读成"已就位"：

1. **武装不到阶梯**：观察者局没有玩家国家 ⇒ 决议 `zzprobe_ab_apply` 点不了 ⇒
   `sitai_probe_ab_stage` 永不写入 ⇒ 阶梯一行不走。实机运行时证据（诊断行照常出、
   `RUN;` 行 0 条）与机制、以及**预注册的两种修法（均未实施、未验证）**见
   `exec/阶段3-实验记录.md` §二 / §三。
2. **编排层的端口是空的**：`ab_auto` 的 `start` / `stop` 端口在当前默认实现下是
   **显式留空**（设计口径是"接口没接上时当场报错、不静默跳过"，见 `README.md`），
   但**默认端口确实是空的**（`ab_auto.default_ports()` 把它们设成 `_unwired(...)`，
   而 `cli.py` 的 `ab-auto` 正是用 `default_ports()`）⇒ **即使解决了第 1 条，
   `v3 ab-auto` 现在也起不了游戏，端到端跑批尚不可用。**

点火层（`game_auto`）本身已实测可用，两局观察者局各有一份独立证据：

* 归档局 `ab-auto-observer`：**18 个月度块**（`ROLE;RUS` 每月在写）、`error.log` 干净；
* 收口期间的实机局（`victoria3` PID 5564，23:47:27 启动）：推进到 **1836.3.20**、
  落盘 6 条诊断行、**`RUN;` 行 0 条**，`error.log` 干净。

两处明细见 `exec/阶段3-实验记录.md` §2.2（归档统计）与 §2.3（实机原文）。

下一局按预注册四条判定：出现**法律转换** = H2 成立；窗口开但法律不变 =
阶段性命中"牌→立法"这一环；B2 与 B 无差别 = 先量 IG 势力实际值再决定，**不许盲调数字**。
