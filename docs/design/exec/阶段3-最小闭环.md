# exec · 阶段 3：最小闭环「战败求存」（一页执行文档）

> 依据：`01-大方向.md` §3「阶段 3」三行。**写完即执行**；本阶段不做三行之外的事。
> 前置（已具备）：阶段 2 证明权重推动落点、三槽价格与节奏已量化、节奏杠杆可用；
> 开局自检与日志快照已是命令（`v3 h1 --health` / `v3 h1-probe --watch`）。

## 假设（可证伪）

> **H2**：一个**真实发生的冲击**（战败）能让**同一个国家**在行为层产生可测差分 ——
> 不只是策略卡换个名字，而是立法推进 / IG 势力 / 财政这些看得见的东西变了。
> 若不成立，说明意图层是一条薄壳，项目天花板要重估（**届时改目标，不加代码**）。

## 设计：怎么做，以及为什么这么做

**主角**：俄罗斯单国（B2 已定）。**手段以 A 级为主**（F5：能改世界就不占槽）：

| 层 | 做什么 | 为什么 |
|---|---|---|
| 冲击 | 战败 → `sitai_` 变量记账（战败记忆、损失清单） | 真实世界状态，不依赖任何牌 |
| 压力 | 真实的贵族失势 / 合法性下降 / 财政恶化（修正 + 变量） | 让**原版自己的公式**转向改革（阶段 1 已证：牌直接读 `has_variable`/`has_journal_entry`） |
| 窗口 | 一个改革窗口 JE（判据驱动：只有压力够大才开） | JE 被 18 张牌读到，是把"处境"喂进原版的最短路径 |
| 节奏 | 覆盖 `NAI` 的 `CHANGE_STRATEGY_*`（温和档：门槛 ≈40 / 周概率 ≈30，**不是风暴档**） | 阶段 2 实测：自然节奏是十年尺度，喂输入推不动任何东西；档位由行为质量定（B26） |
| 递牌 | **只在 A 级表达不了时**才用；占用要报账 | F5 + 阶段 2 价格表（政治 S≈33 / 外交 S≈107 / 行政 S≈690） |

**产物 = 第一份生成物**（P3/F10）：数据源 → 生成器 → 脚本 + 本地化 + 文档，全程 Python。
目录：数据源 `mod/data/*.toml`、生成器 `tools/pdx/modgen.py`、产物 `mod/`（**镜像原版目录树**，
这是引擎硬要求；"平铺"指每个原版目录下只放 `sitai_*.txt`、不自建子目录）。

⚠️ **节奏杠杆的作用域是全局**：`NAI` 的 defines 覆盖没有单国写法，这两个键一改，**所有国家**的
AI 重抽节奏都变。这是有意的（目标本来就是让每个国家都能随世界重新推导），但意味着它**不能**
被用来解释单国差分 —— G2 的差分必须来自 A 级的世界状态变化，节奏只是让这套变化能被原版读到。

**并行轨同时落地**：`v3 modguard` 五道闸门（键/路径不相交、引用完整性、稀释预算、
往返净度、生成可复现 + `why` 非空）—— 它们必须在**第一份产物落地前**就能跑，否则闸门永远补不上。

## 判据（可复制执行）

1. `v3 modgen` 生成产物 → `v3 modguard` 五道闸门全过（不通过不许进游戏）；
2. **对照组**：固定开局（同一存档），**同一套指令序列**跑 A/B 两遍：
   * A = 只装对照组探针（冲击不施加）；
   * B = 施加战败冲击；
   两遍都跑 3–5 年，用 `v3 h1-probe --watch` 快照、开局 `v3 h1 --health` 自检；
3. **G2（差分可复现）**：B 相对 A 在**行为层**有差分，且**再跑一遍仍然出现**（两次同向）：
   * 主指标：立法推进条数 / 改革窗口是否开启；
   * 次指标：IG 势力位移、财政指标、外交落点（三槽分布）；
   * ⚠️ **行为层差分与策略卡差分分开报** —— 只有后者动 = G2 不成立（见失败长相）；
4. **分析命令**：`v3 ab --health`（开局自检：RUN 标记 / 玩家**不是**主角国家 / 观测在流动 / SHOCK 符合角色预期 / error.log 无我们的报错；任一红即退出码 1）→ `v3 ab --logs <归档目录>`（**先行为层、后策略层**分开报，并给 G2 判定）；
5. **G3（三行说得通）**：面板三行（当前目标 / 最大压力与阻力 / 上次改主意的原因）能让人复述"目标 + 主因"；
6. **和平期占槽率 ≈ 0**：不施加冲击的局里，我们的牌几乎不出现（F4/F8：看分布差，不看全中）。

## 失败长相（决定下一步，不是加代码）

| 现象 | 含义 | 处理 |
|---|---|---|
| 策略卡变了、行为层两次都没有差分 | 意图层是薄壳 | **停下重估目标**（H2 失败流程），不加代码、不扩档案 |
| **行为层动了、策略卡没动** | 这恰恰是 A 级手段**应该**有的长相：我们改的是世界状态，原版自己重算（不是薄壳） | 判为 **G2 初步成立**，仍需两次同向；分析器里对应 `g2_preliminary` |
| 行为层有差分但两次不同向 | 冲击不够强 / 判据太细 | 换更强的失败模式（割地 + 赔款 + 革命压力），或把判据从"条数"换成"方向" |
| 差分只在玩家国家出现 | 我们改的是玩家侧而非 AI 侧 | 检查挂载点：应挂 AI 读到的量，不是玩家专属系统 |
| 和平期占槽率不接近 0 | 牌在和平期也常被抽中 | 回退该档案（占用要报账）：加 `possible` 门，或改走 A 级 |
| 闸门③稀释预算超标 | 我们的牌吃掉了原版太多份额 | 降权重 / 收窄 `possible`，按阶段 2 的价格表反推 |
