# D02 行政与普通州并入的原版相位

设计基线为主线 `fd817c9d`。实装为 Windows Victoria 3 1.15.2、Steam 公开构建 `26763837`，安装校验后缀 `fb14`。实机见证沿用已冻结的法国观察档及 3.4.0 发布身份。本轮直接回读原档和当时挂载目录，处置范围是普通自有州开始并入后的推进与行政结算，以及已委托的行政楼自动扩建。普通州启动的本国择时仍为可独立研究的机会。 [D02 领域设计](../domains/D02.md) · [3.4.0 交付结果](3.4.0-交付结果.md)

以下 PowerShell 只读回查州进度、基础人口成本、国家官僚缓存和档案摘要。国家、玩家和州的编号分别以 `country_manager`、`player_manager`、`states` 的数据库记录核对。

```powershell
$evidence = Join-Path $env:USERPROFILE '.codex/evidence/situated-ai/3.4.0/fixed/sa-police-loop'
foreach ($arm in 'replay-vanilla', 'replay-full') {
    foreach ($date in '1836.3.1', '1836.4.1', '1836.5.1', '1837.4.1') {
        $save = Join-Path $evidence "$arm/checkpoints/$date.v3"
        Get-FileHash -LiteralPath $save -Algorithm SHA256
        rg -U --multiline-dotall -o '(?m)^states=\{.*?^516=\{\r?\n\K.*?^\}' --pcre2 $save |
            rg '^\t(country|previous_country|region|incorporation|base_pop_bureaucracy_cost)='
        rg -U -o '(?m)^\tspending_variables=\{\r?\n\t\tcountry=130\r?\n(?:\t\t[^\r\n]*\r?\n)*?\t\tbureaucracy_income=[^\r\n]+\r?\n\t\tbureaucracy_expenses=[^\r\n]+' $save
    }
}
```

## 反例与可执行的下一次判别

`simulation`。以当前净量 120、启动实际占用 40、制度候选耗用 90 和取消实际返还 40 输入，启动后净量为 80，制度候选剩余 −10，取消申请还未结算时仍为 −10，确认返还后为 30。在途错误地再扣 40 会得到 −50。容量为零与负数分开核对。相同全国净量的两个州，若一个本地税容量不足、另一个容量恰等于使用量，只有前者具备本地容量缺口。至少 0.8 占用率的已委托建筑可由全国官僚分支自主扩建，州税容量相等仍不会触发州税分支。工艺、用工与投入决定实际供给，不能从公共项目入队直接推算税收和官僚收益。 [D02 反例](../domains/D02.md#d02bureaucracy) · [D07 工艺](../domains/D07.md)

1. 复用原版 1836.3.1 档，在同一启动窗逐日定位 HYD 130 州 516 首次进入 0 与 1 之间的时点。逐次录下控制国、州主、在途状态、所有活动策略、有效候选和起步前的实际官僚分项。出现启动时，相邻停钟读点同时记录州进度、增减项、国家净量、同国制度目标、州税和可观察回调。没有捕获原生机会时，月档仍只支持推进见证。
2. 若可在该字段上用原创单字段诊断，先验证同触发器的加载、合成和撤回。对相同可负担的普通州比较默认正路径、诊断否决和撤回；检查其他活动策略仍为真时的 OR、首都绕过、特殊内容、在途、失权和国家控制权切换。逐场记录实际开始或等待，并以原版资格、竞争州与同日净量限制归因。
3. 用相同在途状态作继续／合法取消对照，在取消被接受后才回读净返还和进度。行政楼另以同国、同一公共预算窗的两个实际候选州，回读付款国、原版 AI 直接选择与委托归因，随后逐步验证完工、岗位、纸张供给、实际地方税容量和全国官僚。私人队列和容量够但税收浪费的州是对照。
