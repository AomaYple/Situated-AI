## 完整旧链与三消费者统一

无参数与显式 `--profile 1.15.1` 进入同一完整 `distribution.package_inputs/package` 生产路由。
`decisions.build` 先完成既有公共 IR、信息规则、财政和扩展模块、消费者适配器，随后由
`network_profile.compose` 将道路、学校、改善关系插入各自精确物理字段，最终候选再统一取得见证。
没有把两份完整包字典覆盖拼接的生产路径。同一字段由一个 writer 负责，组合器核对原版数值 AST、拒绝既有冲突 writer，
并以剥离新增策略后的逐字恢复证明原文与无关旧功能保留。历史 1.15.0 仍显式进入隔离 profile，不成为当前发布入口。

默认配置保留旧九领域与五扩展模块，经公共 `economy/politics/diplomacy` 映射控制，并接入 R2 三消费者。
保留范围包含既有公共语义与兼容桥；下述学校重权和供给激活扩展是明确登记的变化，不能将本次迁移描述为所有条件及数值不变。
共享 `country_state` 只提供读取和派生，不因共享事实重新启用被关闭消费者；全部关闭仍保留财政历史状态清理路径。

| 消费者 | 实际静态接线与原版保护 |
|---|---|
| 道路 `a0-econ-road` | 采用原版命名 `scope:country` 识别 actor。增量在初始 `value = 25` 后、原版尾部前插入；原版乘零仍消去增量，随后 journal 例外仍可恢复原版总分。插入限幅与尾部放大后的保守界分列，不把局部界当最终选择界。 |
| 学校 `a0-pol-schools` | 六条旧乘法 writer 精确退出，由下述单一 R2 加法评价替代；插入完整原版数值体尾部，保留原版费用、资格及其他策略定义。 |
| 改善关系 `a0-dip-relations` | 保留原生 target 方向；读取已经存在的 pact，不把候选意图当执行结果。增量在原版完整数值体尾部，原生 subject 倍率在其之前；资格、概率、成本和执行继续由原版控制。 |

三消费者分别保留独立、派生和交互路径、完整性组、效应协调与一次有界调整。各贡献含正确 actor 的 AI 条件，玩家不获得自有调整。
静态可降低与生产绑定分开登记；支持矩阵的 `production_eligible` 取真实绑定身份，不能因接口可降低便获得生产完成信用。
非默认策略未被本组合器重写；活跃策略对默认字段的实际覆盖或合成仍须运行时证据。

## 学校六项有意加法政策

精确退役的旧 writer 为 `remaining_school_catchup_need`、`remaining_school_fiscal`、
`remaining_school_administrative`、`remaining_school_capacity`、`school_default_pressure`、
`school_administrative_pressure`。六项不再与 R2 并存，不准通过同源改名恢复旧学校 writer。

新政策为低识字且人口有效的教育需求 **+2**、负行政点 **-2**、实际 default **-2**、需求与教育 agenda 的交互残差 **+1**、
需求且正行政点 **+0.25**、需求且非 default 且正净收入 **+0.5**，最后只限幅一次 **[-4, 4]**。
两种容量来自不同已观察约束，合计 **+0.75**，不另奖励 joint 项；原版实际费用没有再次扣除。
这是有意政策重权，旧乘法尺度没有被算术转换，也不声明输出数值等价。

识字率、人口、行政点、default 是完整性必需输入；缺任一项则该学校 writer 撤回。净收入为辅助输入，未知仅撤回 **+0.5**，
保留已知需求、行政容量和成本。正行政容量可与 default 的完整 **-2** 共存；财政容量在 default 下退出。
独立字面量 PDX 用例分别验证基础 **2**、行政容量 **2.25**、财政容量 **2.5**、两容量 **2.75**、含 agenda **3.75**、
双压力 **-2**、无需求 **0**、压力限幅 **-4** 和玩家 **0**；期望值不由生产 reference evaluator 反推。

主要见证为 [test_release_1151_integration.py](../../../tests/test_release_1151_integration.py)
中的 `test_school_additive_policy_has_literal_independent_pdx_witness` 及完整性、辅助事实、精确替代集合和原文恢复反例。
[test_migration_school_1151.py](../../../tests/test_migration_school_1151.py) 另覆盖错误版本、政策身份损坏、旧/改名 writer、
缺实际桥和原版尾部漂移的拒绝。支持矩阵按版本选择该新见证，不继续以历史 0.35 政策用例代签。

退役替代凭据见 [migration-retentions.json](../../../research/situated/1.15.1/migration-retentions.json)：
六项历史退役定义与六历史替代形成的 36 个精确身份，绑定当前学校 profile、政策 SHA、真实桥、完整 audit program、生成 SHA 与 strip 恢复。
行政与财政容量桥分别对应其实际贡献，没有把迁移名录存在当实现证据。

## 供给立场：三项 typed OR 与三十项追加

当前原版默认策略在旧 33 商品稀缺计划中已有 `oil`、`radios`、`telephones` 三项同名立场。
生产为这三项分别构造一个 typed `idempotent_or` writer，其余 30 项保持 `append`，每个商品只产生一个 `wants_high_supply` enum。
原生完整 trigger 作为 OR 第一分支保留原字节与 AST，第二分支保留旧 AI 稀缺条件：AI、market/good 存在、price **> 0.25**、delta **< 0**。
两个原因同时成立仍为同一 enum，不新增数值信用或重复分数。

原版注释把这些字段声明为生产与贸易规划偏好，且活跃策略可能覆盖默认值。
本次整合**有意扩展该局部立场的激活条件**；不能说原生 trigger 仍是合成偏好的必要条件，不能泛化成任意行动资格 OR。
建筑、贸易实际资格、资源、费用与执行由原生消费者保留，本次没有授予绕过这些规则的权限。
玩家、自有输入未知或关闭只撤自有稀缺分支；原生条件为真时仍保留原生立场，不因自有缺值把它抹去。

`NativeSupplyStance` 只准精确 1.15.1 原件和三商品 body SHA。
`_supply_patch` 在修改前核对整个 goods 父表 AST、恰好三项交集及原 body 字节，拒绝重复定义、未声明重叠、兄弟字段漂移和不完整 program 集合。
typed IR、compiler、render、reference、metadata 与 writer 台账一致区分 OR 和追加。
native 保护投影先独立核对两分支，恢复三个原始 native 节点并消去 30 个追加节点，再比较整个父表及 whole-source 上下文，未跳过 goods 表。

[test_supply_1151.py](../../../tests/test_supply_1151.py) 包含 native-only、scarcity-only、both、neither、玩家、关闭、缺 market/good、
未知读数、严格边界、原生技术/建筑替代、typed 身份、唯一 writer、恢复和漂移拒绝见证。
独立审查另以不调用产品 reference evaluator 或新测试解释器的 PDX AST 脚本，枚举覆盖三个商品的 96 组组合，均等于 `native OR guarded scarcity`；
实际计数 3 个 OR、30 个追加，解析零错误，2.45 秒退出 0。
合成 fixture 的通过仅证明隔离合同，真实完整生产证据另以下方构造及后续工程门验收。

## 配置覆盖台账的最终 P2 修复

最初完整 core-off 构造暴露保留字段缺少关闭处置；加入关闭台账后，独立审查又发现 partial 场景的 P2：
关闭 market 的同名字段可能掩盖仍应存在的 active security writer。
最终 `_configuration_writers` 从同一 canonical 声明同时推导 active 和 disabled 身份：真实信息规则、适配规则、33 个 typed supply program、
当前实际编译的 R2 消费者与共享 builtin 字段表。调用者不能提供任意关闭路径，六个旧学校 writer 不复活。
`coverage` 在无实际 owner 且仍有 active 声明时先失败，之后才允许配置关闭处置；有实际 owner 时继续记录 generated 与关闭贡献明细。

最终独立轻量复核分别验证 economy off/security on、diplomacy off/market on 缺 support owner 均拒绝；
提供实际 owner 的两个正例接受。core off 与 neutral 各保留全部 **61** 个默认策略顶层字段，均 retained、`behavior_verified=False`；
未知字段仍拒绝，默认 active 字段缺 owner 仍拒绝。
该台账为父字段级静态覆盖；每个子贡献的完整性仍由 writer 合同、生成与见证证明，不把父字段有 owner 当成全部子贡献正确。
反例来源见 [test_configuration_coverage_1151.py](../../../tests/test_configuration_coverage_1151.py)。
