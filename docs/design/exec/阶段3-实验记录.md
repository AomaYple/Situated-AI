## 二、结构性阻断：观察者局**武装不了**臂阶梯（机器证据）

1. `tools/pdx/ab_probe.py` 的 `decisions_text()` 把阶梯的**唯一开关**做成决议：
   `zzprobe_ab_apply` → `when_taken = { c:RUS ?= { zz_probe_ab_arm = yes } }`；

   **没被武装过就一行都不走**。`on_actions_text()` 也写死「开局不挂任何钩子」，
   且 `tools/tests/test_ab_probe.py:167` 用 `assert "on_game_started" not in code` 把它锁住。
2. `docs/design/exec/自动化范式.md` §4.4 与 `收口清单.md` §B.1 要求用**观察者模式**点火
   （点「观察」，**没有玩家国家**、所有国家都是 AI）—— 范式自己实测「观察者局里
   `ZZPROBE AB;PLAYER` 计数 = 0」。

## 三、预注册的两种修法（**A/B 都尚未实施、尚未验证**）

### 修法 A（推荐）：月度脉冲里**自武装**

在 `zz_probe_ab_monthly` 的 `c:RUS ?= this` 守卫内、`zz_probe_ab_ladder = yes` **之前**加：

```pdx
if = {
    limit = {
        NOT = { has_variable = sitai_probe_ab_stage }
        is_ai = yes
    }
    zz_probe_ab_arm = yes
}
```

* **为什么这样写**：观察者局里 RUS 是 AI → 第一根月度脉冲自武装；玩家开俄罗斯时
  `is_ai = yes` 为假 → 仍然只能手点决议（**保住原有路径**，不破坏既有人工流程）。
* **为什么不碰 `on_game_started`**：`test_ab_probe.py:167` 已把它锁死，而且开局钩子会把
  大厅/读档阶段也算进 A 臂。
* **`is_ai` 是原版合法触发器**：实测原版用法见
  `game\common\journal_entries\05_montenegro_je.txt:91`、
  `game\common\scripted_buttons\04_russia_buttons.txt:412` 等 5 处。
* **需要补的用例**：① 自武装块排在 `zz_probe_ab_ladder = yes` 之前；
  ② 自武装块带 `is_ai = yes` 守卫；③ 文件里仍然没有 `on_game_started`。
* **风险**：改了实验装置；A 臂的起算点从「玩家点决议那一刻」变成「第一根月度脉冲」，
  与历史局的 A 段口径**不再逐字可比**（历史局是玩家手点）。必须在新记录里写明。

### 修法 B：改用「随机国家」当玩家 + UI 点决议

范式 §4.3 量到「随机国家」按钮 ≈ `(650,1055)`。点它 → 玩家成为某个随机国家、
俄罗斯保持 AI → 再 UI 自动化开决议面板点 `zzprobe_ab_apply`。

* **代价**：要新增「随机国家」与「决议面板里的决议」两份模板 + 多步点击 + 面板态判定；
  范式 §4.6 已把「界面换皮/换语言 → 模板失效」列为已知失败模式。
* **额外污染**：玩家国家会对世界产生**玩家侧**影响（执行文档失败长相表里
  「差分只在玩家国家出现」正是要防的那一类）。
* **结论**：脆弱且引入新变量，**不作为首选**。

### 4.0 复算命令（**自包含，复制即用**，不依赖任何临时脚本或 `%TEMP%` 里的东西）

下面这段 PowerShell 只读日志、不写任何文件；把 `$d` 换成 §4.1 表里的任一归档名即可
逐类数出 `ZZPROBE AB;<类>;<值>;` 的行数：

```powershell
$u = "$env:USERPROFILE\Documents\Paradox Interactive\Victoria 3\v3probe-logs-archive"
$d = "ab-auto-observer"                     # ← 换成要复算的归档目录名
$logs = Get-ChildItem "$u\$d" -Filter *.log -File
# ① 每一类各多少行（ROLE / SHOCK / LEG / JE / LAW / POLI / ADMI / DIPL / INPUT / PLAYER）
$logs | Select-String -Pattern 'ZZPROBE AB;(\w+);' -AllMatches |
    ForEach-Object { $_.Matches } | ForEach-Object { $_.Groups[1].Value } |
    Group-Object | Sort-Object Name | Format-Table Name, Count -AutoSize
# ② 臂阶梯标记有几条（0 = 阶梯没被武装，见 §二）
($logs | Select-String -Pattern 'ZZPROBE AB;RUN;' -AllMatches).Matches.Count
# ③ 「值」的分布（例：JE 的 active / inactive；LEG 的 b55…b80）
$logs | Select-String -Pattern 'ZZPROBE AB;JE;(\w+);' -AllMatches |
    ForEach-Object { $_.Matches } | ForEach-Object { $_.Groups[1].Value } |
    Group-Object | Format-Table Name, Count -AutoSize
```

> 口径提醒：`Select-String` 会把**每个日志文件**都数一遍，而 `--watch` 快照与轮转副本
> 里含大量重复内容 —— 所以 §4.1 的行数是「按文件计的原始出现次数」，
> **不是**去重后的月度块数。要月度块数就用 §4.2 的 `v3 ab`（它内部按内容去重）。
