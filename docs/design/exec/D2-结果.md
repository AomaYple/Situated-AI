# D2：规则绑定与无旁路迁移

状态：`in_progress`。证据类别：`static_check`。本收据只记录本轮真实落地的局部实现和未关闭边界；不把文件存在、测试数量或静态通过解释为全阶段完成。

## 已落地

- `mod/decisions/action_bindings.toml` 被编译器和迁移台账共同读取；当前生产规则均有 source/definition/field/actor/target/operation/binding_id，其中历史基线 1,401 条另有独立身份校验。当前数量见[工作清单](../当前工作清单.md)，历史检查数字只对应各自运行。
- `ConsumerIRBundle` 对 writer、绑定、实例和规则进行逐项反查；缺绑定、重复 owner、字段或作用域漂移会硬失败。
- `tests/test_situated_bindings.py`、`tests/test_situated_inventory.py`、`tests/test_situated_legacy_lowering.py` 覆盖绑定身份和语义漂移拒错。

## 较早批次静态见证（2026-11-02）

新增 `tests/test_situated_migration_oracle.py`，逐项核对当前全部 1,414 条 legacy writer（其中包含历史 1,401 条基线）：

- 独立 oracle 直接读取 `RuleSet.rules`、typed reader 和 predicate，不复用 lowering、参考器或 PDX AST 求值器。
- 每条旧规则覆盖正例、合法反例、逐输入 unknown/invalid/NaN、玩家路径、输入边界和条件阈值候选点；在完整字段上下文复核同字段优先级和 known-false/unknown 短路。
- 原始 RuleSet 与 ConsumerIR lowering 的输出必须逐案等价；writer 语义变异必须被 `lower_legacy` 拒绝。

验证：`.venv\Scripts\python.exe -X utf8 -m pytest -n0 -p no:randomly tests/test_situated_migration_oracle.py`：`4 passed`，11.38 秒；Ruff 检查和格式检查通过。随后共享工作区的 `domain_actions.toml` 与合同解析器正在并发调整，重跑在 `load_model()` 报“联合链字段无效”（2 failed、2 passed）；最终候选须在相关生产修改收拢后重跑，不能沿用此前通过结果验收。

该见证仍属于 `static_check`：没有把 marker 数量、绑定存在或 Python 求值通过升级为 PDX 引擎实机等价。旧规则在生成 AST、原版消费者资格/成本/执行尾部和最终游戏包中的逐 writer 反事实仍未全部闭合，因此 D2 保持 `in_progress`。

## 未关闭

- 仍缺覆盖全部适用原版尾部、成本和逐目标原子单元的有效静态语义收据；已有逐规则见证不替代其余出口。长期游戏行为由用户验收，不是本阶段未关闭的理由。
- D0 范围及后续新增面的逐目标责任仍未全部闭合；最新计数见[D0 结果](D0-结果.md)，不能用旧批次数字描述当前范围。

本页机器收据是当前源码的未完成身份快照，仅更新输入和依赖哈希，不继承历史测试的通过结论；阶段与原子单元仍须各自验收。
