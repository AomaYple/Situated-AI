# 阶段 6 真人试玩包（一页纸）

> ## 本轮没有人类试玩者参与，**G3 未达成**。
>
> 这份包是**给下一次真人试玩**用的。项目里 G3 的判据原文是「**试玩者能复述『目标 + 主因』；反馈关键词是『世界活了』**」（`docs/design/01-大方向.md:149`）—— 这一格只有真玩过的人能填。本轮自动化能给的只是「三行文案确实在屏幕上、三行都在」，**能不能复述**是人的判据，所以我方**不宣布 G3 通过**。
>
> 这页纸**不是开发文档**：你不用懂 mod、不用看代码，照着走 + 填最后两张表就够。

## 一句话背景

你是**俄罗斯**，1836 年开局。这一局的目标不是打赢，而是**输掉一场仗**：战败会被记进账，之后国家会自己开始跟你算这笔账（贵族失势、王权威信破裂、借债变贵）。那扇「改革窗口」就是给我们（和 AI）看的——它写着**你该干什么、压力从哪来、上次为什么改主意**。

## 1. 开局：四步

1. **启动器**：打开 Victoria 3 启动器 → 选含 SITAI 的播放集 → 在 mod 列表里**只勾选**「**SITAI 处境档案 · 奥地利 · 革命潮…俄罗斯 · 战败求存…**」这一项；把「**SITAI t5 临时剧本探针（TUR→RUS 一场博弈）**」**取消勾选**（那是本轮的仪器件，不是给玩家玩的）→ 点「开始游戏」。
   （依据：本机昨晚那次启动的日志 `…\Victoria 3\logs\debug.log:416`/`:417` 显示这两件当时都在挂载列表里，且都匹配 1.14.5。取消勾选后只剩档案本体。）
2. **新游戏 → 选俄罗斯**。必须是俄罗斯：这套档案目前只有它接了战败线（其它国家不会开这扇窗）。
3. **在开局那一屏的游戏规则里找「处境难度」**（规则组 `sitai_difficulty`）。三档循环，点那一行右侧的箭头翻档（本轮实测箭头 ≈ **(905,752)**，点一次换一档）：

   | 档 | 界面上的名字与说明 | 它做什么（以界面上写的为准） |
   |----|--------------------|------------------------------|
   | 默认 | 一视同仁 /「默认档：处境对谁都按世界状态如实生效，既不帮忙也不额外加罚。」 | **第一次试玩就用这一档** |
   | 轻 | 史实友好 /「玩家肩上的那一份轻一些：合法性恢复更快、旧势力的钳制比纯世界状态稍松。」 | 只对你减震（合法性 +10、地主政治力量 +15%） |
   | 重 | 无情 /「玩家肩上的那一份更重：合法性打击更深、旧势力更不肯松手。」 | 只对你加罚（合法性 −20、地主政治力量 +25%） |

   **顺手帮我们看一眼**：三个名字与说明是不是都出现了、是不是互斥（一次只有一个被选中）。
4. **玩到「输一场仗」**（见下一节）。建议留 15 分钟给启动与建局；看到窗之后这局就可以停了。

## 2. 怎么在 1 小时内看到那扇窗

开窗的硬条件（来自条目本体 `mod/common/journal_entries/sitai_ru_defeat_window.txt:22-34`）：

- ① **先真输一次**：俄罗斯投降、或被迫接受对方的战争目标 ⇒ 这笔败仗才被记进账；
- ② **合法性跌到 75 或以下** ⇒ 窗口显示在「日志条目」（活跃）页；合法性回到 75 以上，它退到「潜在」页（**不是消失**）。

> ⚠ **单把合法性压低不会开窗**：没输过仗就没有那笔账，条目根本不出现。这是设计，不是 bug。（上一轮实测：战败冲击本身把合法性从 100 打到 74、之后 73 —— 见 `docs/reports/D33-压力可见面诊断.md:68-70`；所以通常刚输完就会开窗。）

两条最快的路（本轮**没有**在全新开局里走过这两条，哪条都行，**记录你实际走的那条**）：

- **A（推荐）**：随便找一场仗打起来 → 不用认真打 → 战争面板点「**投降**」→ 引擎确认框选「**是**」。
  上一轮那次是在**另一套开局**（带临时剧本探针）里走通的、走的正是「战争面板 → 投降 → 确认框『是』」；全新开局里这个按钮是否同样立刻可点，我们没有验过。
- **B**：让战争打一阵，等敌方战争分数占优，再从战争面板「议和」里接受对方的条件。
- 如果「投降」是灰的：换 B，或者多打几个月再试。

**看到窗就按空格暂停**，然后按第 3 节逐项看、第 4 节回答三个问题。

## 3. 看到了什么（照着点）

### 3.1 三行（这是核心）

1. 左侧竖排图标列里那枚「**红皮书 + 数字徽章**」按钮 —— 本轮实测中心 ≈ **(30,706)**（另一种量法 ≈ (25,706)，是同一枚按钮）→ 打开「日志」面板。
2. 页签切到「**日志条目**」。三个页签（日志条目 / 潜在 / 成立国家）是**同一枚按钮循环切换**的：如果打开的不是「日志条目」，就再点一下那枚按钮。
3. 分组「**国内事务**」→ 条目「**战败求存：改革窗口**」→ 点开。标题下面应写着「国内事务日志条目」。
4. 正文里应能看到**三行**（逐字比对）：

   - `当前目标：趁窗口开着，把旧势力一直拦着的那项改革推过去。`
   - `最大压力与阻力：压力 = 贵族失势 + 王权威信破裂 + 借债成本高昂；阻力 = 等国家重新自己站稳。`
   - `上次改主意的原因：因为战败被记进了账 —— 是这场败仗挪动了 AI 读到的那些输入。`

5. 「**完成条件**」那一格应显示 `❌ 俄罗斯政府的合法性大于或等于 75`。
6. 「**如果完成**」那一格应写「国家重新站稳，改革窗口关闭：俄罗斯将回到弘扬传统价值战略。」**如果这里冒出 `BUG: set_strategy …` 之类的英文报错，请务必记下来**——那是回归。
7. 右侧那个小「**日志条目**」列表里**不会有我们的条目**（它只列原版条目）——别在那儿找，用左边那枚按钮。

### 3.2 压力真的挂上了吗

打开**国家详情**（点顶栏你自己的国旗）→ 页签「**修正**」（本轮同一条路径的取证帧：`tools/out/t5-frames/t33-20-tab-panel.png`）。应该能看到：

- `战败余波` —— **只应有一行**；如果看到两行，请记下来（那是回归）；
- `战败余波：被迫投降（合法性 -15，地主政治力量 -15%，借债利息 +15%）`；
- 若你选了非默认档，还应多一条 `史实友好（你这一份）` 或 `无情（你这一份）`。

> ⚠ 屏幕底部那个小「修正」框**只显示前 2 行、而且不能滚动**——别在那儿判断有没有。

### 3.3 世界有没有「活了」

这条最难，凭感觉写，但要写理由。开窗之后的十几个游戏月里留意：

- 改革 / 立法推起来是更顺了还是更卡；
- 别的列强对你的态度、结盟偏向有没有变化；
- 有没有人趁你虚弱来要东西，或者对你的宣战更克制 / 更大胆。

我们要的不是「更难 / 更随机」，而是「**像有个东西在动**」。

## 4. G3 三问（请用你自己的话回答，不要抄上面的句子）

| # | 问题 | 你的逐字回答 |
|---|------|--------------|
| 1 | 这个处境在**让你干什么**？（目标是什么） | |
| 2 | 最主要的**压力来自哪里**？（哪几条在变差——这是判据要的「主因」） | |
| 3 | **哪里被卡住**？（有没有哪一步你看不懂、找不到、点不动） | |
| 4 | 你觉得**世界是不是「活了」**？ | |

- 卡面上写的是三问「你要做什么 / 哪里被卡住 / 世界有没有活起来」= 这里第 **1、3、4** 行；第 **2** 行是 G3 判据要求的「主因」，所以多问一句。
- 第 4 问的「**世界活了**」= 你感觉**世界里别的东西**因为这场败仗改变了做法，而不是你这边单纯吃了惩罚；请补一句「为什么这么觉得」。
- 最后一行很关键：**上面几答里，哪一句是你自己看出来的、哪一句是上面提示你的**。
