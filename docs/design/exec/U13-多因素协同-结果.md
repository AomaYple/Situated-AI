# U13 多因素协同与 1.2.0 交付结果

> 日期：2026-10-26。版本：`Situated AI 1.2.0`。本收据记录生产源、生成物、原版接口合同、标准包和静态工程证据；不把规则命中、脚本加载或静态检查写成长期 AI 行为、平衡或玩家体验通过。

## 本阶段目标

U13 将多因素处境协同真正落到唯一生产源 `mod/decisions/information.toml`。规则同时考虑战争或和平、违约、债务、净结余、行政能力、人口、识字率、海军规模和国家路线，再通过原版 AI 消费者提供有界倾向调整。原版资格、成本、谈判、随机性、拒绝和行动执行继续由游戏负责。

## 生产改动

- 新增 `literacy_rate` 国家级 reader，范围为 0–1；未知、缺失或底本不匹配时回退原版。
- 新增七条多因素规则：产业建设容量、战争常备军容量、战争海军容量、教育追赶容量、贸易合作容量、经济外交容量和殖民投射容量。
- 产业、教育、贸易和经济外交规则要求财政与行政能力可用；战争规则要求未违约且有正净结余；殖民规则额外要求和平、扩张路线、海军规模和正收入。
- 每个原版字段仍采用唯一作者和优先级仲裁；规则不创建资格、资源、建筑、军队、舰船、条约或殖民机构。
- 已重新生成 60 个生产文件；`mod/common/`、本地化、metadata 和锁文件均由 Python 生成器维护。

## 证据和验收边界

- `static_check`：源、生成器、底本字段、作用域、唯一作者、编码和包边界。
- `snapshot`：锁定 Victoria 3 `1.14.5` 原版、生成锁、manifest 和包内容。
- `simulation`：Python 规则参考实现与生成脚本的合成场景对照；不等于引擎运行。
- `runtime`：只有用户提供的游戏日志或存档观察结果才可记录；本阶段没有新增运行期行为证据。
- 用户仍需在固定 `1.2.0` 包上验收游戏加载、长期行为、数值、存档重载、后期性能、语言呈现和 Workshop 体验。
