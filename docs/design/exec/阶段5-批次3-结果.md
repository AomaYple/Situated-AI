### 1.1 西班牙：把「内战的代价」与「帝国残骸的后果」分成两笔账

这是本档案的**判据核心**，四条压力不是同一件事的四种说法：

| 字段 | 档位 | 它是哪一笔账 |
|---|---|---|
| `country_legitimacy_base_add` | `-35` | **内战的代价** —— 王位被两头撕（伊莎贝尔 / 卡洛斯） |
| `interest_group_ig_devout_pol_str_mult` | `-0.30` | **内战逼出来的那一刀** —— 为筹战费变卖教产 ⇒ 一直拦着改革的那一侧被削掉（**窗口之所以开**） |
| `interest_group_ig_armed_forces_pol_str_mult` | `+0.25` | **内战让军队坐大** —— 两派都必须倚靠它（**窗口里的阻力**） |
| `country_loan_interest_rate_add` | `+0.35` | **帝国残骸的后果** —— 美洲的帝国 1836 之前就没了，本土没有帝国收入可支应内战，只能借贵钱 |

`01a` §K 给西班牙那一行写的是「**帝国残骸、卡洛斯战争、教会与军队势力强**」（`../01a-依据与参考.md:279`）——
只压教会不写军队等于少写一半；而「帝国没了」与「内战」如果混成一笔账，读出来的差分说不清是哪一层起的。

### 1.2 巴伐利亚：原版把这件事**记在别人的账上**，本档案补的是被选那一方的账

三条实测（原版行号逐条打开确认过，不在此重复，见数据源 `why`）：

* **巴伐利亚 1836 已经在普鲁士的关税同盟里** —— `member = c:BAV # 1834`（`common/history/power_blocs/00_power_blocs.txt:70`）；
* **两家同时来拉、出的价一样** —— 奥地利 → 巴伐利亚 `+30`（`common/history/diplomacy/00_relations.txt:9`）、普鲁士 → `+30`（同文件 `:215`）；
* **它自己只写下一条关系** —— 对符腾堡 `+50`（同文件 `:21`，「第三种德国」那条线）。

原版替**集团**（Zollverein 的成员表）与**两强**（德意志统一那一族 JE）记了账，**没替被选的那一方记账**：
朝廷照旧、地主照旧在朝（`common/history/countries/bav - bavaria.txt:15-17`）、外交影响力照旧。
本档案补的就是这一格 —— 但只补上了**代价**那一半（§二·补）。

## 二·补、巴伐利亚的抽象缺口：**「倒向谁」写不进去**（本批最重要的一条）

**「倒向谁」在原版里是真实存在的，不是我们要发明的东西**（本机逐条打开确认）：
有集团（`ZOLLVEREIN`，`00_power_blocs.txt:52-70`）、有两家同时来拉（`00_relations.txt:9` / `:215`）、
有外交博弈（`dp_unify_germany`，`common/on_actions/00_code_on_actions.txt:2484`）、
有「你站哪边」的触发器（`is_supporting_unification_candidate`，同文件 `:2487`）、
有钩子（`on_start_supporting_unification`，同文件 `:7438`）、有 JE 族（`common/journal_entries/00_german_unification.txt:111` 起）。

**而 schema v1 一样也写不了、读不了、挂不上、递不出去** —— 四条各自的机制原因：

| # | 断在哪 | 具体 |
|---|---|---|
| 1 | **写不了** | `[pressure].effects` 渲出来的是**静态修正的数值字段**（`tools/pdx/modgen.py:1209`）；而「与谁的关系」要 `set_relations`、「在谁的集团里」要 power bloc 的 `member =`、「支持谁」要 `is_supporting_unification_candidate` —— **没有一个是修正字段** |
| 2 | **读不了** | JE 判据只支持平铺一行 `key op 操作数`（`tools/pdx/modgen.py:185-186` 的 `Clause.render`），而原版读「你站哪边」**一律**带块或作用域操作数（`= { who = … }`，`00_code_on_actions.txt:2487`；`is_in_customs_union_with = scope:target_country`，`common/ai_strategies/02_diplomatic_strategies.txt:1182`） |
| 3 | **钩子挂不上** | schema 里**没有 on_action 这一格**（产物清单里根本没有 `common/on_actions/` 这一项 —— 冲击效果一律由实验显式调用），而原版给「选边」留的钩子恰恰是 `on_start_supporting_unification`（`:7438`） |
| 4 | **意图递不出去** | 原版的「统一德意志」意图挂在**外交槽**（`ai_strategy_unify_germany`，`type = diplomatic`，`02_diplomatic_strategies.txt:1631`），而 schema 的递牌白名单只有**四张政治议程牌**（`tools/pdx/modgen.py:679-686` 的 `SET_STRATEGY_WHITELIST`） |

**于是本档案记的不是「选了哪一边」，是「选边的代价」**：外交影响力不再是自己说了算
（`country_influence_mult` —— 前六份一份都没用过）、王权为这个选择花掉威信、靠关税保护吃饭的那一派失势。
要真表达「选了哪一边」，需要的是**分支处境**（两条互斥 JE，或一个带取值的变量 + 条件分支）——
现在的唯一办法是把一个处境拆成两份档案，那**属于改抽象**（`阶段5-档案扩张.md:41`），不属于加特例。

**一处必须写清的让步**（不是结论）：原版确有**平铺**的关税同盟触发器
`is_junior_in_customs_union = yes`（`common/treaty_articles/25_trade_privilege.txt:52`），
它在形状上正好能当「我在别人的关税同盟里当小弟」这扇门。**不用它的理由不是「原版没这个词」，是实测教训**：
`ru_defeat` 曾经把判据挂在一个没实测过的门槛（50）上，那一局（`ab-run3-done`）窗口一次都没开、
法律全程没动 —— 一个没跑过 A/B 的新判据会把窗口**静默关死**（JE 就是不出现，没有任何报错）。
所以本档案的门只开在沿用过的合法性 `75` 上，关税同盟那条**留给下一次带 A/B 的校准**。

## 七、勘误：本批那两条「现场断言」当时**改错了**（2026-09-23 当天发现并修正）

本批落地时把 `mod.total` 由 23 改成 **24**、`mod.files` 由 4,777 改成 **4,828**，
并在提交信息与 `阶段5-批次3-收尾交接.md` 里写成「**用户新订阅了一份 Workshop mod**」。
**这个判断是错的**：第 24 个是**我们自己**（跑 A/B 时部署进用户 mod 目录的那份真 mod），
`pdx.mods.discover_mods()` 当时只排除 `zz_probe_` 前缀，于是把它数成了一个订阅项。

把两件事分开看才对：

| 变化 | 是什么 | 归谁 |
|---|---|---|
| +1 个 mod / +51 个文件 | 我们自己部署的 mod 被数了进来 | **我们的工具**（错） |
| `2880069248`（牛奶汉化）+19 文件 / +19 个本地化条目 | 那份 Workshop mod 自己更新过 | 用户侧（真变化） |

所以「4,828 → 23 个 mod 的真值」**不能只做减法**：真值是 **4,796 个内容文件**（不是 4,777）。
修正后 `v3 verify` **234 / 234**、doc 12 的分布数逐条重测（去重路径 4,769、`localization` 条目 1,475 …），
根因与结构性修法见 `../backlog.md` **B83** 与 `收口清单.md` 那一段。
