# A3 结果：质量观测补齐

> 更新：2026-10-15。正在实施，尚未完成质量出口；G1/M3 保持未通过。

## 已实现与边界

自然响应分析复用原有唯一绑定、完整两国矩阵和连续日序号门禁，增加 `role_timing`：记录观测到的加入/失去支持者角色区间，以及相对首次连续可支持样本的区间。已在开窗前加入、末尾仍支持和无记录分别保留截断/未知。角色丢失不是主动退出，END 不补一行退出，日内变化可能漏测；不能把采样区间当精确日历或引擎真实响应时延。历史日期日志仍按旧接口解析。

预算校准默认关闭，`decision_behavior.py --cost-calibration` 仅允许 instrument/control、fiscal-injection none、受控机会；不进入自然、市场或正式包。复用机会事件的确切 scope 与共享 sample-N，在显式国家上下文读取 `GetIDString`、原版承诺触发器 `is_diplomatic_play_committed_participant`、已在独立财政仪器中验证过的 `GetPrincipal`、`GetMaxCredit`、`GetGoldReserves` 和 `GetWeeksUntilBankruptcy`。曾触发原版 `GameStateAccess` 断言的 `GetMilitaryGoodsExpenses` 与 `GetMilitaryShipMaintenanceExpenses` 已从默认路径移除；独立模式不加载额外财政观察器或无关政治 getter。

本金/储备是货币存量，信用是可用额度，破产周数是引擎显示值，保留三位小数。每个字段的作用域、采样精度、未知值、哨兵值和不可归因边界同时写入 `cost_probe.configuration().fields`；国家总量和全局承诺状态不能归因单场外交行动。解析器检查身份稳定与两国不同、同样本完整矩阵、连续序号、有限数值、零与未知，仍输出 `action_cost=null`、`adverse_outcome=null`、`quality_improvement_proven=false`。没有同 tick 独立预算真值时 `engine_interface_validated=false`，不将数值可解析升级为数值真值校准。

## 有界预算 getter 实机事前登记

只检验显式国家作用域的安全读取和协议完整性。计划 `v01-a3-cost-calibration-20261015`，场景 `country-budget-readonly`，control/instrument、pair 1；最多一组，目标一游戏月，墙钟 900 秒，启动额外推进按实际日期另报，总窗口超过 90 游戏日只保留越界结果。无财政注入、无策略偏置、无强制支持者；受控 AUS→SAR 机会仅提供已保存作用域，不提供自然资格或行为质量。

输入为 1836.2.1 英文观察者原件，SHA-256 `379df80b8846bcf375ab38b7ee6ede1a3225bea448ae0469d0687a35396d2466`，本机 Victoria 3 1.14.5。该输入仅有仪器资格，来源/正式机会未完整证明。观察 RUS/PRU，源与生成器指纹由运行器冻结；已审查维修图标诊断挂载仅用于排除已知缺引用，保留严格十类错误、未分类错误、完整挂载和恢复门禁，不给正式资格。getter 错误或断言即否证当前读法，不重复失败窗口或白名单放行。

运行前先通过生成、用途拒绝、矩阵缺项/重复/乱序/跨国、非有限/未展开读数及历史兼容回归。实际正负值、零值、承诺两侧和独立真值分别记录，不从预期补造缺项。

## 首次实机结果：严格错误门禁否证当前预算读法

首次登记运行的报告为 `tools/out/decisions/behavior/control/input-none/20261014-165041/report.json`，场景 `country-budget-readonly`、control/instrument、无注入、观察 RUS/PRU，实际读取到 43 个完整两国样本；费用、维护、本金和储备均能返回有限数值，国家 ID 在窗口内稳定，矩阵解析通过。但 `error.log` 出现一次原版 `Assertion failed: NGameState::GameStateAccess...`，实时错误门禁因此停止并将本局判为失败；没有白名单放行，也不把已解析数值当作引擎接口校准。流水线、恢复、日志和挂载证据保留在该报告目录，失败场景的同一冻结输入不重跑；若继续研究，必须登记不同的受支持作用域或字段拆分。

该结果确认当前实现能发现并拒绝错误读法：`cost_probe` 报告保持 `engine_interface_validated=false`，`action_cost=null`、`adverse_outcome=null` 和 `quality_improvement_proven=false`。后续安全路线已收窄为独立财政仪器中成功过的四个 getter；军事费用 getter 的断言事实保留为否证，不再重复运行同一读法。不得用这次阴性运行解锁 G1/M3 或补造行动代价。

## 2026-10-15 安全 getter 独立复核

修正后的校准只读取四个已有成功证据的国家 getter，并以新的计划和场景登记，避免把字段改动伪装成同一实验的重复运行。命令为：

```text
.venv\Scripts\python.exe -X utf8 tools/probe/decision_behavior.py --save tools/out/checkpoints/sitai_clean_observer_english_candidate_20261011.v3 --arm control --months 1 --timeout 900 --language l_english --experiment-plan v01-a3-safe-fiscal-20261015 --experiment-scene country-fiscal-safe-readonly --purpose instrument --cost-calibration --fiscal-injection none --resource-baseline --initiator AUS --target SAR --observers RUS PRU --pair-index 1
```

报告：`tools/out/decisions/behavior/control/input-none/20261014-174707/report.json`。固定输入仍为 Victoria 3 1.14.5、1836.2.1、英文观察者存档，源 SHA-256 为 `379df80b8846bcf375ab38b7ee6ede1a3225bea448ae0469d0687a35396d2466`；新的场景只改变探针字段集合，未改变生产开关或正式候选。

结果为 `ok=true`，窗口从 `1836.2.10` 到 `1836.4.6.12`，推进 56.88 游戏日。RUS/PRU 各 43 个完整样本，国家 ID 始终为 `3/5`；`GetPrincipal`、`GetMaxCredit`、`GetGoldReserves`、`GetWeeksUntilBankruptcy` 均返回可解析有限值（超大破产周数按原始引擎读数保留，不能解释为精确倒计时）。严格十类错误、未分类错误、Mod 错误、缺失/额外挂载、观察器警告和清理错误均为零，恢复流程完成。

这条结果证明四个 getter 在该受控作用域可安全读取并满足矩阵、身份和序号门禁；它没有证明读数的物理单位、单次外交行动净代价、放弃收益、不利结果或 AI 行为质量。因此 `engine_interface_validated` 仍保持 `false`，`action_cost`、`adverse_outcome` 和 `quality_improvement_proven` 继续为 `null/null/false`。A3 关闭了“安全 getter 读法”缺口，但质量出口仍未完成，A4/G1 不得开启。

## 正式资格与比较器同步

`src/pdx/m3a_screen.py` 现在保留每份原始报告的 `quality_observations` 与 `role_timing`，校验状态、有限数值和布尔字段，并在配对结果中分别输出 `structural_qualified` 与 `quality_ready`。结构性资格仍只表示输入、窗口和机会字段满足配对契约；`quality_ready` 只有在质量状态为 `complete`、两类时延/结果字段具备预注册事实且质量改善明确证明时才可能为真。当前报告仍是 `unsupported/null/false`，因此该同步关闭的是比较器丢字段和误晋级缺口，不是 G1/M3 或 V0.1 产品出口。

## 尚未完成

加入/主动退出的真实时延、单次行动净代价、放弃收益和不利结果仍没有完整受支持证据。角色采样与预算原始量只补观测基础；正式资格/比较器同步已经完成，但质量字段仍需受支持接口、离线反例和实机零错误证据。不能据此打开 G1、记入 M3 合格配对或完成 V0.1。
