# T12 Mod 改动后的全量结构与内容复核结果（历史 1.2.0 基线）

> 日期：2026-10-27。证据类型：全量静态复核。
> 本页只记录上一轮 1.2.0 工作树上的复核过程和工程边界，不证明游戏行为质量、平衡或长期性能。当前候选复核见[1.3.0 阶段收口](阶段收口-1.3.0-结果.md)。

## 复核对象

复核覆盖整个 Mod，而不是只看本轮变更：

- `mod/decisions/*.toml` 生产源；
- 生成的 `common/`、11 种本地化、metadata、封面和生成锁；
- 原版字段、作用域、actor/target 方向、字段唯一作者、优先级、数值范围和未知回退；
- 生成入口、包 manifest、ZIP 路径、编码、换行和发布文案；
- 与生产源相关的 Python、测试、规则和当前入口文档。

## 复核结论口径

- 静态门禁通过只证明源、字段、生成、编码、包结构、文档链接和工程检查契约成立；
- 日志、存档、快照、观察器和长期游戏运行不作为本次门禁，用户可在固定包上自行验收；
- 任何未来修改都必须重新运行受影响静态门禁，并在发布前重新生成和校验标准包；
- 未发现可依据静态证据直接宣称 AI 行为质量、历史合理性或游戏内性能通过的依据。
