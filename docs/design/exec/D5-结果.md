# D5：事实、分档收益、成本与未知语义

状态：`in_progress`。证据类别：`static_check`。本收据只记录本轮真实落地的局部实现和未关闭边界；不把文件存在、测试数量或静态通过解释为全阶段完成。

## 已落地

- 核心/辅助证据已进入仲裁合同：核心证据为 `False` 或 `None` 时候选不替换原版；辅助证据为 `None` 时只保留基础档，并返回 `lower_tier`。
- 过期事实不再作为当前已知输入；派生状态保留 stale provenance 并传播 unknown。机会和承诺拒绝 NaN/Inf，事实 schema 拒绝布尔数值边界和比例错单位。
- 统一 IR、参考求值、独立 PDX AST 和限幅路径已由现有 lowering/semantic tests 联合检查；本轮新增 60 个聚焦测试通过。

## 未关闭

- 仍需为每个真实消费者补齐手写阈值、成本反事实和 PDX/参考/预期三方等价，不能以显式卡或规则数量代替逐目标验收。当前规则和 writer 数量见[工作清单](../当前工作清单.md)。
- D6-D12 的全域行为见证、性能资源门和失败注入尚未完成。

## 2026-11-01 本轮增量

- `industrial_foundation` 移除了 `bureaucracy_positive/strong_legitimacy` 的全局 `requires_any` 资格门；这些事实仍通过行政赤字、财政余额和合法性成本谓词影响增量。和平与未违约仍是原版消费者安全边界，战争/违约仍按退出条件回退原版。
- `education_and_research` 保留低识字率这一自身机会条件，但移除了行政/合法性 `requires_any` 门，避免教育、产业和行政被错误合并成一个全局 AND 门。
- `reform_conservative_guard` 的退出条件改为由 `default`/`insurrection` 的实际替代和原版重新求值决定，不再使用会把“违约但无叛乱”误删的 `no_insurrection` 退出门。
- 新增聚焦见证：经济卡无政治/行政全局门、保守窗口在单独违约压力下可达；相关 `tests/test_situated_depth_semantics.py` 用例通过。该改动仍只证明静态参考器与独立 PDX 求值器一致，不证明游戏内平衡。

## 本轮语义迁移

成本与互补语义落地后，5 个旧的固定数值夹具按独立手写预期更新：

| 场景 | 旧预期 | 当前预期 | 原因 |
|---|---:|---:|---|
| 渐进改革稳定档 | 5.0 | 4.0 | 承诺成本先于排序并降低幅度 |
| 外交主动窗口 | 8.0 | 6.75 | 政治压力成本降低正向幅度 |
| 教育经济局部路径 | 2.0 | 0.9 | 基础档和成本尺度重新校准 |
| 教育路径辅助未知 | 2.0 | 0.65 | 互补关系为 0.25 且未知不虚升 |
| 教育嵌套限幅 | 3.0 | 0.9 | 单次限幅不再放大成本后的基值 |

历史 SC 场景中受相同成本/互补尺度影响的 17 条手写 delta 也同步迁移，保持
`cases.json` 仍是独立输入预期而不是由选择器运行时生成。迁移后的值只反映
固定事实下的静态候选增量；它们不代表游戏内平衡结论。

这些数值只证明固定输入下的参考器/独立 PDX 见证，不代表游戏内平衡或 D5 阶段关闭。

本页机器收据是当前源码的未完成身份快照，仅更新输入和依赖哈希，不继承历史测试的通过结论；阶段与原子单元仍须各自验收。
