## 2. 机制判断：**不是** ①「AND 恒假」，而是 ② 的实机形态 ——「钩子从未挂上」

**判别依据（卡里要的那条）**：**三类全 0**（不是「其它两类有行、只有革命潮 0」）⇒ 指向的是**整块没生效**，
而不是革命潮那一段的触发器永假。引擎自己在 `error.log` 里给了两条**指名道姓**的报错（逐字）：

```
[03:10:53][jomini_effect.cpp:542]: Unknown effect c:GBR at common/scripted_effects/zz_stress_effects.txt:121
                                       （…FRA :122 / RUS :123 / AUS :124 / PRU :125 / CHI :126 / TUR :127 / USA :128，共 8 行）
[03:11:04][pdx_persistent_reader.cpp:268]: Error: "Unexpected token: zz_stress_tick, near line: 6"
                                       in file: "common/on_actions/zz_stress_on_actions.txt" near line: 6
```

* **第 2 条是主因**：生成的 `on_monthly_pulse_country` 块里**直接写了脚本效果调用**：
  ```txt
  on_monthly_pulse_country = {        # ← 生成的形态
      zz_stress_tick = yes
  }
  ```
  引擎在**加载期**把它当**非法 token** 拒掉 ⇒ 这条 on_action 从来没挂上 ⇒ `zz_stress_tick` 从未被调用 ⇒
  **三类全 0**（与实测一致）。官方配方是「原版 on_action 里挂**名字**」+「同一份文件里定义那个 on_action」：
  ```txt
  on_monthly_pulse_country = { on_actions = { <我的 on_action 名> } }
  <我的 on_action 名> = { effect = { … } }
  ```
  **本仓的 AB 探针就是这个配方**（`tools/probe/zz_probe_ab/common/on_actions/zz_probe_ab_on_actions.txt:10-11`
  = `on_monthly_pulse_country = { on_actions = { zz_probe_ab_monthly } }`，`:15-16` = `zz_probe_ab_monthly = { effect = { … } }`），
  而它实测能跑（`阶段3-实验记录.md:118` 一族有 67 条自报）⇒ **同一台机器、同一种 mod，能用的形态与不能用的形态差在这里**。
* **第 1 条是第二个独立缺陷（即使修好钩子也会咬）**：`effects_text()` 的革命潮那一段（部署文件 `:121-133`）长这样 ——
  `if = { c:GBR ?= this c:FRA ?= this … c:USA ?= this  if = { limit = { … } … } }`，
  **第一个 `if` 少了 `limit = {`**，于是 8 个裸 `c:TAG ?= this` 被引擎当**效果**解析 ⇒ 8 条 `Unknown effect`。
  ⇒ 修钩子之后，**这一段的四波仍然一行都不会有**（要写成 `limit = { OR = { … } }` 或与另两类同型的逐国 `if`）。
  ⚠️ **行号不可直接当证据**：引擎对 `scripted_effects` 报的是 `:121-128`，部署文件里对应的是 `:126-133`（**Δ=+5**）；
  `backlog` B84 已记 Δ6/Δ8/Δ5 三例 ⇒ **偏移不恒定**，引用时要用「内容锚」（`c:GBR ?= this` 那 8 行）而不是行号。
