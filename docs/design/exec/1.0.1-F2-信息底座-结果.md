# Situated AI 1.0.1 F2 信息底座结果

> 日期：2026-10-24。记录 F2 信息底座与国家画像合同的工程出口，不构成游戏内行为或平衡验收。

## 完成内容

- `v3 decision-audit --offline` 与生产合同复用同一 `decision_rules.contract()` 校验链。
- 当前报告连接 9/9 个信息域，包含 764 个类型化读取器、21 条信息规则、1,120 条消费者规则和 38 个原版消费者合同。
- 新增原版 `common/on_actions/00_code_on_actions.txt` 中 `on_lost_war` 写入的 `recently_lost_war` 国家布尔读取器。原版将它设置为 1825 天有效期，且只对存在 `scope:victim_of_wargoal` 的战争目标受害方生效。
- `war_defeat_reconstruction` 只在 AI、和平、未违约、有收入且该原版变量存在时提高建设候选 1.05 倍；战争中、违约、收入未知或变量未知均保留原版路径。
- 报告将战争失败列为已接入的当前冲击，将外交羞辱、革命结果、改革结果和资源中断保留为 `unsupported_no_locked_runtime_reader`。
- 规则、消费者、作者、单位、优先级、复杂度、未知回退和玩家边界均通过静态门禁；生产包不包含探针、Python、日志或缓存。
