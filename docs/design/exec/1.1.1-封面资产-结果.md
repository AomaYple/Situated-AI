# Situated AI 1.1.1 封面资产结果

> 日期：2026-10-25。本收据记录一次只改变交付资产、不改变 Mod 行为的维护候选。1.1.0 的已发布标签和附件保持不变；长期游戏行为、平衡和 Workshop 页面仍由用户验收。

## 变更

- 新增 `mod/thumbnail.png`，显示名为 `Situated AI`，使用深色旧世界地图、黄铜装饰、地球、指南针和国家关系节点，视觉方向与 Victoria 3 的历史策略美术保持一致。
- metadata 生成源声明 `picture: "thumbnail.png"`；发布 manifest 和生成锁记录图片的原始字节 SHA-256。
- 生成器、ZIP 校验器和测试将封面作为二进制 PNG 处理，不把它当作 UTF-8 文本、BOM 或 LF 文件。
- 为遵守 Steam Workshop 预览图小于 1 MB 的限制，在保持 1024×1024 构图的前提下使用 PNG 调色板压缩；没有写入水印、日志、探针或临时脚本。
