# D09 油品首轮实机交接

首轮采用 Victoria 3 1.15.2 Steam public 构建 `26763837`，只测油品。初始方案按原版、共用诊断、`native-flag` 的顺序分三个独立启动场次。 [完整对照与后续商品](D09-原创商品立场取证-结果.md)

2026-11-24 已完成原版与共用诊断的显式 OR 两端对照。原版油槽维持中性，显式 OR 00 与 11 在共同日期出现中性和高供给差异。重复油触发段有引擎解析错误。其它格、原版注入和消费者采用待验。 [首轮实机结果](D09-油品首轮实机-结果.md)

## 固定档和读点

从同一份纯原版法国档 `1836.1.30.18` 分叉，SHA-256 为 `ac963cac743d0782d8ff395040ca59bae2d1d6adbfa79ba7daeaa4a1e797ddaa`。原档加载清册没有 Mod 或禁用的 DLC。启动时记录同一构建、实际 DLC、包成员摘要和隔离用户目录。每格先留暂停即刻存档，再保存 `1836.2.1.6`、`1836.2.2.6` 的同条件读档。以首次观察到的新缓存证实重算。两次日档仍未辨别更新时，可加采 `1836.2.8.6`，各对照使用同一个观察终点。

## 三次启动

1. **原版。** 保留日本开局管理卡和法国玩家。保存初始和共同日期的市场、缓存和活动卡，核对原生判断仍处于可读窗口。若日本油槽自然更新，记录实际原版条件，后续同档比较采用这条基线。
2. **共用诊断。** 启用 `fixture-first-round oil`。同一包分别在两个文件中为 `sitai_d09_fixture` 和 `sitai_d09_repeat` 定义油品试片。每格从同一原版档重载，指定一张卡，且仅该卡有对应的可选标记。两卡的管理类型、权重、两项条件、瓷器与艺术品哨兵一致。区别在于单油键显式 OR 与同一块的两个油键。每张卡分别跑四格，再配同包 `sitai_d09_clean`（无油键）和 `sitai_d09_shadow`（只给油出口），按逐项改变绑定油槽。若加载错误可能影响共同数据库、本组正控失效或两张卡无法独立保持，则用原有独立 `fixture-positive oil` 与 `fixture-repeat-good oil` 两次挂载复跑。
3. **`native-flag`。** 单独加载油品 `native-flag`。以自然管理卡运行新标记关和开，两格都设 `sitai_d09_native_probe`，只改变 `sitai_d09_added`。如果艺术品出现，可确认新增键到达默认策略的有效路径。随后保持两个标记开启，分别选择同型的 `sitai_d09_clean` 与 `sitai_d09_shadow`，二者相差一个油品出口立场。先验共同日期的缓存、卡种和纸／艺术品槽，再判具体商品的覆盖粒度。此对照的国别选择仍为诊断卡的受控见证。下一轮可用日本同档另配原版资源扩张卡复验真实活动卡覆盖，动作和供给归因依赖各自的受控见证。

生成命令从独立工作树的仓库根执行。每次指定一个新输出目录。

```powershell
py -3.15 -X utf8 -B research/situated/1.15.2/d09_stance_probe.py fixture-first-round oil tools/out/d09-round1/fixture
py -3.15 -X utf8 -B research/situated/1.15.2/d09_stance_probe.py native-flag oil tools/out/d09-round1/native
py -3.15 -X utf8 -B research/situated/1.15.2/d09_stance_readback.py 'C:\path\to\local-text-save.v3' JAP
```

调试命令在暂停帧使用。每格从未设置任何诊断标记的原版输入档开始。同一启动内重载原版档再设下一格。

```text
effect c:JAP = { set_variable = { name = sitai_d09_fixture_on value = 1 } set_strategy = sitai_d09_fixture }
effect c:JAP = { set_variable = { name = sitai_d09_repeat_on value = 1 } set_strategy = sitai_d09_repeat }
effect c:JAP = { set_variable = { name = sitai_d09_clean_on value = 1 } set_strategy = sitai_d09_clean }
effect c:JAP = { set_variable = { name = sitai_d09_shadow_on value = 1 } set_strategy = sitai_d09_shadow }
effect c:JAP = { set_variable = { name = sitai_d09_native_probe value = 1 } }
effect c:JAP = { set_variable = { name = sitai_d09_base value = 1 } }
effect c:JAP = { set_variable = { name = sitai_d09_added value = 1 } }
```

每格只运行与本格相应的设置命令。变量省略即为假。导出 `game.log`、`error.log` 和存在的 `database_conflicts.log`。每格保存操作日志、表中对象、油与哨兵槽、存档 SHA-256 及实际日期。

## 判读

| 原创策略的油品判定 | 00 | 01 | 10 | 11 |
| --- | --- | --- | --- | --- |
| 显式 OR 的正控 | 中性 | 高供给 | 高供给 | 高供给 |
| 同商品只取首项 | 中性 | 中性 | 高供给 | 高供给 |
| 同商品只取末项 | 中性 | 高供给 | 中性 | 高供给 |

- 共用诊断保留两项独立哨兵且正控满足四格时，可用 `01`、`10` 分辨同商品首项、末项或两项任真。`11` 给出序列化后的最终有效立场，内部枚举数另需引擎读点或消费者的重复敏感见证。
- `native-flag` 先比较自然卡和新增标记开关。同轮正控已证明读取和更新，原版纸槽留存且艺术品出现时，追加块存在可见效果。再看新增标记为真时的两张受控卡。若空卡读高供给、出口卡读出口，同时艺术品及纸保留，证据支持商品级优先。若空卡和出口卡下各独立默认槽都消失，活动卡整体遮蔽仍须结合空卡与自然卡的差异判定。艺术品出现但原版独立纸槽消失时，优先查默认重复块覆盖。
- 明确报错才签拒绝。缺少双哨兵、活动卡漂移、无可验证重算、默认油分支未经同档复核、或市场取样未对时，给对应格登记未知。首轮原档的原版油触发为假。原版触发为真的保留仍须另用原版自然可比档，或在隔离诊断中对称改变一个科技变量并限于接口机制。分开保留天然原版路径的验证任务。
- `native-market` 已有独立试片，留待首轮接口结果。首轮可回读缺口谓词的观测标记和 UI，作用域正确、阈值边界、撤回与真正采纳还须在相同市场及原版机会复验。

## 下游验收边界

最短追踪对象是日本政府在州 895 的关西捕鲸扩建，候选与支付从政府及私营施工队列分别回读。`game/gui/construction_queue.gui:332/409/649` 可定位投资及私人标识。后续查实际项目 ID、发起与付款者、施工进度、既有及新增设施出力、用工和同市场周结算。日本缺少当前油井科技，本轮油井分支无正证。另有夏威夷 658、市场 262、州 140 的历史政府捕鲸项目可校验公共队列和施工读点，夏威夷的历史立场为中性。国家油品条款需另有合资格交易对手，查发起、受理、实际到货及支付。

首轮改动受控管理卡会带来其他原版判断变化。该组的工程或贸易事件只登记为候选线索。可归因的国家消费仍须同一真实管理卡、同一原版资格下独立配对油品改动，跟踪实际公共增供，分别登记私人投资、自治成交和第三方供给。 [原版资格和后续验证](D09-原创商品立场取证-结果.md)
