## 一、这一轮在问什么

上一轮的 H2 判据（**只有策略层动 = 意图层是薄壳 = H2 不成立**）**不变**。

这一轮按查明的机制，在窗口打开时**递一张原版策略牌**。

## 三、这一轮改了什么（只改一处）

1. 数据源新增 `[journal_entry.signals]`（可选表）→ 生成 JE 的 `immediate` / `on_complete`：
   * `immediate`：窗口一开 → `set_strategy = ai_strategy_progressive_agenda`；
   * `on_complete`：窗口一关 → `set_strategy = ai_strategy_reactionary_agenda`（回到开局那条路线）。
2. 世界状态（`[memory]` / `[pressure]` / `[tempo]` / `[reform_inputs]`）**一个字没动** ——
   一次只动一个变量，否则差分归因不了。
3. 探针：加了**自励阶梯**（`is_ai = yes` 时按月份自动施加冲击，观察者局不用点决议）
   与**逐月策略牌读数**（`ZZPROBE AB;STRATEGY;<牌名>;RUS`）。
