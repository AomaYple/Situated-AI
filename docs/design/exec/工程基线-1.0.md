# 工程交付基线 1.0

本页定义当前标准包的工程证据契约。它不定义 AI 行为质量、长期性能或玩家验收；那些由用户在发布包上完成。

## 版本和范围

- 已发布正式交付底本：Victoria 3 `1.14.5`。当前开发生成合同已迁移到A4目标底本`1.15.0`，本机候选、生成锁和标准包通过独立迁移检查点；完整A4阶段与正式交付仍未完成。新研究快照不授予旧包兼容权，正式包与开发候选分开追溯，详见[A4迁移结果](A4-1迁移-结果.md)。
- 包身份：`situated-ai`；用户安装目录：`Situated AI`。版本、不可移动标签、包哈希及实际发布/部署状态统一见[版本交付索引](版本交付-结果.md)和[当前工作清单](../当前工作清单.md)；历史包保留原始字节，不以当前源重建。
- 支持 Windows、macOS、Linux 的 Python 生成和离线检查；游戏 GUI 与长期运行由用户验收。
- 生产源：`mod/decisions/*.toml`；策略和本地化由 Python 生成，历史实验不进入发布 ZIP。

## 生成合同

1. `v3 modgen --write` 从源数据生成仓库产物；`v3 modgen --check` 逐字节核对。
2. `v3 package` 生成唯一生产变体的确定性 ZIP，并写入 `DISTRIBUTION-MANIFEST.json`。
3. 生成器核对原版字段、触发器、效果、作用域、路径、底本 SHA、源 SHA、玩家边界和本地化键集合；任何漂移硬失败。
4. 包内游戏 `.txt`/`.yml` 使用 UTF-8 BOM、LF；仓库源、JSON、TOML、Markdown 和 Python 使用 UTF-8 无 BOM、LF。
5. manifest 列出每个文件的 POSIX 路径和 SHA-256；ZIP 不含重复路径、路径穿越、Windows 保留名、反斜杠或大小写冲突。
   生产游戏脚本目录包含 `common/` 与 `events/`；事件选项政策与其他脚本同样参加生成锁、原版保护和标准包逐字节校验。
6. `mod/generation-lock.json` 只供仓库离线审计，记录生产源码、TOML、底本和产物的原始字节 SHA；不进入游戏包。
   无游戏 CI 核对冻结合同与快照，生产重生成和打包仍须读取锁定原版，缺失或漂移时拒绝。
7. `thumbnail.png` 是标准包必需的二进制资源，必须是 256–4096 像素的方形 PNG，且小于 1 MB；其 SHA-256 必须出现在 manifest 中。
8. 当前正式包使用 `status = released` 与 `publication_channel = stable` 表示交付渠道；`behavior_quality = not_evaluated` 独立保留用户实机验收边界。正式渠道不等于行为、平衡或性能已通过，历史包中的 candidate 合同保持原字节。

## 当前联合决策合同

当前生产链为：原版机会 → 精确对象与真实观测 → 具体行动 → 同因分档取强、独立收益与成本联合 → 消费者末端一次限幅 → 原版比较与执行 → 后续真实观测。

消费者联合贡献让显式行动的需求、收益、成本和条件关系共同参与，相关因果按来源去重；同字段在末端一次限幅。
规则迁移程序按显式因果组和数值方向选择最强已知档，再合并净偏移；未拆分的历史规则不能被当作独立收益重复相加，数值正负也不能代替收益、成本和单位的语义判断。
未知只退出相应项；成本未知使用声明的局部保守分支。资格、单位、原版成本、执行和尾部继续由精确适配合同保护。
参考语义与实际生成数值 AST 需要独立见证；范围与迁移的实际验收状态见[工作清单](../当前工作清单.md)。

跨域关系消费当前世界中已生效的法律、实际制度和识字等已观察条件；候选资格、选项评分或倾向调整不作为行动完成证据。
条件退出或变为未知时，相关关系增量退出，其他已知独立项继续参与。当前关系接线不能被推广为所有领域或所有关系种类都已完成，也不能据此推断世界变化的因果归属。

国家协调采用 `stateless_consumer_observations`，由原版消费者按需求值；同国的教育、政治、产业和安全需求可同时存在。
全国排他路线、其预算与时钟已退役，不再生成对应 effects/on_actions。旧 Mod 路线变量不再被读写，按旧 TTL 自然失效；不新增迁移 writer。
原版 `recently_lost_war` 的合法来源与期限继续保留。当前联合决策直接读取财政与战争状态；
没有实际消费者的财政月度状态更新器不再部署，不生成对应财政 triggers、effects、on_actions 或 TTL。
旧财政迟滞 API 及历史证据只说明独立旧模块能力，不能作为当前生产惯性证据。
取消政治路线迟滞是有意语义变更，不是等价性能优化。

当前架构与计划归档入口见[架构主计划](../架构主计划.md)和[架构子计划](../架构子计划.md)，实际状态由
[当前工作清单](../当前工作清单.md)与[广度深度拓展结果](广度深度拓展-结果.md)维护；[架构阶段收据](架构阶段收据.json)只核验归档 A2。
[历史归档](../archive/README.md)统一导航旧计划、设计及交付证据；其中的旧阶段、路线和参数只作迁移参考。
本基线不复制易变统计、包大小或包哈希。

旧候选的全国排他路线曾使用 TTL 100 日、切换冷却 62 日；这些参数只解释迁移前证据，不再描述当前协调机制。
旧规则的全字段第一匹配、历史路线变量和旧收据不能替代当前消费者联合语义及独立验收。历史原始字节和收据保留，不回写为新合同。

当前字段级保护仍核对真实对象、作用域、具体消费者、原版尾部和未知回退。领域开关或层级名称不能证明细分域已经接线；
活跃原版策略定义的同名字段可能覆盖默认策略，静态发现也不授权推断引擎合并或运行期效果。

## 检查层级

| 层级 | 入口 | 证明 |
|---|---|---|
| 编码与卫生 | `run_check.py encoding/hygiene` | 受控文本、Python 字节码、根缓存和临时目录符合契约 |
| 代码质量 | `lint`、`format --check`、`types`、`deadcode` | Python 语法、风格、类型和无明确零引用候选 |
| 离线合同 | `test-offline`、`baseline`、`modguard --offline` | 冻结源码/产物、解析、快照接口、打包原语、回退和文档链接；不重建原版消费者 |
| 完整静态工程回归 | `test` 或 `full-acceptance --quiet` | 当前 Python 测试选择集和资源报告；不启动游戏，不代表游戏行为 |
| 用户外部验收 | 用户安装固定哈希的标准包 | 引擎行为、长期 AI 行为、平衡、玩家体验、后期性能和创意工坊结果；不作为当前计划门禁 |

## 证据口径

报告必须标明 `static_check`、`snapshot`、`simulation`、`runtime` 或 `inference`。加载成功、脚本解析、评分变化、
根 hook、一次短跑和 Python 基准不能升级为行为质量结论。外部阻塞（如本体资源缺失）记录为环境限制，不把资源复制
进生产包或白名单放行。

产品阶段要求完整生产功能的静态语义验收、工程正确性和可交付性。只有字段合法、文件存在或既有测试通过，不能证明完整功能实现；阶段目标和状态由计划入口维护，旧行动覆盖合同仅作迁移依据。日志、存档和观察器是用户长期验证的辅助能力；没有用户实机材料时，
如实保留行为、平衡和游戏内性能的未验收边界，不因此阻塞静态阶段出口。

## 发布和恢复

发布前确认包可解压、manifest 可复核、源树干净、版本和游戏底本一致。用户应在独立 playset、新游戏和保留原存档的
条件下进行长期验收；卸载不会撤回已发生的世界变化，恢复对应存档和原挂载才是回退方式。后续修复从 `main` 中的交付提交
创建 `hotfix/<topic>`，按语义化版本增加维护版本并回流 `main`；对应发布标签存在时可从该标签定位底本。
