## 最终目标

**Situated AI 让每个国家基于自身处境和可观测信息，在原版机制内持续做出符合自身约束与利益的相对最优决策。**

“相对最优”指受信息、能力、政治阻力、财政成本、外部威胁和原版规则约束的情境最优，不是全知的全局最优，也不是固定国家剧本。
计划的产品出口是一个可安装、可生成、可审计、保留原版资格与执行的 Mod；行为质量仍由用户在标准包上长期观察。

## 交付原则

1. 正确性第一、速度第二、内存第三；任何提速都要先证明字段、作用域、回退、输出和证据契约不变。
2. 先硬约束、后软评分；先国家状态画像、再跨域组合；未知事实不猜测，回退原版。
3. 每个阶段都产出可加载的完整标准包；探针只能放在明确标记的诊断包，不进入生产包。
4. 原版 AI 保留资格、成本、随机性、政治博弈、行动执行和失败处理；Mod 只提供有限、可解释的倾向增量。
5. 每个信息域和消费者都要有唯一作者、来源、作用域、单位、刷新时机、性能预算和验证边界。
6. 工程检查、快照、脚本加载、评分变化和根 hook 只证明各自事实，不能升级为行为、平衡或玩家体验通过。

## 统一实现主线

所有扩展都沿同一条有界数据流实现，不再按国家名称堆叠脚本：

```text
锁定原版可观察接口
    → 信息目录（来源、作用域、单位、刷新、未知值、成本）
    → 国家状态画像（硬约束、能力、压力、机会、结构、冲击）
    → 原版候选消费者（资格和执行仍由原版负责）
    → 单字段有界权重与解释
    → 静态合同、包门禁和用户实机反馈
```

信息目录按政治、社会与人口、财政与行政、生产与建筑、市场与贸易、科技、外交与宗属、军事与战争、
殖民与地理、身份与文化、时间与冲击登记；目录中的事实只有在原版字段、作用域和消费者均能证明时才进入
运行期。不同单位不直接相加，未知值保留 `unknown` 并回退原版。

为了保证推进速度，每次扩展只选择一个消费者集合，先生成一个完整可安装包，再集中执行一次固定验证矩阵；
重复扫描、无界组合、常驻服务和无证据的游戏自动化不进入默认路径。离线合同和生产合同必须调用同一份规则
合同生成器，防止 CI 与有游戏环境出现语义漂移。

## F0.1：1.1.0 条件化激进平衡候选（工程收口完成）

本轮把用户要求的“机制和数值更激进”落实为**条件化增量**，而不是无条件放大所有行动：

- [x] 在合法原版消费者内提高财政、建筑、教育、贸易、外交、军备、科技和制度倾向；倍率是候选权重增量，
  不是行动概率或强制执行。
- [x] 为有财政余量、低债务、高合法性、行政能力充足且处于和平的国家增加 `strong_capacity` 高档，
  让工业、教育、贸易和经济合作在满足条件时更果断；高档条件是严格子集，不与普通档叠加。
- [x] 为高债务且临近破产的国家增加流动性优先级；战争失败恢复只在原版 `recently_lost_war`、和平、未违约、
  有收入和政治能力足够时生效，避免把冲击奖励发给财政或政治上不可执行的国家。
- [x] 将输入短缺、失业、储备、市场可达性、海军可负担性、外交承诺和政治危机纳入更强的条件分层；
  未知值、原版资格失败和玩家路径继续回退原版；原版零目标不会被乘法调整唤醒。
- [x] 保留单字段唯一作者、第一匹配优先级、尾部限制、原版成本、资格、随机性、谈判和行动执行；不引入全局规划器、
  常驻服务、国家专属剧本或无界状态。

本候选的工程出口是“条件明确时更果断，信息不足时更克制”。具体倍率与字段以生成源和审计报告为准；静态通过不等于
俄罗斯、荷兰或其他国家会在长期游戏中产生预设结果，行为和平衡由用户实机验收。

历史 `1.0.2` Windows `.venv` 单 worker 离线回归选择 1,546 项，最终为 1,540 通过、6 跳过、0 失败，墙钟 844.06 秒；

验证输出必须标注 `static_check`、`snapshot`、`simulation`、`runtime` 或 `inference`。静态通过不升级为 AI 行为通过。

## 当前执行顺序和完成定义

历史工程计划 **F0–F8** 与当前 `F0.1` 工程收口均已完成；后续工作回到用户提交日志后的针对性修复循环。每次修复仍须重新生成标准包并运行同一验证矩阵。每个阶段出口均有：

- 一个可安装、可加载、无已知低级字段/路径/编码错误的完整标准包；
- 一份由 Python 生成的规则/验证报告和结果收据；
- 对应测试和资源读数，或明确记录无法测量的边界；
- 用户可据此进行长期游戏观察的版本出口。

“计划完成”只表示仓库工程链、Mod 合法性、解释合同和发布包完成；AI 是否产生历史合理行为、长期平衡、后期性能、跨平台 GUI 和工坊结果，仍以用户实机证据为准。
