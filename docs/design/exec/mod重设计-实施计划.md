# Situated AI 分层联动实施计划

> 计划版本：26.1（2026-10-30）。本页是唯一当前产品计划，替代已收口的终极方案 4.0 阶段队列。
> 起点为 `1.4.0`，目标版本为 `1.5.0`；锁定 Victoria 3 `1.14.5`，身份保持 `situated-ai` / `Situated AI`。
> 状态：P0–P7 已完成生产实现、静态工程验收、合并、版本发布和游戏目录部署；证据见[分层联动执行结果](分层联动-执行结果.md)。长期游戏验收仍由用户完成。流程见 [CONTRIBUTING.md](../../../CONTRIBUTING.md)。

## 目标与边界

**Situated AI 让每个国家基于自身处境和可观测信息，在原版机制内持续做出符合自身约束与利益的相对最优决策。**

本轮解决多重正向条件把发展长期锁住的问题：财政、政治、行政、产业、教育、军事和海外发展不再共用一条全条件门槛。
国家的承受层级与领域需求分开计算，优先补瓶颈，在可承担时逐级增加投入；危机转向恢复和低成本能力建设。
国家差异来自条件，不按俄罗斯、荷兰等国家名称写死路线；本文中的历史类比仅解释因果假设。

完成意味着实际修改生产 TOML、生成器和生成 Mod，工程验证通过、标准包交付、PR 合并、tag/Release 发布、游戏目录安装核验。
仅修改计划、登记字段、增加模拟或通过 CI 均不能独立完成阶段。长期游戏行为、平衡、游戏内性能和玩家体验由用户验收。

## 设计与文件职责

```text
锁定原版事实（作用域、单位、范围、来源、未知策略）
  → 当前能力层级：恢复 / 基础 / 稳健 / 扩张
  → 领域需求：财政、行政、政治、教育、产业、安全、战后、海外
  → 路线记忆：进入 / 保持 / 退出、紧急抢占、TTL、冷却
  → 具体消费者：资格约束 + 层级强度 + 瓶颈优先 + 机会成本
  → 同字段单项有界调整
  → 原版资格、成本、概率、执行、失败
  → 下次求值重新读取事实；用户日志与存档辅助反馈
```

- `mod/decisions/country_state.toml`：事实与路线唯一来源；增加分层与需求合同。
- `src/pdx/country_state.py`、配套协调模块：解析、独立参考求值、编译共享触发器、生命周期和所有权校验。
- `mod/decisions/strategic.toml`：共享意图只表达对应行动需要的能力，不把政治和行政富余变成所有发展的前提。
- `mod/decisions/information.toml`：建设、学校、军备、贸易、合作、殖民等默认策略消费者的分层规则。
- `mod/decisions/adapters.toml`：建筑、投入品、科研、法律、外交宗属等细粒度消费者及局部资格约束。
- `decision_rules.py`、`decision_interfaces.py`、`decisions.py`：派生触发器的类型/所有权/禁用合同与生产接线；保留原版执行尾部。
- `tests/`：参考求值、PDX 子集等价、未知降级、门槛和反例、全生产覆盖和包合同；不以复制实现代替语义验证。
- 当前清单记录事实，新结果页记录证据，版本索引记录不可变交付；旧结果保留版本上下文，不复制当前进度。

## 全领域广度与深度矩阵

“全领域”要求每个原版决策面同时具备三层接线：可观测事实、跨领域协调和具体原版消费者。
只有登记读取器或写入计划不算完成；某一领域没有合法消费者时必须明确标为 `discovered_only`。

| 原版决策面 | 事实层 | 协调层 | 生产消费者 |
|---|---|---|---|
| 政治、法律、利益集团 | 合法性、叛乱、利益集团影响/支持、当前法律 | political、stable_capacity、recovery | 法律 enact 权重、改革门槛、谈判、革命规避、制度评分 |
| 社会、人口、身份 | 人口、识字率、生活水平、阶层/劳动力、文化与家园 | education、political、identity | 学校、健康、社会保障、劳工、迁移、身份领土价值 |
| 财政、行政、国家能力 | 违约、债务、借款、收入、净结余、官僚力 | fiscal、administrative、recovery/foundation | 建设目标、制度扩展、国有化、财政科技、行政科技 |
| 产业、农业、资源、市场 | 建筑评分、生产方式、投入/产出、商品价格/缺口、路线 | industry、foundation/stable/expansion | 建筑、生产科技、农业/工业/资源路线、贸易/经济合作 |
| 科研、教育、技术 | 原版研究权重、前置、教育与健康缺口 | education、administrative、industry、security | 生产、行政、财政、社会、军事、海军科技候选 |
| 外交、贸易、宗属 | 关系、停战、联盟、宗属、自由度、目标可达性 | overseas、fiscal、reconstruction、subjects | 条约类别、港口、殖民兴趣、宗属自治/服从、战争目标 |
| 军事、战争、军需 | 战争、军力/海军、军需商品、战败记忆、技术 | security、reconstruction、fiscal、overseas | 军队/海军目标、编成、补给舰、征召、军需科技 |
| 殖民、地理、海外投射 | 目标州端口/隔离/文化、海军、殖民路线 | overseas、administrative、identity | 州价值、殖民兴趣、战略姿态、港口与防御合作 |
| 时间、冲击与惯性 | 原版近期战败变量；Mod 路线 TTL、冷却、进入/保持/退出 | recovery、route priority | 月度刷新、危机抢占、未知回退；不伪造未暴露的历史状态 |

粗域开关只有 9 个，覆盖报告另按 19 个产品子域逐项追踪：政治、人口、社会、财政、行政、产业、农业资源、市场贸易、科技、教育、外交、宗属、陆军、战争、海军、殖民、地理、身份、时间冲击。
每个子域必须列实际来源限定的事实、生产规则、真实协调触发器及其依赖、原版消费者、优先级、未知回退和静态证据；
不能用裸 key 同名、硬编码领域词、读取器数量或 9/9 粗域接线替代这些关系。子域无法证明链条时显式标为 retained_vanilla 或 discovered_only。
活跃原版策略可能定义与默认策略同名字段；静态接线不证明引擎在各策略状态下的合并/覆盖语义，报告与文档必须保留这个边界。

每一行都必须保留原版资格、前置、成本、政治支持、目标可达性、随机性、执行失败和零值尾部；
分层只改变同一消费者中的有界相对倾向。跨领域联动通过有限协调触发器表达，禁止全局万能分数、世界扫描、
后台服务和无界缓存。

## 持续约束

正确性第一、速度第二、内存第三；Python 3.11+、仓库 `.venv`、三平台工具链、受控文本 UTF-8 无 BOM/LF。
复用成熟标准库和现有解析/生成能力，不引入求解器、后台 AI 服务或世界扫描。
共享层级通过原版消费者时机按需求值；不增加持久变量。既有路线保持月度更新、TTL 100 天、冷却 62 天。
未知核心事实回退原版；缺失高档辅助事实只能降到已证实的低档，不能推定国家健康。产业、战后和海外辅助需求另暴露已证实需求信号；
未获正面证据只表示尚未证明需求，不把原始未知改成假，也不阻挡已证实的能力回退。层级互斥，同字段第一匹配胜出，不累乘发展奖励。
所有合法性、成本、研究前置、机构资格、政治支持、目标可达性和原版终结零分继续由原版负责；不给资源、不强制行动、不改玩家路径。
静态复杂度预算保持现有门禁；性能结论使用同口径时间/内存，不能用 Python 基准冒充引擎性能。

## 阶段与可核查出口

### P0：计划冻结与提交

- [x] 明确新架构、全领域处置、阶段验收和版本；更新当前清单并检查链接、编码、差异。
- [x] 独立中文提交计划，之后持续执行 P1–P7。

### P1：共享分层协调

- [x] 实现恢复、基础、稳健、扩张四档；高档事实缺失不抹掉已知低档。
- [x] 实现财政/行政/政治/教育/产业/安全/战后/海外需求；只消费现有已核实事实。
- [x] 由同一 TOML 生成 Python 参考结果和 PDX 触发器；核对类型、范围、未知输入、AI/禁用边界和触发器所有权。
- [x] 测试低债务借款、无净结余、低合法性、负行政、违约、战争及完全未知；复核互斥性与复杂度。

### P2：经济—科技—社会纵深

- [x] 建设目标区分基础/稳健/扩张，恢复期限制新增承诺；不因小国或缺少既有工业策略永久排除基础发展。
- [x] 工具、铁、煤、钢、纸、基础设施、行政、大学和科研按各自瓶颈和本地投入条件联动。
- [x] 科研选择先补生产和行政能力，再扩大研究投入；已有科技前置、原版候选和有限研究队列不变。
- [x] 教育缺口与财政/行政承受力分别处理；低识字率不是永久禁止发展，科研选择不等同免费研究速度。
- [x] 调整路线与消费者中的过严门槛，既有高承受力共享意图保留兼容合同；保留紧急抢占、迟滞、唯一活动路线和原版回退。

### P3：全领域联动

- [x] 政治/社会：改革仍依据政治可行性，危机优先稳定；不把发展层级改成统一意识形态。
- [x] 市场/贸易/外交：恢复期允许低成本合作，扩张依据能力；商品和关系方向分别在合法作用域读取。
- [x] 军事/战争/宗属：生存优先，财政紧张限制新增长期承诺，战时不削弱原版基础防御。
- [x] 海外/殖民/地理/身份：投射能力、财政和现有路线共同决定强度；保留目标资格、可达性与原版成本。
- [x] 每个领域至少有生产接线和反例；逐项登记哪些保留原版，不能把保留面算成新增能力。

### P4：整个 Mod 复核与结构整理

- [x] 复核全部生产源、生成脚本、原版底本、消费者字段、所有权、玩家边界、零值和限幅尾部。
- [x] 合并被新层级取代的重复/遮蔽规则，清理无用 reader、死代码、过时说明和断链。
- [x] 统一架构说明、玩家安装说明、工坊文案、当前清单与计划；保持 11 种语言键和占位符一致。
- [x] 重生成并运行在线/离线审计，确认新增能力实际进入标准包且没有探针或独立实验包。

### P5：冻结候选与工程验收

- [x] 受影响测试通过后，冻结候选，运行一次完整 `full-acceptance --quiet`；记录实际测试数、跳过、覆盖率、worker、时间、RSS。
- [x] 编码、lint、format、types、baseline、deadcode、生成、在线/离线字段审计和包合同通过；失败必须修复，不能降低门禁。
- [x] 清理测试可再生缓存后运行 hygiene；结果写新收据，明确 `static_check` / `simulation` 边界。

### P6：Git 与版本交付

- [x] 版本升为 `1.5.0`，生成标准 ZIP 和 `.zip.sha256`；中文提交并推送主题分支、创建 PR、附加到会话。

### P7：游戏目录部署与最终清理

## 验证设计

参考案例覆盖同一国家从缺行政/低识字/债务压力到稳定发展的转变，以及富裕海洋国家在海外承诺与产业升级之间的权衡。
这些用例检验条件和输出方向，不预测 GDP、具体战争或改革年份。属性测试检查互斥、边界、未知降级、玩家和禁用等价；
PDX AST 子集解释器对照 Python 参考结果，生产审计确认每个触发器确有消费者与原版来源。
最终全量复核覆盖所有 Mod 内容，不能只检查新增代码；静态工程交付完成后，用户反馈再驱动后续维护版本。
