# Situated AI 1.0.0 交付计划

> 版本：7.2（2026-10-22）
> 目标：交付一个使用锁定 Victoria 3 原版接口、可重复生成、可审计并符合 Paradox Launcher 目录结构的 Situated AI 1.0.0 标准 Mod。长期实机行为、平衡和玩家验收由用户负责。

本页是当前唯一产品计划。历史阶段和实验记录保留为事实来源，不构成当前待执行队列。持续原则见[Mod 开发原则](../../principles/Mod开发原则.md)，工程检查和 Git 流程见[CONTRIBUTING.md](../../../CONTRIBUTING.md)。

## 交付范围

- Mod 以可读取的国家与世界处境影响原版 AI 倾向，覆盖政治、人口、财政、行政、经济、市场、贸易、外交、宗属、军事、战争、殖民、地理、身份和世界状态等已登记维度。
- 只有在锁定版本中能由原版脚本或公开数据读取的事实，才进入运行期规则；衍生事实、静态发现、消费者映射和未知能力分开记录，不把分析到的字段误称为运行时可读。
- 生成内容只使用锁定 Victoria 3 `1.14.5` 中有证据的字段、触发器、效果、作用域和路径。保留原版资格、成本、行动执行、随机性与国家身份；Mod 仅对 AI 倾向施加有限修正。
- 正式 ZIP 是标准 Mod，不含 Python、工程探针、日志、缓存、本体资源修复或历史实验。用户负责创意工坊发布和长期体验判断。

## F0：完成生产 Mod

- [x] 统一生产 TOML、规则、消费者适配器、版本、模块开关和元数据；每个被修改字段只有一个生产作者。
- [x] 让声明式信息规则和原版消费者适配器覆盖当前承诺的处境领域；规则具备输入来源、条件、边界、理由及未知值回退，不混加不可比较的单位。
- [x] 生产输出保持玩家路径与原版行动权；无奖励资源、无强制行动、无国家写死路线、无外部常驻服务。
- [x] 完整生成锁定版本全部游戏语言的自有本地化，检查键集合、占位符、语言头、路径和编码边界。
- [x] 生成器以原版底本和源指纹为输入，底本漂移、未知接口、重复作者、非法结构或不完整语言时硬失败。

## 用户验收边界

工程门禁证明的是源码、原版接口证据、语法解析、生成合同、包结构和 Python 工具链。它们不能证明脚本引擎运行期语义、国家长期行为、决策质量、平衡、后期游戏性能、GUI 呈现、存档迁移结果或创意工坊页面。用户收到标准包后自行进行这部分验收；若发现问题，以版本、存档、原始日志和最小复现为依据制作后续修复版，不回写已发布版本。
