# K4 关系、成本与动态仲裁结果

> 记录日期：2026-10-31
> 计划版本：30.0
> 证据类型：静态检查、生成见证、Python 参考求值；不代表长期游戏行为通过。

## 已实现并验证

- `ActionCard` 现在显式登记 `enables`；关系生成器拒绝未知目标、重复元数据和非有限强度。
- `complements`、`substitutes`、`conflicts` 要求显式对称配对；只有有向 `enables` 图禁止环；所有关系路径受两级深度限制。
- 关系元数据支持作用域、条件事实和未知策略。当前生产源为 `industrial_foundation → education_and_research` 登记 `peace` 条件，未知回退原版。
- 仲裁器拒绝 NaN/无穷输入，承诺/政治成本进入可行性与增量，稳定的行动 ID 使用升序词典序作为最终决胜。
- 参考求值对同一消费者的全部可行候选进行一次统一仲裁；关系互补只提供有限软增量，替代/冲突抑制候选，使能关系保留硬依赖。
- 状态向量的基础派生拒绝非有限数，并分别保留能力、压力、机会和承诺维度的未知值。
