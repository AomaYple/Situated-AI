## 三、为什么"牌换了法还不换"——**已查明：政府里只有地主**

第二局（`--months 96`，加了 ENACT / GOV 两行分辨器）跑到 **1844.1（≈96 个月）**，
读数**全部同向**：

```
AB;ENACT;none;俄罗斯         96 / 96 —— **一次都没开过立法**
AB;GOV;landowners;俄罗斯     96 / 96 —— 政府里**只有地主**
（intelligentsia / industrialists 一次都没出现过 —— 它们从未进入政府）
AB;LAW;law_serfdom;俄罗斯    222 —— 法律没变
AB;JE;active;俄罗斯          163 —— 窗口大部分时间开着（inactive 25）
AB;STRATEGY;progressive_agenda  102 —— 进步牌是主态
AB;STRATEGY;conservative_agenda  28 —— 原版自己重抽到保守牌 28 次
AB;STRATEGY;reactionary_agenda   58
AB;SHOCK;yes;俄罗斯          164 —— 冲击在（no 24）
零报错：error*.log 对 `sitai` 0 命中
```

⇒ **候选「甲 · 政府支持不足」成立**（原版读本 `common/laws/readme.md:9-10` 点名的正是这条）：

* **AI 一次都没开始推那条法**（`ENACT;none` 96/96）—— 不是"开了没成"，
  而是**根本不动手**；候选乙（怕革命）据此**排除**：怕革命也会先开立法再被打断；
* 政府里**只有 `ig_landowners`** —— 而地主正是 `law_serfdom` 的守旧方，
  也是 `law_tenant_farmers` 的反对方（那条法会把地主政治力量 −0.25，
  `01_land_reform.txt:155`）；
* 我们那把"改革派抬头"的修正（知识界/工业家 `pol_str_mult +0.5`）**没能把它们送进政府**
  —— `+0.5` 抬的是 clout 份额，而"在不在政府里"是另一个判定。

**因此瓶颈不在牌，也不在权重，而在"改革派有没有进入政府"。**
这是 `01-大方向.md` §0.1 那句"最优 = **约束下的**可行最优"的字面体现：
AI 的处境已经变了、它的目标函数已经指向改革，但**约束集（谁在朝）不允许它动手** ——
于是它什么都不做，而这恰恰是"按约束推出来的最优"。

⚠️ **还不许下定论的一半**：我们只证明了"AI 不动手"，没证明"AI 想动而不能动"。
`ENACT;none` 也可能是"它在推别的法"（我们只盯了两条土地法）。
下一局要把 `ENACT` 扩成"当前在推的**任意**法"（`is_enacting_law` 需要具体法名，
所以要先查有没有更通用的判据），只有在"它在推别的法"被排除之后，
「甲」才是一个**结论**而不是一个**强假设**。

   * ⇒ 下一处要动的**不是**再加大权重（原版明说 100000 也不保证），而是
     **换一条能让 AI 组出改革派政府的机制**，或者承认这条约束、把
     "AI 会去推哪条法"作为**可观测的意图**而不是"真的换法"。
2. 无论走哪条，**这一轮的产物都留下**：递牌能力（生成器）、自励路径（探针）、
   牌/窗口/立法/政府四类逐月读数（分析器）——它们让"下一步为什么失败"每次都**当场可辨**。
