# exec · B88 杠杆设计：**停滞**由什么决定，以及改革侧该动哪一根

> 起因：`阶段5-实机读数补记.md` §三·补.2 的归因说「阻塞在**合法性**那一侧」。那句话**方向对、机制错**
> —— 本轮去读原版 defines 与字段用法之后发现，合法性并不在立法停滞的公式里。这一页把机制钉清楚，
> 并给出**按原版证据选**的杠杆（已经落到 `tr_defeat.toml`，等下一局验证）。

## 二、原版机制：停滞（stall）由两条决定，**没有合法性**

`common/defines/00_defines.txt`（逐行打开确认）：

| 行 | 内容 | 含义 |
|---|---|---|
| :177 | `LAW_ENACTMENT_IG_CLOUT_STALL_EFFECT = 1.0` | **反对派 IG 的政治力量**是停滞的基础影响 |
| :178 | `LAW_ENACTMENT_IG_NEUTRAL_MULT = 0.5` | 中立时乘 0.5 |
| :179 | `LAW_ENACTMENT_IG_UNHAPPY_MULT = 1.0` | 不满时乘 1.0 |
| :180 | `LAW_ENACTMENT_IG_ANGRY_MULT = 1.5` | **愤怒时乘 1.5** —— 同样的力量，愤怒的反对派造成的停滞是中立时的 **3 倍** |
| :175 | `LAW_ENACTMENT_MOVEMENT_SUPPORT_PASS_EFFECT = 1.0` | 运动支持影响**通过** |
| :176 | `LAW_ENACTMENT_MOVEMENT_SUPPORT_STALL_EFFECT = 1.0` | 运动支持影响**停滞** |
| :181 | `LAW_ENACTMENT_MAX_PHASES = 3` | 推成要过 3 个阶段 |
| :171 | `LAW_ENACTMENT_COOLDOWN_DAYS = 730` | **推失败一次，那条法 2 年内不能再推** |

⇒ 两条推论：

1. **「连续 33 个月仍在 `is_enacting_law`」= 在停滞，不是失败重试**。真失败会立刻结束这次立法
   （`is_enacting_law` 转假）并进 730 天冷却 —— 读数里那 33 个月是**连续**的，没有中断，
   所以每一次检查点都在"没推进但也没出局"。
2. 合法性不在停滞公式里。它是**开窗**（我们 JE 的 `possible` 读 `legitimacy <= 75`）与
   **政府组阁**那一侧的输入；把"法没换"归到合法性上，会把人的注意力从真正的杠杆上带走。

## 三、那原来的改革侧输入为什么没用

`tr_defeat.[reform_inputs]` 原先只有两条：工业家 / 知识界政治力量各 +0.5。
它们喂的是**原版牌的权重输入**（`ai_strategy_progressive_agenda` 读这两个 IG 是否 `is_powerful`，
`03_political_strategies.txt:528-544`）—— 而读数显示**牌的落点本来就对**
（`tanzimat_reforms` 亲改革派、`change_law_chance = 100`），AI 也真的去推了。
换句话说：**原来那两根杠杆作用在"想不想"上，而卡住的是"推不推得动"。**

## 四、按证据选的两根新杠杆（已落到数据源）

| 字段 | 取值 | 为什么是这个值 | 反例（不采用的） |
|---|---|---|---|
| `country_law_enactment_success_add` | **0.1** | 原版 `common/` 里 **433 处**使用，正向取值中 **0.1 出现 146 次**（次高 0.05×21）—— 原版自己的主力档；且它正是"通过率"这一侧的字段 | 不继续抬 IG 份额：那一侧已经够（见 §三） |
| `country_opposition_ig_approval_add` | **+3** | 原版 10 处使用里正向只有 +1 / +3，取高档；它改的是**反对派的脸色**，也就是上面 :178-180 那三个乘数所读的东西 | `state_pop_support_movement_land_reform_add/mult`：**声明了但没接线** —— 只出现在 `modifier_type_definitions` 自己（1 处），脚本 0 处、**exe 无字面量**。用它过得了我们的闸门 ①（键在定义池里），但在游戏里很可能什么也不做 |

> ⚠️ **最后那一行是这一页最值钱的一条**：`modifier_type_definitions` 里"有定义"不等于"引擎会读"。
> 这份档案的闸门 ① 查的是定义池，所以这类键能混过我们全部门禁 —— 判据要加一条"原版脚本用过
> **或** exe 里有字面量"，本轮已按这条筛过候选（`country_institution_impact_add` 同样 0 处、exe 无字面量，一并排除）。

## 五、下一局怎么验证（读数已经就位）

`v3 preflight --archive tr_defeat` → `stage3_rerun.py --months 66 --archive tr_defeat --fresh-logs`，然后看：

1. **`PROG`（立法进度）**：现在是数值读数。旧局看不到进度，只能看到"在推 / 没成"；
   新局应当能看到进度**推进到第 2/3 阶段**，而不是原地打转。
2. **`CLOUTV` / `CLOUTP`（三个 IG 的政治力量，数值）**：验证 -0.30 那条压力到底降了几分
   （旧局的夹逼读数里 landowners 与 intelligentsia 都是 b25，档内变化**量不出来**）。
3. **`LEGV` / `LEGF`（合法性，数值）**：把"合法性有没有被冲击打下去、有没有回升"从档位变成数字。
4. **判据不变**：`LAW` 从 `law_serfdom` 变成目标法 = 行为层真的动了（G-EXIT-5.x 要的那一条）。

> **如果这一局法还是没换**：下一个候选是 `country_law_enactment_stall_mult`（原版只有 4 处、
> 且 `power_bloc_principles` ×3 在用，取值 -0.33）—— 但那属于"再压停滞"，
> 应当在**读完成功/停滞的数值**之后再决定，别一次动两根。
