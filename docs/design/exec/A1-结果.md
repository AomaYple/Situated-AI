# A1 结果：首版开关与包契约

> **更新日期**：2026-10-15
> **状态**：开关与包契约已实现，最新回归及元数据加载、存档状态退出仍需验收。A1 尚未全部完成，不宣称 V0.1 或行为质量完成。

## 已实现

- `mod/decisions/fiscal.toml` 增加显式 `fiscal.enabled`。当前实验候选明确写为 `true`；通过 `Policy` 的关闭变体可生成安全对照包。
- 开关关闭时，默认策略正文逐字回到底本，不追加财政中立/侵略字段，也不生成财政 scripted trigger、effect 和 on_action；政治与市场扩展继续由各自开关控制。
- 数据源增加 `[package]` 契约：产品版本、候选状态、父包、存档兼容范围、支持平台和平台证据说明。产品版本 `0.1.0` 与 Python 工具版本 `0.3.0` 分开记录。
- `.metadata/metadata.json` 由 `pdx.decisions` 生成实际启用模块和源指纹；`DISTRIBUTION-MANIFEST.json` 从实际元数据提取同一契约，记录财政源、扩展源、原版底本和生成器 SHA-256。变体实参另由 `generation` 记录，避免共享原始源指纹掩盖实际参数差异。
- `v3 package --variant current|control|disabled` 分别构建当前实验、零偏置财政和全关安全包，CLI 与 Python API 默认均为 `disabled`。全关关闭扩展；控制组保留财政生命周期、仅令策略偏置为零。非法变体拒绝并保全已有目标。
- 生成器开关往返只删除固定受控的旧生成物，未知探针/用户文件仍保留并由一致性检查拒绝。财政关闭仍核验共享原版策略底本；无参数财政挂载入口读取实际开关。
- 继续保持仓库源文件 UTF-8 无 BOM、LF；ZIP 仅在游戏 `.txt`/`.yml` 交付边界添加 BOM，确定性、路径安全、原子替换和 legacy 隔离不变。

## 边界与后续

### 2026-10-15 独立状态安全实验事前登记

目的为校准新增元数据加载、含财政状态存档的关闭及 TTL；不是 M3/M4 或可玩交付验收。计划 `v01-a1-state-safety-20261015`，最多两个场景、每场一组，单臂最多四游戏月、墙钟 1200 秒，最低可用内存 4096 MiB。

准备场景 `fiscal-state-preparation`，control/instrument：载入 1836.2.1 英文观察者输入，SHA-256 `379df80b8846bcf375ab38b7ee6ede1a3225bea448ae0469d0687a35396d2466`。该输入只有加载/仪器资格，来源及外交机会未完整证明。用生成器零偏置财政包和既有生命周期仪器，私有计数改用 A1 名称防止历史计数污染；第二个观测月的压力注入只制作真实风险状态，不创造外交机会。运行目标三游戏月并归档自动存档，保存等待及启动推进另报。第六月恢复注入不在本轮窗口，状态包必须仍含两国风险；无状态、同类引擎错误、挂载或恢复失败就否证，不补造存档。

第二场仅在准备通过并原件确认两国风险后执行：同版本存档，disabled 包和兼容同 ID 的只读生命周期观察器，不注入、不调用更新器。读取连续序列，要求真实 `yes→no` 且之后没有重新续期；精度为各国月度采样，不能从采样间隔推断精确过期日。最长四游戏月，保存/重载及输入 SHA 先冻结在本页。

两局使用已审查的维修图标诊断挂载以排除已知 VFS 缺引用，沿用完整错误和恢复门禁；图片来源和部署 SHA 进入运行器冻结源。诊断挂载不提供正式纯原版资格，不放宽错误门槛。保存处境受压力注入污染，禁止晋级正式行为输入。

### 准备结果与不同状态校准登记

上述准备实机运行报告为 `tools/out/decisions/a1-safety-20261015/preparation/20261014-163039/report.json`：严格十类错误为零，无未分类错误、Mod 错误、挂载差异或恢复错误；快捷键 5、空格、最小化后台均实测通过。推进 92.32 游戏日，归档日期 1836.5.1。两国风险在日志中进入，但原版财政状态随后变化，不能证明保存点仍有两国风险；原定两国状态存档出口未通过，不运行依赖它的关闭臂。

新的独立问题只校准同名状态的序列化与引擎 TTL，不改变财政或外交。计划 `v01-a1-ttl-state-20261015`，最多两个场景、各一组；每臂最多四游戏月、墙钟 1200 秒，最低可用内存 4096 MiB，继续计入既有错误停止规则。`seed` 场景载入相同英文输入，用实际 disabled ZIP 和兼容生命周期 ID 的仪器，一次写入 RUS/PRU 的 `sitai_fiscal_risk`，TTL 从真实 Policy 读取为 62 天，私有 seeded 标记禁止续期；目标一月并保存。只有实际保存状态和两国首样本确认才进入 `disabled` 场景：同版本重载新保存点、同 disabled ZIP，仪器去掉全部状态写入，连续读取四月。正例要求两国风险 `yes→no` 且不复现；缺序列/缺国、任何引擎/挂载/恢复错误继续失败。这只验收存档 TTL，不代替真实财政条件或行为质量；新增源与前次压力注入明确不同，原失败不追认。

`seed` 实机报告 `tools/out/decisions/a1-safety-20261015/ttl/seed/20261014-163846/report.json` 通过，实际推进 57.88 游戏日，含启动速度验证造成的额外推进，不能写成精确一个月性能样本。两国样本均为 `yes,yes`，实际保存点为 1836.4.1，SHA-256 `b71a765aaef4ea40a99f11753f368f03ad436714a7e9572099725cc6ac7835cf`。利用既有 SAV 记录字节范围定位，RUS（ID 3）、PRU（ID 5）各有一个状态 flag；记录中的 `tick=29/27` 保留原值，不把未校准的序列化单位当作计时真值。

`disabled` 实机报告 `tools/out/decisions/a1-safety-20261015/ttl/disabled/20261014-164423/report.json` 通过。它使用 seed 原件、英文、实际全关 ZIP 和完全只读的兼容观察器；RUS 序列为 `yes→no→no→no`，PRU 为 `yes→no→no→no→no`，两国均观察到退出且未复现。严格十类错误均为零，未分类错误、Mod 错误、缺失/额外挂载、清理错误均为空，挂载 24 项，流水线 249.736 秒；这只证明同名状态的保存、读取和 TTL 退出，不能换算精确过期日或行为质量。

关闭后财政干预立即停止，已有存档变量最多按剩余 TTL 退出；这不是立即删除存档状态，也不能撤回已经发生的外交行为。源仍显式开启实验候选，缺失/非法开关直接失败；交付默认全关，实验候选必须显式选 `current`。A1 的开关、包契约、加载、状态退出和恢复出口已具备独立证据；最终工程回归另报。

当前包仍是 `experimental`，尚未取得 G1 pilot、M3 合格行为配对、行动代价/不利结果或 M4 正式候选证据；不能把 A1 记为 V0.1 完成，也不能把包加载成功写成 AI 行为质量通过。

下一步补齐 A1 实机边界，同时推进 A3 的受支持质量观测和正反例回放。A2 当前检查点目录盘点没有正式合格输入；不依此停止独立校准。
