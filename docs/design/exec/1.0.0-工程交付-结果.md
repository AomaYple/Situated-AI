# Situated AI 1.0.0 工程交付结果

> 日期：2026-10-22。证据类型：`static_check`、`snapshot` 和 Python 工具实测。本轮没有启动游戏。
> 对应计划：[1.0.0 交付计划](mod重设计-实施计划.md)。Git 合并收据以本次 PR、CI 和合并提交为准。

## 交付内容

生产源统一为 `mod/decisions/*.toml`，由 `decisions.py`、`decision_rules.py`、`decision_adapters.py`
和 `distribution.py` 完成生成、原版接口核对和 ZIP 交付。保留原版资格、成本和行动执行，只修改 AI 倾向；
Python 不进入游戏运行期。锁定 Victoria 3 `1.14.5`，底本 revision 为
`9f8281a37e85639359b3b0c2c5df0196e975ca4b`。

当前生产合同登记 93 个字段作者、60 个原版字段、20 条信息规则、38 个消费者、1120 条消费者规则和
6 个战略意图。这些是生成合同的规模，不表示引擎已经实际执行这些规则或产生了预期行为。
包内覆盖本体 11 种语言，键集合、占位符、语言头和路径通过工程检查，英语回退列表为空；实际语言呈现和
译文质量仍由用户审阅。

已删除旧 `mod/data/`、`mod/legacy/`、旧实验生成器、长期 GUI/行为/压力实验链及其专属测试；保留生产
生成、原版全量静态分析、快照、离线合同、仓库卫生和资源测量工具。内存采样器统一迁至
`tools/ci/mem_baseline.py`，冻结原件仍保留。历史审计、报告、原始游戏资料和冻结证据不改写当时事实或原始字节。
规则、贡献指南、README、手册、导航和当前计划同步到这一交付边界。

这与有游戏完整回归的选择集不同，不能直接比较耗时。它们不是已经运行通过的测试。
前序完整回归曾因退役合同断言、Ruff 正则别名和格式检查失败；已修复并复跑受影响集合及上述完整回归。
Ruff 默认缓存曾遇到本机 `os error 5`，最终使用相同规则的 `--no-cache` 完成检查，没有跳过检查或放宽规则。
最终将 mypy 目标试降至 3.11 时，本机可选 numpy 类型桩仍因 3.12 `type` 语法中止；已恢复既有 3.12
类型检查口径并复验，最低 3.11 运行时兼容性仍以真实解释器矩阵为准。
本次 PR 首轮 CI 暴露了离线合同仍调用原版消费者重生成的问题：无游戏 runner 因缺少锁定原件失败，
同时有一项文档合同断言失配。修复后引入 `mod/generation-lock.json`，冻结源码、TOML、底本和生成物的
逐字节哈希；离线门禁拒绝任何漂移，检查语法与快照接口。它不证明当前游戏内容，也不进入发布 ZIP。
生产 `modgen --write/--check` 和 `package` 继续要求锁定原版；缺失时硬失败并保全旧输出，不能用冻结产物
静默重建。真实依赖原版的用例逐项标记为集成测试；离线继续覆盖打包原语、源码/产物漂移和拒绝分支。
修复定向回归 167 通过、3 跳过，随后完成上述无游戏离线回归、baseline 和完整回归。
离线日志为 `tools/out/ci/offline-no-game.log`、`tools/out/ci/baseline-no-game.log`；
首轮 CI 失败日志保留在 `tools/out/ci/remote-logs/`，最终远端结果以本次 PR/合并提交为准。

## 交接边界

静态解析、原版字段证据、快照、生成合同和 Python 回归不能保证所有引擎运行期语义都正确，也不能保证游戏
永不报错。本轮没有启动游戏，没有新增国家行为、平衡、后期性能、跨平台 GUI、存档迁移或创意工坊发布证据。
上述长期验收由用户在标准包上完成，发现问题后按包版本、存档、原始日志和最小复现修复。
三平台 Python CI 与最终 Git 状态以本次 PR/合并提交的检查记录为准，不能借用历史绿色记录。
