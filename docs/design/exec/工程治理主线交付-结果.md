# 工程治理主线交付结果

## 范围与交付修正

本轮为工程治理，不开发 Mod 功能。主线基准为 `9a3a7a6`，生产版本仍为 3.2.0，
游戏底本仍以该版本的生成锁为准；没有恢复 A3/A4 产品计划，也没有发布或部署新版本。

首次治理在未完成候选分支上进行，其 PR #92 包含 36 个先前未合并产品提交。
最终 CI 出现大量产品合同失败，不能按工程治理名义混入主线。
候选及此前治理完整保留在 `codex/repository-governance` 的 `d6274ad`，失败证据保留，不重签历史身份。

本次从主线独立提取并适配规则、构建、资源、卫生与检查入口修正，不复制候选生产源、生成锁、
研究底本或产品验收结论。候选中的损坏链接审计、Steam 类型和条件风格修正保留在候选；
主线没有这些源码修改，避免缺少旧版游戏时伪造生产重生成。

## 工程改动

- 规则职责与提交边界统一；治理不自动启动产品计划，未完成候选不夹带进入独立治理交付。
- wheel 使用临时源码副本构建，检查模块集合与原始字节、重复 ZIP 路径及 CRC，构建目录自动回收。
- 卫生工具拒绝不存在或非目录根，不跟随符号链接和 Windows 重解析点，读取失败显式报告。
- 资源前置门禁在没有其他重型进程时仍检查可用内存，预算与运行保护线保持。
- 内存插件原样传播 unittest 的正常跳过，不再把它误记为夹具失败；实际夹具异常仍记录并传播。
- 统一检查入口通过 `-B` 与环境变量阻止嵌套 Python 写入字节码；新增实际子进程回归。
- 删除无依据的“所有魔法数字均为游戏实测值”说明，精简重复配置注释；测试选择、断言和 CI 必需门禁保持。
- Ruff 统一为原 Windows 锁文件已有的 0.16.7，CI 从项目 dev 声明安装，避免本机与 CI 浮动版本分歧；不更改规则列表或豁免。
- 当前工作清单区分主线、未完成候选和用户反馈；不把历史归档进程写成当前仍在运行。
- Dependabot #93/#94 的 CodeQL init/analyze 补丁统一为 4.39.3；完整提交 SHA 与上游正式标签核对一致。
  GitHub Actions 更新按组提出，避免同一 Action 的 init/analyze 分别创建 PR；合并后核对替代关系并清理机器人旧分支。

## 验证与状态

定向离线工程回归 77 passed、2 deselected；baseline 全部步骤通过，包括 43/43 快照断言、173 张生成表、
离线生产门禁、9/9 领域决策合同、AI 可执行面与引用审计。mypy 检查 385 文件通过；
Ruff 0.16.7 检查与格式、源码编码和差异检查通过；实际 wheel 精确包含全部 123 个源码模块及原始字节。
早期 Ruff 缓存出现写入错误，使用不写缓存的标准参数重跑同一规则检查通过；没有增加豁免。
完整回归使用标准工具生成 JUnit、覆盖率、测试身份与内存报告，结果写入忽略的 `tools/out/test-runs/`；
最终 CI 与合并状态以治理主题分支对应的 GitHub PR 检查为准，不以定向检查代替完整回归。
规则、文档与工具改动不能单独证明 Mod 行为质量。
本机当前游戏为 1.15，主线生产锁定 1.14.5；本次使用离线工程合同，不从新版游戏重生成旧版生产文件。
完整回归的前两次调用分别发现自动读取了新版游戏，以及无游戏根位于共享输出树造成环境分类错误；
两次诊断的失败和主动停止原因均保留。最终使用共享输出树之外的显式缺失游戏根，保留原有 integration 跳过机制；
相关共享写入扫描用例已在该环境定向通过，没有修改扫描、增加白名单或删除测试。

固定提交 `1cef1d8` 的完整运行历时 933.98 秒，2 workers，6485 passed、4220 skipped，无断言失败或错误；
跳过分类为 game 4203、environment 8、artifact 6、platform 3，无未知原因。
完整验收仍为失败：覆盖率 76.56% 低于原 86% 门槛，doc_tables/verify 模块下限也未满足；
此外 unittest 正常跳过被采样插件误记为错误，导致内存证据门禁无法判定。后者已补复现并修正，原始报告保持不变；
修复后的工具回归 117 passed；真实子进程分别验证正常跳过不记采样错误、实际夹具异常仍非零退出。
覆盖率门槛、测试选择和断言不变，没有旧版游戏时不声称完整验收通过。
本次独立治理按改动域回归、离线合同、源码字节保持和三平台必需 CI 验收；
锁定旧版游戏的集成覆盖与完整覆盖率验收仍受环境限制，不转写为 Mod 功能或行为完成。

旧工作区 30 个可再生缓存目录的删除命令被执行策略拒绝；本轮对单一绝对缓存路径再次使用原生删除，

候选分支和历史证据保持；没有改动用户游戏目录。
