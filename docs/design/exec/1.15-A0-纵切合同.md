# 1.15 A0 三纵切合同

本页冻结 A0 的三个候选消费者及其证据边界。它是后续接线的合同，不证明 1.15 已经接入生产，
不继承 1.14.5 的作用域、零值、终止条件或执行证明。静态底本以本机 1.15.0 原始字节为输入，
文件 SHA、版本身份和逐项位置由 `tools/out/version-1150/inventory.json` 及本页配套产物绑定。
`A0-ECON-ROAD`、`A0-POL-SCHOOLS`、`A0-DIP-RELATIONS` 是稳定合同 ID；政策阈值只能在后续唯一生产源维护。

## 共同接入边界

| 项目 | 合同 |
|---|---|
| 冻结写点 | 仅下述三个完整源路径与精确字段；同文件其他定义和字段不是允许写点 |
| 观察时点 | 原版调用该消费者的这一次求值；不创建新轮询、事件扫描或定时国家 tick |
| 观察 TTL | 本次消费者求值；跨求值不缓存国家、州、目标或费用状态 |
| 刷新 | 消费者即时读取是拟采用的模型；引擎实际调用频率、刷新调度均为 `runtime-unknown` |
| 原子性 | 同一项贡献只使用同一 actor、同一具体 target、同次求值的事实；不得拼接不同州或不同双边对 |
| unknown | 缺对象、缺 scope、不可读、失效或未重证均为 unknown；只撤回依赖它的新贡献，原版算式继续 |
| 开关 | 模块关闭与非 AI 路径保持原版结果；未经证明的 actor 归属不接入新贡献 |
| 外部状态 | 仅观察现有游戏事实；不得把假想资源预留、行动成功概率或未执行的利益写成已实现状态 |
| 证据等级 | AST、官方注释和脚本用例分别记录；它们不能替代实际消费者运行语义或游戏行为 |

A0 不发布参数或新评分实现。后续适配必须保留原版数值运算顺序、资格、费用、随机机会、零值、
执行与退出路径；不能把乘法、除法、加法、覆盖或截断混成统一权重。任何涉及零值的具体行为均须
逐消费者重证；“零中性”不是通用前提。字段存在或语法可解析也不是“合法可写”的证明。

## A0-ECON-ROAD

候选消费者为 `game/common/decrees/00_decree.txt` 的 `decree_road_maintenance.ai_weight`。
该文件 1–8 行原版说明将 modifier 作用州、解锁科技所属国家、AUT 施加成本和 AI 权重区分开。
同一消费者 84–87、93–96 行在 `scope:country` 读取国家日志，同时在当前 root 州读 `is_capital`；
102–105、121–124 行将国家的 home-state 变量与 root 比较。这些是当前原版的静态作用域见证：
actor=`scope:country`，target_state=`root`，不通过 owner 猜测决策者。

| 角色/读数 | 具体合同与来源 | 当前证明边界 |
|---|---|---|
| actor | `scope:country`；同消费者国家日志和变量读取 | 静态绑定明确；每次求值实际国家、调用时间与重复次数为 runtime-unknown |
| target | 当前 root 州，候选固定 `decree_road_maintenance` | 国家变量与 root 比较保持精确同一州，不枚举全国所有州 |
| `A0-FACT-RELATIVE-INFRASTRUCTURE` | 原版同 ai_weight 的 `relative_infrastructure`（28、42、56、70 行附近） | 当前同消费者读取已静态证明；精确数值定义与刷新仍待运行验证，不替换为旧 infrastructure_delta |
| `A0-FACT-ROAD-DECREE-PRESENT` | 原版同 ai_weight 的 `has_decree=decree_road_maintenance` | 当前同消费者存在性读取已静态证明；不等于新行动已执行成功 |
| 国家利益 | 原版 `scope:country.has_journal_entry`、home-state 变量及州 `is_capital` | 仅保留原版利益输入；不新增写国家变量、日志状态或州归属 |

利益 ID 是 `A0-OBJ-LOCAL-INFRASTRUCTURE`：同一州真实基础设施需求与地方建设能力，保留原版国家
首都、家乡州与日志任务利益。modifier 明示基础设施人口加 1/最大加 20、州建设 +0.10；原版解锁
centralization、cost=100 AUT。不能由成本定义推断 actor 可读 authority 余额、当前财政或实际支付能力；
这些新事实不在此纵切的已证明读数内。

原版 ai_weight 基值 25；三个基础设施不足级别分别加 100，按当前州是否已有道路法令采用不同条件；
富余分支乘 0。后面还有国家内容例外加 1000 与乘 1.5，因此这里的乘 0 **不是整个消费者的终止零**。
必须保留完整 `ai_weight` 的运算顺序、所有内容例外、国家利益与每个尾部；不得把后续例外移到新贡献
之前或剪掉。modifier、解锁、成本、country/state trigger、其他 decree 定义在写点之外。

官方原文称 ai_weight 决定 AI 得到 decree 的 chance；这支持“偏好机会”的静态用途，不证明归一化
概率、候选比较器、零值最终裁决、平手、每次求值频率或行动执行。A1 可据同消费者明确 scope 与
读数准备有界局部贡献，仍须逐操作验证生成顺序和未知事实退出；不把原版内层乘零改成永久禁用。

最初勘察的 `building_railway.ai_value` 被移出冻结写点：`buildings.md:49–52` 只给州 scope，而
建筑组还存在外国投资系数，州 owner 不能替代实际投资/建设 actor。该旧规则仍在 migration.json
中待重证；此次换用具有明确 actor 与州同消费者见证的道路法令，不迁移铁路权重或猜测其国家归属。

## A0-POL-SCHOOLS

候选消费者为 `game/common/ai_strategies/00_default_strategy.txt` 的
`ai_strategy_default.institution_scores.institution_schools`。对应利益 ID 为
`A0-OBJ-EDUCATION-CAPACITY`：国家当前识字与制度承载需求，分别观察财政、行政代价和政治议程。
不以低识字直接宣称学校能建、大学能提高识字或某项投资已成功。

| 角色/读数 | 具体合同与来源 | 当前证明边界 |
|---|---|---|
| actor | 当前策略所服务国家；root 国家是旧合同并有当前政治策略的国家日志任务用例 | 同学校分量真实国家日志读取支持 country root 静态形状；实际调用时机仍未知 |
| target | 同一 actor 的 `institution_schools` 类型 | 不是另一个国家或另一个州；不得用普通 `target_country` 名称代替 |
| `A0-FACT-LITERACY` | 旧 reader `literacy` / `literacy_rate`，比例；当前行政策略有读取例子 | 当前消费者中的合法读数待重证；需求与能否负担分离 |
| `A0-FACT-SCHOOL-AGENDA` | 同学校评分块 `has_journal_entry=je_tp_pool_educational_reform` | 可供 A1 消费的最小静态国家利益观察；country root 来自当前脚本用法，未声称引擎实测 |
| `A0-FACT-SCHOOL-LEVEL` | 旧 `schools_investment` / `institution_investment_level`，参数 `institution_schools` | 当前 `00_strike_triggers.txt:30–43` 是工作安全和社保制度的参数形状，不能充当学校参数已证明；存在性也不是行动成功 |
| `A0-FACT-FISCAL-PRESSURE` | 当前原版 `in_default` 使用；旧财政读数及其定义在迁移清单保留 | 实际 default 与净盈余必须分别重证；不把余额当可预留预算 |
| `A0-FACT-BUREAUCRACY` | 旧 `bureaucracy` 及当前脚本中的同名国家读数 | 行政不足只影响依赖该事实的新贡献，不统一关闭全部发展路径 |

默认策略的学校基值为 10。原版注释 `00_default_strategy.txt:1586–1587` 明确：其他策略的制度评分
会加法合并。当前政治策略中保守议程的学校分量为 100，教育改革日志任务可乘 2；坦志麦特议程有
1000 的学校分量。完整所有策略定义及其同名字段应由 scanner 的条目追踪，不能只考虑默认策略。
目前没有已验证的“学校分量 −10”证据。

因此，在默认项上乘一个因子只改变默认项，并不乘最终所有活动策略合计值。后续若只改本合同写点，
必须将行为命名为“默认分量的有界改变量”，保留其他活动议程的加法贡献。若需求改为修改最终合计，
必须先重开写点范围、证明实际活动策略与合并关系，不能偷偷增写所有策略。制度投资比较器、零值、
负值、平手、随机机会、实际支出与更新调度均未获得 1.15 运行证明。

旧 `remaining_school_catchup_need`、`remaining_school_fiscal`、`remaining_school_administrative`、
`remaining_school_capacity`、`school_default_pressure`、`school_administrative_pressure` 保留为旧 ID，
分别重证需求、财政与行政依据，不能整组继承为统一容量门。投资资格、法律/制度存在、最大等级、
行政费用、实际支出与原版执行不由新评分绕过。

## A0-DIP-RELATIONS

候选消费者为 `game/common/diplomatic_actions/00_relations_actions.txt` 的
`increase_relations.ai.propose_score`。利益 ID 为 `A0-OBJ-BILATERAL-SPACE`：在当前国家与精确对手之间
保留合作空间，观察原版关系、态度、地区目标与行动代价。它不是旧生产中已有同字段规则的自动迁移；
当前旧 adapter 中没有该精确写点规则。

| 角色/读数 | 具体合同与来源 | 当前证明边界 |
|---|---|---|
| actor | `diplomatic_action.md:118` 称 AI country 总是 root | 只在原版该消费者求值时读取，不产生新的外交对象扫描 |
| target | 具体 `scope:target_country`，原版同 propose_score 反复采用此名 | 静态冻结采用实际脚本名称；官方同段 scope:target 只作说明别名，不新造第二对象 |
| `A0-FACT-DIPLOMATIC-ATTITUDE` | 同 propose_score 的 `has_attitude`，who 为精确 `scope:target_country` | 可供 A1 消费的最小静态双边利益观察；保留原版态度来源和触发顺序 |
| `A0-FACT-BILATERAL-RELATIONS` | 当前 pact requirement 原文 `scope:target_country.relations:root`；旧 reader `target_relations` / `relations:root` 位于 target_country | 必须保持方向与 actor-target 对；pact requirement 中使用不自动证明 propose_score 中合法 |
| `A0-FACT-FISCAL-PRESSURE` | actor 的当前财政压力，依赖前述来源 | 只是对既有承诺代价的局部考虑，不宣称共同预算扣减或资源预留 |
| 原版利益来源 | 地区 befriend/protect 目标、protective/conciliatory 态度、夏威夷日志任务、目标国家等级、属国关系 | 各项原版语义和非默认策略产生的输入保持完整；新规则不覆盖国家态度或地区目标 |

原版基值 5；地区目标加 20，protective 加 5，conciliatory 加 20，夏威夷日志任务加 20，
目标等级乘 3 后加入，满足属国关系再乘 2。必须按现有顺序保留完整链。
`diplomatic_action.md:140` 只说明 propose_score 用于具体交易的优先级；不能据此推断零值拒绝、
最高分必选或概率分布。该动作 `requires_approval=no`；通用文档中 accept_score 正值接受的说明
不能套成该动作的额外批准要求。

`evaluation_chance` 的 0.5、最多影响力支出占比 0.25、`will_propose`、`will_break`、潜在/可选/可行
条件、维持条件、和平、外交相关性、非去中心化、驱逐外交官、关系上限和 pact cost 150 均在冻结写点之外。
同一 propose_score 反复读取 `scope:target_country`，据此冻结此实际名称；文档的 scope:target 是说明别名，不将它另设为可读对象。原版文档明确 evaluation_chance 只对提议者求值，没有目标数据；禁止把双边 reader 放到这里。
完整动作退出与保持尾部应保留到该定义结束，不能只保留 propose_score 的相邻几行。

## A0-BUDGET-LOCAL-ONLY

预算按一次引擎已选消费者与候选的求值计数；全量离线扫描与运行时预算分开。三条纵切每次只接收
一个原版已给候选，不新枚举候选、不做跨候选笛卡尔积；静态 tag 全列并不意味着运行时全世界扫描。

| 新增开销项 | 冻结上界 | 依据 |
|---|---:|---|
| 全局扫描 | 0 | 只消费本次引擎给定对象 |
| 候选扩展与候选笛卡尔积 | 0 | 州/制度类型/双边对象已确定 |
| 每次选定候选数 | 1 | 本合同精确消费者身份 |
| 新增 scope 路径跳数 | 1 | 精确 scope:country 或原版已绑定双边对象；不追踪 owner 冒充 actor |
| 新增 iterator 嵌套 | 0 | 不增加 any/every/random/ordered 遍历 |
| 新增块深度 | 3 | 单层 AI/开关 guard、局部事实条件、一个有界贡献所需形状 |

`static-baseline.json` 机械记录当前三消费者与存在的旧冻结对应字段的实际深度、节点数、重复键和
查询形状，用作后续差异基线；原版已有扫描保持原样，不赋予新代码额外扫描额度。该 +3 是合同设计
上界，不是观察到的引擎性能极限；后续生成器须验证实际差异，并结合每消费者的原有规模检查增长。
需要更深表达式或第二候选时必须先变更合同与证据。运行时耗时、求值频率和总体开销为 unknown。

## 机械清单、逐国覆盖与复算

唯一生成入口为 `tools/ci/architecture_inventory.py`，读扫描器 `inventory.json` 后输出：

| 产物 | 内容与解释 |
|---|---|
| `migration.json` | 所有旧 TOML 的 reader/rule/action/relation/strategy/intent/绑定/初始化写入声明，以及实际冻结编译器展开的 reader、action、writer、物理消费者与冻结原版策略 ID；保留源路径、指针和命名空间 |
| `observation.json` | 每个静态国家 tag × 三纵切，另加动态国家通配三行；事实来源、scope、即时读取、TTL、刷新、预算、利益、接线状态逐行明确 |
| `actor-objectives.json` | 三个利益目标来源及逐国目标映射；不复制政策阈值，不依据当前可达性删国家 |
| `static-baseline.json` | 当前原版与旧冻结产物的字节、SHA、块深度、赋值、重复键和查询形状；不存在的旧外交写点标 absent，不能当零成本 |
| `configuration-baseline.json` | 构建期 TOML/加载器/生产 profile 的现存入口与源身份，以及当前安装语言头、目录、注册来源；新 1.15 配置与键尚未实现 |
| `cost-baseline.json` / `cost-*.log` | `--measure` 时串行采集命令墙钟、命令进程树 RSS 与完整输出，明确样本身份与失败 |

迁移清单所有项默认 `pending_reproof`，`automatic_inheritance=false`。旧声明中的 migrate、合并、移除
或原版保留字段只保留作来源，不作为 1.15 结论。reader 同名但 scope/参数/原始来源不同必须保持独立；
派生规则不得被原始 TOML 的少量模板数替代。逐国相同静态模板是完整枚举，不是运行覆盖：
`runtime_observation=unknown`、`consumer_wiring=not_connected_1.15`，不得表述为已接入。

全量扫描的 DNA、portrait 解析限制、第三方许可证非 UTF-8 与语言注册文件形式问题保留并分类影响。
所选脚本有任何解析失败就阻断对应合同；所选三脚本无失败时，其他分类只限制其自身覆盖，不隐瞒、
不据此宣称全底本无错误，也不要求在 A0 修复第三方文件。

复算（本地实际游戏根目录作为参数，不启动游戏，不改生产或冻结锁）：

```powershell
.venv/Scripts/python.exe -B -X utf8 tools/ci/architecture_inventory.py --game-root 'C:/Program Files (x86)/Steam/steamapps/common/Victoria 3' --inventory tools/out/version-1150/inventory.json --measure
```

成本中的离线 model build 构造旧冻结 IR，不是本机 1.15 重生成。旧 `modgen --check` 读取本机 1.15
预计按版本锁硬失败；真实失败输出必须保留，不能刷新旧哈希或从冻结生成物回退后宣称生成通过。
RSS 以命令根进程及其子进程之和采样，排除观察器，采样峰值是下界；样本不同不能据数字宣称加速。
这些成本只证明离线工具成本，不证明游戏内性能。

工具消费前重算扫描器自指纹、核对 schema/1.15 版本与扫描器源码身份，并逐源核对所选消费者、事实、
国家定义与版本身份当前字节；缺失、重复、局部解析失败或漂移显式拒绝。重复 JSON 键、越界输入源、
输出指向游戏安装或受控源目录也拒绝。成本子进程显式使用参数安装根作为 `V3_ROOT`。

配置选择构建期入口，不预设新增游戏 UI：现有 `mod/decisions/fiscal.toml`、`extensions.toml`、
information/adapters/country_state 的开关由 Python 加载；发布 profile 会覆盖开发默认开关，
不能只改 enabled 就宣称发布已关闭。旧加载器明确锁定 1.14.5，因此这里只确认可复用的工程入口，
1.15 的核心/模块类型、默认值、有效组合与产物行为由 A1 另建唯一来源。原版语言设置入口仍未证明；
本机语言目录与头及注册来源是独立静态分母，不从旧 DEFAULT_LANGUAGES 继承。自有键、占位符、路径、

本页已冻结三纵切的静态 actor/target 形状及各自最小可读事实；辅助学校财政/行政/识字、制度等级与
双边关系读数的上下文合法性或数值定义仍需补链。全盘扫描中的非 ai 字段、间接引用、scripted value
及引擎不可见消费者的完整语义分母仍未证明；不能以 17348 等候选数作为完整消费者总数。动态国家

明确处置，不能以本页和矩阵存在就关闭整个 A0。

本页的静态冻结、未知语义清单、全旧身份处置、逐国来源与成本基线可形成 A0 交接证据。A1 后续仍须
