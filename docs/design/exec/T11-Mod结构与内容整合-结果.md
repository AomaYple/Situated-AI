# T11 Mod 结构与内容整合、更新、清理和优化结果（历史 1.2.0 基线）

> 日期：2026-10-27。证据类型：静态检查、生产源审计和包输入审计。
> 本页记录上一轮 1.2.0 基线的结构收口，不把静态结果写成游戏行为或数值体验通过。当前候选见[1.3.0 阶段收口](阶段收口-1.3.0-结果.md)。

## 本阶段范围

本次按新的计划边界检查生产源、生成物、Python 生成器、测试、文档入口和发布包输入。长期游戏运行、AI 行为质量、数值平衡、
游戏内性能、本地化呈现和 Workshop 体验由用户在固定包上验收，不属于本阶段静态门禁。

## 收口结果

- `mod/decisions/*.toml` 仍是唯一生产源；`mod/common/`、本地化、metadata、manifest 和 ZIP 只通过 Python 生成器维护。
- 生产 Mod 身份统一为显示名 `Situated AI`、Mod ID `situated-ai`、PDX 资源前缀 `sitai_`，原版底本锁定为 Victoria 3 `1.14.5`。
- 生产文件与工程文件分开；`generation-lock.json`、Python、报告、快照、日志、缓存和历史实验不进入标准包。
- 现有决策规则保持字段级唯一作者、原版资格/成本/概率/失败路径和未知回退；没有新增重复字段作者或全世界扫描。
- 观察、存档和快照工具保留为用户反馈辅助能力，不进入发布包，也不作为长期验证门禁。
- 忽略规则继续只覆盖虚拟环境、缓存、工具输出、发布 ZIP 和本机运行态；跟踪的快照与历史证据按原始字节保留。

## 明确未改动

当时生产基线是 1.2.0 的局部多因素协调；本页不描述当前 1.3.0 的新增国家状态和路线。长期行为、数值和游戏内性能由用户外部验收，不能从结构收口推断为已实现。
