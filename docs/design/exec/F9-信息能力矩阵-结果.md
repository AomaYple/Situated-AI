## 结果

- 信息目录发现 329,929 个唯一条目；本地化入口扫描 2,177 个文件、1,172,063 个键。未能建立可靠合同的信息保持 `unknown` 或 `unsupported`。
- 所有目录条目都有静态处置：353 个连接到候选目录 ID、2,177 个仅作解释的本地化条目、317,720 个没有可证明的 Mod 消费者、9,664 个保留原版行为、15 个解析或接口不支持。处置是当前规则和范围的说明，不代表所有信息都可在游戏运行期读取。
- 候选报告包含 1,179 条规则连接、353 个唯一信息 ID、0 条未解决的规则连接。规则连接与唯一信息覆盖分开计数；同名或路径连接不升级为运行期证据。
- 当前信息合同仍有 324,189 项作用域未知、327,737 项单位未知。它们没有被推断成安全的生产输入；新增规则仍须先证明来源、作用域、单位、消费者、未知回退和成本。
- 生产与离线情境审计均为 9/9 域、765 个读取器、1,146 条规则、375 个字段，输出逐字节一致；审计类型为 `static_generated_contract_only`，`behavior_verified=false`。
- F9 未修改 Mod 行为、生产包或版本，继续复用 `1.1.0` 候选。JSON、快照和压缩逐项清单均是 `tools/out/` 中的可再生产物，没有将本机大文件加入 Git。
