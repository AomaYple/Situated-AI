## 当前工作树与历史包

当前主线生产源已提升为 `1.4.0`，`v1.4.0` 标签和 Pre-release 已公开，附件包含按合并提交重建的标准 ZIP 与 SHA-256 校验文件；`v1.3.0` 标签和 Release 保持不可移动，作为历史交付基线。当前 `dist/` 包是可再生忽略输出，不能替代 Release 中按标签冻结的包。需要复现任一交付时，应切换到对应标签并运行仓库声明的生成、锁定和打包命令。

`v1.0.0` 保留当时的 Mod ID `sitai.decisions`；`v1.0.1` 及以后使用 `situated-ai`。显示名和安装目录均为 `Situated AI`，内部脚本前缀为 `sitai_`。

## 验收边界

标签、Release、包 manifest、路径、编码、语言集合和 SHA-256 只证明交付物身份与静态工程合同。它们不证明 AI 在所有国家和时段的行为质量、历史合理性、数值平衡、长期性能、存档兼容、本地化呈现或 Workshop 体验；这些事项由用户在固定包上验收，反馈再回到当前计划。
