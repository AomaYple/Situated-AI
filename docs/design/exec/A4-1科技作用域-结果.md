## 实际修改

新增独立证据 [1.15.0 technology scope](../../../research/situated/victoria3-1.15.0-technology-scope.json)，
SHA-256 为 `1c928bf462a07b399f9058256c1c97cd85cda6a036aea73bac47eae6dcd44336`。
`engine_scope.technology_evidence` 读取该证据，继续核对实际 EXE、所有已登记脚本及冻结的原始字节。
旧 1.14.5 证据保留原始字节；其他尚未完成迁移的消费者没有由此获得新版许可。

字段链为当前 `CTechnologyType` 的 `ai_weight` token `0x53ce`，经过 parser `0x141902b30` 的精确分支，
落入 `+0x68` wrapper、`+0x70` script value；真实 AI 调用 `0x1415d0690` 求值同一成员。
候选来自已核实类型的技术数据库；国家由 RTTI 标识的 `CCountry` lookup 取得，tag5 与实际国家 ID 一起进入上下文。
三个求值 scope 槽均指向同一国家，辅助容器计数为零。没有把技术定义指针授予为可命名的技术 scope。

新版顺序为**资格 → 基础权重 → 成本 → 随机 → 比较/同分选择 → 命令检查与入队**。
资格先于基础权重；旧证据中的相反顺序不再用于当前说明。基础权重为零也不是终结拒绝：
非正随机分支返回中性倍率，后续原版选择仍有自身规则。Mod 不替换这些原版路径。
