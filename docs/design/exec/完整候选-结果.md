本机 `n-auto` 完整回归不计通过：Windows/Python 3.14 与 pytest-xdist/execnet 曾在约 7% 处触发原生 access violation。本批未重复同类无新信息的崩溃；串行结果用于确认正确性，不能推导并行速度或内存收益。完整七模块本轮没有形成新的游戏加载、接口、AI 行为、语言显示或玩家路径证据；这些事项进入 F1。F2 仍需长期/后期/压力、速度、CPU、内存、保存恢复、兼容与正式交付验证。
