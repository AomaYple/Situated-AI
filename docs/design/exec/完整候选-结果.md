## 2026-10-17 实现批次

财政、市场与政治候选继续复用现有实现，新增外部防御模块，并接入同一个默认策略补丁。外部模块使用锁定原版默认策略中的 treaty、相邻、博弈角色与 war goal 用例，保护明确防御方；盟约/防御条约与邻国安全原因取较大权重，评价进攻方时贡献反向。保证独立方向未核实，未接入；没有全世界扫描、强制参战、资源注入或新增持久状态。

package 新增 complete、fiscal、security、market、reform 实验变体；current、control、disabled 保持原含义，默认安全包不变。complete 强制 experimental，组合财政/外部/市场/政治，附原生国家面板只读解释；需要匹配版本本机面板底本，指纹进入交付清单。完整包覆盖默认策略与国家面板，均有明确兼容成本。原版政治路线和法律选择仍由引擎决定，启动节奏不是完整法律规划器。

配置与说明从实际参数生成。财政、政治条件可在国家上下文展示；市场与外部支持需要博弈双方，国家面板没有该上下文时明确不计算本次分数，不伪造实时贡献。GUI 作用域、布局、刷新、隐藏求值及帧成本仍待实机。

### 本地化覆盖

生产与解释候选的语言集合来自锁定的 Victoria 3 `release/1.14.5` 精简快照，共 11 种：`braz_por`、`english`、`french`、`german`、`japanese`、`korean`、`polish`、`russian`、`simp_chinese`、`spanish`、`turkish`。生成器为每种语言输出相同的自有键集、语言头和稳定路径；受影响测试检查重复语言头、未知目录、键覆盖和确定性。

本批实验候选对九种尚未审校的语言使用英语源文本作为显式回退，实际语言写入 manifest 的 `localization.fallback_languages`，不能把它表述为最终翻译质量完成。正式发布前必须逐语言审校、清空回退列表，并在 M2 实机验证每种语言的加载、解释键和保存/重载。`game_auto` 当前只有中英文 GUI 模板，这是自动化覆盖边界，不是 Mod 本地化范围；legacy 历史包仍按双语历史契约维护。

### 定向检查

新增测试先在缺失配置、候选变体、外部生成与完整解释包时失败，再实施。首批 174 passed；解释整合后的联合定向为 206 passed、32 subtests passed。其后格式和静态修正尚须重新验证，不用该数字追认最终源码。

lint 初轮发现循环依赖延迟导入风格和两处复合断言，已改为模块级导入与独立断言；最终静态、baseline、完整回归、成本和 ZIP 指纹在实际执行后追加。没有实机或质量通过结论。

引擎版本现场仍为 Victoria 3 release/1.14.5；首次资源查看约 7.17 GiB 可用，无 Victoria 3/cargo/rustc/link 进程。它只是准备时快照，不是游戏内存测量或启动许可。旧响应/解释的同输入累计停止保留；新实机仍需先核验合法来源、环境、账本和资源。

## 候选冻结前复核与修正

首轮完整覆盖率为 3930 passed、20 skipped、1 failed、1743 subtests passed，pytest 659.79 秒，总覆盖率 89.49%；整体和核心覆盖下限通过，但该轮不是测试全通过。唯一失败是规则测试仍锁定旧速度附件 2.4 的 P0/R 排期，现已改为检查用户要求的新主计划顺序，继续保护 M3-A/M3-B、累计停止、vanilla 噪声、unsupported 与历史 G1 扫描原件。

随后补充直接调用/配置超大整数反例，先复现 OverflowError，再将有限权重范围判断放到浮点有限性转换之前，稳定按配置错误拒绝。自复核又发现 package 的帮助已列新变体，CLI Literal 仍只允许旧三种；新增真实 Typer 命令路由反例先失败，修正后全部八种变体与实际 CLI complete 打包通过。相关五文件定向为 159 passed，230.29 秒；不是完整回归耗时。

最终回归前，一次辅助 JUnit 参数未正确引用含空格路径，导致零用例运行，退出失败；错路径 XML 已移入本批忽略证据目录，没有纳入源码。另一轮在发现 CLI 缺陷后于 252.24 秒主动结束本任务拥有的测试子进程，退出 15，不计通过。最终回归改用 covgate.run_pytest 的独立参数传递和 cov --check-only，不继承共享 PYTEST_ADDOPTS 报告路径。原日志分别保留，失败与中止不由后续成功覆盖。

lint、格式和 mypy 已复核；mypy 检查 217 个源文件。离线 baseline 通过：43 条快照断言、生产 5/legacy 69 个生成物、976 条引用及 2409 个定义的死代码审计。完整回归最终结果在实际结束后追加。
