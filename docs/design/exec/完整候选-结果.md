# 完整候选实现与集中验证结果

本页记录[主计划 3.0](mod重设计-实施计划.md)的实际实现、检查和实机结果，不另建计划。2026-10-17 以前的 A1–A5/M1–M5 结果保持原范围，历史失败与账本不变。

## 2026-10-17 实现批次

财政、市场与政治候选继续复用现有实现，新增外部防御模块，并接入同一个默认策略补丁。外部模块使用锁定原版默认策略中的 treaty、相邻、博弈角色与 war goal 用例，保护明确防御方；盟约/防御条约与邻国安全原因取较大权重，评价进攻方时贡献反向。保证独立方向未核实，未接入；没有全世界扫描、强制参战、资源注入或新增持久状态。

package 新增 complete、fiscal、security、market、reform 实验变体；current、control、disabled 保持原含义，默认安全包不变。complete 强制 experimental，组合财政/外部/市场/政治，附原生国家面板只读解释；需要匹配版本本机面板底本，指纹进入交付清单。完整包覆盖默认策略与国家面板，均有明确兼容成本。原版政治路线和法律选择仍由引擎决定，启动节奏不是完整法律规划器。

配置与说明从实际参数生成。财政、政治条件可在国家上下文展示；市场与外部支持需要博弈双方，国家面板没有该上下文时明确不计算本次分数，不伪造实时贡献。GUI 作用域、布局、刷新、隐藏求值及帧成本仍待实机。

### 定向检查

新增测试先在缺失配置、候选变体、外部生成与完整解释包时失败，再实施。首批 174 passed；解释整合后的联合定向为 206 passed、32 subtests passed。其后格式和静态修正尚须重新验证，不用该数字追认最终源码。

lint 初轮发现循环依赖延迟导入风格和两处复合断言，已改为模块级导入与独立断言；最终静态、baseline、完整回归、成本和 ZIP 指纹在实际执行后追加。没有实机或质量通过结论。

### 当前证据边界

引擎版本现场仍为 Victoria 3 release/1.14.5；首次资源查看约 7.17 GiB 可用，无 Victoria 3/cargo/rustc/link 进程。它只是准备时快照，不是游戏内存测量或启动许可。旧响应/解释的同输入累计停止保留；新实机仍需先核验合法来源、环境、账本和资源。

实现、实机运行、行为质量和最终交付分别更新。旧 G1/M3、unsupported/null 和 V0.1 未完成状态不因新代码或 ZIP 改变。
## 候选冻结前复核与修正

首轮完整覆盖率为 3930 passed、20 skipped、1 failed、1743 subtests passed，pytest 659.79 秒，总覆盖率 89.49%；整体和核心覆盖下限通过，但该轮不是测试全通过。唯一失败是规则测试仍锁定旧速度附件 2.4 的 P0/R 排期，现已改为检查用户要求的新主计划顺序，继续保护 M3-A/M3-B、累计停止、vanilla 噪声、unsupported 与历史 G1 扫描原件。

随后补充直接调用/配置超大整数反例，先复现 OverflowError，再将有限权重范围判断放到浮点有限性转换之前，稳定按配置错误拒绝。自复核又发现 package 的帮助已列新变体，CLI Literal 仍只允许旧三种；新增真实 Typer 命令路由反例先失败，修正后全部八种变体与实际 CLI complete 打包通过。相关五文件定向为 159 passed，230.29 秒；不是完整回归耗时。

最终回归前，一次辅助 JUnit 参数未正确引用含空格路径，导致零用例运行，退出失败；错路径 XML 已移入本批忽略证据目录，没有纳入源码。另一轮在发现 CLI 缺陷后于 252.24 秒主动结束本任务拥有的测试子进程，退出 15，不计通过。最终回归改用 covgate.run_pytest 的独立参数传递和 cov --check-only，不继承共享 PYTEST_ADDOPTS 报告路径。原日志分别保留，失败与中止不由后续成功覆盖。

lint、格式和 mypy 已复核；mypy 检查 217 个源文件。离线 baseline 通过：43 条快照断言、生产 5/legacy 69 个生成物、976 条引用及 2409 个定义的死代码审计。完整回归最终结果在实际结束后追加。

### 生成与交付

八种 ZIP 均由同一生成入口实际生成，逐件核对 ZIP CRC、清单完整文件集合、全部 SHA、UTF-8/LF 及交付边界 BOM，并独立重复生成完整包验证字节确定性。数据源与 current 未被实验变体改写。

完整实验包 `tools/out/releases/situated-ai-complete-experimental.zip`，64,940 bytes、17 个条目，SHA-256 `7e4a237819b7f151f5c5cf002b767f188720f42daf447b927ce909ce75e37042`。同目录另有 current/control/disabled 及 fiscal/security/market/reform 隔离 ZIP。完整包包含四模块与原生国家面板解释，仍为 experimental，engine_verified/quality_improvement_proven 均为 false。GUI 布局和真实上下文未验收，不能称为正常可玩或正式发布。

### 集中实机派发前检查

只读复核现存 25 份输出检查点、3 份用户自动存档及 1 份 Steam 云存档。28 份本地输入中 5 份满足仪器头部/来源条件，但全部被原账本累计停止规则拒绝；其余 23 份被版本、旧状态、无效规则或来源/日志门禁拒绝。Steam 云文件为带 SAV 前缀的 ZIP（gamestate/meta）；当前读取器不支持此格式，元数据有界读取也没有形成可核验的版本/观察者字段，不猜测转换或升级，不把它称为损坏存档。

具体停止输入为 a8be…、379d…、3ade…、preparation 3d1f…、seed b71a…；a8be 的第二次断言来自已导入 prior_failures，不能只数 runs。既有新局配方也被相同原规则拒绝。这里只调用原只读停止检查，没有预留实验、挂载、改变账本或启动游戏；没有游戏内推进、UI、行为或质量样本。

本批原件位于 `tools/out/evidence/complete-candidate-20261017/`：`dispatch-input-review.json`、`cloud-input-review.json`、`cloud-format-review.json`、`candidate-freeze.json`、`candidate-cost.json`、`cli-cost-serial/report.json`。它们是本地忽略证据，代码、参数和命令可从现有生成/验证入口复核。

## 最终完整工程验收

最终完整回归退出 0：3934 passed、20 skipped、1743 subtests passed，pytest 631.61 秒，含覆盖率检查的包装 634.06 秒。JUnit 收集 3954 项，无失败、无错误；总覆盖率 89.51%，整体 86% 与 11 个核心下限全部通过。运行前后全部 src/pdx 与 tests 的 Python SHA 相同，没有用运行中改源码追认通过。测试默认 -n auto --dist loadscope，自适应预算保持原配置。

20 项跳过包括 12 项 Windows 符号链接权限、1 项平台没有 FIFO、7 项本机引擎日志缺失；它们保持未验证，不算通过。并行中的 benchmark 不产生有效性能计时；新候选路径的有效成本见上述独立串行测量。

0.5 秒诊断采样的进程树 RSS 峰为 2759.98 MiB，只描述本次正确性回归；没有冻结同语义旧候选、相同 worker 和相同环境的对照，因此不计算套件提速或内存下降比例。完整原件为本批 regression-verified/full-cov.log、full-junit.xml、full-regression.json 与 final-cov.json。

最终编码检查、Ruff、格式检查（375 文件）、mypy（217 源文件）通过；受影响文档的本地链接/锚点已检查，并修复旧清单锚点与历史快照搬迁后的相对链接。先前唯一完整回归失败、零用例参数错误和主动中止均保留，不由这次成功覆盖。

同步最终状态后，规则、机械数字和 CLI 文档的 23 项定向测试通过（11.45 秒），335 条本地链接/锚点通过；离线 baseline 再次通过，包含 43 条快照断言、174 张表、生产 5/legacy 69 个产物、976 条引用和 2409 个定义的死代码审计。新增状态说明没有改变冻结源码、测试或游戏产物。
