## 三、这张表暴露的三件事（都是可执行的）

### 1. 8 份档案用了同一张通用牌，其中 4 份与原版的开局意图**方向相反**

9 份里 8 份声明 `ai_strategy_progressive_agenda`。而原版给 RUS / AUS / EGY 的开局政治牌是
`reactionary_agenda` / `conservative_agenda` / `conservative_agenda` —— 也就是说我们一把把
它们从**保守/反动**推到**进步**，且没写「为什么这个国家该转向」的目标函数依据。

**这是「9 份档案其实是同一份」的又一个证据**（前一个证据：`-35` / `+0.5` / `-0.3` 三个数
在 9 份里完全一致）。修法不是改数字，是**先把每个国家的目标函数写出来**，再让牌的选择
由目标函数推出来。

### 2. TUR / CHI 有量身定做的原版牌，我们没用

- `ai_strategy_tanzimat_reforms`：`pro_interest_groups = { ig_intelligentsia ig_industrialists ig_armed_forces }`、
  `change_law_chance = { value = 100 }`（原版注释逐字：*Tanzimat AI needs to enact a lot of laws in rapid succession*）、
  `possible = { has_journal_entry = je_sick_man_main }`（`03_political_strategies.txt:1113-1180`）；
- `ai_strategy_maintain_mandate_of_heaven`：`pro = { ig_landowners ig_armed_forces }`、`revolution_aversion = 100`（`:961-`）。

这不是"更原版"的审美问题 —— 它直接决定**变法频率**（`change_law_chance` 100 vs 10）
与**革命厌恶**（100 vs 50），是我们那份 `progressive_agenda` 表达不出来的量。

### 3. PER / SPA / BAV 的政治槽在原版里是空的 → 这三份要么新增牌，要么说明为什么不需要

它们连开局牌都没有，意味着「政治槽落进兜底」。对 `bv_alignment` 这份"选边"档案，
这一点尤其要紧：它的处境本来就该走**外交槽**（`01a`:309 已写「它的最优解不是内部改革，是选边」），
而我们现在给它声明了一张**政治**牌 —— **层次搞错了**。
