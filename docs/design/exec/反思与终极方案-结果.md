# 反思与终极方案结果

> 日期：2026-10-26。本文记录工程方法的纠偏和当前终极方案，不替代产品原则、实施计划或阶段收据。

## 对此前行为的反思

过去曾把计划阶段和文档状态误认为生产 Mod 已经实现，也曾在缺少游戏行为证据时过早收口。更具体地说，早期 U 阶段收口时，`mod/` 产物字节基本没有发生对应的行为源变化；静态合同、脚本加载成功、评分变化或根 hook 记录也曾被表述得接近 AI 行为通过。这混淆了工程交付、模拟证据和用户实机验收的边界，也让验证节奏被反复的低收益检查拖慢。

本次纠正有四点：

1. 唯一生产源是 `mod/decisions/*.toml`；PDX、本地化、metadata、manifest 和包只由 Python 生成器产生。
2. 每条规则必须连接已核实的原版 reader 和消费者；同一字段只允许一个完整调整，未知值显式回退原版。
3. 静态检查、锁定底本快照、合成模拟、运行日志/存档和用户行为验收分开记录，不用一种证据替代另一种。
4. 先完成生产源和可交付包，再集中运行受影响测试与冻结候选回归；游戏长期行为、平衡和体验由用户在固定包上验收。

## 当前终极方案

权威路线是 `docs/design/exec/mod重设计-实施计划.md` 的 U0–U13 队列。核心架构为：

```text
原版可观察信息
    → 有来源、单位和未知策略的事实层
    → 有边界的国家状态画像
    → 政治、财政、经济、外交、军事、科技、人口、地理评估
    → 目标冲突、预算、机会成本、路线惯性和冷却
    → 原版 AI 消费者中的有界倾向调整
    → 原版资格、成本、随机性、谈判、失败和执行
```

方案尽可能利用锁定底本中可合法读取的信息，但不假定不可见引擎状态，不创建原版没有的资格或资源，不接管前线微观战术，也不以全局 debuff 制造国家差异。国家的历史感来自处境、能力和约束；同一国家在条件变化后可以转向。

U13 把可证明的跨领域组合正式落到生产规则：产业建设同时检查和平、财政、行政和产业路线；战争军力同时检查战争、违约、净结余和行政能力；教育追赶同时检查识字率、人口、和平和承受力；贸易、经济外交和殖民投射分别检查外部机会与财政、行政、海军和路线条件。每个阶段都生成完整标准包，用户长期实机证据仍是行为门禁。

## 现状

当前候选为 `Situated AI 1.2.0`，底本为 Victoria 3 `1.14.5`。U0–U13 的工程源、生成、字段合法性、编码、包边界和文档入口已收口；`v1.2.0` 标签和远端合并状态以最终 Git 收据为准。静态工程完成不表示 AI 行为、平衡、后期性能、本地化体验或 Workshop 发布已经通过。
