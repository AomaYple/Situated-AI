## A 独立验证入口

从完整仓库以项目 Python 运行 `python -B -X utf8 -m tools.probes.company_weight_injection --archive <冻结ZIP路径>`。附加 `--installation <锁定安装根>` 可用本机安装复算同一公司成员。入口只输出 ZIP 摘要。验证器读取一份 ZIP 字节快照并核对冻结摘要，再核对解出的公司成员。可选编译先验证游戏、公司及 define 的有效源集、字节和写点，随后对自有空壳编译 26 个直属 `ai_weight`，完成后复核底本。验证入口以显式安装根设置一次性 Python 子进程的 V3_ROOT，编译模型和底本使用同一份安装。子进程只返回公司成员摘要。原版定义供应标识、定位和合同核验。其余公司字段留给游戏。 [冻结候选验证入口](../../../tools/probes/company_weight_injection.py) · [评分投影](../../../tools/probes/first_score_injection.py)

#122 已包含缺省值证据、受控适配器和编译模型。验证入口复用现有编译器，修改范围为探针、合成测试和本收据。正式源码、生成锁、生产载荷及其发布指纹沿用 #122。测试使用合成公司块对照有序编译结果，验证跟踪的 26 个标识只增加规定字段，并覆盖内置评分、竞争来源、漂移、ZIP 篡改和脚本解析失败。 [D08 离线用例](../../../tests/test_company_weight_injection_probe.py) · [模型入口](../../../src/pdx/situated/compiler.py) · [生成锁](../../../mod/generation-lock.json)

### 候选静态与运行证据

当前 ZIP 回读核对 16 个条目、成员指纹和隔离安装文件树。锁定安装重编译只覆盖公司成员。这组静态证据涵盖 D08 入口和包字节，完整架构工程与语义验收仍有其余生产范围。候选状态为本地冻结，发布尚未进行。 [工程交付基线](工程基线-1.0.md)

独立实机试验用同一法国观察档，从 1836.1.1 推进至 1836.2.1。起点存档 SHA-256 为 `9cded8a012578b4cf35bcb659c820d7b8b2c422809ee9278a9e9121eb48df34e`。试验将瑞典可成立的基础林业公司评分分别设为 0 和 10000，最终分别成立基础金属采矿公司与基础林业公司。这组见证覆盖单一标量评分接入及实际成立。26 公司候选已在正常模式进入法国新局，同版存读和候选评分因果对照待独立收据。长期表现、平衡、玩家路径和体验仍待证。 [阶段 3 独立实机取证](阶段3原版保留与接入取证-结果.md)
