## 假设（可证伪）

> **原版 AI 意图层的「可喂输入」与「可挂载字段」能从原版文件里自动枚举出来，
> 且其中属于我们能推动的那一类（A 级：IG / 法律 / JE / 变量 / 财政 / 态度…）比例足以支撑第一版设计。**

## 判据（动手前定，可复制执行）

1. `v3 ai-surface --write` 生成 `docs/design/02-可执行面.md`；**再次 `--check` 退出码 0**（生成可复现）。
2. 生成物含四张表：① **牌面总览**（34 张牌 × 槽位 × 权重基准 × 条件数 × 有无 `possible`）；
   ② **原版 AI 读到的输入**（按出现次数排序，标注 trigger / script value / scope）；
   ③ **粒度可行性表**（候选因子 → 命中的原版输入 → 示例 → 初判）；④ **defines 面**（`NAI` 键 + `AI_*` 计数）。
3. 每一条判为"进第一版"的因子都能指出**具体读法**（触发器名 / 脚本值名）与出现次数。
4. 人工部分（写入结果文档）：**失败模式清单 5–8 条**（症状 + 动哪个输入 + 判据）+ **H1 最小实验设计**。
5. 门禁：`ruff` / `mypy` / 新模块用例全绿；覆盖率不下调。

## 失败长相（什么现象说明假设错了）

| 现象 | 含义 | 处理 |
|---|---|---|
| 提取器只能拿到字段、拿不到"读了什么输入" | 权重块结构比预期复杂 | 改为按 scope 递归 + 记录未识别 token，不猜语义 |
| 候选因子里"读不到"占比过高（> 60%） | 可执行面太窄 | 触发 §3 阶段 1 的失败处理：**收窄 §0 承诺范围**，并记进 §7 |
| 原版权重块几乎不读国家状态（都是常量） | "喂输入"（B 级）这条路很窄 | 手段重心移到 A 级与 C 级，并如实写进 `01a` |

## 依赖与顺序

1. 先做**最小验证**：能否从 `03_political_strategies.txt` 的 `conservative_agenda` 里自动提取出
   `weight` 的条件与触发器名（预期能拿到 `has_journal_entry` / `is_princely_state` / `has_radical_leftist_government`）；
2. 验证通过 → 全量扫 5 个策略文件 + `defines/00_ai.txt` → 生成文档；
