# 生成 Mod 架构复核结果

2026-11-04；证据类别为 `static_check`。复核对象为当前生产源、实际生成的 PDX 与正式 3.2.0 标准包，
依据[当前架构主计划](../架构主计划.md)、[Mod 开发原则](../../principles/Mod开发原则.md)和
[工程交付基线](工程基线-1.0.md)，不使用退役的全国路线计划代替当前合同。

## 结论与身份

实际生成物符合当前的“精确观测 → 具体行动 → 同因分档取强、独立收益成本联合 → 消费者末端一次限幅
→ 原版比较与执行 → 后续真实观测”架构；本次检查未发现需要修改生产 Mod 的架构阻塞项。
这个结论限于下述静态合同，不能推广为全部原版行为都被接管、所有领域深度相同或游戏行为已达到最优。

固定包为 `dist/situated-ai-3.2.0.zip`，SHA-256
`9b3752732b72a099ddf1162b77814e30a7048aedb107584f55cb47ecd40a1fa9`。
包内99个文件，全部84份 `common/*.txt` 脚本重新解析通过；插入标记在各文件内配对且不重复。
新增脚本块未出现 `every_country` / `every_scope_country` 循环，旧 `sitai_*route*` 名称未出现；
自有 scripted effects 和 on_actions 只保留独立财政更新器。
这是有限静态检查，不证明引擎的总调用次数或运行时间。

## 逐层对照

| 架构要求 | 实际生产接线及复核依据 | 证明边界 |
|---|---|---|
| 信息与对象明确 | reader 保留来源、作用域、参数和单位；`compiler` 核对真实消费者的 ROOT、owner、候选法、目标国和目标州 | 未暴露的引擎状态保持未知，不把登记的信息当作可读取信息 |
| 最小行动单元可追溯 | 显式卡和规则行动经 `action_instances`、绑定表、`ConsumerIRBundle` 连接实际 writer 和物理字段；重复身份或作者拒绝生成 | 显式卡与规则行动仍是不同的生产表示，不声称全部规则都已变成同一种显式卡 |
| 独立需求可并存 | 国家协调采用按需观测；建设、教育、政治、安全消费者各自读取相关事实；行政地方征税需求与全国官僚需求分组 | 具体行动仍有必要资格和相关条件，不承诺无条件建设 |
| 同因去重、收益成本联合 | `programs._groups` 对同一因果和方向选最强已知档；独立组共同参与；显式卡由联合数值程序处理 | 同因的 `else_if` 是有意去重，不是全消费者第一匹配；数值方向不能自动证明经济收益含义 |
| 消费者末端一次限幅 | 实际 PDX 为各组求和后在物理消费者边界限幅；混合单位、非法混合 add/multiply 或重复 writer 硬失败 | 原版自己的数值处理继续保留；不能把各字段偏移相加为国家全局最优分数 |
| 跨域反馈用真实观测 | 已生效公校法、实际学校制度、识字、当前生产方式、同州投入/运输、真实经营状态和战争状态参与后续消费者 | 评分不算行动完成；不推断某项政策造成某项世界变化，也不声称有通用因果学习 |
| 有限状态与惯性 | 全国排他路线 effects/on_actions 不生成；财政迟滞、62日TTL及原版战败观测继续存在 | 没有全领域持久规划器或每类行动的统一冷却机制 |
| 原版消费者保留执行权 | Mod 只接入有限有界倾向；科技前置、转法支持、条约资格、实际成本、随机和终结零分由原版继续决定 | 默认与活跃策略同名字段的引擎合并/覆盖仍未建立实机结论 |
| 关闭、玩家与未知回退 | AI守卫、领域关闭、核心未知退出与辅助未知低档由参考器和实际PDX见证核对 | 局部未知的低档不等于假定财政健康；不能据静态守卫断言长期玩家体验 |
| 生成包与安装一致 | 正式生成锁、标准ZIP验证及本地发布入口核对固定字节，游戏目录99文件相同 | 本轮工具和源码冻结清单更新没有改变已发布Mod脚本、数值或包哈希 |

核对的生产入口包括 `src/pdx/situated/compiler.py`、`decision_ir.py`、`programs.py`、
`action_instances.py`、`joint_chain_contract.py`，以及 `mod/decisions/` 的行动、绑定、观测和关系源。
实际脚本抽查包括行政建筑、社会/生产科技与防御条约；整包解析和原版保护审计另覆盖完整文件集合。

## 一个实际贯通例子

`mod/common/buildings/07_government.txt` 的 `building_government_administration.ai_value`：

1. 原版评估某个候选州中的行政建筑，Mod 在该消费者时机读取同一州的征税容量和使用量、owner官僚与融资状态，
   以及本类建筑真实启用PM的投入压力。
2. 同州征税不足独立贡献 `+0.10`；全国官僚缺口的修复贡献按已证实财政状态取 `+0.25 / +0.10 / +0.05` 档，
   不重复累加这些档。
3. 已知借款或违约的融资压力独立贡献 `-0.25`；真实活跃配方的纸、电话短缺另计相应投入成本。
4. 所有适用贡献合并，再将倍率限于 `0.50–1.35`，交还原版建设比较和执行。

隔离其他贡献时，同州征税不足即可得到 `1.10`，无需全国官僚不足、低价纸或财政全部健康。
再加入正常借款，净倍率为 `1 + .10 - .25 = .85`：需求依然参与，真实成本降低了净倾向。
健康财政下同时存在官僚缺口与征税不足，倍率为 `1 + .25 + .10 = 1.35`；纸投入压力再减 `.20` 时为 `1.15`。
这些是实际脚本的静态数值语义，不保证原版下一步一定建设该建筑。

## 广度、深度与不能夸大的地方

当前源中有11张显式行动卡、19个行动家族、5731条规则绑定；规则绑定包含同一原因的分档和对象变体，
不能据此宣称有5731种独立行动。`decision-audit` 的2123个reader也包含不同消费者对相同游戏属性的读取，
不是2123种互不相同的原版属性。审计的927个字段、74个适配物理源与全消费者见证的物理消费者分母也不混用。

本轮重新读取原版并重建生产输出的独立盘点共有8856项声明，其中878项映射为实际数值写入；
其余并未因此算作新增AI能力。`native_coverage` 仍列出4585项 `unimplemented_legal`、542项 `pending`、
30项 `unknown` 和2821项 `observation`，`business_complete=false`。
这份全原版能力目录比已交付X1的有界目标更宽，不能用“来源保护已闭合”把它们改签为已实现。
来源保护审计中4384项明确保留原版、878项有数值实现，3594项保留接口/业务复核责任；
活跃未知用法为0，未闭合的来源保护责任为0，解析失败为0。
这些分别回答“有没有越权改写”和“有没有实现所有可能功能”，不能混为同一个完成结论。

显式 `relations.toml` 当前只有两条教育与产业的真实互补边；其他领域联动还通过具体消费者和严格链路绑定实现。
这既不代表全Mod只有两条联动，也不支持声称任意领域之间都有通用多跳因果模型。
当前架构是受原版约束的按需、有限、可解释倾向系统，具备继续扩展具体事实和消费者的基础，
不包含全知规划、自学习、直接资源分配或绕过原版资格的执行器。
