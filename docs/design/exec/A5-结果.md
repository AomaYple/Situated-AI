## 打包成本与提速边界

Windows 11 / Python 3.14.7，固定主线 `b596e12` 的旧打包实现作成本参考，7 轮 AB/BA 交错，每轮各打 9 包，三个变体轮换；计时、tracemalloc 与独立进程 RSS 采样分开口径。事前预算为新增单包耗时不超过 50 ms、Python 峰值 10,000,000 B、采样 RSS 200 MiB。基准与测试/其他检查错峰，没有同语义旧说明实现，不计算提速比。
